## 一、四条交付明细

### 1.1 A8 · 空态「🕐 最近调出 · 近 7 天」

改前空态只有「快捷操作 + 🔥 近期最常用（callCount 降序）」。本轮改为两段：

- **🕐 最近调出 · 近 7 天**：`lastCalledAt >= now - 7d`，按 lastCalledAt 降序，≤8 条——「用过多久」和「用得多频」是两个问题，上周刚翻过的资料不该被三个月没用 20 次的工具压下去；
- **🔥 近期最常用 · 按调用次数**：既有口径，按 id 去重排除前段（同卡不在空态出现两次），≤8 条。

★ **顺带修一个真 bug（勘验发现）**：热词行此前一律标 `type:'res'`/📄——Enter/点击对任务/好奇/策展台行会误按资源逻辑分发：策展台行定位 `/workspace/undefined`，任务/好奇行不写 `bumpHeat` 计数。现按 `pushHeat` 时的真实 type 分发（行仍带 data-id，`bindResultEvents` 按 id 解析不受影响）。

### 1.2 A9 · 前缀直筛 `#标签` / `@项目`

- `parseOverlayQuery(q)` → `{ tags[], proj, kw }`：`#x` 计入 tags、`@x` 计入 proj、其余为 kw；
- **tags 取交集**（全部命中才算——「直筛是收窄不是扩大」，与主应用 R89 `matchCard` 逐字同口径）；**`@x` 收窄**到任务（项目名命中）+ 项目实体（名称命中）；资源/好奇/策展台两不沾，指令在场时排除；
- **单个 `#`/`@`（后缀为空）回落普通词**——避免边输入边筛打空结果（R89 同款惯例）；
- 高亮（`hl`）与 ws 树过滤改吃去指令后的 `hlKw`——`#`/`@` 是指令，不该在标题里找 "#x"；
- **选型偏离登记**：提案为「前缀过滤 **或** 按项目分组」二选一，取前缀分支（与主应用同构，避免两套语义）；content script 纯 Vanilla 就地实现（v2/README 已知地雷：不引主应用模块）。

### 1.3 D4 · 资源采集边界说明（走提案的「或明确边界并说明」分支）

勘验确认 **ResourceCard 模型无 `projectId`**——资源由台面/分类组织，任务才是持挂载方（单向挂载红线）。给资源采集加「关联项目」需要改数据模型 + 迁移 + 红线评估，超出本条提案预期 ⇒ 按提案预留的第二分支落地：采集表单 台面/分类 行下加一行边界说明（`.zy-cap-boundary`，走 `--zy-text-3` 令牌）：

> 资源卡不挂项目——需要与行动同行时，先入台，再到任务详情里「挂载到任务」

**把边界写在用户会看到的地方，而不是让他猜。** 若产品负责人要求真挂项目，须先立项改模型（04-46 任务书 §一 已注明）。

### 1.4 D5 · document 级 Esc 收口（R92 登记遗留）

改前全浮层只有两处 Esc：搜索输入框（R92 D2 两段式，挂输入框元素上）+ 已保存回执（`onSavedKeydown`）。⇒ 焦点一离开输入框（点过结果区/表单背景）Esc 即失效；**corner 表单（资源/好奇/任务采集）从来没有 Esc**。

本轮统一收口：`onDocEsc`（document capture）由 `openOverlay` 注册 / `closeOverlay` 移除，四类场景各归各位：

| 场景 | 行为 |
|---|---|
| 已保存回执态 | 让位 `onSavedKeydown`（它自带「Enter 打开 / Esc 关闭」语义） |
| 搜索面板，焦点在输入框 | 让位输入框自己的两段式（target 阶段），避免双重处理 |
| 搜索面板，焦点不在输入框 | **镜像两段式**：有内容先清空，空再关闭（与框内 Esc 语义一致） |
| corner/center 表单浮层 | 直接关闭（此前无 Esc） |
