## 一、一句话

策展台从“卡片陈列 + 分类整理”收口为一张围绕中心论点展开的成果画布：论点卡是唯一 L1 入口，论证结构直接在金字塔 / 树状画布上编辑，节点可挂资源卡，最终生成可离线打开、可分享的自包含 HTML。

## 二、五项产品决策与落地

| 决策 | 落地 | 判据 |
|---|---|---|
| 顶部中心论点是一张论点卡，点击打开右侧详情 | `thesis-banner` 整卡可点、可键盘触发；空态进入创建；`CurationThesisDrawer` 展示标题、内容、创建时间与最近更新 | 论点横幅、抽屉和画布根节点读取同一张 `ResourceCard` |
| 论证深度、来源覆盖不再展示 | 指标条只留“论据卡片总数 / 佐证附件数量”，两格均可下钻 | 旧字段与对应计算在策展台现役正文零命中 |
| 金字塔 / 树状直接切换 | 两种版式共享同一份 `Category.parentId` 树，只切换布局，不复制数据 | 切换函数只改 layout，不创建第二棵树 |
| 删除左侧论证结构目录 | 左侧目录、旧四视图、卡片网格与策展批量栏退役；画布是唯一工作区 | 旧目录与批量栏在现役模板零命中 |
| 画布采用思维导图式编辑 | 选中节点 `Tab` 建子级、`Enter` 建同级；新建即进入标题编辑；就地改标题与说明；拖拽子树改父级；防自身、后代循环与四级上限 | 回归分片 `101-curation-mindmap.cjs` 覆盖键位、持久化、拖拽与反馈 |

## 三、实现范围

### 3.1 画布与数据

- 论点卡继续使用现有卡片模型，不新增第二套论点实体。
- 金字塔与树状都从同一份分类树派生，节点标题与说明分别写回分类名称与描述。
- 新建同级节点插入当前节点之后；新建子级成为当前节点最后一个子节点。
- 拖拽只接受合法父级；根节点只允许升为一级；超过四级上限时明确拒绝并提示原因。
- 布局切换后画布回到左上起点，避免用户在新版式里“丢失当前位置”。

### 3.2 节点与资源

- 节点支持关联资源卡，关联入口沿用既有资源选择能力。
- 无资源的叶节点显示证据缺口，并提供补证据入口。
- 全台检索同时覆盖论证节点与节点下资源卡。
- 资源 chip 可从画布打开右键菜单，继续进入详情或相关动作。

### 3.3 分享

- 分享入口先预览、后下载。
- 支持“阅读长文 / 论证树”两种版式。
- 支持链接、附件、来源、日期四个内容开关。
- 支持纸白 / 墨黑双主题。
- 产物为自包含、无脚本、无外链资源的 HTML；文本转义，仅输出 `http(s)` 链接，不泄露内部 ID 或本地路径。
