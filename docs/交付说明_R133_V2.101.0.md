## 一、四项交付明细

### E1 · 语义色三档阶梯令牌（四主题齐挂）

tokens.css 为 success/warning/danger 各补 `--{sem}-bg-soft`（软底）+ `--{sem}-border`（环/描边）两档，四主题（linear/raycast/apple/notion）按各自主色换算齐挂（文本直接用既有 `--success/--warning/--danger` 主令牌）。

**消费点收敛（tokens.css 之外硬编码清零）**：
- `ResourceDetailDrawer` 危险钮 hover `rgba(229,72,77,.1)` → `var(--danger-bg-soft)`；
- `ImportTemplateModal` 提示条 `rgba(217,160,60,.1/.4)` → `var(--warning-bg-soft)/--warning-border`；
- `ResourceEditForm` 引用告警底 → `var(--danger-bg-soft)`；
- `RecycleBin` 危险钮 `#e5484d`×3 + color-mix → `var(--danger)/--danger-border`（**顺带修正**：浅色主题下此前一直渲染暗色 danger）；
- `workspace.css` dup 校验环/错误文本 `#e5484d`×3 → `var(--danger)/--danger-bg-soft`。

### E2 · 圆角体系补全 + ★完备性守卫（抓到同族 BUG 新例）

1. **★又抓一例 R130-T5 同族**：`--radius-lg` 被 `CompassTree .tree-level-card` 引用但**从未定义** → 方向树层级卡一直渲染成直角。tokens.css 补 `--radius-lg: 14px`（弹层/大卡片档）。
2. **全站悬空令牌清账**（引用扫描 vs 定义比对，共 7 族）：`ImportTemplateModal` 重灾区 `var(--text2)/var(--text3)/var(--rads)/var(--warn)` 四族悬空 + `RecycleBin var(--text4)` + `CompassTree var(--warning-light)` + `TaskManagerPanel/workspace.css var(--text-1)`——全部重指现役令牌（`--warning-light` 落新生成的 `--warning-bg-soft`）。
3. **守卫断言（R133-2）**：全站被引用的 `var(--radius*)` 必须在 tokens.css 有定义，**金丝雀实证**：临时注入 `var(--radius-xl)` 引用后断言即红、移除复绿——此类静默失效从此出不了门禁。

### E3 · 选区色 + 禁用透明度档

1. 全局 `::selection { background: color-mix(in srgb, var(--accent) 18%, transparent); color: var(--text) }`——四主题选中文本不再跟浏览器默认实色蓝打架；
2. `--opacity-disabled: 0.5` 定义（口径修正：不采 appica 的 .65——现网 :disabled 众数即 .5，取众数避免整体对比度漂移），全站 10 处 `:disabled { opacity: .4/.45/.5 }` 离散字面量收敛至令牌（三处 .45/.4 统一为主档，属预期内的微小对齐）。

### E4 · 运动令牌 + 卡片入场递进

1. tokens.css 定义 `--dur-fast: 120ms / --dur: 150ms / --dur-slow: 250ms` + 统一减速曲线 `--ease-out-soft: cubic-bezier(.2,.8,.2,1)`；
2. **全站 219 处** `.12s/.15s/.25s` 字面量一次性收敛（`.15s` 为众数 → `--dur` 主档 150ms，视觉零漂移）；扫描证实全部落在 transition/animation 声明行、无越界；`src/content` 浮层为 .ts 注入样式、自带 `--zy-*` 体系且不受 newtab 令牌作用域覆盖，**天然豁免**（R77-3 锁色值不漂移机制不动）；
3. 卡片入场递进：`.card-grid > .res-card` fadeIn `var(--dur-slow) var(--ease-out-soft)`、逐行 +20ms 错峰、第 8 行封顶（其后统一 140ms）。**fill=backwards**（而非 both）——防动画终帧钉死 `.res-card:hover` 上浮；`.res-card.flash` 规则在后，闪烁定位语义优先。
4. 存量 `.2s cubic-bezier(.16,1,.3,1)` 抽屉弹簧与 1.2s/2.2s 闪烁动画为**有意设计的异构曲线**，不并档、保留字面量（R133-8 扫描口径即 `.12/.15/.25s` 三档）。

**断言连带改写**：R68-3/R68-6（锚点 `.15s` → `var(--dur)`，语义不变）。
