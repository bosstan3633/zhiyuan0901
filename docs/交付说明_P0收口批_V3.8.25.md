## 一、为什么开这一批

上一批（P0 批一 G1·C6·A4）做的是「全站 emoji → 线性图标」。方向是对的，但**执行过度**：批量剥离 emoji 时，把"图标名从哪来"这一层也一起删了，于是留下 8 处**两支同值的空三元**和一批空串。

它们有一个共同点，也是本轮最值得记的一句话：

> **类型对、构建过、门禁绿、界面静默少一块。**

`vue-tsc` 不管（`''` 是合法 `string`），`build` 不管，回归不管（旧判据钉的是 emoji 字面量，emoji 没了正好"通过"），死 CSS 不管（类名还在，只是没内容）。**只有人眼看界面才会发现**——而这一批的错误全都藏在"图标位"里，缺一个图标比缺一个按钮难发现得多。

## 五、一次判据自己的误报（比 bug 更该记）

P0-S4 首次运行时点名 **13 处 `main-focus` "键不存在"**，我据此一度往 README / changelog / 透视卡写了"主攻标记一直渲染成指南针"的结论。

**这个结论是错的。** `main-focus` 从 G1 批一起就在 `Icon.vue` 第 47 行（十字靶心），只是键名带连字符、写作 `'main-focus':`（引号键），而判据最初的正则只认裸标识符键 `^  ([a-z][a-z0-9]*): `。

> **错在尺子，不在数据。**

修法是正则补上引号键，**不是**往图标表塞一个重复键（塞了会触发 `TS1117` 重复属性，typecheck 当场红——这也算门禁替我们挡了一次"改数据迁就判据"）。

**纪律**：新增"现扫型"判据，必须先用它跑一遍**已知正确的样本**确认不误报，再上棘轮。否则它一红，你会去改数据，而该改的是它。

三处错误叙述已全部撤回，并写进判据正文。

## 八、B1-a 追加批（`GlobalSettings.vue` 内联样式收口，同日落地）

### 8.1 干了什么

`GlobalSettings.vue` 的 **43 处静态内联样式归零**（模板内联 `style="…"` = 0），换成 **32 条命名规则 + 6 条 `:deep()` 规则**，每条都带"为什么是这个类"的注释。文件 2,722 → 2,810 行（+88，几乎全是注释）。

**边界（写进判据 P0-S7 正文，免得下轮再争）**：只算静态 `style="…"`；`:style` 动态绑定按你 Q2 的拍板**保留**（本页还剩 4 处：树深度缩进 ×3、确认按钮禁用态透明度 ×1）。

### 8.2 顺手挖到 6 个真缺陷（4 个是"看着有、其实没有"）

| # | 缺陷 | 为什么没人发现 | 修法 |
|---|---|---|---|
| 1 | **`v-html` 注入的节点拿不到 scoped 的 scope id** ⇒ 字段管理预览卡那 8 条 `.gs-pv-*` 规则**一条都没生效**，标签一直是一串纯文字而不是胶囊 | 判死扫描器只看"类名在模板里出现过没有"，看不见"出现了但选择器匹配不上" | 宿主 `.gs-preview-card` 加 `:deep()` |
| 2 | **`<option>` 的内容模型是纯文本**，子元素一律被浏览器丢弃 ⇒ G1 把 `🗂 资源卡` 换成 `<Icon>` 后，5 个选项里 6 枚图标**从来没显示过**，比原来的 emoji 还少一个标识 | 构建过、门禁绿、DOM 里确实有那个 SVG 节点 | 移除，只留文字；R127-3 加重指 + 负锚 |
| 3 | **`Icon` 用 `width/height` 定尺寸，外层 `font-size` 对它无效** ⇒ 手册页空态写着 `font-size:34px`、里面却是 `:size="13"`，那颗"大图标"一直比正文还小 | 同上 | `:size="34"`（**本批唯一故意改变像素的一处**，属修复） |
| 4 | **`var(--ok, var(--info-green, #3A6B4C))` 两个令牌都不存在**（真名 `--success`）⇒ 连接成功态在四主题里一律吃硬编码深绿，深色主题下对比度不足 | 有兜底值，所以"能显示"；只是不跟主题 | 改 `--success`，收成 `.gs-sr-ok` |
| 5 | **同步日志的状态三元两支返回同一个空格**（`? ' ' : ' '`）⇒ 成功与失败两种日志视觉完全一样 | 文案不同，所以"读得出来" | 改 Icon check/warn + 正常行小圆点 |
| 6 | **`PoolCardsPanel.groupOf()` 的 `startsWith('http') ? 'url' : 'url'`** | 同 5 | 直接 `return 'url'`（它属 B1-c 待收口文件，被扩面后的判据顺手扫出） |

### 8.3 判据侧改动

- **P0-S3 扩面**：原判据只认 `? '' : ''`。现改为「**两支是同一条字符串字面量即红**」（正则反向引用），一次覆盖三种写法：空串版、空格版、任意同字面量版。扩面时**当场又扫出第 6 个 bug**（`? 'url' : 'url'`），不是预防性推测。
- **新增 P0-S7 内联样式棘轮**：`Workspace.vue` / `GlobalSettings.vue` 模板静态 `style="…"` 必须为 0。三条边界写死在判据正文（只算静态、只算模板段、先剥注释）。
- **R127-3 重指**：锚点从 `<option value="resource"><Icon name="package" …/> 资源卡</option>` 改为 `<option value="resource">资源卡</option>`，并加负锚 `!/<option[^>]*>\s*<Icon\b/` 钉住不许塞回去。
- 回归 **1,784 → 1,785 通过 / 0 失败**。

### 8.4 一次工具自己的坑（值得记）

给 `dead-css-scan.cjs` 喂了一句含 `<style scoped>` 字面量的注释，它用 `/<style([^>]*)>([\s\S]*?)<\/style>/g` 非贪婪抽样式块 —— 于是把那句注释当成真样式块起点，**整段 TS 被当 CSS 解析**：规则数 3,721 → 4,051，报出 16 条假的"祖先断"、1 条假的"判死"。改成不含字面量的表述后恢复 3,753 / 0 / 0。

**纪律**：脚本区注释里不写 style 标签的字面量；判据红的时候，先分清是代码错了还是尺子读错了 —— 这是本批第二次遇到"错在尺子"（第一次是 P0-S4 的引号键）。
