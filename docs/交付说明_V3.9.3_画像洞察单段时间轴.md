# 交付说明 · V3.9.3 画像洞察单段时间轴

**日期**：2026-10-20
**版本**：V3.9.3
**性质**：在既有画像洞察信息架构内重排首屏与时间轴，不改数据模型与写入链路。
**高保真原型**：`/Users/beantan/.codex/visualizations/2026/10/20/01a15761-2fa1-7c42-b23a-369bd1184014/profile-insights-prototype.html`

---

## 一、一句话

画像洞察从“四段纵向长页”收成“先方向、再今天”的工作台：首屏先回答本周精力放在哪里、今天从哪三件事开始；今天 / 本周 / 本月 / 本年改为单段切换，默认本年，全年热力图直接展开，点任意日期格就能看当日战报。

---

## 二、本轮三项产品决策

| 决策 | 落地 | 结果 |
|---|---|---|
| 首屏先方向、再今天 | `PiOverview` 左右双栏：左“这周精力”、右“今天三件事” | 用户进入页面先获得判断与行动，不必先读一排数字 |
| 时间轴收成单段切换 | `PiRangeTabs` + `activeRange` 四选一挂载，默认 `year` | 页面不再被四段纵向拉长，同一时刻只有一个阅读尺度 |
| 年度热力图直连战报 | `PiYear` 向 `Heatmap` 传 `default-expanded`；点格先保留 `selDay`，再发出 `open-battle` | 默认看见全年节奏，点任意日期直接打开当日战报 |

---

## 三、改了什么

### 3.1 首屏与页头

| 区域 | 改动前 | 改动后 |
|---|---|---|
| Hero | 页头 + 四格 KPI + 使命与主攻，承担多重职责 | 只保留页头动作与“使命主线 + 主攻项目”方向坐标带 |
| 四格核心读数 | Hero 与概览重复出现 | 唯一归位 `PiOverview`，仍保留下钻、口径 tooltip 与中性进度条 |
| 首屏信息顺序 | 指标先占视野，行动在下方 | 左栏方向判断、右栏今天三件事，先看处境再做选择 |

### 3.2 时间轴

| 区域 | 改动前 | 改动后 |
|---|---|---|
| 时间尺度 | 今天 / 本周 / 本月 / 本年四段同时挂载 | 四选一单段挂载，默认本年 |
| 导航 | 页签与左轨各自表达状态 | 页签与左轨共用 `activeRange`，切换只换当前模块 |
| 动效 | 长页连续阅读 | 单段入场动画；`prefers-reduced-motion` 下关闭 |
| 键盘 | 页签仅可点击 | 完整 `tablist` 语义；方向键循环，Home / End 直达首尾 |

### 3.3 年度热力图与战报

- `Heatmap` 新增 `defaultExpanded?: boolean`。画像洞察默认全年展开；调度台等其它宿主仍默认近 26 周概览。
- 年度热力格点击后先写回选中日期，保留选中描边，再打开该日战报，不再出现“弹窗打开但格子没选中”的断层。
- 窄屏下概览双栏降为单列，四格读数降为两列，时间轴页签横向铺满；左轨在 900px 以下隐藏，页签仍可完成切换。

### 3.4 可读性修正

页签英文副标原先使用 `--text-4`，在 notion 主题下约 2:1，接近不可读。`theme-contrast` 的 W12-G 判据当场报红；本轮提升到 `--text-2`，保留弱化层级但不牺牲可读性。
