## 一、交付结论

V4.2.3 修正采集入口认知，完成资源卡 URL 唯一与存量安全合并，重整资源池控制行，修复策展图片全屏，统一导出 HTML 的附件交互，并把今日复制模板补齐 `MOC-` 项目前缀。

## 二、功能变更

### 1. 采集入口

- 桌面快捷键直接采集到任务卡池、好奇心卡池或资源卡池。
- 手机 PWA 采集进入 Inbox；Inbox 保留三卡转化，定位改为“移动采集与待处理收件箱”。
- 产品手册与应用内说明不再使用“Inbox 是唯一采集入口”。

### 2. 资源 URL 唯一

- 新增统一 URL 工具，规范域名大小写、锚点、追踪参数和尾斜杠。
- 浮层保存前读取最新数据复核；应用内新建 / 编辑、Inbox 转化和书签导入共用同一 URL 身份。
- 重复 URL 不提供强制新建旁路，改为复用或定位已有资源卡。

### 3. 存量安全合并

按 `capture id → 规范 URL → 60 秒标题双写特征` 顺序修复存量重复：

- 纯标题相同不全局去重。
- 无 URL 兜底必须同时满足标题完全一致、创建时间相差不超过 60 秒、一侧缺 URL，且候选取向唯一。
- 重复卡软删进回收站；常用夹、任务支持、好奇心支持、策展投射与旧愿景 / 使命引用自动迁到保留卡。

### 4. 资源控制行

- 资源状态筛选改为下拉，默认“全部”。
- 下拉保留全部 / 待打标 / 已调出 / 从未调出的计数。
- 常用夹入口固定在控制行最右侧，并使用强调色与数量徽标。

### 5. 策展图片全屏

- 全屏使用独立 Teleport 沉浸层并请求原生全屏，失败时自动保留固定覆盖层。
- 全屏中支持上一张 / 下一张、缩放、重置、拖动和下载。
- 全屏层优先处理 Esc，退出全屏不会顺带关闭原预览。

### 6. 导出 HTML 附件

- 删除底部附件清单。
- 图片附件进入图库，支持切换、缩放、全屏和下载。
- HTML / PDF 等非图片附件统一“下载并打开”。
- 附件本体缺失时显示“本体缺失，无法下载”，不生成失效链接。
- 中心论点关联卡、中心论点附件和节点资源卡附件使用同一规则。

### 7. 今日复制

固定模板：

```text
推进[[MOC-项目名]]项目，任务内容，助力【指标名】指标落实到位
```

- 项目名已有 `MOC-` 时不重复。
- 缺少有效项目、成功指标或任务时禁用并说明原因。
