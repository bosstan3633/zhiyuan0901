# V4.3.2 需求盘点与开发任务

> 日期：2026-11-14
>
> 基线：V4.3.1（`4163fe2`）

## 一、需求盘点

### A. 调度台月历

1. 左侧待排期任务与右侧月历上下等高；任务较多时只在左侧内部滚动。
2. 左侧只显示“未完成且尚未安排计划执行日期”的任务。
3. 任务拖入月历日期后，视为已排期，立即从左侧待排期列表移除。
4. 取消某项任务的排期后，只清空计划执行日期，任务重新回到左侧，不删除任务。
5. 月历支持切换上月、下月、指定年份和月份，并可一键回到今天。
6. 月历任务按状态与日期着色：
   - 已完成：绿色；
   - 今天执行：橙色；
   - 未来执行：灰色；
   - 已逾期未完成：红色。
7. 点击月历右上角“今天”后，日详情弹层必须位于正确层级，不能被子容器裁切或遮挡。

### B. 卡片池入口与资源常用夹

1. 调度台卡片池的“任务 / 好奇心 / 资源”页签显示今日新增数量角标。
2. 角标为 0 时不渲染；超过 99 显示 `99+`；使用低强调色，不使用红色压力色。
3. 卡片池提供明确的二级页面入口。
4. 从调度台进入二级卡片池后，默认使用列表视图，并按最近入池时间倒序。
5. 资源页签改为常用文件夹模块，而不是直接平铺资源卡。
6. 常用文件夹第一位固定为“今日采集”：
   - 自动收录当天新增的资源卡；
   - 跨自然日自动切换到新一天；
   - 只做虚拟筛选，不复制、不移动资源真身；
   - 点击后进入资源池，并叠加当天新增过滤。

## 二、交互约束

- 月历不是删除面。删除任务仍只在卡片池二级界面执行。
- 排期只写既有 `dueDate`，继续复用“计划执行日期”，不新增第二日期字段。
- 今日采集不改变资源卡归属、标签、常用夹成员或云端数据结构。
- 页面角标统计使用本地自然日边界，不依赖云端同步完成。
- 今日三件事继续以任务卡状态为今天唯一真源；月历状态与任务卡同源。
- 移动采集 PWA 与 PC Inbox 保持退役，本轮不恢复入口、请求或后台任务。

## 四、验收标准

1. 左侧任务池与月历同高；左栏内容超出时滚动，页面本身不被撑高。
2. 已排期任务不再出现在左侧；取消排期后立即回到左侧。
3. 月历可切换年份、月份并回到今天，日期详情始终浮在正确层级。
4. 四类任务颜色在四主题下均可区分，文字与背景满足对比度门禁。
5. 三个页签的角标只在今日有新增时出现，且不抢主标题与页签焦点。
6. 从调度台进入二级卡片池默认列表视图，最近入池的资源卡排在最前。
7. “今日采集”位于资源常用夹第一位，点击后只展示当天新增资源卡。
8. 移动采集、PC Inbox 与旧 `capture_inbox` 请求均不回流。
