## 三、必须拍板的 6 项（冲突与开放问题）

### ① 方向台项目目录侧栏——去还是留？【最高优先】

- **原型要求**：删除侧栏，改为「主航线目标卡内的项目小卡 `@click` → 联动下方项目详情展板」。
- **冲突**：R117（V2.85.0，昨天刚交付）正是把「📦 全部项目」目录栏迁进 `ProjectCuration` 左栏，承载**置顶分组 / 组内拖拽排序 / 跨区拖拽自动切换 pinned / ＋新建项目** 四项能力；您当时的原话是「**项目详情目录还是需要**」。
- **按 R117 立下的规矩**「结构退役必须带走能力」：若删侧栏，这四项能力必须有承接方。
- **可选方案**：
  - **A** 保留侧栏（原型此项不执行）——零风险，但与原型「消除双工作台割裂」意图相左
  - **B** 删侧栏 + 能力迁到主航线项目行卡（拖拽排序/置顶）+ 头部「＋ 新建项目」——形态最贴原型，改动最大
  - **C** 删侧栏 + 保留 `ProjectCuration` 独立路由 `/compass/projects`（非内嵌态仍带左栏）——折中

### ② `isHub` 是否渲染论点横幅？
工作假设：**hub 态一律不渲染 `.thesis-banner`**（资源台没有「中心论点」概念，原型明确「绝对不渲染」）。若 hub 态当前确实渲染了空引导，即为缺陷修复。**请确认**。

### ③ 调度台首屏布局：左右分栏 → 上下堆叠？
原型是三件事全宽居上、项目调度整块在下。这会改变 `#dispatch-split` 的既有结构与其回归断言。**是否改？**

### ④ 资源台卡片压缩幅度（120px → 86~92px）如何取舍？
现状卡片承载：标题（2 行 clamp）+ 摘要（2 行 clamp）+ 标签 + 链接 + 分类 + 附件徽标 + 热度。压到 86px 必然要**砍字段或改悬停显形**。
- **A** 严格按原型：摘要 1 行截断、标签收进 hover
- **B** 折中：压到 ~100px，保留摘要 1 行
- **C** 仅收 padding/标题字号，高度不变

### ⑤ 主题自适应的目标口径
原型色板是「浅底 `#F8F9FA` + 薰衣草蓝 `#5E6AD2`」——与现有 4 套主题（深空薰衣草 `#5E6AD2` 深色 / 极简白 `#0071E3` / 光速黑 `#FF6363` / 纸墨白 `#2383E2`）**都不完全吻合**。
- **A（推荐）** 不新增主题，只做**硬编码治理 + 4 主题 × 4 台面走查**，保证重构后四套主题都不塌（无白底白字/刺眼反差）
- **B** 额外新增一套「浅色 + 薰衣草蓝」主题
- **C** 调整现有浅色主题的 accent 值向原型靠拢

### ⑥ 节奏：一轮做到底 还是 分两批？
本轮为纯 UI 改造，但涉及 **5 个文件 + 3 个脚本断言面**。R117 的「一轮做到底」是用户明确拍板；本轮**建议仍一轮做到底**（四台面 + 主题治理一次收敛，避免中间态主题不匹配）。
