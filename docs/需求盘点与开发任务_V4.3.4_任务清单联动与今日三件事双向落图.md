# V4.3.4 需求盘点与开发任务

> 版本：V4.3.4
> 日期：2026-11-16
> 基线：V4.3.3
> 范围：调度台任务清单、今日三件事、任务日历、卡片池今日角标与今日复制文案

## 一、需求清单

### 1. 左侧任务清单遵守筛选并区分落图状态

- 左侧任务清单必须使用顶部搜索、项目、状态与快捷筛选后的同一份任务集合。
- 未落图任务统一排在前面。
- 已落图任务统一排在后面，并按计划执行日期升序排列。
- 每条任务显示“未落图”或“落图 月/日”，让用户直接看出是否已经进入日历。
- 拖入日期、修改日期、取消排期都只更新任务卡本体的 `dueDate`，不生成第二份排期数据。

### 2. 今日三件事与今日日历双向联动

- 任务拖到今日日历、通过日期菜单安排到今日、或从任务详情安排到今日时：
  - 保留今日日历排期。
  - 今日三件事未满时自动加入三件事。
  - 今日三件事已满时不覆盖已有槽位，只保留日历排期并给出明确提示。
- 任务进入今日三件事时，自动把计划执行日期写为今天。
- 自动推荐、AI 复核、手选、复制历史三件事到今天等入口使用同一口径。
- 任务完成状态继续以任务卡为唯一真源。

### 3. 周视图任务卡按空间自适应

- 月视图继续使用紧凑单行任务条。
- 周视图使用更高的任务卡，展示：
  - 最多两行任务标题。
  - 项目名称。
  - 成功指标。
  - 当前任务状态。
- 周视图单日直接展示更多任务；超出部分保留“更多”入口，日期格内部可滚动。

### 4. 右侧日历增加容器边距

- 星期栏与日期网格放入独立内层容器。
- 容器保留边框、圆角、轻背景和四周留白，不再贴满模块边缘。
- 桌面与窄屏都保持日期格可读；窄屏仍支持容器内横向滚动。

### 5. 三卡页签角标只统计今天

- 任务、好奇心、资源三个页签只统计当天新增。
- 时间范围固定为“今天零点（含）到明天零点（不含）”。
- 自然日翻转时自动重新计算。
- 0 时隐藏，超过 99 显示 `99+`。

### 6. 今日三件事复制文案改用项目原名

- 固定格式：

```text
推进[[项目]]项目，任务内容，助力【指标名】指标落实到位
```

- 不再自动添加 `MOC-` 前缀。
- 项目名、任务名或成功指标缺失时继续禁用复制。

- 左栏筛选、排序、落图日期显示与拖拽排期一致。
