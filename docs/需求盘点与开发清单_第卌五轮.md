## 2. 功能点明细（T-01~T-06）

- **T-01** 北极星三档周期：Period=`day/week/all`；days=1/7/9999、dhiDays=1/14/9999；WRR 日档=todayOpened；下排改「新增卡片/删除卡片」。
- **T-02** 工作台页头：`wsTodayAdd/wsTodayDel`（当日 0 点起算）入 hero-stats（五项）。
- **T-03** 任务管理迁移：新建 TaskManagerPanel（卡片视图默认+全量能力）+ 共享 TaskDetailDrawer；CompassHome Tab 切换（默认我的好奇心，v-show/v-if 双策略）。
- **T-04** 项目策展：CompassActions 下方 `.curation` 面板；左列项目名+愿景/使命小卡+战略目标放大+四数值；右列按指标分组+新建/关联；三件事单击联动/双击详情/删除重选/呼吸灯。
- **T-05** 角标移除：App.vue taskBadge + CSS 全清。
- **T-06** 门禁：版本 2.20.0 五处同步；regression R45 批次 14 项（累计 395）+ 老断言重定向；vue-tsc 0；E2E 扩至 8 项；交付物+git tag。
