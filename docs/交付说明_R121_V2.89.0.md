## 六、偏差与说明（3 条）
1. **方向树锚点导航降精度**：原型为六项纯导航；重构后 L3-L6 合为一卡，`layer-5/layer-6` 无独立锚点 → 点击 5/6 项滚动到 L3-6 卡顶部（能力保留、精度略降）。
2. **树内目标级折叠退役**：原型目标列常显（三列分支）；「⊞展开/⊟收起」改为只控指标层（Q6/Q8 拍板范围内）。
3. **展板日期与健康信息降权**：由原 Hero 大字卡收进统计条尾注（`⏱ 起止 · ● 推进中/⚠ 存在停滞`），信息零丢失、占位大幅降低。
