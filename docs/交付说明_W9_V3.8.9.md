## 一、为什么要做这件事

原「知源仪表盘」埋在设置页第一页：品牌区点击跳首页+战报抽屉的链路绕远，复盘/画像/生命周期这些**看自己**的能力与**改配置**的设置页混在一起。用户拍板（2026-10 原型评审）：

1. 画像洞察独立成页 `#/profile`——品牌区一键直达，调度台「📈 复盘」同落点
2. 设置页知源仪表盘面板退役（能力整体迁出，不减一项）
3. 资源生命周期并入画像洞察页 §3（设置页不再有此面板）
4. 三处归档提示条深链改指 `/profile#lifecycle`
