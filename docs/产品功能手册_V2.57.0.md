# 知源调度台 · 产品功能手册

**版本**：V2.57.0 · 2026-09-11 · 与产品实装版本同步（品牌口径对齐 00 母版 R2；R64-R88 结构变化见下方变更摘要）
**定位**：你在浏览器里的个人调度中台——万千可调用，自有我方向

> **这本手册怎么用**：手册以产品界面为架构（第 1~11 章 = 你在屏幕上看到的每一个界面），以模块为结构（每章按屏幕分区展开），逐点对照撰写。每个功能点给出三件事——**内涵**（它是什么）、**用法**（怎么用）、**意义**（为什么这样设计）。对着屏幕读手册，界面上每一个可见元素都能在本文找到。

> **V2.41.0 结构变化速览（R71 · 结构性性能治理）**：本版为**性能版**，**零界面改动、零交互改动、零数据模型改动**，只做"更快"——把"打开就顺"从愿望做成了可复现的硬指标。① **分类树索引化**：资源台与策展台的分类树此前每调用一次就全表扫描一次（侧栏单个节点要扫 5 遍，整树渲染是 O(n²)），现改「一次建索引、处处查表」——`byId / childrenOf / 深度 / 路径 / 后代 / 家族`全部 O(1)，且带缓存；② **模板内方法调用清零**：卡面路径徽标、分类计数、看板列分组等原先在模板表达式里逐卡重算的函数，全部改为预计算表；③ **长列表离屏跳过渲染**：资源台与策展台的**卡片 / 列表**视图给每张卡加 `content-visibility`，屏外卡片不参与布局与绘制；④ **下钻面板惰性求值**（抽屉未开不做全量计算）；⑤ **数据聚合与持久化减负**：投射解析由 O(投射×资源) 降为 O(投射+资源)，策展台指标一次遍历出全部口径，保存路径去掉一次整树冗余序列化，事件日志改为就地扫描不再建中间数组。
> **实测（中规模数据：资源台 100 分类 / 760 卡片 / 402 投射 / 400 任务 / 6 策展台，2 轮中位数）**：资源台「☰ 列表」切换 **307ms → 37ms（-88%）**、资源台「▦ 卡片」62.8ms → 17.4ms（-72%）、策展台「☰ 列表」108ms → 19ms（-82%）、策展台「▤ 看板」108ms → 5ms（-95%）、切到资源台 87ms → 46ms（-47%）、资源台内搜索键入 37ms → 14ms（-63%）。**所有视图切换均降至 40ms 以内**。

> **V2.46.0 结构变化速览（R77 · 浮层主题化）**：网页浮层此前是一套**写死的品牌绿**——底色、文字、强调色全部硬编码，浮在任何网站上都是同一副绿色面孔，与用户自己选的主题毫无关系。本版让它**入乡随俗**：① **底色与文字跟随宿主环境**的明暗偏好（系统深色则浮层深色）；② **强调色取知源当前主题**——你在知源里选深空薰衣草、极简白、光速黑还是纸墨白，浮层的强调色就跟着变（主题切换即时生效）；③ 移除顶部那条绿色渐变装饰条。同时按"主色稀缺"规矩收敛——**强调色只保留主按钮、焦点环、当前选中行三处**，搜索 chip、类型页签、分段控件等一律改中性，不再满屏铺色。遮罩也变轻了：由厚重模糊改为半透明轻纱，页面内容仍看得清，浮层改用自身边框与阴影撑住层级。

# 第一章 顶栏与全局框架

顶栏常驻所有页面上方，是全局导航与全局工具的载体。

| 功能点 | 内涵 | 用法 | 意义 |
|---|---|---|---|
| 🏠「调度台」页签（Logo） | 产品主页入口，固定第一位 | 任意时刻点击回到调度台首页；刷新浏览器也自动回到此页 | "今天从哪里出发"是产品的第一心智，主页永远一键可达 |

## 附录 A · 三卡状态机

```
任务：todo ⇄ doing → done（completedAt 随动；全产品唯一状态出口）
好奇：待探索 → 探索中 → 已求证
              ↘ 已搁置
      任一态 → 转任务 / 转资源（fromCuriosityId 溯源）
资源：无状态机（复用计数即生命线）
删除（三卡通用）：软删 deletedAt → 回收站 → 恢复 / 永久删除（清附件）
```

## 附录 B · 指标口径（方向状态四指标）

| 指标 | 口径 |
|---|---|
| 战略目标 / 推进项目 | 目标数=使命下拆解的方向数；推进中=挂有任务（任务数≠0）的项目数（R64 起 DHI 计算退役，回归直白计数） |
| WCE 好奇探索 | 状态为「探索中+已求证」的好奇项数 + 转化为任务/资源的卡数（fromCuriosityId） |
| WRR 资源复用 | 日=今日打开卡数；周=本周调用次数；累计=累计调用次数 |
| 未归档任务 | 未挂项目/指标或引用失效的任务数（口径全产品唯一，任务卡库「⚠ 未归档」筛选同源） |
