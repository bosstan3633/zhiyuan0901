## 一、Bug 修复（3 项）

### BUG-1 · 写入记录主计数与详情对不上
- **根因**：主计数 `logTotal = 事件日志全条数 + 调出数`，副行只拆三卡——愿景/使命等**非三卡事件**进主数却无处安放；且调出条目从未进入明细抽屉，双端口径都裂。
- **修复**（CompassHome.vue）：口径统一为「当日三卡事件（新增/删除/恢复/清理）+ 三卡调出」，**主计数 = 副行之和**；明细抽屉 = 三卡事件 + 当日调出条目（可定位）+ 系统事件（`.sys` 灰显、不计数），按时间降序合并。抽屉标题对 log 显示计数口径数。
- **验证**：回归 R52-1/R52-2 + R51-7（语义升级）。

### BUG-2 · 已完成项目显示/隐藏失效 + 完成口径升级
- **根因**：「已完成项目」开关五处实现全为过滤 `status === 'archived'`（归档≠完成），手动标 done 的项目切开关无反应——R49-C6 落地时的口径错位。
- **修复**：`stores/compass.ts` 新增共享口径 **`isProjectDone(p)`**：`status done/archived` 或 **项目下有任务且全部完成（派生，纯计算不回写）**；主航线 / 项目总览（CompassShell）/ 完整方向树 / 全局搜索项目类型（计数+列表）**五处统一改用**；各处 doneCount 同步换口径。
- **验证**：回归 R52-3/R52-4（五处引用 + 旧口径字符串清零）。

### BUG-3 · 策展中心不出现在「设置—工作台全景」
- **排查**：全景树只遍历真实 Workspace 实体，代码层不产泄漏；泄漏疑与用户数据中出现同 id 工作台实体有关（导入/历史）。
- **修复**（全局收口）：`stores/app.ts` 的 `workspaces` computed（顶栏 Tab/设置/全景/导出/快捷键等**所有枚举的唯一来源**）显式排除 `CURATION_WS_ID`——单点防御全覆盖。
- **待真机复核**：用户数据侧泄漏路径复现确认。
