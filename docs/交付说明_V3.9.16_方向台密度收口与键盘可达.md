## 一、本轮反馈与结论

本轮不是新增业务面，而是把“看起来乱、点起来不稳、发布包偏重”三类底盘问题一次收口：

1. **方向台阅读层级统一。** 页头、项目舱头、指标头与任务行共用一套更紧的字阶和间距；任务仍保留独立白底、缩进与分叉臂，不用悬停位移制造噪声。
2. **键盘入口不再只修局部。** 全站非原生点击面统一接入 `v-pressable`，Tab 可达，Enter / Space 触发同一点击；编辑态、嵌套交互和重复按键不被劫持。
3. **视觉门禁不再“跳过即绿”。** 方向树折叠注入独立方向 / 项目 / 指标 / 任务夹具，四主题都实际验证舱头、开合把手与收起态。
4. **热区补齐到真实可点尺寸。** 顶栏保存状态点视觉仍为 7px，透明命中盒补到 28px；骨架条「建议目标」同样达到 28px。
5. **工程侧只删真死物。** 删除任务面板从未渲染的旧平铺模板与遗留样式，删除未引用的 `icon32.png`，无损压缩其余图标，并移除已失效的 `pinyin-pro` 手动分包配置。

本轮没有改变六层模型、三卡数据关系、策展树结构或四主题令牌。

## 二、实现结果

### 2.1 方向台密度与层级

- 方向台页头、项目舱头、指标头与任务行统一收紧字号、行高和间距。
- 任务行保留独立白底、缩进和分叉臂，层级归属继续可读。
- 移除靠悬停位移制造反馈的噪声，交互反馈回到颜色、边框与焦点态。
- 项目塔与项目全景继续共享同一任务归属口径：`tasksOfProject / tasksOfMetric`。

### 2.2 键盘可达与焦点

- 新增并铺开 `v-pressable` 指令：非原生点击面补齐 `tabindex`、`role`、Enter / Space 触发与按压反馈。
- `contenteditable` 编辑态优先保留文本输入，Enter / Space 不误触外层点击。
- 嵌套交互控件不重复触发外层动作。
- 键盘静态审计从 **352 处 / 44 文件** 降到 **0 处 / 0 文件**；假修复保持 **0**。
- 仍需如实保留两项残余风险：**54 处 `outline: none/0`** 与 **32 处遮罩层**。前者需继续逐条确认是否有可见替代焦点态，后者需继续由 Esc、焦点圈定与关闭后焦点回归覆盖。

### 2.3 方向树折叠与响应式

- 视觉实拍注入独立方向 / 项目 / 指标 / 任务夹具。
- 四主题均验证折叠舱头、卡头、开合把手与收起态；不再因备份夹具 `directions[].projects` 为空而跳过。
- M6 响应式覆盖 1440 / 1024 / 800 三档 × 四台面，共 12 组合。
- 页面级横向溢出为 0，首屏 `<28px` 热区为 0。
- 新增 `M6-8`：保存状态点与「建议目标」必须实测达到 28px。

### 2.4 工程治理与发布包

- 删除 `TaskManagerPanel.vue` 中从未渲染的旧平铺模板和遗留 `.section-label` 样式。
- 删除未引用的 `icon32.png`，压缩 `icon16 / icon48 / icon128`。
- 移除无效的 `pinyin-pro` 手动分包配置；运行时仍只有 `vue / vue-router / pinia` 三个依赖。
- 生产构建继续启用 Terser 与 Lightning CSS 压缩。

## 五、UI 设计层面的下一步方案

下一轮仍不建议再叠新容器，而应继续减少同屏竞争：

1. **项目全景只保留一条阅读路径。** 固定为「项目切换 → 项目摘要 → 指标泳道」；状态、说明与低频动作不再和主信息抢同一屏。
2. **项目塔强化主信息。** 每张项目卡只突出项目名、下一步、主指标、进度、停滞与断链；低频操作收进行尾菜单。
3. **任务统一成账本行。** 项目塔、项目全景、项目详情与任务池共用同一结构，成熟度、优先级、删除与完成固定在行尾，减少卡中卡。
4. **密度与层级令牌统一。** 全站复用同一套字阶、发丝线、间距阶与 28px 热区；优先删装饰，不靠继续加边框和底板解决分区。
5. **无障碍残余风险专项收口。** 逐条核验 54 处 `outline:none` 的可见替代焦点态，并为树画布单独设计方向键 / Home / End / Enter / Space 契约。
