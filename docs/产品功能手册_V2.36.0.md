# 第二章 调度台（默认首页）

> 打开新标签页即到达。回答一个问题：**今天，从哪里出发？**

## 2.1 页头

| 功能点 | 内涵 | 用法 | 意义 |
|---|---|---|---|
| 标题「调度台 · 今天，从哪里出发」 | 页面身份声明 | — | 每天打开的第一眼是"今天"，不是"仓库" |
| 「● 数据存储正常 · 刚刚写入」存储状态 | 写入回执：绿色=正常（显示最近写入时间）；红色=写入异常（含原因） | 正常时点击查看已用容量；异常时点击**一键重试写入** | 数据可感知原则——存没存上必须看得见，失败必须能给动作 |
| 今日记录 · ⬇ 入台 N | 今天新入台的卡片数（资源+任务+好奇） | 点击打开记录抽屉 | 每天的"收进"可视化 |
| 今日记录 · ⬆ 移出 N | 今天软删除的卡片数 | 点击下钻 | 删除也是调度行为，可见才可复盘 |
| 今日记录 · ↗ 调出 N | 今天被你调出打开的卡片数 | 点击下钻；明细可点击定位到原卡 | **调出是产品核心动作**，单独计数 |
| 今日记录 · ✎ 写入 N | 今日三卡事件（新增/删除/恢复）+ 调用次数合计；系统级写入灰显不计数 | 点击下钻完整事件流 | 写入记录=你的调度痕迹 |

## 2.2 方向状态四指标（顶部指标条）

| 功能点 | 内涵 | 用法 | 意义 |
|---|---|---|---|
| 日 / 周 / 累计 切换 | 四指标的统计周期 | 点击切换，四格联动刷新 | 同一组数字看不同时间尺度 |
| 战略目标 / 推进项目（R64 起） | 目标数=使命下拆解的方向数；推进中=挂有任务（任务数≠0）的项目数（R64 起 DHI 百分比计算退役）｜原口径：在轨项目占已投射项目的百分比。在轨=窗口内有任务完成、或有进行中任务、或项目任务已全部完成 | 悬停看副行（X 方向 · Y 已投射 · Z 在轨）；点击下钻各方向明细表，点击方向行可定位主航线 | 回答"我是不是在主线上跑"；项目全部做完**不会**掉出在轨（完成也是推进） |
| WCE 好奇探索 | **激活好奇项（探索中+已求证）+ 好奇转化为任务/资源的卡数** | 点击下钻：激活好奇清单 + 转化明细，条目可定位 | 好奇心是过滤信息的闸门——不仅被记录，还要转化为行动才算闭环 |
| WRR 资源复用 | 日=今日被打开的卡数；周=本周调用次数；累计=累计调用次数 | 点击下钻调出资源清单，条目可定位 | 资源的价值在被调用；复用是"调度"区别于"收藏"的硬证据 |
| 未归档任务 N/M | 未挂项目/指标（或引用失效）的任务数 / 总任务数 | 点击下钻待归档清单：**就地选项目→选指标完成归档**，点击标题跳任务调度定位 | 快速采集的任务会沉淀在这里；这是"采集→归档"闭环的治理入口 |

## 2.3 今日三件事

| 功能点 | 内涵 | 用法 | 意义 |
|---|---|---|---|
| 事件卡（01/02/03） | 今天最重要的三件事，每件绑定一个任务 | 单击选中（联动右下项目调度）；双击打开任务详情抽屉 | 三件事是"行动视角"的最小单元，与方向链硬关联 |
| 复选框（卡左侧） | 完成标记 | 点击打勾——同时把绑定任务置为已完成（再点恢复待办） | 三件事的完成=任务系统的完成，双写不脱节 |
| 📦 项目标签 / 🎯 指标标签 | 该事件所属项目与成功指标 | 悬停看全名；未关联时显示「未关联」 | 行动与方向的连接线，一眼可见 |
| 「×」移除 | 把事件从今天三件事移除（**不删除任务本体**） | 点击即可 | 计划变化不该变成数据损失 |
| 「＋ 从任务库选取」（空槽） | 从全域任务中选一件加入今日 | 点击打开选取弹窗：搜索/置顶优先；已完成或已入选的置灰 | 每天空槽是行动的入口，不是待办的压迫 |
| ⚖ 锁定条「已满 3/3」 | 三件事硬上限提示 | 完成或移除一件后可再加入 | ≤3 是纪律：超过三件就不是"最重要" |
| 「复制昨日」 | 把昨天的三件事结构复制到今天（完成态清零） | 点击即可，可再逐槽调整 | 例行事项不必天天重选 |
| 「导出」 | 按日期范围导出三件事为 CSV（含项目/指标/状态/创建时间） | 点击 → 选起止日期 → 导出 | 三件事是可带回工作汇报的个人复盘数据 |
| ‹ 日期 › | 切换查看/编辑昨天、明天的三件事 | 点击箭头或直接看日期 | 提前规划与回看都支持 |

## 附录 A · 三卡状态机

```
任务：todo ⇄ doing → done（completedAt 随动；全产品唯一状态出口）
好奇：待探索 → 探索中 → 已求证
              ↘ 已搁置
      任一态 → 转任务 / 转资源（fromCuriosityId 溯源）
资源：无状态机（复用计数即生命线）
删除（三卡通用）：软删 deletedAt → 回收站 → 恢复 / 永久删除（清附件）
```

## 附录 B · 指标口径（方向状态四指标）

| 指标 | 口径 |
|---|---|
| 战略目标 / 推进项目 | 目标数=使命下拆解的方向数；推进中=挂有任务（任务数≠0）的项目数（R64 起 DHI 计算退役，回归直白计数） |
| WCE 好奇探索 | 状态为「探索中+已求证」的好奇项数 + 转化为任务/资源的卡数（fromCuriosityId） |
| WRR 资源复用 | 日=今日打开卡数；周=本周调用次数；累计=累计调用次数 |
| 未归档任务 | 未挂项目/指标或引用失效的任务数（口径全产品唯一，任务卡库「⚠ 未归档」筛选同源） |
