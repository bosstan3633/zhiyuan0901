## 一、需求 A：三卡详情页重设计（按已确认方案 A 标准）

**设计标准（三卡通用）**
1. AI = 标题行右侧主上下文动作（outline-accent），三态：未跑 → 跑中（spinner）→ 已跑（chip「🤖 已X · MM-DD HH:mm」+ 文案翻「↻ 重新X」，凭 `aiTouchedAt`，R152 已落字段；任务/好奇卡若未打此标，采纳写库处补打）。
2. 动作跟着对象走：链接/来源的「↗ 打开 / ⧉ 复制」贴输入框右侧，不再放页脚。
3. 页脚收敛两钮：左 🗑 删除（ghost + 二次确认，点一下变「确认删除？（进回收站）」3s 回落）+ 右 primary 提交（Ctrl+↩ 提示）。
4. 降噪：附件说明收进 `?` tooltip；时间戳 10.5px 一行；创建/打开数合并。
5. 资源卡删「策展台」下拉（零信息控件 + 曾致真身静默迁移 BUG，见 `ResourceEditForm.vue:52-55` 注释），分类升单列全宽。
