# V4.6.0 · 选题成果、同步恢复与策展布局

## 交付范围

- 本机启动、数据包导入与云端恢复统一经过 `normalizeAppData()`；旧快照缺少选题卡、选题状态、资源关系或今日槽位数组时自动补齐，修复云同步后或切换调度台时 `undefined.map()` 白屏。
- 选题详情把“发布 / 成果链接”提升到首屏主信息区，支持 `http(s)`、完整裸域名与 `obsidian://`；单击打开详情，双击直接打开成果。
- 任务清单与选题清单的折叠入口移动到清单标题旁；收起后右侧日历 / 看板自动铺满整行，并在正文头部保留展开入口。
- 选题卡支持从左侧清单拖入月历与周历，拖入今日时继续遵守今日三件事三个槽位的容量与严格同源规则。
- 方向树在单项目策展聚焦时使用最大 1180px 的居中内容列，降低愿景、使命与战略目标的视觉权重，让项目及其指标 / 任务成为主视觉。
- 策展台把中心论点与页面工具栏合并为同一双列控制台；900px 以下自动单列，减少纵向占用并保持左右对齐。
- 云同步恢复只替换业务数据，不再派发画布历史重置；切换或删除策展台时仍按原规则清理对应会话时间线。

## 交互规则

- 成果链接是选题详情的第一跳转目标：单击只进入详情，双击才直接打开链接，避免浏览详情时误跳转。
- 折叠状态只影响呈现，不删除或重排任务 / 选题；展开入口与标题旁折叠入口双向可达。
- 选题拖入非今日日期只写入计划执行日期；拖入今日仍与今日三件事使用同一集合，满额时拒绝第四项。
- 旧数据归一化只补缺失结构，不改写已有卡片的业务内容；导入、启动与云恢复使用同一入口。
- 单项目聚焦只调整方向树内容列宽与留白，不改变六层归属、筛选范围或折叠状态。
