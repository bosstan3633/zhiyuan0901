## 二、交互口径

- 中心论点仍是策展台的结构根；高频的金字塔 / 树状切换与画布操作保持在画布工具条，分享只保留页面行动条行尾一次。
- L2 起节点的左右箭头只改变当前同层级顺序，不改变父子关系；跨层级仍通过拖拽或剪切操作完成。
- L2 起节点编辑标题：聚焦节点后单击或按 `Enter` 进入标题编辑，`Ctrl+Enter` 创建同级节点；编辑态内 `Enter` 只确认当前标题。
- 方向树的层级详情是只读观察面；结构编辑继续回到方向台，任务拖拽归位是唯一允许的写库动作。

## 三、数据与稳定性

- 云同步继续沿用 Supabase 现行契约：设置页使用 `idle | connected | error` 三态、`sb_publishable_` key、密码不回显；登录、检查、上传、恢复共用忙碌锁。
- 策展节点、方向树详情和任务拖拽均在本地数据模型上工作；任务归位只经页面注入的持久化回调，避免组件绕过宿主直接写库。
- 代码索引、回归分片与交付文档同批更新；旧 Airtable 实现和设置入口不再作为现行能力维护。
