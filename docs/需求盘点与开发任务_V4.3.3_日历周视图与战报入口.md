# V4.3.3 需求盘点与开发任务

> 日期：2026-11-14
>
> 基线：V4.3.2（`dfa490f`）

## 一、需求盘点

### A. 任务日历

1. 点击“今天”后，当天安排在日历中的任务通过中央弹窗完整展示。
2. 当前日详情存在文字叠压、标题与元信息互相覆盖的问题，需要修复。
3. 日历支持“月视图 / 周视图”切换：
   - 月视图展示当前月份及相邻月份日期；
   - 周视图只展示当前 7 天；
   - 前后按钮在月视图切月、在周视图切周；
   - “今天”同时校正月份与周起点。
4. 左侧待排期任务改为“所有没有计划执行日期的任务都会列出”，不再由任务池暗中排除已完成任务。
5. 是否显示已完成任务继续交给上方项目、状态和快捷筛选决定。
6. 老库 `dueAt` 与数字型 `dueDate` 需要在载入 / 导入时转成 `YYYY-MM-DD`，避免任务日历调用字符串方法时崩溃。

### B. 卡片池资源文件夹

1. 资源页中的“今日采集”和常用夹模块点击后，直接在中央弹窗展示明细，不再先跳到二级资源池。
2. 文件夹明细弹窗需要支持：
   - 打开单张资源卡；
   - 一键打开全部可访问原链；
   - 从常用夹移出成员；
   - 进入常用夹管理；
   - 今日采集只做当天虚拟筛选，不复制、不移动资源真身。
3. 卡片池页签的今日新增角标需要降低视觉强调：
   - 与页签文字同色；
   - 不使用红色；
   - 不使用高对比底色或边框；
   - 数字为 0 时隐藏。

### C. 今日战报

1. 今日战报点击后应优先打开弹窗，不能等待事件日志和云端校正完成后才响应。
2. 首屏先显示本地已有数据，云端账号操作记录在后台补齐。
3. 今日战报提升为调度台页头主入口，AI 推荐降为次级入口。
4. 浏览器快捷键新增“打开今日战报”：
   - 不设置默认键位；
   - 用户在浏览器扩展快捷键页自行分配；
   - 未打开知源页时可直接打开并进入调度台；
   - 已打开知源页时复用当前窗口中的页面并打开战报。

### D. 今日三件事

1. 三个计划槽中的任务卡不再被强行拉伸到统一高度。
2. 卡片按标题与元信息的真实内容高度收口，减少大面积空白。
3. 今日三件事仍以任务卡为当天状态唯一真源。

## 二、交互约束

- 计划执行日期继续复用任务卡既有 `dueDate`，不新增第二日期字段。
- 日历只负责排期与查看，不承担任务删除；删除仍只在卡片池任务管理入口完成。
- 周视图与月视图共用同一排期、状态色、拖入、取消排期和详情链路。
- “今日采集”是虚拟筛选，不写入常用夹成员，不创建第二张资源卡。
- 常用夹移出只删除当前夹镜像，不改变资源真身、其他常用夹和策展台镜像。
- 今日战报的事件日志补读失败时继续使用本机缓存，不阻塞弹窗。
- 移动采集 PWA、PC Inbox 与旧 `capture_inbox` 请求继续保持退役。

## 四、验收标准

1. 点击“今天”后，当天任务在正确层级弹窗中展示，标题和项目 / 指标信息不重叠。
2. 月视图与周视图可正常切换；前后按钮移动正确周期，今天回到当前日期。
3. 没有计划执行日期的任务全部进入左侧列表，已完成任务是否出现由上方筛选决定。
4. 老任务数据中的数字计划日期不再导致页面渲染错误。
5. 今日采集与常用夹点击后直接打开中央明细，可完成打开、移出、打开全部和管理。
6. 页签角标不再呈现为高压力红色徽标。
7. 今日战报入口点击后立即出现弹窗，快捷键可从浏览器命令配置并在页面内打开战报。
8. 今日三件事三张卡按各自内容高度展示，不出现统一拉伸造成的大块留白。
9. 移动采集、PC Inbox 与周期 AI 分析均不回流。
