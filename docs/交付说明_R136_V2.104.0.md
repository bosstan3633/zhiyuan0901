## 一、交付明细

### A3 · 按任务推荐资源卡（应用推荐首场景）

- **入口**：任务详情抽屉底部「🤖 推荐卡」（拆解步骤旁）。
- **投料**：该任务上行链画像（任务→指标→项目→目标→愿景/使命，复用 R135 `projectChain`）+ 全库资源卡目录（`cardDirectory`：一行一卡，过滤软删、**排除该任务已挂载**、上限=深度档 cards×2）。
- **契约**：参谋提示词「宁缺毋滥 ≤5 张、按贴合度降序、why 必须说清支撑任务的哪一步、cardId 不许编造」；parse 走 `sanitizeRefs`（幻觉 id 丢弃）+ apply 二次校验（卡存在未删未重复才挂载）。
- **采纳语义**：`task.mountedResourceIds.push` + 触 `updatedAt` + 一次 persist——走的是任务详情里手工挂载的同一条字段通道。

### 1d · ✨ AI 理解（搜索意图重排，只读）

- **入口**：Ctrl+K 搜索面板类型页签行右端「✨ AI 理解」钮（命中 ≥2 条才可用；再点一次清除）。
- **机制**：把当前字面命中的前 20 条（id/类型/标题/台/分类/摘要）+ 关键词交给「搜索意图理解器」，模型回 ≤6 条真相关 + 一句意图理解（note）；命中集消毒（id 必须属于给定列表）、why/note 截 40 字。
- **呈现**：列表顶部插入「🤖 AI 理解」精选组（标题左封 accent 线 + 每条带入选理由 chip），**原分组列表与排序一字不动**；改词即清（watch searchQuery）。
- **性能红线兑现**：键入路径（120ms 防抖/hitRank/分组渲染）零参与、不发请求；`aiRerankRun` 函数段零写库（断言机器检查）。
- **入口 chunk 守卫升级**：GlobalPopups 与 RDD 同属 App.vue 静态挂载——AI 依赖全懒（点击时 `import('@/shared/ai/config'…'select')`），R136-1 断言锁死 + 产物级复核（入口 chunk 无 `chat/completions/zy_ai_v1`，仅存 import 调用点本身，实现落独立懒 chunk）。

浮层（content 侧）本轮**未接** AI 信号通道——按排期，浮层入口在真实网关实测后再评估接入，避免双上下文持密钥。
