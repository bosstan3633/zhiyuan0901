## 写作纪律

1. **数字一律回源码/实跑**，不引用旧文档的数字。
2. **判据只增不减**：被改写的旧断言要写"重指理由"，不静默删。
3. **说清代价**：改了像素就说改了哪几处；改了时长/位置就说新契约是什么。
4. 版本号七处同步（`manifest.ts` / `package.json` / `package-lock.json` ×2 / 手册页 / regression 版本锚 / `v2/README.md` / 根 README）。
