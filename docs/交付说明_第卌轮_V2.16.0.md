3. **REQ-051 附件卡片正面展示（拍板：图标+数量徽章 🖼 n / 🧾 n）**：新增共享组件 `AssetBadge.vue`（分组计数徽章 + 点击弹文件列表 + 图片 objectURL 弹窗预览 / HTML 新标签打开，click stopPropagation 不干扰卡片开合）；资源（Workspace 卡片/列表/看板）、任务（全域任务列表/看板/今日聚焦/选取弹窗）、好奇（CuriosityPanel 卡片/列表/看板）全部接入；**好奇面板改按 fieldConfig.curiosity 目录消费**（assets/tags/custom 字段流，显隐/排序一处开关即控）。
4. **REQ-052 死代码清理**：`UIPrefs.fieldViewCfg`（第二套字段配置历史残留）从模型 + 默认值移除，回归断言防复活。
5. **工程治理**：版本号 2.16.0 五处同步（manifest/package/关于页动态/ManualPage/regression）；回归 **314 → 325** 项全绿（R40-1~R40-11 新增 11 项）；vue-tsc 0 错误；dist 干净重建（34 assets，无旧 hash 残留）。

## 四、技术要点

- **目录化零迁移**：FieldConfig 分区结构（{resource,task,curiosity} 三数组、各自 order/visible）完全不动；老数据仅在 loadData 时自动补 assets def（repository 行 82-87）→ 升级无感。
- **字段渲染链路**：`fieldRenderKind('assets')` + `fieldValue case 'assets'`（文本摘要「2 图 · 1 HTML」，列表/CSV/预览兜底）；`defaults.ts` 三型 assets def（resource order6 / task order8 / curiosity order5，默认 visible）。
- **转卡挂载关系红线保持**：目标任务卡 `mountedCuriosityIds=[源 id]` 回指；源卡软删 deletedAt 由调用方执行；单向无环。
- **附件 Blob 零变动**：转卡只搬 AssetMeta 引用拷贝，IndexedDB `zy_assets` 完全不动（性能红线维持）。
- **AssetBadge viewer 独立实现**（同 AssetManager 行为不共用代码）：避免牵动 R39 附件回归断言；后续可再抽公共 viewer 收敛。
