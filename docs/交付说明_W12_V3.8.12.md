# 交付说明 · W12 / V3.8.12 方向台按原型 1:1 还原

## 一、本轮做的是什么

W11 把结构**造出来**了（六层链、纵向舱、全景视图），但**摆的位置不对**。
对照原型逐块核实后，实际与原型的差异是**结构性的**，共 6 处，全部本轮修掉：

| # | 原型要求 | 实际实现（错在哪） | 本轮处置 |
|---|---|---|---|
| 1 | `section.hero` 两栏：左 Slogan/副标，右动作组 | 面包屑 + 6 项读数 + 7 个按钮全塞进 `.tree-page-head` 一行 flex，首屏第一眼是一行密排小字，**Slogan 完全缺席** | 补 `section.hero` + `.hero-l`（面包屑/eyebrow/Slogan/副标）+ `.hero-r`（`.hero-acts` / `.hero-meta` / `.hero-stats` 三组），`.tree-page-head` 整族退役 |
| 2 | `spine → lvpanel → towers` 三段，1/2 层正文只在 `lvpanel` 里 | 愿景 22px 大卡摆在 **spine 之上**，等于在六层链条之外另起一个平级区块，首屏被它吃掉，"逐层收窄"在版面上断掉 | 愿景/使命正文搬进 `CompassLayerPanel` 的 `#entity` 插槽（骨架条之下）；就地编辑 + 关联卡片能力随迁；面板内原本那份只读副本一并删除（否则同一句愿景页面上出现两份，且用户分不清哪份能改） |

### 新增分片：`04-w12-restore.cjs`（W12-1 ~ W12-10）

为什么必须新开一片：W12 全部动作是「把已交付的结构摆回原型指定的位置」。
这类改动的失效形态与 W11 不同 —— W11 是「新增结构时少做一层」，**W12 是「结构都在，但摆错了地方」**：
元素在、样式在、能力在，唯独不在原型说的那个位置上。而"位置对不对"这件事，
W8 / W11 现有的 17 条判据全都钉不到（它们守的是层级与归属，不是版面顺序）。

十条分别钉：HERO 两栏在位 / 1-2 层正文在面板插槽内（钉位置不钉存在）/ 骨架条头部与宽度编码 /
左栏是项目导航 / 舱-指标-任务三层尺寸 / 操作钮 hover 化且能力未丢 / 容器内边距属跨页纪律 /
页头八个出口逐项在位 / 分组头 pill 与发丝线 / 左栏序号短且间距只由一层承担。

原则不变：**只换承重锚，不换所守行为**。

**W8-1 / W8-2 / W11-11（焦点契约三条）**：愿景的"重边框"由 `shadow-lg` 重框改为**左侧 2px accent 实轨 + 大留白**。
原因：愿景块现在住在面板里，面板自带卡面，块内再套一张卡会变成"面板里套卡"的双层框，主角反被面板抢走。
**守的行为未变** —— 仍是"独占一行 + 大留白 + 强调框，主角感由版式承担而非只降字号"。

**W8-3（层级倒置）**：内容标题载体随 `.lt-title` 退役，改由 `.hero-title` 承担（`--fs-headline` 17px）；
16px 基准载体由 `.tree-page-head .crumb` 迁到 `.hero-crumb`。
★关键：旧 16px 那条原本已成**死样式**（页头退役后无人渲染），R51-6 / R123-10 两条判据仍在守它 ——
挂在死样式上会让那两条**假绿**。本轮把它迁到真正在渲染的载体上。

**W11-2（连接线）**：横臂宽 12→15px、任务轨内缩 22→26px，锚改为钉"宽度存在且 > 0"而非具体像素
（钉死像素会让"跟随原型调轨道缩进"这种纯视觉调整反复改判据）；同时**补钉铆钉点**
`.tw-rail > :deep(section)::after`（原型 `.metric::after` 那个圆点，是横臂的收头）。

**W11-9（全景投影）**：左栏定位入口由 `scrollToLayer(n)` 改为 `gotoTower(projId)`，两条 `ensureTower` 调用点随之改钉；
守的仍是"任何定位都能抵达、不挑视图"。

**W11-1（纵向舱序列）**：舱间距由 `gap: 4px` 改为 `40px`（原型 `--sp-8`）。
4px 是当初"纵向序列"刚落地时的值 —— 舱几乎贴着舱，而"区隔明确"正是本条要守的东西，反而没做到。
锚改为钉**间距 ≥24px**（钉死像素会让"跟随原型调呼吸感"反复改判据），并补钉「舱体自身不许再叠 `margin-bottom`」。

## 四、踩坑账（本轮实证，全部可复用）

**1. 「结构都在，但摆错了地方」是门禁的盲区。**
W11 建的 13 条判据守的是层级与归属，17 条 W8 判据守的是字号与焦点 ——
**没有一条能发现"愿景卡摆在了骨架条上面"**。元素在、样式在、能力在，回归/typecheck/build 全绿。
这类改动必须新开一片钉"谁在谁的上面"，否则下一轮同样看不见。

**2. 删一块 UI 会同时产生样式孤儿，删完不跑扫描器就留下一笔看不见的债。**
本轮删左栏留下 `.layer-header/.layer-num/.layer-name/.layer-desc` 5 条；删 Panel 的只读副本留下 `.lvp-chip` 1 条。
两次都是 R4-Ev① 变红才暴露 —— 而它红的原因是"**实跑扫描器两桶非零**"，不是"我删错了"。
**规则：任何结构删改之后立刻跑 `dead-css-scan.cjs --json`，看 `死` 与 `祖先断` 两桶（注意键名是 `死` 不是 `判死`，我在这上面绕了一圈）。**

**3. 原型的数值不能直接覆盖已拍板的跨页一致性纪律。**
本轮曾把 `.compass-layout` 的 padding 从 `20px 36px 64px` 改成原型 `.page` 的 `26px 32px 64px`，
结果 `R21-3` / `R123-3` / `R125-1` 三条同时红 —— R125「骨架 1440+36」把四页页边距拍成一条跨页纪律，
方向台侧的内缩正落在那条规则上。原型是"一张图"，项目是"四页一起"；拿前者覆盖后者，
会让另外三页不动的情况下方向台单独"对齐了"，那正是 R123/R125 要挡的事。**已回滚，并把这条纪律显式钉进 W12-7。**

**4. 切片锚点必须锚"在后的那个"，且要考虑嵌套标签。**
W12-2 最初写 `t.slice(idx('<template #entity>'), idx('</template>'))` ——
插槽内是嵌套 `<template v-if>`，首个 `</template>` 早于插槽起点，切出来是**空串**：
正锚恒假、负锚恒绿，**判据自己骗自己且全绿**。改锚 `</CompassLayerPanel>` 才对。
（与 W11 记的"切片锚要挑在后的那个"同族，但这次的坑更深一层：不是挑错，是被嵌套标签插队。）

**5. 跨标签字面量判据对空白极敏感。**
`class="x"` 紧跟模板串这种锚，一次格式化就静默失效（不报错、不变红，只是不再生效）。
本轮把 `R99-3` 从跨标签 `includes` 改成**分段正则**。**规则：判据锚尽量用正则或分段，别用跨标签字面量。**

**6. 自造的编号格式会挤掉真正要读的东西。**
左栏序号曾写成「目标·项目」复合号（`3·1`）—— 但左栏只有 210px，
复合号既占掉项目名前面的空间，又与舱头的 `tw-idx` 对不上号（读者在两处看到两把不同的尺子）。
改回原型那种「N.M」两级短号。**规则：编号的位数要按容器宽度算，不要按"信息完整度"堆。**

**7. 间距要查"有没有第二份"。**
舱间距同时给了 `.tower-list { gap: 40px }` 与 `.tower { margin-bottom: 40px }`，
两级相加成 80px —— 每一处单看都合理，合起来页面就比原型松散一倍。
这类问题在静态判据里天然抓不到（本轮是 W11-1 钉死 `gap: 4px` 逼出来的）。
**规则：改间距时把该维度上所有承担者一起列出来，确认只有一处。**
