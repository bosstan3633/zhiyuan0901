## 一、为什么：浮层是一副"与用户无关"的面孔

浮层是知源**唯一运行在用户真实工作环境里的界面**——用户 90% 的时间在别的网页上，浮层就浮在那些网页上。但它此前是一套**完全写死的品牌绿**：

```
#0E7A4E 品牌绿 ×15 处（选中态、徽标、焦点环、主按钮、装饰条……）
#FDFDFC 面板底 / #1A1D23 主文字 —— 无论宿主是深色还是浅色
顶部一条绿色渐变装饰条
```

后果有三：

1. **与用户的选择无关**——用户在知源里选了深空薰衣草 / 极简白 / 光速黑 / 纸墨白，浮层毫无反应；
2. **与宿主环境无关**——深色网页上浮一块白面板、浅色网页上浮一块白面板，永远不合时宜；
3. **主色铺得太满**——选中态、类型页签、搜索 chip、分段控件、徽标、装饰条全是绿色，与"强调色克制"的规矩相悖。

---

## 二、关键约束：浮层拿不到 `tokens.css`

浮层是 **content script 注入到宿主文档** 的独立 DOM。新标签页的 `shared/styles/tokens.css` 与它**不在同一个文档里**，CSS 变量无法跨文档继承。

⇒ 主题色必须由 **JS 传入**。本轮做法：

- **明暗**：纯 CSS —— `@media (prefers-color-scheme: dark)` 内建两套色阶，零 JS 参与；
- **强调色**：JS —— 读 `zy_ui_v2.theme`，把对应主题的 accent 注入为 `--zy-accent` / `--zy-on-accent`；
- **防漂移**：`THEME_ACCENT` 表与 `tokens.css` 的四个 `--accent` 值由 **断言 R77-3 双向锁定**——改任一侧，回归必红。

> 关于九条规则之"样式只用 tokens 变量"：本项是**有理由的例外**。浮层运行在宿主文档，取不到 tokens.css，只能自建 `--zy-*` 变量体系；色值全部取自 tokens.css（linear 主题的明暗两套），并由断言锁定不漂移——**等价于变量化，不是硬编码回潮**。

### 3.2 A2 · 轻 scrim

| 项 | 原 | 现 |
|---|---|---|
| `.zy-scrim` | `rgba(15,17,20,.18)` | `rgba(0,0,0,.18)` |
| `.center` 遮罩 | `rgba(245,243,238,.72)` + `blur(20px) saturate(1.4)` | `rgba(0,0,0,.18)` + `blur(6px)` |
| `.zy-panel` | 无边框、轻阴影 | **1px 边框** + 加强阴影（最外层 `0 32px 72px rgba(0,0,0,.22)`） |

遮罩变轻后，浮层改用**自身边框与阴影**撑住层级——浮层打开时页面内容仍可辨。

### 3.3 C2 · 主色稀缺

强调色**只保留三处**：

1. **主按钮** `.zy-btn-primary`
2. **焦点环** `.zy-field-input:focus` / `.zy-field-select:focus`
3. **当前选中行** `.zy-result-item.sel`

改中性的一律用 `--zy-bg-3` + `--zy-text-2` / `--zy-text`：搜索 chip、类型页签 active、分段控件 active、台徽标、保存提示文案；采集图标底（资源）改语义蓝，与结果列表一致。**hover 也从绿色渐变改为中性底**——hover 不是"当前选中"，不配用强调色。

## 六、踩坑

**R77-4 首跑失败**——断言检查 `.zy-panel::before` 不存在，但我在新样式里留了一行注释：

```
/* R77（A1）：原顶部绿色渐变装饰条（.zy-panel::before）已移除 */
```

**注释里写了选择器字面，把否定断言绊倒了**。这与 R73 的 `R73-11`、R74 的 `R74-1` 是同一类问题（本项目第三次）。修法：注释改成不含选择器字面的表述。**写否定断言时，注释也要一起想一遍。**

（同类问题 R76 还出现过一次变体：断言匹配**接口字段连串**，新增字段后被拦腰截断。）
