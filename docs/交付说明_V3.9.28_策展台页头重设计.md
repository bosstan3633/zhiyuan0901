# 交付说明 · V3.9.28 策展台页头重设计

> 日期：2026-10-28
> 基线：远端 `codex/unified-perf-feature` V3.9.27（`0c4c61e`）
> 原型：`评审交接包/原型_策展台页头重设计_审核稿_V1.html`
> 性质：策展台页头信息架构与视觉层级重设计；不改数据模型、策展树结构或四主题令牌。

## 一、当前产品现状盘点

本轮以远端最新 V3.9.27 为基线，而不是本地 `main` 的 V3.9.22。盘点结论：

| 区域 | V3.9.27 现状 | 问题 |
|---|---|---|
| 台身份 | V3.9.24 起与中心论点拆成两层，`.ws-id-head` 高 52–56px，台名 16px | 行高仍高于 R84 原始 ≤40px 预算；台名与论点标题的主次差不够 |
| 中心论点 | 全宽单行横幅：徽标 + 标题 + 描述 + 详情入口 | 能看见论点，但没有表达「L1 / 论点卡 / 金字塔根节点」三层语义；视觉上仍像一条提示带 |
| 行动条 | 画布读数、两个导入入口、检索、设置、分享平铺一行 | 七件事等权，缺少职责分组；分享入口在 V3.9.23 已收进行动条 |
| 视图切换 | 金字塔 / 树状在画布头 | 位置正确，不应再在页头复制第二入口 |
| 既有纪律 | 一个动作一个入口；策展画布主色稀缺；分享固定行尾 | 原型中曾出现论点卡内「分享」与行尾重复、论点卡内「金字塔」与画布头重复，均不落地 |

产品主体保持三卡、六层方向树、策展画布与本地优先存储结构；当前远端基线已具备调度台、方向台、画像洞察、策展台、设置与手册六个主要台面。本轮只调整策展台页头，不把局部视觉重设计扩散到数据模型、画布布局或其他台面。

## 二、设计方案

### 2.1 三层信息架构

1. **台身份行（36–40px）**：图标收进 accent 淡底方片；台名 19px；台描述单行省略且为空不占位；右端保留分类数、镜像数与最近更新流水入口。
2. **中心论点主舞台**：L1 徽标 +「中心论点 · 论点卡」+「金字塔根节点」构成 kicker；论点标题成为页头主句；说明行承接判断背景；右端「论点卡详情 →」只是整卡动作的可读提示，不是第二个按钮。
3. **页面级行动条**：画布读数 / 内容导入 / 检索与成果三组，用发丝分隔；导入成果 HTML 与导入模板保持一级可达；分享固定行尾且维持 ghost 次级。

### 2.2 一个动作一个入口

- 分享成果只保留行动条行尾一处，论点卡内不再出现。
- 金字塔 / 树状切换只保留在画布头，论点卡内不放「查看金字塔」。
- 论点卡只负责「打开论点卡详情」；编辑、AI 提炼与分享继续各归详情与行动条。
- 未设立论点仍是整卡可点 + 单一明确按钮，不新增第二套空态。

### 2.3 视觉规则

- 全部颜色、字阶、圆角、阴影走现有 `tokens.css` 语义令牌；强调色仅用于 L1 徽标、图标方片、左侧竖条与详情提示。
- 分享保持 ghost，不把行动条变成主色按钮墙。
- 1440 下三层页头保持单行行动条；800 下描述让位、论点标题最多两行、行动条分组换行、分隔线隐藏。

## 三、实现范围

- `v2/src/newtab/views/Workspace.vue`：页头三层结构、论点镇台卡、行动条分组与发丝分隔。
- `v2/src/newtab/views/workspace.css`：台身份 36–40px、19px 台名、论点卡 kicker / 主句 / 说明、行动条分组与窄屏规则。
- `v2/scripts/regression/114-v3928-curation-head.cjs`：新增 7 条断言，锁三层结构、一个动作一个入口、行动条分组、空态与窄屏。
- `评审交接包/原型_策展台页头重设计_审核稿_V1.html`：本轮审核原型入库。

未改：`AppData` / `ResourceCard` / `Category` / 策展树父子关系 / 金字塔与树状布局算法 / 四主题令牌 / 分享产物格式。

### 3.1 视觉巡检工具修复

全量四主题巡检暴露了 `theme-audit.cjs` 的三处稳定性问题，本轮一并修复并补入既有 R4-En 判据：浮层宿主页改为长巡检前预建，避免连续 19 个场景后创建第二页面卡死；Service Worker 休眠后改由扩展页调用 `chrome.tabs`，用真实 `zy-ping` 探针并带超时；同 URL `page.reload()` 偶发挂起改为带超时的同址 `goto`。这些修改只影响验收工具，不改变产品行为。
