## 五、偏差与说明（3 条）
1. **列数控件双入口**：工具条一级新增方片（原型）后，筛选气泡内旧列数分段控件未拆除——两者同源 `resCols`，零行为分叉；留待后续原型确认后归一。
2. **「分类 N · 待分类 M」尾注退役**：原 hub 指标格 hint 删除，分类数改并入页头描述（Q1 原型口径）；`uncategorizedCount` 仍服务侧栏「待分类」入口，数据链路未动。
3. **列表视图分组头同步改写**：列表视图分组头与卡片视图共用同一行模板，随之获得三计数格式（原型仅画卡片视图；口径统一、无信息损失）。

## 六、数据与兼容
- **零数据模型 / 零存储结构变更**：`hot` 筛档复用 `callCount`；`total` 为派生字段；右键菜单、挂载链路、下钻抽屉零改动。
- 默认列数 5→6 仅影响从未设置过列数的用户首见；已设置过的沿用本地偏好。
