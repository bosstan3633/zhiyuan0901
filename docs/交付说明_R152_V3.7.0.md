## 一、你报的"Ctrl+Enter 定位没反应"——真因不在键盘，在 keep-alive

复现脚本（`/tmp/zy_r152_ctrl.cjs`，跑在你的库上）第一次跑就抓到了：

```
toast: "🎯 已定位到任务卡片" + "⚠ 该卡片不在当前视图（可能被筛选或已归档）"   ← 两条同时出现
hash:  #/   （没跳，也没滚到那张卡）
```

**根因**：R148 给资源台补了 keep-alive，于是 `useWsLocate` 里那条 `watch(() => route.query.hl, …, {immediate:true})` **在你离开资源台后依然活着**。你从调度台定位一张**任务卡**时，资源台也抢着消费这条 `hl`：把左侧分类重置成「全部」、弹一句"该卡片不在当前视图"、最后 `router.replace` 把 query **抹掉**——真正的消费者（任务面板）随后拿不到信号，滚不动。

**修法**：按任务面板早就立的同一条纪律办——`hk` 指明别的卡型就让路（`if (hkQ && hkQ !== 'res') return`）。不新增机制，只是让资源台别再替别人消费。

顺带把键盘约定平移到鼠标：**Ctrl+单击 = Ctrl+Enter = 只定位**（此前鼠标侧根本没有"只定位"这条路）。**双击仍然不定义**——双击必然先触发两次单击，会把链接开两个 tab，与其加 250ms 单击延迟换"双击语义"，不如让鼠标和键盘各走各的即时路径。

## 二、AI 检索结果并回主列表（顺手修掉一个我自己引入的错）

上一版 AI 命中另列一组，导致**同一张卡在扁平列表里出现两次**：`syncIndexFromId()` 用 `findIndex` 永远命中第一条，你鼠标停在主组那行、按 Enter 执行的是 AI 那行——这就是"手势没按约定走"的观感来源。

改成：命中行**就在原来那个列表里**，顶到本组最前，挂「🤖 命中」徽标 + 模型给的理由；弱相关仍显式标「🤖 低置信」，不因为并组就藏掉。

**改的过程中我自己踩了一脚**：第一版只做了"排序"，结果**字面零命中的卡根本不在 `filteredResults` 里**——AI 唯一捞回来的那几张会被整批丢掉，等于把"换个说法也召得回"这个功能本身删了。R150 冒烟的 S3a 就是为这条而存在，它当场红了（14→11），补上"把命中的卡回查注入本组"才恢复 14/0。**这条教训写进断言**：并组不等于丢弃。

## 三、标签体检：空要有原因

`buildTagGovernJob` 是全站**唯一没有消毒账的 run 型场景**：四类静默 `return`，跑完只说"模型没有给出可采纳的建议"，说不出是真没建议还是建议被丢。

- 补 `drop = { noContract, notInUse, notInTree, self }` + `audit()`，空态直接点名，例：「模型没按契约给 merges/rehome」「5 行的标签在库里找不到（已剥 # 与次数尾巴后仍对不上），例：#项目运营→#产品开发」；
- 新增 `findTagIn()` 归一查表：剥 `#`/`＃` 前缀、剥「（8 次）」尾巴、全名与叶子名双口径——**判据变准不是变松**，命中后一律用回查到的**库里真名**落库；
- 蓝图迁移（`sanitizeBlueprint`）共用同一套归一，模型写 `#旧标` 不再整批丢；
- 提示词补一句「标签名原样回填：不要加 #、不要带次数尾巴、不要改写一个字符」。

**这条仍需你在真实网关上验一次**：mock 会乖乖按契约答，所以"补了账"只能证明账会显示，不能证明你那家模型的真实写法已被救回。跑一次看新写的空态文案即可。

## 七、色彩 / 布局 / 交互 / 详情 体检（你要的第 3 条）

跑在你的真实库上，自动量四把尺子（溢出、截断、点击区、对比度）+ 9 张截图。**本轮只记录，不顺手改**——版式改动必须你看着图拍板，我不在交付刀里偷做视觉改版。

**能确证的问题（按影响排序）**
1. **卡片视图 6 列太挤，内容被吃掉**：`.rc-desc` 摘要溢出 884~1517px（截掉 85~91%），`.rc-x-link.url` 每条链接被 ellipsis 掉 10~14%，**卡片本身横向溢出 178~216px**（最后一列标签顶出边框）。→ 建议：列数默认从 6 降到 4，或摘要行数封顶 2 行 + 卡片 `min-width` 兜底。
2. **列表视图标题溢出 417~420px**：`.rr-title` 没有 `min-width:0` 类的约束，长标题把动作条挤走。
3. **检索面板底部快捷键提示在 1440 宽下换行成三行**（"↑↓ 选 择 / 打开链 接 / 定位卡 片"）——你自己的截图里窗口更宽所以看不出来。→ 建议：提示条 `white-space:nowrap` + 窄屏降级成只留图标。
4. **点击区过小**（高度 <26px，Apple HIG 下界）：顶栏台图标 16×21、主题下拉箭头 4×11、设置页导航图标 18×22、调度台指标条里的「日/周」29×21 与 `cf-open`「待办 4」29×16。→ 这些是**可点的**（cursor:pointer），但命中率差。
5. **信息密度**：调度台顶部三块指标条（卡片总数/附件数量/最近更新）占掉约一屏 1/6，其中「附件数量 0」是零值仍占一格。

**量不出来、我不下结论的**：对比度。我的自动对比度脚本把 `color(srgb …)` 写法和半透明层叠算错了（一度报"白字白底 ratio=1"）。修正后仍有 `.rc-x-link.url`（10.5px 强调色链接）与 `cf-label` 报 3.85:1，低于 WCAG AA 的 4.5:1——**这条需要你真机眼看**，或者 R153 我把对比度检测修成可信指标再报数。**详情抽屉本轮没量到**（脚本没把它打开），列入 R153。
