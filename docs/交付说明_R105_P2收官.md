## 一、五条交付明细

### B4 · 好奇心培育降权（调度台）
- `.curio-teaser` 一行摘要默认折叠：`共 N 条 · 待探索 X · 探索中 Y`（实时派生；空态给 Ctrl+Shift+I 引导）；点击展开完整 `CuriosityPanel`；
- **不持久化**（同 R94-B2 口径：默认折叠管的是"每次进门的第一眼"）；
- **R67-F4 直达锚点自动展开**——用户带意图来（Ctrl+Shift+I/模块直达），不让 TA 再点一次。

### E2 · 策展台页签 >5 收起「≪ N」（App.vue 顶栏）
- `E2_TAB_MAX=5`：超过 5 个策展台，页签只显示前 5 + `.tab-overflow`「≪ N」指示；
- hover 指示展开全部（mouseleave 顶栏收起），点击亦可保持展开；**活动台恒可见**（前 5 之外时替换末位显示——"我在哪"不可丢）；
- 与既有 «/» 手动折叠正交（那个只在工作台页生效，语义是"只看当前台"）。

### D3 · 重复卡确认视图「仍然新建一张」（浮层）
- `showDupConfirm` 加第三按钮 → `saveCapture(forceNew)` 跳过 B5 查重；确认文案同步改写（不再说"只能定位不能重复收录"）；
- **Event 误传防护**：`__zy_cap_save__` 的点击监听原直接传函数引用——`addEventListener('click', saveCapture)` 会把 **Event 对象**当作首参 forceNew（truthy）⇒ 每次点击都跳过查重！改为箭头包装。整屏确认例外不变（R78-3 重指）。

### C3 · 浮层字号阶梯
- 定义五档 `--zy-fs-2xs(10.5) / xs(11) / sm(12) / md(13) / lg(14)`（自建 --zy-* 体系内，主题无关）；文本档字面量（10.5/11/11.5/12/12.5/13/14px，共 30 处）全部归并；**10-14px 字面量零命中**由否定断言把守；
- 搜索/采集输入态 17px 保留（提案许可）；15px 以上展示级尺寸（按钮/标题/图标）不入阶梯。

### W10 · 搜索纳入 link（拍板 2026-09-12：按提案原文纳入）
- `matchCard` 补 `r.link` 小写包含匹配；两台（资源台/策展台）与浮层（res blob 本就含 link）搜索范围自此完全统一为 title + link + description + tags + 自定义字段。
