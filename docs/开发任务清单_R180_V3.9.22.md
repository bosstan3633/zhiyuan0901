## 四、开发任务

### R180-A · 画像洞察

#### R180-A1 年度热力图铺满宽度

**现状与根因**

- `v2/src/newtab/components/dashboard/Heatmap.vue:340` 把列宽写死为 `repeat(${weekCount}, 12px)`。
- `v2/src/newtab/components/dashboard/dashboard.css:62/67/75` 同时写死 `grid-auto-rows: 12px`、格子 `12px × 12px`、`.dz-year { width: max-content }`。
- 结果：格子固定 12px，1440 页面右侧留下整块空白；放大窗口也不会变宽。

**实现要求**

- `.dz-year` 改为 `width: 100%`，首列星期标签固定，其余周列用 `minmax(0, 1fr)` 分配。
- 日格改为 `width: 100%; aspect-ratio: 1`，让列宽决定行高；不再写死 12px。
- 宽屏目标：1440 内容区下测得单格约 20-22px，7 行网格约 165-175px 高。
- 窄屏保底：≤800 时保持可读最小格宽并允许 `.dz-year-scroll` 横向滚动，不允许页面级横向溢出。
- 月份刻度、星期标签、未来日虚线必须随新尺寸对齐。
- `gridCells()` 继续使用 `yearCells` 的 `col/row/lv`，PNG / HTML 导出坐标与屏上同源。

**验收**

- 1440 实测：无右侧大块留白；单格宽 20-22px；热力带高约 170px。
- 1024 实测：仍铺满，不挤压成不可读小格。
- 800 实测：容器内横滚，页面无横向滚动条。
- 四主题截图均无错位；PNG / HTML 导出格数、坐标与屏上一致。

**判据影响**

- 重指 `99-recent.cjs` R172-21：原来锁 `grid-auto-rows: 12px` / 12px 格子，改为锁 `1fr` 列模板、`aspect-ratio: 1`、窄屏横滚。
- `105-v3921-compass-round2.cjs` R175-10 的导出同坐标口径保持不变。

- 画像洞察页所有项目详情入口传 `mode="modal"`；调度台主攻入口也复用同一模式。

#### R180-C1 新建战略目标弹窗

**现状与根因**

- `v2/src/newtab/views/CompassTree.vue:700` 的 `addDirection()` 直接创建「新战略目标」，切回项目塔后进入 contenteditable 改名。
- 用户点击后没有输入过程，容易误以为没有添加成功。
- 空态主行动 `v2/src/newtab/views/CompassTree.vue:1476` 也直接调 `addDirection()`。

**实现要求**

- 新建统一走中央 `Modal` 表单，字段：
  - 名称：必填，去首尾空格，空值不允许提交；
  - 期限：按现有 `Direction.term`，`远期 / 中期 / 近期`；
  - 状态：`进行中 / 暂停 / 归档`，对应 `active / paused / archived`。
- 确认后一次性创建并持久化；取消不落库。
- 创建成功后关闭弹窗，切到项目塔、清除筛选与断链态、滚动到新目标并高亮。
- 空态主行动改调同一个“打开新建弹窗”函数，不保留第二套创建逻辑。

**验收**

- 点击「＋ 战略目标」先出现表单；取消无新增。
- 名称空、纯空格时提交被阻止并给出明确提示。
- 三字段保存后重载仍存在，期限 / 状态回显正确。
- 新目标出现在战略目标模块并有短暂高亮。
- 空态按钮走同一个弹窗。

**判据影响**

- 重指 `21-b7b-empty.cjs` C5-1：空态主行动仍调同一入口，但入口从直接 `addDirection` 改为打开新建弹窗。

#### R180-C3 任务行删除改为解除指标关联

**现状与根因**

- `v2/src/newtab/views/CompassTree.vue:930` 的 `deleteTaskDirect()` 调 `softDeleteTaskToTrash()`，直接软删任务。

- `projectId`、`metricId` 为空，所有 `metric.taskIds` 不再包含该任务。

- 撤销 / 重新挂载路径不被破坏。

**判据影响**

- 重指 `99-recent.cjs` R175-1 / R175-2：删除断言翻转为解绑断言，补“任务未删除 + 回任务池 + 指标引用清空”正锚，以及“方向台软删函数不回流”负锚。
