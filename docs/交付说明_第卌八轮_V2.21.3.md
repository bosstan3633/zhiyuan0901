## 一、Bug 修复

### A-1 · TDZ 崩溃「Cannot access before initialization」——诊断增强（未复现，先装听诊器）

七项排查均未复现（排除模块循环 / 数据形状 / A2 导入形状），上次结论维持：疑似特定 UI 状态触发的间接 TDZ，最快路径 = 拿到崩溃现场堆栈。

本轮落地**错误自动落盘**，让下一次崩溃无需现场抓取：

- 新增 `src/shared/utils/runtimeError.ts`：`installRuntimeErrorHandler()` 捕获 window error / unhandledrejection，把 **错误消息 + stack 全文 + 时间戳** 写入 `zy_event_log`；
- `main.ts` 启动即挂载；App.vue 的 `onErrorCaptured` 链路不动（仍打控制台）；
- 设置 → 仪表盘 → **错误日志** 页可见并可一键复制/导出。

> 效果：再遇到崩溃，打开设置 → 错误日志，导出最后一条含完整堆栈的事件即可定位，不再依赖 F12 现场。

### A-2 · 全局检索「点 A 开 B」竞态（overlay-impl.ts）——已修复

**根因**（代码级确认）：R47 拼音字典异步就绪后，`runSearch` 会**整体替换并重排结果数组**；浮层结果行绑定的 `data-idx` 是点击瞬间的行序号——若用户恰好在"就绪重排"窗口内点击，`searchResults[idx]` 已指向另一张卡 → 点 A 开 B。应用内搜索（GlobalPopups）是 Vue computed + 模板直传对象，无此竞态，问题仅在内容脚本手写 DOM 浮层。

**修复两点**：
1. **点击按卡 id 解析**：结果行改为携带卡片真实 id，点击时先按 id 查找，找不到才兜底行序号（覆盖重排窗口）；
2. **拼音补跑冻结顺序**：就绪后的补跑不再重排列表，只在原结果上**追加**拼音新命中项，原有顺序与行位置不变。

### B-2 · 今日/本周增删**双口径**：新建 X · 导入 Y（口径已拍板）

之前「今日 +366」的困惑根源：导入的卡继承原 `createdAt`，按创建时间统计会把导入日误读为"今天新建了 366 张"。拍板口径 = **双口径并显**：

- 三卡模型新增可选 `importedAt` 字段；`mergeImport` 导入时给每张导入卡打戳（存量已导入卡不追溯）；
- 设置仪表盘动态条：`今日 +N` 旁出现灰色小标 **「导Y」**（今日导入数），`本周` 同规格；
- 明细列表：导入卡带 **「⇪ 导入」** 徽标，与手工新建一眼区分；
- 北极星「今日 +N / −M」下钻明细同步双口径。

### B-3 · 任务删除入口补全（三视图 + 详情降级）
