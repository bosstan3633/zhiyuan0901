## 一、本轮改了什么

### 1. 知源品牌页（画像洞察）

- 页头压缩到 30px 高，年度热力图前置，首屏不再先给指标数字。
- 画像时间轴中已完成的任务 / 选题统一切换为灰阶、删除线、灰状态点，不再与推进中的卡抢视觉。
- 卡片分析删除「你的方向状态」，重排为：卡片构成与使用 → 三件事是否持续推进 → 资源生命周期与高价值沉睡证据唤醒。

### 2. 任务 / 选题资源挂载

- 任务 / 选题详情不再在抽屉里做资源下拉筛选，改为打开资源卡池多选弹窗。
- 弹窗支持关键词检索、标签 / 说明 / 链接过滤、多选一次挂载；已关联资源禁用重复选择。
- 只写独立 `SupportLink` 关系表，不改资源卡或任务卡本体，遵守卡间零挂载。

### 3. 调度台卡片池

- 任务日历：过往落图卡片用虚线呈现；已完成卡灰阶降噪，正在推进的卡保持亮色。
- 卡池时间线：补左侧时间轴线与 18px 留白；完成任务灰阶 + 删除线，推进中任务保留状态色。
- 选题日历 / 时间线：只呈现选题卡自己的 `dueDate` 落图，不渲染任务卡、今日三件事槽位或历史镜像。

### 4. 今日三件事跨设备同步

- `dailyFocus` 作为主快照业务数据上传，槽位内容、顺序、完成态与 `doneAt` 整体保留。
- 云端清单按日期记录 `dailyFocus`，另一设备拉回后按日期与槽位 id 合并；单边修改时 B 设备结果与 A 设备一致。
- 同日同槽双边同时修改时沿用现有冲突策略：保留本机值，不静默覆盖。该边界本轮未做真实双设备实机验证。
