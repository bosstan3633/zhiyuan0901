## 一、功能清单（验收视角，逐条可核）

### F1 任务详情页结构（改造 R165-A 版）
- 头部三行：① 勾选+标题+关闭；② **AI 三入口独立行**；③ 状态 chip / 成熟度 / **子任务进度胶囊** / AI chip（「🤖 最近：X · MM-DD HH:mm」三入口共用）。
- 正文序：说明 → **↳ 子任务清单** → **🧭 资源支持** → 归属（项目→指标级联，保留）→ 优先级 segment → 链接整行+↗ → 标签 → 附件折叠 → meta。
- 页脚两钮不变（ArmDeleteButton + 完成并关闭）。

### F2 子任务清单管理
- 就地操作：回车加行 / contenteditable 改名 / 勾选完成（删除线+进度联动）/ × 删除（清单行非卡，无回收站）。
- 三视图呈现（**有子任务才显示，零子任务零噪音**）：
  - 卡片视图：卡底「`↳ 子任务 1/2`」胶囊 + 迷你进度条（done/all 宽度）；
  - 列表视图：行内胶囊，**点击就地展开清单**（不跳详情，可勾选）；
  - 看板视图：卡内小条「`↳ 1/2`」，拖拽语义不变（整卡跨列）。
- 头部进度胶囊与列表展开态同源同步（computed 反查 subtasks）。

### F3 AI 中央对照弹窗（新组件，三入口共用）
- 布局：居中（宽 ~920px，max 94vw/82vh）；头=标题+副标题（回显「执笔：X · 要求：Y」）+**角色下拉**+×；体=左「本卡现状」（标题/说明/标签/归属/子任务/资源支持六项，实时生成）｜右「AI 建议」逐条（勾选框+徽标+判词，弱相关默认不勾）；脚=说明文案+「放弃全部」+（拆解专属）「📝 步骤写进详情(N)」+「✓ 采纳…(N)」primary。
- 角色切换：下拉=内置专家+`aiCustom`（与设置页同源），含「⚙️ 管理专家」跳转；**选中即带当前指令重跑**（右栏 loading → 建议集更新）。
- 一次性指令：输入条+「↻ 带要求重跑」（回车同效）；只影响本次运行、不存专家设定；换角色时要求保留。
- 三态与互斥：入口钮各自 spin、全局一把锁；跑完落 AI chip；**勾选采纳才写库**（AI 不替决策边界不变）。
- Esc 先关弹窗再关抽屉（层级意识，不一次关两层）。

### F4 找资源支持（AI job + 关联表）
- `buildTaskSupportJob(taskId, subId?)`：投料=任务标题+说明+标签（子任务则带父题）→ 本地预筛候选（词面/标签打分取 top ~40，**排除已关联**）→ LLM 只排序+一句判词（`buildEvidenceJob` 同法）→ 评审行（高/中置信、无判词判弱不勾）。
- 采纳=写 `SupportLink`；任务本体/资源本体零改动。
- 任务侧「资源支持」区：行=资源标题+判词+↗；**点行=打开资源链接**（`toOpenableUrl` + `recordResourceOpen` 计热度）；×=解绑（只删记录）；底部搜索框手动关联（from=manual）。
- 子任务行挂「🧭N」徽标（subId 定位的关联计数），点开=该子任务关联列表。
- 资源侧「支持的任务」反查区（只读，含子任务行；解绑入口留任务侧）。
- 删除卫生：任一端软删→显示过滤、恢复即回挂；物理删→purge 记录（`metric.taskIds` 同法）；撤销窗口随卡。

### F5 AI 补全（任务侧新 job）
- `buildTaskEnrichJob(task)`：对照现状找缺项——验收标准（追加进说明，已填不覆盖）/ 建议标签（词表复用 canonicalTagsOf 归一）/ 归属建议（判弱默认不勾）/ 估时提示（仅展示不写字段）。
- 采纳=直接写本卡字段 + 落 `aiTouchedAt`；弹窗左栏实时反映现状。

### F6 数据层
- `TaskCard.subtasks?`（可选段零迁移）、`AppData.supportLinks?`（可选段）、`fromCuriosityId` 删除（ResourceCard/TaskCard 两处 + cards.ts 两处 + 红线注释）。
- 合并：`supportLinks` 走 `mergeByIdArr`（无 updatedAt 实体段先例）；`subtasks` 随卡 LWW 骨架内字段，不动卡片合并器。
- 导入兼容：旧包无 supportLinks=空段；含 fromCuriosityId=静默剥离（repository stripKeys 扩一键，R165-B 同法）。
