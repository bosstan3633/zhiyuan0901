# V4.2.1 需求盘点与开发任务

> 版本：V4.2.1  
> 日期：2026-11-10  
> 基线：V4.2.0（`main` / `023395f`）

## 一、需求口径

### 1. 云同步成功不能被子回执误报

- 上传或拉回已经完成时，先落“本机与云端一致”，再生成本次同步明细。
- 辅助明细缺字段、载荷丢失或生成失败时，只把对应行降级为只读，不把主同步误报成失败。
- 状态灯不得因为辅助明细失败从绿色切成红色断线；用户无需再点一次同步才能恢复。

### 2. 云同步只收业务数据

- 进入云端：资源卡、任务卡、好奇心卡、Inbox、策展台及其节点 / 分支顺序、方向台项目 / 指标、今日三件事。
- 留在本机：主题、页面布局、排序筛选、右侧抽屉宽窄、其他 `UIPrefs`。
- 保存界面偏好不得增加“本机待上传”的序号，也不得触发自动同步。

### 3. 今日三件事复制

- 每个有效计划位提供“复制”。
- 固定句式：`今天计划推进{项目}项目下{指标}成功指标的{任务}任务`。
- 缺少有效项目或成功指标时禁用复制，并在悬停说明原因，不生成半截句子。

### 4. Inbox 行内操作

- 完整 Inbox 列表行内提供：转任务卡、转好奇心卡、转资源卡、打开原链、编辑、删除。
- 调度台五条预览提供：三种转化与打开原链。
- 编辑、删除只在完整 Inbox 页面提供，避免预览区承载过多操作。

### 5. AI 助手成功态

- 拉取模型列表成功或连接验证成功显示绿色成功态。
- 只有真实错误显示红色错误；修改 API 地址、API Key 或模型后清空旧测试结果。

### 6. 采集资源卡幂等

- 同一条采集只生成一张资源卡。
- 旧记录缺源 URL、标签或描述时，优先复用旧卡并补齐，不因标题相同新建第二张无链接副本。
- 判重只认采集标识，不按标题粗暴合并；不同采集的同名资源卡仍可共存。

### 7. 策展 HTML 证据图库

- 中心论点关联卡可在导出 HTML 中打开原链接。
- 中心论点附件、分支节点附件进入导出文件。
- 同一节点多张图片可打开大图并前后切换，附件图库独立于其他节点。
- ZIP 模式使用相对附件路径；分享文件不注入可执行脚本。

### 8. 同台多节点重复挂载同一资源卡

- 同一资源卡可分别挂到同一策展台的不同节点。
- 判重范围是“本台 + 本节点”，不是整个策展台。
- 同一节点重复挂载保持幂等；选择器只把当前节点已挂载的卡置灰，并标记“已在本节点”。

## 三、本轮不做

- 不改变三卡模型、六层方向模型或资源镜像白名单。
- 不让资源卡、好奇心卡、愿景、使命产生新的挂载关系。
- 不把普通卡片附件或 AI 凭据上传云端。
- 不把同步历史放回顶栏；历史仍只位于云同步面板和设置中心。

## 四、验证边界

- 真实 Supabase 后端尚未完成端到端联调。
- 双设备真实冲突尚未在两台实体设备制造并验证。
- 实体手机尚未测试；`390px` 仅为响应式视口。
- 性能数据只代表本机桌面 Chromium。
