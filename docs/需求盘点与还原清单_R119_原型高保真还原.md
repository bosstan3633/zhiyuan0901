## 2. 结构性根因（3 条，决定改动方式）

1. **令牌命名错位**：原型 `--radius-sm:6 / --radius-md:8 / --radius-lg:12`；实现 `--radius-xs:6 / --radius-sm:8 / --radius:12`。原型还有 `--accent-border: rgba(94,106,210,.28)`，实现**全库零定义**，改用 `color-mix(accent X%, border)` 临时替代 → 所有「强调边框/主攻框」偏色（方向树主攻框、资源卡 hover 边等）。
2. **类名体系整体重写**：原型类名（`anchor-vm-bar` `focus-stream-bar` `goals-3col-grid` `tree-sidebar-nav` `tree-metric-branch` `res-compact-card` `thesis-hero-banner` `pyramid-*` `mirror-res-card` …）在实现中**零命中**。意味着不是改名，而是另一套骨架 —— 还原需按原型结构重建 DOM，不能靠改样式。
3. **主题制差异**：原型是**单一浅色令牌集**（`--bg #F8F9FA` / `--surface #FFF` / `--text #191C1E` / `--accent #5E6AD2`），产品是 **4 套主题**且默认 `linear` 偏深色。→ 见 §5 决策 1。

## 5. 四个决策点（已拍板 2026-09-16）

| # | 决策点 | 拍板结果 | 落地口径 |
|---|---|---|---|
| 1 | **主题口径** | **保留 4 主题 + 默认切浅色** | 以原型令牌值重建「浅色基线」并**设为默认主题**（第一眼即原型）；其余 3 主题按**同一套语义比例**映射（同一 accent 混比、同一圆角/间距刻度）。禁止新增主题。 |
| 2 | **管理能力取舍** | **视觉对齐 + 能力收纳** | 版式 / 字号 / 布局 / 配色**严格按原型**；原型的静态 mock 处，产品既有的管理能力（拖拽排序 / 批量 / 删除 / 多筛选 / 空态 / 管理按钮）**一个不删**，一律收进 **hover / 右键 / ⋯ 菜单**，不占主视觉。 |
| 3 | **交互语义** | **保持现状** | 本轮**只改视觉**（字号 / 布局 / 配色 / 结构骨架），**不动交互语义**：今日三件事单击仍=选中联动；资源卡单击仍=开详情抽屉、双击=打开链接。 |
| 4 | **交付批次** | **一轮做到底** | R119 一次性交付 4 台面 + 门禁全绿 + 出包，沿用既有节奏。 |
