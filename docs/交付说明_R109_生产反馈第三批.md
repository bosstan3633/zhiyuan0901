## F12-a · 资源台全景修复（用户现象：策展台内容出现在设置→资源台全景）
- **根因**：`panCards` 分类视图分支与 `panCountByCat` 计数均按 `categoryId` 裸匹配——无 `workspaceId` 过滤
- **修复**：两处补 `workspaceId` 收紧——策展台卡不得混入资源台分类视图
- 树头措辞修正：`全景 · N 策展台` → `全景 · 资源台`（panHubWss 恒为单台）

## F12-b · 分类软删（用户拍板：分类软删即可，不用立项）
- `Category` 加 `deletedAt?: number`（可选字段，零迁移）
- 三条链路统一软删：删除分类 / 删除策展台（分类随台）/ 合并重复分类（被合并方）
- 回收站新增「📁 分类」分区：恢复 = 清 deletedAt；其下卡片不自动归位（仍在待分类/回收站）
- 树/全景/导入 ensureCat 均排除软删分类（wsCats / panTree / panTotalCats / ensureCat 四处同步过滤）
- **限制**：恢复分类后其下卡片不自动归位（需手动归位）——弹窗内黄字提示
