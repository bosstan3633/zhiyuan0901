## 三、REQ-031 性能调优明细（8 个瓶颈全量处理）

| # | 瓶颈 | 改动 | 量级收益 |
|---|---|---|---|
| P-031-1 | 搜索关联 O(n²) 查找（ws/cat find + 任务项目嵌套双循环 + 工作台每台全量 filter） | `buildSearchMaps()` 一次遍历构建 `wsName/catName/projName` Map + `wsCount` 卡数累加，`collectResults` 内全部 O(1) 查找 | 千卡每键 ~3 次全量数组扫描 → 1 次构建 + O(1) |
| P-031-2 | 渲染二次 O(n²)（每组 filter + indexOf） | `renderResults` 单次 `for` 按 type 归桶（buckets 4 数组），索引直接 `offset + j` | 结果 100 条 ~5 组 × 2 次全量 → 1 次 |
| P-031-3 | 每键重建计数与 Tab DOM | `countCache` 计数缓存（仅 onChanged 数据变更失效）；`renderTypeTabs` 按 `data-search-type` 判断，类型不变只更新 `.cnt` 文本不重建 DOM | 每键 4~5 次全量 filter + 整行重建 → 0 |
| P-031-4 | escapeHtml 用 createElement | 正则白名单替换（`& < > " '`） | 单次调用 ~10 倍提速 |
| P-031-5 | 应用内搜索无防抖 | `searchQuery` 即时回显 + 150ms 防抖写入 `debouncedQuery` 驱动 `filteredResources` | 快速键入不再每键全量 filter ×2 + 分区 computed |
| P-031-6 | persist 后整页重渲染 | `repository.ts` `saveData/saveDataNow` 前置 `selfWriteAt = Date.now()`；`app.ts` onChanged 回调 `isSelfWrite(Date.now())` 短路，跳过 `syncCache` + 全树替换（本地 listener 已同步新引用）；外部写入（popup/content）仍正常全量同步 | 每次保存一次全页重算 → 0 |
| P-031-7 | 定位串行等待（N×600ms） | `handleLocate` 改 `Promise.all` 并行询问所有标签页 + 单页 150ms 短超时 + 取首个命中 | 3 标签页最坏 1800ms → 150ms |
| P-031-8 | 采集去重全量扫描 | `openCapture` 打开时构建一次 `capUrlMap`（url→resource），`saveCapture` O(1) 查重，新增卡片增量写入 | 千卡保存动作全量扫描 → O(1) |
