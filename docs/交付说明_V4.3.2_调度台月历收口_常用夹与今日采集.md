# V4.3.2 交付说明

> 版本：V4.3.2
>
> 日期：2026-11-14
>
> 基线：V4.3.1（`main` / `4163fe2`）

## 一、交付结论

V4.3.2 在 V4.3.1 的月历排期基础上完成调度台日常使用链路收口：

1. 待排期任务池只保留“未完成且未排期”任务，并与月历严格等高、独立滚动。
2. 月历补齐年月选择、四色状态、日详情浮层层级与拖入 / 取消排期闭环。
3. 卡片池增加今日新增角标、二级页面入口和资源常用文件夹模块。
4. “今日采集”成为固定在资源页第一位的自动虚拟夹，只筛选当天新增资源卡。

移动采集 PWA 与 PC Inbox 继续保持退役，浏览器采集直接进入任务、好奇心或资源卡池。

## 二、月历排期

- 左侧 Task Pool 只列 `status !== 'done'` 且没有 `dueDate` 的任务。
- 已排期任务从左侧移除，只出现在月历对应日期。
- 任务拖入日期即写入既有 `dueDate`；取消排期只清空 `dueDate`，任务回到左侧。
- 左侧和月历共用 `clamp(620px, 68vh, 730px)` 高度，左栏内部滚动。
- 月历标题可打开年月选择器，支持切换年份、选择 12 个月、上下月与“今天”。
- 任务状态色：
  - 已完成：绿色；
  - 今天执行：橙色；
  - 未来执行：灰色；
  - 逾期未完成：红色。
- 日详情从私有 Teleport 切到共享 `Modal.vue`，浮层层级与遮罩统一。
- 月历不承担删除；删除仍只在卡片池二级界面完成。

## 三、卡片池与常用夹

- 三池页签增加今日新增角标：
  - 0 不渲染；
  - 99 以上显示 `99+`；
  - 使用低强调 accent-light，不使用红色。
- “进入卡片池”和二级页内部切换均携带 `fresh=1&freshAt=...`。
- fresh 模式默认列表视图，并按最近入池时间倒序。
- 资源页改为常用文件夹模块：
  - 第一位“今日采集”；
  - 后续为现有常用夹、数量和最多两张预览；
  - 点击今日采集进入 `/deck/resource?fresh=1&freshAt=...&today=1`。
- `PoolCardsPanel` 增加 `today` 虚拟筛选，不改写资源真身。
- `ResourceFolderDrawer` 支持从首页指定文件夹打开并滚动定位。
- 今日新增统计使用本地自然日边界，跨日自动切换。
