# 交付说明 · V4.7.6 卡片节奏与每日三件事

> **版本**：V4.7.6
> **发布收口**：2026-11-26；最终复验 2026-11-27
> **交付形态**：Chrome MV3 扩展源码 + 桌面安装目录 + ZIP

## 一、本批交付

### 1. 卡池时间线与完整详情

- 任务、选题、好奇心三个卡池新增卡片流时间线，只读取真实新增、标题 / 描述 / 标签修改与状态推进，不伪造历史。
- 时间线沿用当前筛选结果，隐藏已删除卡片及其历史记录。
- 单击卡片延迟 260ms 打开对应完整详情；双击直接打开链接：任务 / 选题读 `link`，好奇心读 `sourceUrl`。
- 空链接只提示“该卡还没填链接”，不回落详情。
- 画像时间轴中的四类卡也改为打开完整详情，不再使用字段删减的摘要抽屉。

### 2. 任务列表与看板按项目分组

- 任务列表、任务看板均支持“按项目分组”，并保留“未关联项目”组。
- 分组只改变阅读结构，不改变任务归属、拖拽改归属与既有筛选链路。

### 3. 画像洞察重构

- 首屏顶部改为年度卡片热力，直接呈现用户过去每日的卡片节奏。
- 热力计分覆盖：新增卡片、修改卡片、浏览 / 调度、状态推进、今日三件事完成、资源关联、成果交付。
- 普通浏览计入热力；同一卡片同类动作当日只计一次；删除与取消不加分，历史无记录不补造。
- 默认台面仍为时间轴；原“热力图”Tab 改为“卡片分析”，集中产品使用状态、三件事分析与资源生命周期 / 高价值沉睡唤醒。
- 时间轴新增“三件事”Tab，只投影真实每日任务 / 选题槽位；“浏览器快捷键”入口从时间轴移除。

### 4. 日历历史三件事

- 过往日期继续以卡片形式留存今日三件事，不因日期过去而消失。
- 同一任务 / 选题连续多日出现时：过往以**虚线卡**呈现，当下以**实线卡**呈现。
- 历史卡可单击打开完整详情，也可取消该日落图；取消只写 `focusHistoryHidden`，不清 `dailyFocus`，不改原卡当前计划。
- 历史卡不可拖拽、不可改状态；今日仍沿用既有取消 / 替换链路。
- 隐藏记录支持云合并：不同日期 / 同日不同槽自动并集，同日同槽异值保留本机并生成冲突。

### 5. 调度台页头与主攻项目

- 移除大标题、“AI 推荐今日重点”等旧页头入口。
- 顶部改为紧凑“当前主攻”模块，最多展示三个主攻项目；项目详情右侧滑出，含成功指标与任务。
- 主攻上限统一为三个，存量超出项目不被强制裁剪；画像卡片分析、方向树提示与内置手册同步到三个。

### 6. 知源蓝与视觉基座

- 四套主题主行动色统一为知源 Logo 蓝；原 `oppo` 主题对外更名“知源蓝”，保留 OPPO 式清透材质、圆角与留白语言。
- 统一表面、圆角、页边距、焦点与轻阴影令牌；保留减少动态效果设置。
