### A1 · 卡片元数据补全（单卡 + 批量）

- **单卡**：资源详情抽屉 footer 新「🤖 补全」→ 建议（标签/描述/分类）→ 采纳**只回填编辑表单**，用户核对后自行保存（双重确认）；描述仅在为空时填充；
- **批量**：标签管理右列「全选本标签」旁新「🤖 批量补全(N)」→ 逐卡建议 → 勾选采纳才落库（一次 persist）；
- ★踩坑修复备案：RDD 被 App.vue **静态挂载**，首版静态 import 把 248KB AI 栈卷进入口 chunk——已改 `defineAsyncComponent` + 点击时 `import('@/shared/ai/*')`，并把这个教训升级进 R134-2 断言锁死；R113-2 孤儿组件守卫同步扩识别 async 常量注册。

### A2 · 沉睡资源唤醒

设定阈值天数（默认 90，14–365 钳制）→ 投影沉睡卡（未置顶未星标且超期未打开）+ 进行中任务 + 活跃战略目标 → 模型逐卡 verdict（revive/archive/keep + 理由 + 用法提示）→ 采纳语义：**唤醒=置顶回视野、归档=送回收站（可反悔）**、保留=不动。

### 深度诊断 v0 · 两专家会诊

「一键诊断」按勾选专家**逐员调用**（job.run 接管多轮调用与进度回显：⏳→✅）：目标管理专家（链对齐/期限压力/孤儿工作）+ 知识管理专家（分类法/标签失衡/沉睡错位）→ findings（severity/title/detail 证据/suggestion）→ **只读会诊不自动写库**（采纳按钮不出现）。
