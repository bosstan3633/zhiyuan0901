## 二、五项逐条

1. **R173-1 运行错误留痕真断链** ★真缺陷 —— `shared/utils/runtimeError.ts` 的 `source` 三态补 `'render'` 并导出 `recordRuntimeError()`；`App.vue` 的 `onErrorCaptured` 在置 `renderError` 前显式落盘；徽章 0 藏 >0 现；`GlobalSettings.vue` 的 `p === 'dashboard'` 分支补 `refreshErrorCount()`。**窗口监听仍最早注册**（`main.ts` 顶部，TDZ 崩溃多发于模块初始化期）。**复测追加**：光有「换页刷新」不够——同文档 hash 切换不会触发 `watch(activePage)`，探针实测「写入 1 条 → 徽章仍空」⇒ 补 `subscribeErrorLog()`（订阅 `chrome.storage.local.onChanged`，落盘变化即回填条数），`onUnmounted` 退订。
   - **★A4 判据构造坑**：原打算塞一张缺字段的资源卡逼出渲染崩溃 —— **打不出来**：`repository.ts` / `migration.ts` 对每个数组字段都有 `Array.isArray` 兜底归一化，脏数据会被静默修好（这条同时也说明老判据是空转的）。改用**打包后懒加载 chunk 缺失**（拆包 / 杀软删文件 / 更新中断都会遇到）：临时改名 `GlobalPopups` 产物 chunk → 动态 import 失败 → Vue 异步组件错误处理 → `onErrorCaptured` → 落盘 `source=render`，全屏兜底屏接管并有「🔄 重试渲染」出口。
2. **R173-2 复盘弹框补「选角色 + 一次性提示词」** —— `narrateReview(rep, cfg, opts)` 新增 `NarrateOpts`：`personaId` 走 `chainPersonaText()` 进系统消息「【执笔视角】」，`directive` 进用户消息「【用户本轮指令】」。弹框加 `.dz-rpt-ctl` 行（角色下拉 + 指令输入 + ↻ 重新生成），角色列表复用 `allPersonas()`（与全站同一真源，不另起一份）。**红线不变**：AI 只续写洞察/建议，数字白名单越界整段弃用。
3. **R173-3 零动作判词失真** —— `acts === 0` 先分流：唯一主张 `CLAIM.zero='本期没有任何动作记录'`，结论与论据 `rel` 同源（「以上统下」闭环是构造保证，不是祈祷），并明说"这不是停滞、也不是偏斜，是记录没进这里"，建议给「先收一张卡进来」。原句「0 个活跃日…整体在使命射程内、有在推进」不再可能生成。
4. **R173-4 热力图一行 12 月** —— 12 月块同排（判据：12 个 `.dz-mb-h` 的 `top` 全等）、月块头只留月名（`span:nth-child(2)(3)(5)` 隐藏）、格间距 3px→2px、悬停放大 1.6 倍；1440/1280/1100 三档页面横向溢出 ≤1px。**复测追加**：1100 档热区仍溢出 15px，量出来是 `.dz-wk` 星期行（7×9px 汉字 + 6×2px 缝 = 需 75px，该档月块只有 66px；`aspect-ratio:1` 的格子能缩，汉字不能）⇒ 扫描 1000→1440 取到真实断点（1280 档月块 75.5px 是最小装得下的档，1240 档仍差 3px）：`@media (max-width:1279px) { .dz-wk { display:none } }`。该档格子只剩 8px、字母本不可读，日期仍在每格 tooltip 与「点格子看那一天」里。
5. **R173-5 概览带只留指标 + 说明悬停** —— 只留数字 pill（长括注挪 `title`），人话总结进 `.dz-ov-tip`。**顺手修掉两条本轮实测出来的版式坑**：
   - 人话块从流里拿掉后，`.dz-ov-meta` 会抢走整行把 5 张存量卡挤成 100px 竖列 ⇒ `flex: 1 1 100%` 让它独占第二行（区块高度 386px → 190px）。
   - 浮层锚在**药丸**上时，窄屏（1100）药丸落到行首会把 460px 浮层顶出左边界 388px ⇒ 改锚 `.dz-ov-meta`（`position: relative`）+ 悬停期间放开 `.dz-sec` 的圆角裁切（`.dz-tip-open { overflow: visible }`）。
