## 二、★ A6 挖出的真缺陷：六种浅底色没有暗色覆盖

```css
/* 改前 —— 六条全在 @media (prefers-color-scheme: dark) 覆盖块之外 */
.zy-ri-icon.res{background:#E9F1FA;}        /* 资源蓝 */
.zy-ri-icon.task-done{background:#E4F2E8;}  /* 完成绿 */
.zy-ri-icon.task-doing{background:#FBF1DE;} /* 进行黄 */
.zy-ri-icon.task-todo{background:#EFEFEA;}  /* 待办灰 */
.zy-ri-icon.curio{background:#F9F3E4;}      /* 好奇黄 */
.zy-ri-icon.ws{background:#E9EAF6;}         /* 策展台紫 */
```

R77（A1）给浮层做了明暗两套变量，但**这六种图标底色漏在覆盖块外** ⇒ 宿主是暗色时，
这六个浅色块会一个个突出来。所以 A6 不只是"颜色多"的审美问题，**是暗色模式的真缺陷**。

同类还有 **4 处**：

| 位置 | 内容 | 缺陷侧 |
|---|---|---|
| `866` / `913` | 内联 `color:#BFC3C9`（分组计数） | **明色**：浅灰在白底几乎看不见 |
| `1339` | 重复卡确认图标内联 `#FBF1DE / #8A5A00` | **暗色**：浅琥珀底突出来 |
| `222` | `.zy-saved-icon` 默认 `#E4F2E8 / #2E7D42` | **暗色**：浅绿底突出来 |

采集面板的 `.zy-cap-icon.res / .curio` 也是同款写死浅底，一并处理。

### 处理

```css
/* 类型/状态一律靠 iconText 的形状区分，底色统一中性 + 1px 边框（明暗两套都需要一条边界） */
.zy-ri-icon{…;background:var(--zy-bg-3);border:1px solid var(--zy-border);}
```

`iconClass` 与 `iconText` **一字未改** —— `📄 / ✓ ◐ ○ / 💡 / 📁 / 🗂 / 📦` 的形状区分仍在，**信息零损失**（`R93-2` 把守）。

**徽标三档**（新增 `--zy-warn` / `--zy-ok` 两个令牌，**明/暗各一套**，色值取自 `tokens.css` 的 apple/linear 两套，不臆造）：

| 档 | 成员 | 样式 |
|---|---|---|
| **中性** | `ws` `cat` `ws-badge` `curio-status` `prio-mid` `status-todo` | `--zy-bg-3` + `--zy-text-2` |
| **强调** | `status-doing`（正在推进） | `--zy-accent` 淡底 + accent 字 |
| **警示** | `prio-high`（需要优先处理） | `--zy-warn` 淡底 + warn 字 |
| 中性+淡出 | `status-done`（终结态） | 中性 + `opacity:.6`（对齐 `.archived` / `.cf-item.done` 既有口径） |

## 三、★ A5：对提案的一处偏离（需裁决）

**提案原文**（`04-16:89`）：「二选一。推荐**保留 chip**，Tab 行改为"有输入时才出现的轻量提示行"。」

**勘验发现：按字面实现会砍掉一个真实用法。**

浮层空态（`!lastQuery && searchType === 'all'`）的内容是
**四个「打开 X 页面」的快捷操作 + 近期最常用 Top 8** —— **没有任何类型浏览入口**。
⇒ 无输入时隐藏 Tab 行，**"打开浮层 → 直接点『任务卡』→ 浏览全部任务"这条路径就断了**。

**本轮做成反向去重**：

| 控件 | 改前 | 改后 |
|---|---|---|
| Tab 行 | 常驻，6 个带底色的块 | **常驻，但轻量化**（一行纯文字 + 计数，当前项下划线 + 文字色） |
| chip | `searchType !== 'all'` 时显示 | **再加一个条件：必须有输入**（`lastQuery` 非空） |

理由：**真正的冗余发生在无输入时** —— 那时 Tab 行就在眼前、其 active 态已经说清了当前类型，chip 是**第二份**。
有输入时相反：输入框内容长、注意力在框内，chip 紧邻输入框最能说明「当前只看 X」。

**能力清单（零损失）**：

| 场景 | 类型显示 | 切换 | 复位 |
|---|---|---|---|
| 无输入 + 全部 | Tab 行 active=全部 | ✅ 点 Tab 行 | — |
| 无输入 + 已选类型（Tab 键指令设的） | Tab 行 active | ✅ 点 Tab 行 | ✅ 点「🔍 搜全部」 |
| 有输入 | chip（贴输入框）+ Tab 行 active | ✅ 点 Tab 行 | ✅ chip 的 × |

> **回退方法**：`updateChip()` 的判据改回 `searchType === 'all'`，并把 `.zy-type-tabs` 的显隐改为由 `lastQuery` 控制。
> 两处都是单行改动。
>
> ⚠ **另一处刻意不动**：Tab 行轻量化时**不引入强调色**。R77（C2）已把此处定为中性
> （强调色只留主按钮 / 焦点环 / 当前选中行），本轮不推翻既有决策 —— 当前项用**文字色 + 字重 + 下划线**标出。
