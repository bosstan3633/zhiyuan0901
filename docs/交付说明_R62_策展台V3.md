## 二、逐项语义

### 1. 五指标条（仅策展台）
- **🏛 策展主题**：thesis 卡标题；点击打开论点卡详情；未设立时提示引导
- **📊 卡片总数**：台内原生 + 镜像；下钻 = 按分类树明细（缩进 + 直属卡数，点击定位分类）
- **🔀 来源构成**：台内 / 镜像 双数字；下钻 = 两栏明细，镜像行点击 → 定位资源台源卡
- **📎 附件数量**：下钻 = 附件明细（卡名·附件名·大小·时间）；图片行内预览、HTML/PDF 走 openHtmlAsset 新标签打开（复用 AssetManager 语义）
- **🕐 最近更新**：下钻 = 更新流水 Top 30，点击打开卡片

### 2. 主题卡（isThesis）设立与字段组
- 设立入口：**右键台内卡 → 🏛 设为中心论点**（每台仅一张，设立即替换旧论点）；右键已设卡 → 取消；金字塔根节点 ✕ 亦可取消
- 镜像卡不可作为本台论点（引用回落语义）
- **thesis 字段组**（62-3）：`FieldConfig.thesis?: FieldDef[]`，默认字段 = 论点(标题)/论证(描述)/标签/创建时间/链接(隐藏)/附件；设置 → 卡片与字段 → **🏛 策展主题卡** 独立设计页，增删改与三卡同源（FieldEditor）
- 老数据归一化：加载期缺 thesis 组幂等补默认；导入合并兼容（缺组先补再按 key 并集）
- 卡片/列表视图渲染分流：isThesis 卡走 thesis 组字段序，其余走 resource 组

### 3. 金字塔视图（⬡ 页签）
- **L1 根** = 中心论点卡（渐变高亮卡，单击详情 / 双击打开链接）；无论点时显示设立引导
- **L2 起** = 分类树按深度铺开（每层一行，节点宽度自适应）；节点 = 头部（名称+计数+⟨⟩+⋯）+ 卡片 chips 区
- **拖拽**：
  - 卡片 chip → 节点 = 挂入（`canMountInNode` 校验，非资源卡拒绝；镜像卡 = moveMirrorTo 只改投射落点）
  - 节点头部 → 另一节点 = 上沿 25% 同级排序、其余挂子级（childIds 防环 + `levelOf+heightOf>4` 层级校验）
  - 节点 → 根区 = 升为一级（卡片拖到根区 = 提示不收）
- **⟨ ⟩** = 同级前移/后移；**＋** = 新建子节点（≤4 级）
- **节点 ⋯ 菜单 6 项**：🌳 新建子论点 / 🌿 新建同级 / 📤 从资源台镜像分类（弹窗选资源台分类，mirrorCategoryToBoard，重复镜像拦截）/ 🗂 打包所选卡片入此节点（批量栏同款）/ ✎ 重命名 / 🗑 删除节点（卡片回待分类，确认池）
- **批量栏新增「🗂 打包成节点」**：输入节点名 → 建节点 + 所选原生卡归入（镜像卡提示不移动）
- 左侧树 ↔ 金字塔联动：树点击选中分类，金字塔对应节点闪烁；下钻抽屉点分类同样联动

### 4. 左树层级色点
L1 绿（accent）/ L2 蓝 / L3 紫 / L4 金，一眼分层。

## 六、真机验收路径建议

1. 加载 dist → 进入任一策展台：hero 下出现 5 指标条；逐卡点击验证下钻
2. 右键一张台内卡 →「🏛 设为中心论点」→ 切 ⬡ 金字塔：根节点出现论点卡
3. 金字塔：卡片拖入节点 / 节点拖到另一节点挂子级 / ⟨⟩ 调序 / 拖到根区升一级 / 超深拖拽被拦
4. 节点 ⋯ →「📤 从资源台镜像分类」→ 选资源台分类 → 镜像卡出现在节点内（📡 徽标）
5. 批量管理选 2-3 张卡 →「🗂 打包成节点」→ 输名 → 卡片归入新节点
6. 设置 → 卡片与字段 → 🏛 策展主题卡：增删自定义字段 → 回策展台看论点卡渲染变化
7. 右键卡片：整份菜单（打开/复制/移动/置顶/论点/删除）应正常弹出
