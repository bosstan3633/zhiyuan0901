## 二、三条值得记的处置经验

### 1★ 生命周期留宿主，展示搬进来（`about`）

`refreshStorage()` 与 `subscribeSaveError(...)` 在宿主 `onMounted` 里调用并返回取消订阅函数（REQ-038 备案，宿主实例可能被路由复用）。
**若把订阅一并搬进子组件**，`v-if` 切页会销毁重建 ⇒ 订阅反复退订重订、卸载钩子归属改变。

⇒ 判定标准：**谁拥有订阅，谁就拥有生命周期**。子域只接收 props、把「已处理」以事件抛回。

### 2★ 共享符号走 props，且要在文件头说清"为什么这次没搬"

`runtimeVersion` 被 changelog / about / extension **三个子域共用**，`formatBytes` 被 about / export 共用。
把它们抽成 `settings/shared.ts` 是对的，但那是**另一个决定**——藏在一次搬移里会让评审者看不出这是共享符号而非本子域私有。

⇒ 本批保持定义留宿主、props 传入，「是否上提」留作独立一笔。

### 3★★ 搬样式一律脚本切原文，禁止手抄（**本轮血的教训**）

本轮**连续两次**凭印象写错 CSS：

| 位置 | 我写的 | 真值 |
|---|---|---|
| `.gs-manual-open` | outline 按钮 + `inline-flex` + `gap:6px` | accent 实心按钮，**无** inline-flex、**无** gap |
| `.gs-about-row` | `align-items:flex-start; gap:20px; padding:11px 0` | `justify-content:space-between; padding:8px 0` |
| `.gs-about-name` | `var(--fs-title)` | 字面 `16px` |
| `.gs-about-motto` | （漏了） | 含 `font-style:italic` |

四次错误**都是"编译通过、判据全绿、只有像素知道"**——因为死 CSS 普查要 6 分钟实拍才跑得到。

**而后三个在补了程序化搬移后自然消失**（用脚本切原文，人只核对边界）。
⇒ 纪律：**搬样式 = 脚本切原文，人手只负责核对边界，不负责重打内容。**

### 4★ CSS 注释里写 `/* 某注释 */` 会提前闭合注释块

搬移时我在注释里引用了宿主原注释 `` `/* 关于 */` ``，那个 `*/` **当场闭合了 CSS 注释块**，后续注释内容被当 CSS 解析 ⇒
`vite build` 失败：`Unknown word '.gs-about-row'`。
两个新组件同时中招（about / changelog）。

⇒ 症状是 build 失败（不是静默），属于**好现象**；但它证明了一件事：**这类错误只在 build 时暴露，而 build 不在回归链里**。

## 四、★ 实拍工具本身在这一轮暴露了四个盲区

`v2/scripts/shoot-settings-prototype.cjs` 是本轮新写的量具，它在自证过程中踩了四个坑，**每一个都会让图骗人**：

| # | 盲区 | 症状 | 修法 |
|---|---|---|---|
| 1 | `--only` 补拍时**整份覆盖**索引 | 16 张塌成 1 张，图都在只有索引丢了 | 读既有 JSON 做并集 |
| 2 | 只改 `location.hash` 不重挂载 | 正文对、**左栏 active 停在上一子域** | 改走**点击左栏**（用户真实路径） |
| 3 | 整页 `goto` 重载 | 顶栏「调度台」active 在两跑间不一致（62px） | 同上——点击同时解决 2/3 |
| 4 | Playwright 指针停在 (0,0) | 顶栏首项 hover 高亮被拍进去 | 每张截图前 `mouse.move` 出视口 |

★还有一个更隐蔽的（**假信号套着假信号**）：
修 ②③ 后，等就条件仍写着"hash 必须等于 `#/settings?page=xxx`"，而点击路径下 hash 恒为 `#/settings`
⇒ **跳过 0 张** ⇒ 新旧两张都还是上一次的 ⇒ `img-diff` 报"逐像素一致"。

**0 张新图 + 两张旧图相同 = 0 差**。若不是顺手核对张数，这会被当成"验证通过"上报。

⇒ 纪律：**截图工具的每一条"快捷路径"都会漏掉某种状态，捷径越短越容易漏；优先选与用户操作同构的那条。**
