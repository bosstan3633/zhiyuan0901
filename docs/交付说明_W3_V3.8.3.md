## 一、本批交付

### #6 ⌘K 浏览态双 Tab 改版（V3.8.3 核心）

**用户拍板两决策**：
1. 「AI 动作独立 Tab」= **真 Tab 切换控件**（不是分组标题上移）——浏览态顶部加一行「常用内容 / AI 动作」Tab，点/键切换两个视图
2. 「常用内容前置」= **近期最常用置顶**——按调用次数排的资源/任务/好奇心卡在最前，快捷操作、快速开关依次

**实现要点**：
- `GlobalPopups.vue`：浏览态（空查询）由「AI动作+AI建议+快捷操作+快速开关+近期最常用」单列分组，改为**双 Tab 隔离**
  - `browseTab` state（`common` / `ai`，默认 `common`）+ `setBrowseTab()` 切换时重置 `selIndex=0`、`selectedId=''`（防止选中索引指向另一 Tab 的集合并错位）
  - **常用内容 Tab** = `recentResources`（🔥 近期最常用，按 `callCount` 降序）→ `QUICK_ACTIONS`（快捷操作）→ `PALETTE_TOGGLES`（快速开关）
  - **AI 动作 Tab** = `aiPanelRows.proactive`（AI 动作 · 主动）→ `aiPanelRows.passive`（AI 建议 · 被动）
  - `flatList` 改为**按当前 Tab 过滤构建**（AI Tab 只推 `ai` 项，常用内容 Tab 只推 `res`/`qa`/`tgl` 项）——模板渲染序天然等于扁平序，保住 R60-1 纪律（渲染序=扁平序），`selIndex` 只在当前 Tab 的可见集合内连续
  - 删除死变量 `aiRowLen`（旧的跨组索引基，Tab 隔离后不再使用）
  - 新增 CSS：`.gp-browse-tabs` / `.gp-browse-tab` / `.gp-browse-tab.active`（active 用 `--accent-ink`/`--accent-light`，对齐 `gp-type-tab` 淡底深字口径）

**判据迁移**（历史称号冻结，文案锚改指）：
- `95-R161-R166.cjs` **R158-2**：flatList 顺序断言从「AI动作→AI建议→快捷操作→近期」改为「AI Tab 内 proactive→passive；常用内容 Tab 内 recent→QA→tgl」+ `browseTab.value === 'ai'` 锚
- `99-recent.cjs` **R171-4**：快速开关索引基从 `QUICK_ACTIONS.length+PALETTE_TOGGLES.length+j` 改为 `recentResources.length+QUICK_ACTIONS.length+i`（常用内容 Tab 内序）

**新增判据**：W3-1 ~ W3-3（挂载/常用内容置顶/AI Tab 隔离与选中重置，挂 `99-recent.cjs`）

## 四、边界如实

1. **AI 动作 Tab 默认不选中**（默认落常用内容 Tab）——用户若想让 AI 组恢复为「一打开就看见」，切一下 Tab 即可；本轮按用户拍板的「常用内容前置」执行
2. **Tab 切换重置选中**是设计而非缺陷：`selIndex` 是跨 Tab 共享的单一索引，不重置会让键盘 ↑↓/Enter 落到另一个 Tab 的行上（选中行与执行行错位）
3. **搜索模式（有查询）不受影响**：Tab 只在浏览态（空查询）出现，搜索态的分组渲染与键盘导航原样保留（R60-1 搜索分支未动）
4. **真机复核待用户实测**：双 Tab 的视觉观感、常用内容置顶的肌肉记忆、AI Tab 切换后的键盘导航、快速开关在新索引基下的行为
