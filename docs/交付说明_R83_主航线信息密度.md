## 一、问题：最贵的位置，放着最没信息量的东西

方向台首屏的主航线模块，此前长这样：

```
┌─ 愿景 ────────────────┐ ┌─ 使命 ────────────────┐
│ 愿景  [进入方向树 ›]   │ │ 使命  [进入方向树 ›]   │
│ 让每一位规划师在家长…  │ │ 以好奇过滤信息…        │   ← 两块卡，各占两行
│ （两行 clamp）         │ │ （两行 clamp）         │

┌─ 目标 ─────────────────────────────┐
│ 目标  三年内建成…   45%   项目 3    │              ← 期限？主攻？进度怎么算的？都没有
│ [客户洞察] [年度规划] [产品重构]     │              ← 三个只有名字的胶囊
```

**首屏最贵的纵向空间，被"两块占地方的卡"和"一串只有名字的胶囊"占着；真正该一眼看到的——期限、主攻、进度——反而一个都没有。**

M1 / M2 / M3 说的是同一件事，落在同一个组件，故**合成一轮**改完。

### M1 · 愿景/使命压成一条 44px 锚点条

- `.mr-vm-row`（两卡）→ `.mr-vm-bar`（一条）：`height: 44px`、12px 单行 `ellipsis`、**整条可点**进完整方向树；
- **「进入方向树 ›」由每张卡各一个收敛为右端一个**——原来两个入口指向同一个地方，是重复；
- **tier 标签（愿景 / 使命）保留**：去掉后两段引文分不出谁是谁，它们是这段的语义锚；
- 愿景 `flex: 1.2` / 使命 `flex: 1`——沿用原 `.mr-vm-row` 的 `1.2fr 1fr`，改动前后重心一致；
- `title` 挂全文兜底（单行省略后仍可悬停看全）；空态沿用「尚未设定愿景 / 尚未设定使命」。

**收益**：两块卡 ≈85px → 一条 44px，**让出约 40px**。目标网格是 `auto-fill minmax(340px, 1fr)`，让出的空间直接变成**多看到一行目标卡**。
（M1 原文写"≥60px"，实测 40px——差在原文估算时把两卡之间的 gap 与外边距也算进去了，实际没有那么多。**如实记录，不凑数。**）

### M2 · 目标头补期限 / 主攻 / 进度口径

- `termText()`：`long / mid / short` → `远期 / 中期 / 近期`；**未设期限 `v-if="dir.term"` 不显示**（不留空位）；
- `focusedOf()`：主攻项目数，**只在 >0 时显示**——写"主攻 0"是噪音；
- 项目数与主攻数合并为一段「项目 3（主攻 1）」，避免头部碎成一地；
- `45%` 后的 `ⓘ` 是 tooltip，口径与 `projectProgress` 的实现**逐字对应**：
  > 各项目进度的算术平均；项目有任务时 = 已完成任务 / 全部任务，无任务时取项目手动进度

### M3 · 项目胶囊 → 两行小卡

- 行 1：`🎯`（主攻）+ 名字 + `停滞`（停顿时）；
- 行 2：迷你进度条 + `pct% · done/total`；
- 已完成 `opacity: .55`，对齐 `.archived` 既有口径。

两处刻意的取舍：

1. **主攻用 🎯，不用 ★**。R60 已把主攻的视觉语言定为 🎯（原 📡 投射退役后统一），引入 ★ 会和既有的 ⭐ 星标语义打架。
2. **停滞用文字标，不只变色**。原 `.chip-proj` 的主攻只靠强调色边框区分——**颜色对色弱用户不可见**。新增的「停滞」直接给文字。

### ★ 性能：进度与状态必须预计算

`projectProgress` / `isProjectStalled` 内部都要遍历 `d.tasks`。若在模板里对每个 chip 调一次，就是 **O(项目数 × 任务数) 每次重渲染**——这正是 R71"模板方法调用消除"要治的。

```ts
const projMeta = computed(() => {
  const m = new Map<string, { pct: number; done: number; total: number; stall: boolean; finished: boolean }>()
  for (const p of allProjects()) {
    const pr = projectProgress(p)
    m.set(p.id, { pct: pr.pct, done: pr.done, total: pr.total, stall: isProjectStalled(p), finished: isProjectDone(p) })
  }
  return m
})
```

模板一律 `projMeta.get(p.id)`，由 `R83-7` 否定断言把守。
