## 门禁与交付约定（每批次结束）

`npm run typecheck` → `node scripts/regression.cjs` → `node scripts/e2e.cjs` → 性能批次加跑 `node scripts/perf.cjs` → 真机截图比对 → 版本 6 处同步 → `docs/交付说明_R1xx_V2.xx.0.md`。

**本机环境缺口（R128 起存在）**：Playwright Chromium 缺失、品牌 Chrome 忽略 `--load-extension` → E2E 与真机比对在有网络/Windows 开发机补跑（`e2e.cjs` 支持 `ZY_CHROME` 覆写）。

**R130 补跑重点（本轮为纯视觉/交互批次，真机复核必需）**：
1. 设置 → 标签管理：树角标 = 右列「N 张」（含回收站有软删卡的标签）；双击右列卡片出详情抽屉；多选拖到左树标签——落点行高亮、拖拽行半透明、松手移动成功。
2. 资源台列表视图：行右缘与容器对齐、分类树与内容间有 14px 间距；指标三格与卡片区为圆角。
3. 调度台/方向台/策展台顺带巡检 `--radius-md` 生效面（三件事卡/任务卡/论点横幅/展板）无布局位移。
4. 策展台金字塔：整体居中、左右留白；列多时横向滚动不挤压；真全屏口径不变。
