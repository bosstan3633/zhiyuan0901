## 一、一句话

策展台现在是一条完整的成果生产线：中心论点卡作为 L1，节点用 `Tab` / `Enter` 就地长成 L2–L4，整棵子树可拖拽或剪切粘贴；节点下可关联或解除资源卡；阅读长文、论证树和高清长图从同一份真实树生成；成果 HTML 可在另一台知源里新建或合并复现。

## 二、本批产品决策与落地

| 决策 | 落地 |
|---|---|
| 建支按钮全部删除，只保留键盘操作 | 工具栏、节点卡和空态均不再提供建支按钮；选中节点后 `Tab` 建子级、`Enter` 建同级，新节点立即进入标题编辑 |
| L2 节点的 `Tab` / `Enter` 必须真正生效 | 节点取得键盘焦点、标题与说明改为“单击选中 / 双击编辑”后，键盘事件不再被内部按钮或输入框吞掉 |
| 选择节点后整棵子树可移动到另一节点下 | 整个节点卡可拖拽；拖动时移动自身及全部后代，防自身、防后代循环、防超过四级上限 |
| 拖拽实现复杂时至少有备用通道 | 支持 `Ctrl/⌘+X` 剪切、`Ctrl/⌘+V` 粘贴为子级，与拖拽共用同一套合法性校验 |
| 资源卡关联可撤销 | 每个资源 chip 提供 `×`，只解除当前节点关联；资源池源卡和镜像源卡状态不变 |
| 分享必须严格保留真实 L1–L4 | 阅读长文与论证树都递归输出真实层级；L3 / L4 不再被错误标成 L2 |
| 两种分享版式都保留 | 阅读长文与论证树同时保留；分享 HTML 内可下载完整高清长图 |
| 高清长图不能影响产品性能 | 只在分享抽屉打开或点击下载时生成，不进入启动链，不常驻 DOM |
| 分享 HTML 导入时由用户选择新建或合并 | 解析并预检完成后弹窗展示节点 / 资源规模；用户选择“新建一个策展台”或“合并到当前策展台” |
| 无公开网址与本地附件有明确边界 | HTML 中无公开网址的资源只保留标题和说明；本地附件默认不进入分享文件 |
| 删除策展台：原生卡进回收站，镜像不影响池卡 | 本台原生卡与分类软删进回收站；台内镜像只移除投射引用；资源池源卡状态不变；3 秒内可整台撤销 |
| “论据卡片总数 / 佐证附件数量”可看明细 | 两格继续打开右侧下钻抽屉，分别展示卡片与附件明细 |

## 三、实现范围

### 3.1 思维导图编辑

- 节点标题和说明改为单击选中、双击或 `F2` 就地编辑。
- `Tab` 创建子级；`Enter` 创建同级；新节点挂载后立即聚焦标题。
- 节点卡整卡可拖拽，资源 chip 与内部按钮单独拦截，不会误触整树移动。
- 非法落点给出原因：自身、后代、超过四级、中心论点不可移动。
- `Ctrl/⌘+X` 只记录来源，`Ctrl/⌘+V` 才执行移动；移动失败时原树保持不动。
- 剪切粘贴与拖拽共用 `validateDrop` / `moveNode`，不存在两套规则。

### 3.2 资源关联

- 节点资源 chip 支持删除徽标，解除当前节点关联。
- 镜像卡走既有投射移除流程，池卡本体不写回。
- 台内原生卡解除关联后回到未分类，仍保留在资源卡池。
- 分享时收集全部非论点证据，包括镜像卡。

### 3.3 成果分享

- 阅读长文按 L1–L4 递归生成章节。
- 论证树按真实层级递归生成横向树，节点角标使用真实 `L${depth + 2}`。
- 有公开 URL 的资源输出可点击原文链接；无 URL 的资源只保留标题、说明。
- 两种版式都保留来源、日期、附件清单开关和纸白 / 墨黑主题。
- 分享抽屉打开时，从同一棵 `Category` 树直接绘制完整高清长图，避开滚动、折叠和窗口宽度影响。
- 长图作为 PNG 内嵌进分享 HTML；接收方可在 HTML 内下载，不需要知源扩展。
- 分享 HTML 内嵌一份惰性 `application/json` 快照，不执行脚本，不输出内部 ID 或本地路径。

### 3.4 成果回导

- 只接受知源策展成果 HTML；无法识别时明确报错。
- 先解析并校验完整快照，再在内存中构建导入计划，最后统一持久化。
- 新建模式创建独立策展台、论点卡和完整 L2–L4 节点树。
- 合并模式按“父节点路径 + 标题”复用节点；重名自动加序号，不覆盖无关内容。
- 同一池卡在同一目标台重复导入时复用投射，不重复建卡；投射落点变化时更新到新节点。

### 3.5 删除语义

- `deleteDeck` 软删本台原生资源卡与分类，并移除本台镜像投射。
- 不再调用 `pruneMirrorCats()` 清理资源池镜像分类。
- 不反写资源池源卡的分类、软删状态或内容。
- 撤销使用整台快照恢复台、卡和分类。
