## 三、拍板口径（实现依据）

1. **策展中心镜像语义**：投射 = 引用式镜像（实时同步，源增删改即时反映；策展中心内只查看/打开/移出投射，不提供删除源数据操作；清空 = 清投射清单，源数据零影响）。真机验证：源新增卡 2 秒内出现在镜像区；清空后源卡原样保留。
2. **投射/清空操作**不计入「今日入台/调出/移出」计数，写入事件日志（后续可扩展）。
3. **策展中心增强**（谭老板补充）：自有目录树增删改、原生卡片新建（视觉区分）、置顶/拖拽排序与其他工作台一致。

## 四、数据模型变更（向后兼容）

- `AppData.curationProjections?: CurationProjection[]`（可选；导入合并沿用并集口径，旧数据缺省 undefined → 空镜像）
- `ResourceCard.curOrder?: number`（仅策展中心原生卡拖拽排序使用）
- 常量 `CURATION_WS_ID = 'zy-curation'`：策展中心不建 Workspace 实体，仅作 categories/resources 归属标记——不进数字槽计数、不进工作台 Tab
