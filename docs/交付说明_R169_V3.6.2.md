## 三、★ 环境事故备案（本轮最重的非产品发现）

**本机安全策略拦截 node 父进程的同步 spawn**：`spawnSync` 一律 `EBUSY`（cmd.exe / where.exe / 复制出的 exe 同拦，重试无效）；**异步 `spawn` / `detached` / bash 直接调正常**。R168 前该策略不存在，regression 内嵌实跑门禁（entry-matrix / entry-literals / pinyin --check）因此整批假红。处置：

- `regression.cjs`：spawnSync 优先；通道被拦（error/status=null）时回退读 `scripts/.gate-cache.json`（机器本地运行时产物，已入 `.gitignore`，**不进仓**）；
- 新增 `scripts/regression-eb.cjs` **外带实跑器**（异步 spawn 串行跑三实跑门禁 → 写缓存），本轮门禁全部经它实跑，**判据不变：仍是真实退出码**；
- spawnSync 若恢复，两条通道行为一致（缓存带哈希+脚本改即失效）。

**次级坑**：`codeOnly()` 注释剥离会被模板里 `accept="image/*"` 的 `/*` 吞掉后续代码 ⇒ R169-25 对 Workspace.vue 改裸读（已写进断言文本备案）。
