## 一、这一段到底解决了什么

调度台原来只有「📊 周报」浮层：一周一屏、看完就散。R172 把它换成**常驻的知源仪表盘**，回答三个原来回答不了的问题：
**这一年我怎么走的**（年度热力图）· **那一天我做了什么**（日详情 + 下钻到具体卡片）· **这段时间的投入和方向对不对**（复盘 + AI 文本报告）。

四段改三段（概览带 / 热力图 / 复盘），周报浮层与 `weeklyReport.ts` **物理退役**（不留 `v-if="false"`），唯一还有用的 `weekWindow` 并入 `reviewReport.ts`。

## 二、六件事逐条

1. **事件日志补「调出」(`call`)** —— 原来只记新增/删除/改状态，"打开一张卡看内容"这件事从来没进过日志，所以任何"你这一周真正用了什么"的统计都无从谈起。新增 `EventAction='call'` + `recordCallEvent`，`stats.ts` 两个打开入口成对记账（`hotStats.ts` 不存在，真收口点是 `shared/storage/stats.ts` —— 这是开工前逐项核实抓出的 9 处文档失真之一）。
2. **`zy_daily_stats` 按日聚合引擎**（`shared/utils/dailyStats.ts`）—— 六类事件折叠 + 推进三维 + **前缀和**库容查询（时间绑定的数据基础）+ 防刷分双规则（同日重复调出第 2 次起 ×0.5；采集后 24h 内即软删该笔 ×0.3）。**零迁移**：没有这个键时启动不报错、热力图空态、首日写 `fullSince`。
3. **概览带 5 张存量卡「时间绑定」** —— 点热力图任意一天，存量卡显示的是**截至那天**的库容 + 当日增减；不选日则回到今天。加权分保留为副行（Q10），主数字是**件数**不是分数（可读性三层）。
4. **年度热力图 + 日详情 + 共用下钻** —— 12 月块 × 366 格，六档**语义**图例（静默/轻触/常规/高负荷/冲刺/满格，硬判据禁裸 `L1~L5`），P90 由实际数据算出；日详情四列指标可点开，下钻分组逻辑上移成 `shared/utils/drillRows.ts` 单一实现（顺带修掉 `t1/t2` 与 `time/time2` 契约不一致导致的时间列空白）。
5. **复盘段两栏 + AI 文本报告** —— 左「我的量」右「我的方向」，四范围（周/月/自定义/项目）+ **等长窗口环比**（杜绝"部分月 vs 整月"的假下跌）+ 8 条偏离规则（规则只陈述事实并给出阈值与实际值）。AI 复盘是**中央弹框的四段文本**：结论 → 支撑论据 → 洞察 → 建议。
6. **导出三件套 + 入口整合** —— 复盘段与热力图段各有 ⬇ 导出（CSV / Markdown / PNG）；调度台删 5 个旧入口，只留「📈 复盘」直达 `/settings?page=dashboard`。

## 三、AI 复盘为什么这样切分（本轮最关键的一次设计取舍）

`04-67 F29` 要求「以上统下」闭环：论据每条标注它支撑结论里的哪句主张，且**用词与结论逐字一致**。
这件事**不能交给模型**——模型自由发挥时，逐字一致永远验证不了，判据就只能写成"看起来挺像"。

所以：

- **规则给事实**：`shared/ai/review.ts` 本地一次算完四段骨架、全部数字、以及主张词常量 `CLAIM`。结论句与论据 `rel` 引用的是**同一批常量**，闭环是**构造保证**；论据③三态（有完成 → 有实物产出 / 只有进行中 → 开了口没闭合 / 皆无 → 完全没被触碰）由证据决定，有完成项那一分支里根本不出现"偏弱/没闭合"这些词。
- **专家给判断**：模型只续写「洞察」与「建议」两段，投料里给出「可用数字」白名单并明令不许改动；输出里出现白名单外的数字 ⇒ **整段弃用**，留本地版。
- **本地版是终稿之一**：未配置 API 时弹框明说「本地规则版」，不假装跑过模型（这条文案判据进了 R172-17）。
- **写库只在显式点击**：`存为资源卡` 走 `saveReportCard`，并**登记进全局撤销栈**（撤销 = 软删进回收站，不越"删除一律软删"红线）；`生成任务` 经页面内 bus 预填快速采集面板，保存键仍在用户手里。
  ★ 为什么单开一条 bus 而不是复用扩展快捷键那套：`chrome.runtime.sendMessage` 自发消息**不会回到同一文档**，MV3 语义如此。
- **启动零 AI**：`ReviewPanel` 对 `@/shared/ai/review` 只有 `import type`，实现在点击函数里 dynamic import，弹框是 `defineAsyncComponent` + `v-if`。

## 八、施工坑（入血泪账）

1. **异步组件 + `v-if` 的 watch 必须 `immediate`**：`open` 出生即 true ⇒ 不写 immediate 就没有任何一次触发，路径静默失效而**结构断言全绿**。判据：活性探针 + 把 `immediate` 本身钉进断言。
2. **就绪信号要按视图取**：真库默认视图是金字塔时，等 `.res-card` 会打满 8 秒超时——量到的是"我等错东西"而不是"切换慢"。
3. **合成 `keydown` 唤不起面板**（应用侧键位不吃非可信事件）⇒ 改点工具栏真入口。
4. **文档基线漂移**：开工先核实 9 处（`hotStats.ts` 不存在、tokens 真路径、theme-audit 实际 40 图非 36、GlobalSettings 门禁实为 3,575…），核实成本低于按错文档施工后再返工。
5. **Bash/PowerShell 共享 cwd 会漂**：`cd` 过仓库根之后 `node scripts/x.cjs` 直接找不到模块——长命令一律带绝对 `cd` 前缀（本轮复现两次）。
