字段口径

节点可编辑顶层名 / 子名 / 收卡定义 contenteditable（纯文本，零 v-html）。配对走「节点 id」不走名字：模型输出的名字在 parse 阶段就解析成 id 引用，迁移表与卡片归宿只存 id，显示名随时可改、落库时按 id 取当前名——否则用户改一个顶层名，十几条映射当场断链（本原型已按此实现，改名后迁移表自动跟随）
逐顶层否决沿用既有语义：未勾选顶层 → 其子节点与指向它的映射一并作废（apply 里 rootNames 过滤）。双栏把它画成"作废行降透+删除线"，并在影响条计入新增的剪掉数

指令作用域全站统一两档：左档=对象级（默认）「这张卡 / 这个台 / 这个任务」，右档=入口级「这类入口共用」，升档必须用户主动点（已拍板）。标签三个入口（tagBlueprint / tagAssign / tagGovern）没有"某张卡"的对象语义，所以默认档就是「本入口」，右档置灰并提示改走「↗ 存为角色」——存为角色是第三种出口（按钮，不是档位），把调好的口径升级成可复用专家，进 customPersonas，任何入口下拉都能选。历史 5 条带每轮「顶层数/耗时/是否采纳」，因为梳理的效果要横向比才知道哪条指令真的管用
