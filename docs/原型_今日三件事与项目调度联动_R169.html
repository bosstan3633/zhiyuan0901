1. 今日三件事：从"纯手选"变"规则推荐 + 你调整"

  • 依据三条，全部本地算，不发 AI 请求：① 主攻战略目标下的项目（现行 goalOf 反查）；② 过去 7 天三件事完成 12/21 与顺延；③ 任务调度里的状态分布（待开始 / 进行中 / 距截止 / 子任务未启动）。
  • 每条推荐必须写出理由，且带「采纳 / 忽略」——推荐不自动占槽，采纳才写 dailyFocus。
  • 三格上限 FOCUS_LIMIT=3 不变；勾选完成仍是双写（槽 + 任务卡）。
  • 现状：零推荐逻辑，候选只按 pinned 排序取 30 条；dailyFocus 按日键永久留存但无任何聚合层（要统计"过去一周"必须新增一层只读派生）。

2. 项目调度：上归属 / 下两栏可拖

  • 复用 R167 已验证的做法：mousedown 里 preventDefault() 防选区，不给容器加 pointer-events:none（否则把手自身点击复位失效）；窄屏退单栏并隐藏把手。
  • 现状：两模块同在 CompassHome.vue（834-973 行），联动是纯 computed 链 focusSelIdx → selTask → curProject，无事件；抽屉里已有 .ds-desc / SubtaskList 可直接搬。
