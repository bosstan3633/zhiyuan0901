## 一、五项交付明细

### T1 · 标签管理右列「全选本标签」

**需求**：当前标签下所有卡片一次性全部选中，批量移动。

**实现**：右列头部加「全选」勾选框（与资源台全景「全选本分类」同款样式与语义）——`ttAllChecked`（全选态=当前结果集全部已选）+ `toggleTtAll`（一键全选/清空）。**口径（用户拍板）**：跟随当前类型过滤 + 搜索结果集（`ttRows`），所见即所得。

### T2 · ★拖拽移动标签 bug 修复（A 不减 / B 不增 / 资源台不同步）

**根因**：`ttMoveCards` 用 `tags.includes(from)` **精确匹配**，而右列展示判据是 R130-T1 定案的 `cardHasTag`「路径+叶子」双口径——卡上存裸叶子名（如「图片处理类」）而选中态是「父/子」路径（或反之）时，该行在右列**可见、可勾选**，移动时却被静默 `continue` 跳过，表现为「拖过去没反应」。资源台卡片与标签管理读同一 `tags` 字段，移动不生效则同步自然不发生。

**实现**：
1. 移动判据与展示判据合一：`fromLeaf = from.split('/').pop()`，过滤 `t !== from && t !== fromLeaf` 的所有源标签变体 → 写入目标路径 → Set 去重；toast 计数与右列所见一致；
2. 同标签落点短路（`targetPath === from` 直接返回，不再谎报移动）；
3. 拖拽健壮性：卡片行 `dragstart` 写 `dataTransfer.setData('text/plain', ids)`（跨浏览器启动保障）、根/子标签行 `@drop` 补 `.prevent`。

**实测**（页面级 headless，全链路真实 handler）：卡存「图片处理类」→ 选「工具/图片处理类」→ 全选 → 拖到 #AI工具箱 → 卡上 tags 变 `["AI工具箱"]`，左树 #AI工具箱 角标 `1 卡`、右列 A 标签下清空——A 减 B 增 + 资源台同步成立。

### T4 · 项目详情页左栏主体 = 本项目详情目录（锚点导航）

**需求**（用户）：左栏应展示「项目详情目录」而非整体项目目录，且可向右拖拽、自适应。

**实现**：
- `projToc` computed：📦 项目概览（含项目进度%）→ 🎯 每个成功指标（标题+完成度%）→ ⚠ 未归类任务（有才出）→ 📎 任务附件；点击 `scrollToSec` 平滑滚动定位（锚点 id：`pd-sec-overview` / 既有 `metric-sec-*` / `pd-sec-orphan` / `pd-sec-assets`，`scroll-margin-top: 72px` 避让顶栏）；
- 滚动高亮：window scroll（passive）监听 `onTocScroll`，当前区块实时点亮，`onUnmounted` 摘除；
- 拖拽与自适应：R131 的 `.pd-split` 把手（180–420px 钳制 / 双击复位 / `UIPrefs.projRailW` 持久化）原样保留，右栏 `.board flex:1 min-width:0` 撑满。

### T5 · 项目全景地图（左栏顶部可折叠块 · 用户拍板形态）

「🗺 项目全景」标题行常驻左栏顶部、默认收起；点开显示 目标→项目 树（主攻点标识+进度%，当前项目高亮），点击即切换 `?p=` 并自动收起、目录回到概览锚点。embedded 弹窗态整栏不出。

**实测**：全景展开→点「项目二」→ 展板标题切「项目二」、`?p=proj2`、全景自动收起；目录三项（概览/指标 1/附件）渲染与点击高亮正确；零 pageerror。
