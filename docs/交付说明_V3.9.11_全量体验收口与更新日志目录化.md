# V3.9.11 交付说明 · 全量体验收口与更新日志目录化

> **发布日期**：2026-10-23
> **版本**：V3.9.11
> **范围**：策展成果一致性、好奇心资源支撑、画像四段只读 AI、性能 SLO、视觉验收、更新日志目录化
> **不改变**：方向台既有布局与六层模型、三卡数据模型、策展台金字塔 / 树状双架构

## 一、本轮交付

### 1. 策展成果收成一根树

- 分享抽屉预览、自包含 HTML、高清长图统一消费 `buildCurationRenderTree()`。
- L1–L4 层级、节点排序、资源与附件计数只从一处派生，不再三套递归各算一遍。
- 分享页保留真实层级；公开 `http(s)` 资源可点击，无公开网址与本地附件按既定边界降级。
- 新增节点 5,000 / 资源 5,000 / L4 / 逻辑尺寸 / 像素面积上限；超限前置拒绝。

### 2. 好奇心卡资源支撑

- 新增独立 `curioSupportLinks` 记录表，卡本体不持有对方 id。
- 好奇心详情支持搜索资源、建立关联、打开原文和解除关联。
- 解绑只删除关联记录，不修改资源池源卡。

### 3. 画像四段只读 AI

- 今天 / 本周 / 本月 / 本年均有按需载入的 AI 续写入口。
- AI 上下文只读本地已算好的事实白名单，不新增统计口径。
- 配置缺失或调用失败时保留本地规则洞察；不自动落卡、不改用户数据。

### 4. 设置页产品更新日志目录化

- 左侧为 175 个版本的目录线，右侧为独立滚动内容。
- 点击任一版本定位正文；目录与正文同步高亮，当前运行版本有明确标记。
- 滚到底会选中最早版本，不会因末条短于视口而停在前一版。
- 720px 以下目录在上、正文在下，取消嵌套滚动；目录项 44px 高且支持键盘焦点。

### 5. 性能、视觉和回归门禁

- 六类真实 Chromium SLO：网页浮层、⌘K 首屏、搜索键入、页面切换、分享抽屉、高清长图。
- 四主题 × 26 场景 = 104 张实拍；方向树折叠由夹具补种转为真判。
- 新增可逐项勾选的视觉验收清单，键盘与读屏未覆盖的地方明确写“部分通过”。

## 四、边界与遗留

- **性能 SLO 是单轮真实采样**，不等于连续 7 天稳定。慢机、大库和长期趋势仍属于 V3.9.12 的持续验证工作。
- **全站键盘与读屏仍有欠账**：`a11y-tab-audit` 当前报告 250 处可点击不可聚焦元素、54 处会掐掉焦点环的样式。本轮更新日志与策展节点的专项通过，不能写成全站可访问性通过。
- **分享兼容**已覆盖本机外部 Chromium 的纸白 / 墨黑 × 桌面 / 移动 / 打印，但仍缺 Chrome / Edge / Safari 与真实客户环境矩阵。
- **大型策展树**已有硬上限，但 5,000 节点规模下的视口虚拟化、平移缩放与移动端手势仍待专项验证。
