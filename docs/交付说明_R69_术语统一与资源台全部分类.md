# 交付说明 · R69（V2.38.1）术语统一与资源台「全部分类」根节点

**发版日期**：2026-09-10 ｜ **版本**：V2.38.1 ｜ **基线**：V2.38.0（6f55ab5 → 本轮待 commit）

> 本轮为**补丁版**：不含新功能面，解决三项「产品自我表述不一致」——界面术语、资源台默认落点、设置页键位说明。

## 一、交付内容（D1–D3）

### D1 术语统一：「工作台」→「策展台」（222 处 · 29 个文件）

- **背景**：母版 R2 已定稿「三大固定台 = 调度台 / 方向台 / 资源台」+「策展台 ×N」，但源码的用户可见文案仍是旧称「工作台」，与产品自我表述冲突。
- **改的范围**：界面文案、搜索浮层双端（应用内 + 网页）、设置页、内置使用手册、toast、空态、确认弹窗，以及代码注释。
- **不改的范围（有意保留）**：
  - **Airtable 同步列名「所属工作台」**——这是**接口契约**，改列名会破坏用户已有 Base 的列匹配与同步映射；
  - 内部字段与类型名 `Workspace` / `workspaceId` / `ws-*` CSS 类；
  - 历史迁移注释（R53/R61/R64/R65「旧工作台并入资源台」）——史实叙述，改了反而失真。
- **落点分布**：`Workspace.vue` 36 处（图标设置 / 导出菜单 / 删除确认 / 重命名弹窗 / 空态 / 搜索占位）· `GlobalSettings.vue` 35 处 · `GlobalPopups.vue` 25 处 · `overlay-impl.ts` 17 处 · `App.vue` 18 处 · `CurationCenter.vue` 18 处 · `manual-data.ts` 15 处 · 其余 7 个文件约 20 处。
- **向后兼容**：搜索类型的关键词过滤仍接受输入「工作台」（`['策展台','ws']` 与 `['工作台','ws']` 双条目并存），老用户习惯不被打断。

### D2 资源台默认根节点「全部分类」（`CurationCenter.vue`）

- **现状**：左侧目录顶端原是「📥 未分类」，`activeCat` 默认空串，进入资源台只看得到未分类卡——与「资源台是资源卡唯一居所」的定位不符。
- **改造**：
  - 新增聚合哨兵 `ALL_CAT = '__all__'`；左侧目录顶层为「🗂 全部分类」（**默认选中**），其下保留「📥 未分类」；
  - `viewLabel` / `viewNative` / `viewProjCards` / `isParentView` / `mixedCardsOf` 全部新增聚合分支：全台原生卡 + 全部投射卡，扁平呈现不分区；
  - 标签显示「🗂 全部分类」，删除某分类后回退目标由「未分类」改为「全部分类」。
- **数据层防污染（关键）**：聚合哨兵值一旦被当作 `categoryId` 写库就会产生脏数据，已堵住全部 3 条路径——
  1. 新建卡 `openCreateCard` → 抽独立函数 `newCardCatId()`，聚合 / 待分类视图统一回落 `''`（未分类）；
  2. 文件导入 `handleFileImport` → 复用 `newCardCatId()`；
  3. 拖入空白区 `onAreaDrop` → `activeCat === ALL_CAT ? '' : activeCat`。

### D3 R68 遗留缺陷修正 + 清理

1. **设置页快捷键映射表键位错（界面在说谎）**——「策展台快捷键」面板仍按「第 N 个 = 修饰键 + N」显示，与 R68 实装的「1=方向台、2=资源台、3 起=各策展台」不符。改为 `i + 3`，并重写面板描述与映射表头说明。
2. **快捷键速查口径**——`Ctrl+Shift+K` 描述「打开工作台」→「打开调度台」；`Alt+3…9`「各工作台」→「各策展台」。
3. **过时描述**——设置页「修改全局快捷键（含方向台 / 资源台 / 完整方向树）」：open-compass / open-resource 已于 R68 从 manifest 下架，改为「（完整方向树等）」。
4. **垃圾文件清理**——删除 `src/content/search-overlay.ts.orig.bak`（57KB，V2.21 浮层拆分前的旧实现遗留）与 `scripts/.r6a`。
5. **测试脚本同步**——regression.cjs / e2e.cjs 中引用旧文案的断言锚点（R32-7/7b/8/17、R53-8、R44-10 及 e2e E2E-3/E2E-19 选择器）全部改到新文案；`getByText('工作台全景')` 修正为实际菜单名「资源台全景」（该选择器自此才真正可用）。
