## 一、范围与原则

- 策展模式页（`CompassCurationPage.vue` + `curation/CurationTreeLayout.vue` + `curation/CurationPyramidLayout.vue`）：**按原型一比一还原**，含布局、视觉、交互行为。
- 方向台、调度台：**沿用同一套视觉语言做布局与视觉升级**，功能行为不变，只改呈现层。
- 不新增数据字段、不改数据结构、不动云同步协议；纯前端呈现与交互层改造。
- 设计 token 先抽为共享变量，三个页面统一消费，避免三处各写一份绿色。

## 二、设计 Token（三页统一，新增共享样式）

- 轻绿体系：`--zy-green #2e9e63 / --zy-green-deep #1e7a4b / --zy-green-soft / --zy-green-faint / --zy-mint`，映射进现有主题变量，四主题（纸墨白/深空薰衣草等）各自给出色值，过主题对比门禁。
- 圆角层级：卡 20px / 模块 14px / 条 10px / 胶囊 full。
- 阴影：常态 `0 1px 2px rgba(28,36,28,.05)`、浮起 `0 10px 30px rgba(46,158,99,.10)`。
- 层徽统一：战略目标=序号方块、项目=绿胶囊"项目"、指标=浅绿小胶囊"指标"、主攻=紫胶囊。
- 胶囊工具按钮 + 分段控件（视图切换）成为全局范式。

## 三、功能清单（用户可感知）

### A. 策展模式页（一比一还原原型）

1. 根脉带：愿景/使命从两张大卡收为一条 56px 横带，左愿景右使命，悬停浮现"详情"，点击仍开详情抽屉；主干线下接"战略骨架"章节标。
2. 二级工具栏：筛选（目标/项目下拉+清除 chip）｜视图（金字塔/树状分段）｜层级（全部展开/折叠至目标）｜导出（下拉菜单 Markdown/HTML，提示导出范围），四组成组。
3. 树状视图：战略目标双列瀑布大卡（序号方块+进度环+折叠钮），项目卡带层级线，指标自适应网格，任务叶片状态点+划除。
4. 金字塔视图：根脉带→目标→项目→指标卡隶属结构图；任务可拖拽归位（同项目绿框/跨项目红框拒绝并提示）；未归档"散叶"区网格罗列、可拖入指标卡。
5. 项目筛选聚焦态：根脉带与目标卡降为半透明背景，聚焦横幅（脉络面包屑+退出按钮），项目卡加绿边放大成主角；树状/金字塔行为一致。
6. 全部展开/折叠至目标真实生效：折叠后目标卡显示"已折叠 N 项目"徽记（修复当前点击无反应的 bug）。
7. 详情抽屉保持现有六类节点内容，视觉并入新语言（绿色 eyebrow、圆角、按钮）。

### B. 方向台（同语言优化，功能不变）

8. 愿景/使命（NorthStarPanel）收为同款"根脉带"横条，与策展页一致；展开详情能力保留。
9. 战略骨架条（CompassSpine）与项目塔（CompassTower）并入新视觉：层级线、绿色进度、胶囊徽记、卡片圆角阴影统一。
10. 方向台顶栏操作区改胶囊工具按钮成组排布。

### C. 调度台（同语言优化，功能不变）

11. 今日三件事、卡片池、任务清单+日历等模块卡片统一圆角/阴影/边距；进度条、状态点、胶囊徽记换用新 token。
12. 调度台顶栏操作（AI 推荐/今日战报/为什么这样排）改胶囊按钮成组。
13. 页签角标、任务状态色（今日橙/完成绿/待开始灰）与新 token 对齐。

### D. 工程与文档

14. 新增/更新回归分片：根脉带、工具栏分组、双列瀑布、聚焦态类名、折叠徽记等锚点。
15. E2E 更新：策展页折叠/展开断言、聚焦态断言；四主题视觉普查重跑；代码索引、文档读数同步。
16. 更新日志 V4.3.6、交付说明、README 版本行。

## 四、开发任务拆解（执行顺序）

1. 抽共享设计 token 与公共类（新共享样式文件），过主题对比门禁。
2. 策展页：根脉带 + 二级工具栏（含导出菜单、筛选 chip）改造。
3. 策展树状：双列瀑布 + 目标大卡 + 项目/指标/任务新样式。
4. 策展金字塔：新结构图样式 + 聚焦态 + 散叶区（拖拽逻辑沿用现有 useTaskRelocationDnd，只换皮）。
5. 聚焦态横幅与两视图联动。
6. 方向台：根脉带化 + 项目塔/骨架条视觉统一。
7. 调度台：模块卡片与顶栏视觉统一。
8. 回归/E2E/视觉普查/索引/文档/日志/交付说明。

## 五、验收标准

- 策展页与原型 V0.3 视觉逐项对齐（根脉带 56px、双列瀑布、1560px 内容列、聚焦态半透明背景）。
- 折叠/展开按钮点击可见层级变化；项目筛选后聚焦横幅出现、背景信息弱化。
- 金字塔拖拽归位行为与线上一致（同项目成功、跨项目拒绝）。
- 方向台、调度台功能零回归：E2E 全绿、静态回归全绿、四主题普查 0 失败。
- 四主题下新绿色 token 对比度全部达标。

## 六、明确不做

- 不改策展页只读边界、不新增写库路径。
- 不改拖拽归位的数据口径（useTaskRelocationDnd 不动逻辑只接新 DOM）。
- 不做移动端新页面；响应式仅保证不横向溢出。
