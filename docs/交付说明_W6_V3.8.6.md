## 二、交付明细

### ① 日详情（今日战报）按原型重写（DayDetail.vue + dashboard.css）

**原型真源**：`docs/原型/今日战报-DailyLogTimeline.html`

**新五段结构**（对齐原型）：
1. **头部**：`dz-day-ic` 图标 + `dz-day-title`（今日战报 / YYYY-MM-DD）+ `dz-day-sub` 日期 + 关闭钮
2. **摘要**：`dz-dl-sum` / `dz-dl-recent` 一行摘要
3. **四格统计**：`dz-stats` — 新增（sc-create）/ 调出（sc-call）/ 推进（sc-status）/ 清理（sc-del）
4. **热力带**：`dz-heat-band` — 四格统计下方一条热力带，rec.w / levelName / 强度 `min(100, round(w/55*100))%`，背景 `var(--heat-{lv})`、文字 `var(--heat-ink)`
5. **降序时间线**：`flowGroups` 改 `b.ts - a.ts`（下午在前，对齐原型）+ 上午/下午/晚上分组 + `dz-tl-row` 时间线行
6. **页脚**：查看全部记录 › + ExportMenu 三格式（PNG / HTML / Markdown）

**退役**（分析段整体）：
- 四列下钻 `dz-mcols` / `DrillCardList` 挂载
- 库容变化条 `deltaOf` / `stockAt` / `dz-dstock`
- `dz-hintline` / `dz-badge.hi`
- `groupEventRows`（分组逻辑仍在 `drillRows.ts` 单一实现，ReviewPanel 消费）

**CSS 死类清零**：dashboard.css 删 `.dz-mcols` / `.dz-dstock` / `.dz-hintline` / `.dz-badge.hi`，新增 `.dz-stats` / `.dz-stat` / `.dz-heat-band` / `.dz-day-ic` / `.dz-dl-*` 等字面量类。

### ② 三张卡模块标题入框（CompassHome.vue）

- 三张卡整块包进 `<div class="card deck-frame">`（与今日三件事/年度热力图同款框）
- `.deck-frame { padding: 12px 20px 16px; }`
- 内层 ModuleCard 用 `:deep` 压成无框无底（background/border/shadow 置空、module-title 隐藏、module-body padding:0）——避免双框
- bt-tab 三枚与 bottom-pane 三面板结构不动

### ③ 任务卡默认列表视图 + 卡片视图 AI 入口右上角直跑补全

**TaskManagerPanel.vue**：
- `viewMode` 默认 `'card'` → `'list'`
- 卡片视图 3 处 `<TaskAiMenu @detail>` → `<TaskAiCorner :task="task">`
- 列表/看板/项目页 9 处 TaskAiMenu 保留（9+3 拆分）

**TaskAiCorner.vue**（新建）：
- 右上角角标（top:8px right:56px，避开 pin/star）
- 点一下直接跑 `buildTaskEnrichJob`（kind='enrich'），**无菜单**
- AI 依赖零静态引用（点击时才 `import('@/shared/ai/config')` + `import('@/shared/ai/taskEnrich')`）
- AiDrawer 走 `./lazyAiDrawer`
- 样式恒显 opacity .72
