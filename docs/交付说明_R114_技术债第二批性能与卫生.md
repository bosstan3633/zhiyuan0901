## 一、本轮核心成果

### 1. 全局搜索「慢」的真凶（P0，产品级缺陷修复）⚠️ 本轮最重要发现

**现象链（CDP 网络层实证）**：
- content script 隔离世界里，vite 的 `__vitePreload` 辅助器把动态 import 的依赖 chunk 以 **document base** 解析——在网页上就是 `https://目标站/assets/chunk-*.js`
- 每次打开浮层（含空闲预热）向**宿主网站**发起 2~3 个必然 404 的跨域请求 + MIME 报错
- 真实网站上这是真实的网络往返（慢站可秒级），且浮层实现链路带病运行

**修复（构建期，双保险）**：
| 项 | 文件 | 动作 |
|---|---|---|
| 禁用 modulePreload | `vite.config.ts` | `build.modulePreload: false`（扩展场景本地磁盘加载，preload 无收益纯有害） |
| 动态 import 改写插件 | `vite.config.ts` | 新增 `fix-content-dynamic-imports` closeBundle 插件：dist 内相对路径动态 import → `chrome.runtime.getURL` 绝对路径（content 与扩展页两界皆安全），本轮改写 **10 处** |

**验证**：宿主页 hits 由 3 个 chunk 404 → 仅 `/` + favicon；console 错误 3 → **0**；浮层打开 + 搜索正常。

### 2. drawPyLinks 减负（M3 交互窗口最大单体）

`--profile` CDP 采样显示金字塔 SVG 连线绘制单体 **505ms**（样本数），根因：根级过滤在每节点回调里 `wsCats.value.find(...)`（O(节点×分类)）+ 同一节点最多 2 次 `getBoundingClientRect`。改为一次 rect 读建 Map + `catById` 反查。实测 M3 6610→4624ms。

### 3. 静默 catch 清零（04-59-⑤）

14 处全数处置：
- **11 处** `content/overlay-impl.ts`：`chrome.runtime.sendMessage` fire-and-forget → 收敛为 `safeSend()`（try/catch 兜扩展上下文失效 + `.catch` 兜 MV3 Promise 拒绝，注释意图）
- **1 处** `App.vue`：storage.onChanged 注册失败 → `console.warn`（容量红点不更新需留痕）
- **1 处** `GlobalSettings.vue` 导入前自动备份失败 → **showToast 告警**（安全网失败必须让用户知道）
- **1 处** `GlobalSettings.vue` 导出读 UI 偏好失败 → `console.warn`（降级不带 uiPrefs 段需留痕）

### 4. perf.cjs 扩指标 + 第 4 处门禁漂移修正

- **第 4 处门禁漂移**：旧 M6「全局搜索唤起」在扩展页上派发合成 Ctrl+K——content 脚本根本不在扩展页运行，**恒 ≈0ms 假指标**（同 e2e 停 R69 / perf 15006ms / __navTo 误命中之第四例）
- 新增：`M2c 回到调度台`（此前无度量）· `M5a 全局搜索唤起` / `M5b 键入 6 字净耗时`（独立 http 宿主页 + service worker `tabs.sendMessage` 真实唤起）· `M3b 窗口二长任务`（与 M3 主窗口分离，互不污染可比性）
- `__searchType` 防抖窗口参数化（浮层 60ms ≠ 应用内 240ms）

### 5. E2E-21 flaky 根修

坐标 force click 在长序列后会被残留浮层盖住（事件落点到顶层元素）→ 改 DOM 直调 `.click()` + 轮询等关闭（8×250ms）。复跑稳定 22/0。
