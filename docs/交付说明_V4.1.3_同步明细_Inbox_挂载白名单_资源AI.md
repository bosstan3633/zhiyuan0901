## 二、同步回执与状态口径

- “本机待上传”比较本机当前内容与上次成功同步基线。
- “最近实际同步”是最近一次实际上传、拉回或一致性检查写入的回执，不是新的待办清单。
- 双端都有改动时必须显式选择；不允许用“最近检查时间”冒充满意同步。
- 绿 / 黄 / 红三色只表达同步关系；具体原因同时写入按钮标题和无障碍标签。
- `prefers-reduced-motion` 下保留颜色语义，停止呼吸动画。

## 三、卡间关系

现行挂载白名单只有两条：

1. 任务卡 -> 资源卡。
2. 策展节点 -> 资源卡。

下列能力退役：

- 资源卡反向关联任务。
- 资源详情中的“支持的任务”只读反查入口。
- 好奇心卡、愿景和使命的卡间挂载入口。

镜像投射、策展节点资源关联、六层归属和软删语义不在此次退役范围内。
