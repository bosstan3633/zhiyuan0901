## 六、过程发现（两条环境级知识）

1. **Chromium「Esc 后全屏禁用」sticky 机制**：同一 WebContents 内用户按过 Esc 后 `requestFullscreen` 会被静默拒绝（防钓鱼）。E2E-22 必须用独立新开 page 跑。
2. **Vue 3.5 defineEmits 泛型**：双 script 块文件中跨块类型引用（`LifecycleCard['kind']`）在 emits 签名内解析失败——用元组语法 `locate: [id: string, kind: '...']` 解决。
