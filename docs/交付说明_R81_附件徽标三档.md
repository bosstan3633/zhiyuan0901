## 一、问题：卡片上写着「🧾 1」，点开却是 PDF

```ts
// 改前（AssetBadge.vue:24-25）
const imgCount  = computed(() => list.value.filter(a => a.kind === 'image').length)
const htmlCount = computed(() => list.value.length - imgCount)
//                                                   ↑ 总数减图片数 == "HTML 数"，PDF 被吞进这一档
```

一张挂了 **1 个 PDF** 的资源卡，正面显示 **🧾 1**（HTML 徽标）；点进去却在列表里看到 📕 图标、点开弹出 PDF 阅读器。**徽标说的和实际给的不是一回事。**

第二个问题：**无论挂几个附件，点徽标都先弹一个列表浮层**。挂单个附件时，这个列表只有一行，用户为了打开一个文件要经历「点徽标 → 看列表 → 点那一行」三步。

第三个问题（本轮勘验时才发现）：**这个口径错误不止一处**。

## 三、改动

### 3.1 T1 · 抽共享 `assetSummary()`（三出口收敛为一）

`shared/utils/assetKind.ts`（R80 已建的类型判定工具）新增：

```ts
export function assetSummary(list: Array<{ kind: AssetMeta['kind'] }> | undefined | null): string {
  const arr = list || []
  const imgs  = arr.filter(a => a.kind === 'image').length
  const pdfs  = arr.filter(a => a.kind === 'pdf').length
  const htmls = arr.filter(a => a.kind === 'html').length
  const parts: string[] = []
  if (imgs)  parts.push(`${imgs} 图`)
  if (pdfs)  parts.push(`${pdfs} PDF`)
  if (htmls) parts.push(`${htmls} HTML`)
  return parts.join(' · ')
}
```

**为什么抽而不是改三处**：与 R80 抽 `guessAssetKind` 同一个理由——三处各写一份，改天再调口径必然漂移一处。放在 R80 已建的 `assetKind.ts` 里，不新增文件。

⚠ **兼容**：仅当卡上确有 PDF 时输出才变化（多出「N PDF」一档）；**无 PDF 的卡输出逐字不变**，`04-18` 与既有文档里的「N 图 · M HTML」示例仍然成立。

### 3.2 T2 · 徽标三档

```ts
// AssetBadge.vue —— 三档各自 filter
const imgCount  = computed(() => list.value.filter(a => a.kind === 'image').length)
```

```html
<span v-if="has" class="ab" :title="badgeTitle" @click.stop="onBadgeClick" @dblclick.stop>
```

### 3.3 T3 · 单击分流 + 提示随内容变

```ts
function onBadgeClick() {
  if (!has.value) return
  if (list.value.length === 1) { void openAsset(list.value[0]); return }  // 一击直达
  openList()
}
const badgeTitle = computed(() => {
  const n = list.value.length
  if (n <= 1) {
    const a = list.value[0]
    if (!a) return ''
    return a.kind === 'image' ? `${a.name} · 点击预览` : `${a.name} · 点击打开`
  }
  return `点击查看 ${n} 个附件`
})
```

- **单个**：图片 → 弹窗预览（复用既有 `AssetPreview` 多图通道）；PDF / HTML → `openHtmlAsset` 落盘 `file://` 打开（R14 已验证的通道，PDF 由 Chrome 内置阅读器渲染）；
- **多个**：维持原列表浮层，不变；
- **`title` 从写死的「点击查看附件」改为随数量变**——单个时把"将要发生什么"说清楚（点击预览 / 点击打开），多个时才报数量。
