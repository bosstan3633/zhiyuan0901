# 交付说明 · V3.9.7 画像与调度台交互收口

**日期**：2026-10-21  
**版本**：V3.9.7  
**性质**：11 项产品反馈的集中收口。包含界面布局、对象直达、指标解释、项目详情、二级页导航、数据去重与视觉减扰；数据模型和本地优先边界不变。

---

## 一、交付结果

| # | 反馈 | 交付结果 |
|---|---|---|
| 1 | 画像台顶部模块占用空间和视觉焦点 | 保留标题、刷新、导出、全部记录，压缩高度并弱化视觉 |
| 2 | 画像台中部左右留白和不对称 | 改为严格等宽，取消固定高度，按内容自然等高 |
| 3 | 画像指标明细点击后去卡片池定位 | 任务开任务详情；资源有链接直接打开、无链接开详情；好奇心开详情 |
| 4 | 标签分布缺少解释和行动 | 新增独立抽屉，包含定义、当前含义、行动建议和 AI 治理入口 |
| 5 | 调度台手边卡默认行数过多 | 任务卡、好奇心卡、资源卡各默认 5 行 |
| 6 | 调度台右栏高度与内容失衡 | 上方按内容固定，最近调出按可用高度显示 5–7 条，左右等高 |
| 7 | 主攻项目点击后需要另行查找 | 就地滑出项目详情抽屉 |
| 8 | 卡池「查看全部」后不能切换类型 | 二级页可自由切换任务、好奇心、资源，切换同步路由 |
| 9 | 方向台视图切换离项目模块太远 | 「项目塔 / 项目全景」入口迁入项目模块区 |
| 10 | 成功指标下创建任务重复 | `aggMetric()` 接入 `dedupeSorted()`，创建与删除只作用于对应任务 |
| 11 | 界面阴影、装饰元素干扰阅读 | 清理方向台与设置页遗留装饰样式和失效 CSS |

---

## 二、交付边界

- 所有交互都留在当前工作面，减少跳页和重新定位。
- 指标下钻以对象本身为终点，不以列表位置为终点。
- 标签分布解释由独立组件承载，沿用现有 AI 入口，不新增数据字段。
- 所有数据仍保存在本地，未引入新的远程依赖。
