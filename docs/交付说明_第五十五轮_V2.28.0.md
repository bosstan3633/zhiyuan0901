## 一、策展卡片平权与混排（A · 原 #1）

- **实测定性**：投射卡移入原生分类后再拖拽，链路本身是通的；"没法拖拽"的实质 = 原生卡与投射卡分属两个区块无法混排。
- **A1 统一混排列表**：`CurationProjection` 新增可选 `curOrder?: number`（与原生卡 curOrder 同键）；分类视图合并为**一张混排网格**（`mixedCardsOf`/`viewMixed`），排序权重 `置顶 > curOrder > createdAt`；拖拽排序 `reorderMixed` 对混合列表统一重编号（原生写 r.curOrder / 投射写 p.curOrder）。
- **A2 语义固化**：镜像卡 A→B 后 A 消失 B 出现（现行为保持）。
- **A3 平权**：原生卡可入镜像分类、镜像卡可回任意分类/待分类、混排列表内相互排列——**权重完全一致**。
- **A4 视觉区分保留**：原生蓝竖线 / 投射虚线+📡；📡 源分类实时镜像区独立（不参与策展排序）。

## 二、任务调度迁方向台（B · 原 #2a，Q3 拍板）

- **B1**：`TaskManagerPanel` 迁至方向台项目总览之下（`#task-mgmt-module`），**默认展开**，卡片/列表/看板三视图与全部筛选能力原样保留。
- **B2 调度台底部简化（Q2）**：移除「任务调度」Tab 与 zone Tab 机制，好奇心培育**去 Tab 头单区直呈**。
- **B3 定位链路**：任务类定位统一 `/compass?zone=task`（CompassShell 滚动定位 `#task-mgmt-module` + moduleFlash 高亮）；MetricDrillDrawer 未归档任务、写入记录 locateRec、background 旧 zone 路由全部改道。

## 三、快速采集任务（C · 原 #2b）

- **C1 弹窗**：任务名称/任务内容/所属项目/所属指标（项目→指标级联）**四字段全非必填**；Ctrl+Enter 保存直存全域任务（未挂项目=未归档任务）；已保存态 Enter 打开任务管理（方向台）/ 5 秒自动关。
- **C2 三端**：① content 浮层 `openTaskCapture`（overlay-impl，任意网页快捷键触发）；② 应用内 GlobalPopups `taskcapture` 面板（App.vue 转发 `zy-open-task-capture`）；③ popup 降级（`mode=task`，chrome:// 页）。background `open-tasks` 改为采集分发。
- **C3**：`open-tasks` 描述「打开任务调度」→「**快速采集任务**」（键位不变）。

## 四、方向状态迁调度台（D · 原 #3，Q1 拍板）

- **D1**：`MetricBar`（四格 + 日/周/累计 + 详细指标下钻）迁至**调度台最顶部**（今日记录条之上）；方向台以主航线置顶。
- **D2 调度台 4 指标降级**：项目调度 2×2 大卡 → **卡片头部右侧一行状态栏**（🎯指标数 📋任务总数 ✓已完成 ◐进行中），点击下钻弹窗保留。
- **D3 DHI 新口径（已拍板）**：在轨 = 窗口内有任务完成 **或** 有进行中任务 **或** 项目任务已全部完成（修复"全部做完反而掉出在轨"）；主数字 = 在轨项目占已投射项目百分比（`dhi.pct` 直读，不再从副标正则反解）；档位 清晰≥75% / 关注≥40% / 模糊>0 / 未启动=0；MetricDrillDrawer dhiRows 同步新口径。

## 五、分栏拖拽修复（E · 原 #4）

- **根因（实锤）**：`curColsStyle` 模板字符串写的是 `${curSplit}`（ref 对象）而非 `${curSplit.value}` → 生成 `"minmax(240px, [object Object]%)"` 非法值被 CSSOM **静默拒绝**（行内 style 完全缺失，headless 实证）——与 R46 BUG-3a 同族（漏 .value）。修复为 `${curSplit.value}`。
- **E2 分隔条常显**：常显细线（::after），hover/拖动增强为强调色；命中区 8px。
- **E3 钳制修正**：`minmax(240px, X%)` → `minmax(0, X%)`（240px 下限曾造成小宽度"拖不动"假死）；窄窗隐藏分隔条。

## 六、体积与性能（F · 原 #5）

- **F1 图标瘦身**：删除 manifest 未引用的 icon512（228K）/icon256（68K）→ **dist 1.7M → 1.4M（-296K）**。
- **F3 拼音缓存 LRU**：3000 上限整表清空 → 逐出最旧 + LRU 触碰，消除大库反复重算抖动。
- **F4 切工作台渲染**：工作台卡片网格 `content-visibility: auto`（屏外跳过渲染，针对实测最慢项 595ms 的渲染段）。
- **F2**：vendor 208K（Vue 全家桶）与拼音字典 308K（已按需加载）保留；搜索倒排/虚拟滚动仍列后续大项。

## 七、项目详情页改版（G · 新 #1，双列目录为用户方案）

- **G1 左栏双列联动目录**：左栏两列（约 372px sticky）——第一列「📦 全部项目」（约 148px，单击切换项目），第二列「📐 项目目录」树（根=项目名+进度 → 指标（进度/计数）→ 任务（状态点+标题）+ ⚠ 未归类区）：
  - **拖任务到另一指标节点** = 变更所属指标（taskIds 双写 + 展板即时反映）；拖到未归类区 = 摘除指标保留项目；
  - **拖指标节点整体移动** = 重排 `metrics` 数组（前/后落点 drop-line），调度台项目调度指标组**天然实时同步**（同一数组）；
  - 单击节点 = 右侧展板滚动定位（`#metric-sec-<id>` / `data-task-id`）+ sec-flash/task-flash 高亮。
- **G2 归属链横向化**：愿景→使命→战略目标→项目 一行横排小卡（跳树保留），纵向空间大幅压缩，页面焦点回归项目全景。
