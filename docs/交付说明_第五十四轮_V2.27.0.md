## 一、方向台二级导航闭环（方案 A · A1–A4）

- **A1 来源感知返回 + 面包屑**：项目详情/完整方向树页头重构为「方向台 / 页名（上下文）」面包屑（「方向台」段可点回总览）；返回按钮感知来源——方向树带 `?from=proj&p=<id>` 进入项目详情时返回键为「← 返回方向树」，项目详情带 `?from=tree` 进树时返回键为「← 返回项目详情」，无来源默认「← 返回方向台」。
- **A2 断链补全**：方向树项目节点新增 📄「进入项目详情页」（携带 `from=tree` 闭环）——此前仅有项目全景抽屉无页面直达。
- **A3 定位跳转**：项目详情 4 处跳树（🌳 按钮 + 归属链三节点）统一 `goTreeLocated()`，携带 `?hl=<dirId>`；方向树 `locateHlGoal()` 展开对应目标并滚动居中 + `goal-flash` 闪烁 1.4s（路由切换与 query 变化均监听）。
- **A4 Esc 返回**：两二级页挂文档级 `onPageEsc`（抽屉/弹层打开时让位其自关——`.task-sidebar/.overlay/.modal-mask` 存在即跳过）。

## 四、策展中心拖拽修复（D1–D4 · 新 #3，R53 回归 bug）

- **D1 卡对卡统一语义** `onAnyCardDrop`：任何卡拖到任何卡上 = 同分组排序 / 跨分组移动并插入落点位置（原生↔投射混合同样成立）——修复旧实现「跨分类拖到卡上无反应」。
- **D2 源镜像卡可拖**：📡 源分类实时镜像区的卡片新增拖拽——拖到树节点或卡上 = **拖拽即镜像入组**（自动创建单卡投射记录 `projectSourceCardTo`，已有记录则移动；源数据零影响）。
- **D3 状态复位**：所有可拖元素挂 `dragend → clearDragState`（dragId/dragCatId/dropMark 统一清理），杜绝拖拽取消后的状态残留。
- **D4 视觉反馈**：卡片拖过树节点时显示 `drop-into` 虚线高亮（复用 dropMark 机制）。

## 五、设置导航重组（E1 · 新 #4）
