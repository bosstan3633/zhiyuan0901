## 一、B1 · 删除工作台改软删（P1 红线修复）

- `deleteWorkspace` 不再物理 filter 移除资源卡，改为**全部写 `deletedAt` 移入回收站**（可恢复）；分类与工作台本身维持物理删除（无软删语义）；确认弹窗文案同步改为「资源卡将全部移入回收站（可恢复）」；
- **策展空间守卫**：`workspaceId === CURATION_WS_ID` 时拒绝删除并提示（全局空间不可从此入口删）；
- **回收站孤卡回落**：恢复时若原工作台已随删台消失 → 自动移入首个可用工作台的未分类（原分类消失 → 移入未分类），Toast 说明去向——软删承诺闭环到「恢复后一定可见可用」。
- E2E-19 全链路实证：删除 → 工作台消失 + 卡片带 deletedAt + 回收站可见。

## 二、B2 · 跨上下文并发写合并（P1 数据完整性）

- **合并层**（`repository.ts → mergeExternalData`）：外部写入到达时——
  - 本页无未落盘修改（`saveTimer` 为空）→ 原整树替换（零开销快路径）；
  - 本页有未落盘修改 → **卡片数组按 `id + updatedAt` LWW 合并**（本页没动的卡取外部；双方都动过取新者，**平手取本地**保护正在输入的表单；外部新建收编；外部物理移除且本页未动 → 尊重外部）；**dailyFocus 按日期键合并，双边同键都改过时下沉到槽级 LWW**；其余段（compass/workspaces/categories/tagTree/fieldConfig/stats/curationProjections）「本页相对存储镜像有改动则保留本页，否则取外部」；
  - 合并结果与外部全等（典型为自有写入回声）→ **只同步不回写**，切断「回声→合并→写→回声」写环。
- **配套修复**：① `saveTimer` 触发后清空（旧实现定时器 id 永不清空，导致快路径永不生效——插桩发现的隐藏缺陷）；② `lastPersistedJson` 存储镜像三处维护（本地保存载荷 / 外部接收 / 合并后指向 ext，保证「脏」判定始终相对 storage 实际内容）。
- **实机复验（双标签页并发勾选三件事）**：修复前最终存储 `s1=todo, s2=done`（A 的改动静默丢失）→ 修复后 **`s1=done, s2=done`（两处修改全部保留）**，事件流干净收敛无写环。已知边界：非卡段（compass 等）双边同段真冲突时保留本页（段落粒度，严格优于旧「后到全量覆盖」）。

## 三、B3 · 「今日」时间边界动态化

- `CompassHome todayStart` 由 setup 一次性固化 → `computed`（`nowTick` 每 30s 走一格，复用既有存储状态定时器），页面常开跨零点后「今日入台/移出/调出/写入记录」口径自动前移；
- 北极星 memo 键拼上当日日期（`period:dayKey:version`），跨零点后 DHI 日窗口/新增计数不再沿用昨日缓存。

## 四、B4 · 搜索命中字段两端同构

- 应用内（GlobalPopups）检索 blob 补 **标签**（raw.tags）；网页浮层任务 blob 补 **标签 + 项目名**、好奇心补 **标签**——两端命中字段集合一致（资源两端本就含标签）。

## 五、O1 · 检索召回排序（价值项）

- 打字搜索排序升级为：**置顶 > 星标 ｜ 同权重三级兜底：标题全词命中 > callCount 热度 > lastCalledAt 最近调出**——弱相关的常置顶卡不再永久压制刚高频调出的强相关卡，排序语义与「三秒调度」心智对齐（浏览态原有的热度排序保持不变）。

## 六、O2 · 任务卡库「⚠ 未归档」筛选

- `TaskFilter` 新增 `unarchived` 维度（下拉「⚠ 未归档」），口径与北极星 O23 同源（`taskArchiveIssue`：未挂项目/指标或引用失效），筛选偏好照常持久化——快速采集沉淀池获得就地治理入口（入口不再只有顶部指标第四格下钻）。
