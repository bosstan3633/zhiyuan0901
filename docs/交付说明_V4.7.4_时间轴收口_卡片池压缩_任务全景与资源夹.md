## 一、本轮口径

本轮只收口五个使用面，不新增卡片类型、不改六层方向模型、不改卡间零挂载红线、不新增运行时依赖与埋点。

- **时间轴只记录“还在库里的卡”**：只保留 `create` 与 `status` 两类动作；删除、恢复、清理事件不回流，当前已软删卡片连同其历史新增 / 修改记录一起隐藏。
- **单击与双击分工明确**：单击延迟 260ms 打开详情，双击取消待开详情并执行直达；资源卡双击直接打开 URL，未填链接时只提示“该卡还没填链接”，不回落详情。
- **归属信息按卡型显示**：资源卡与好奇心卡在时间轴小卡和详情抽屉里都不再显示“所属项目 / 成功指标”；任务卡与选题卡保留两行归属。
- **画像首屏优先让位给时间轴**：产品使用状态与方向状态从两块面板压缩为紧凑状态条，保留下钻入口与全部指标，只压缩说明文字、间距与卡片高度。
- **四类卡片池控制条统一瘦身**：任务、资源、好奇心、选题共用更紧凑的搜索 / 筛选 / 视图语言；任务控制条单行，资源与好奇心检索框 28px，选题控件 30px。
- **资源夹缩小但出口不减**：系统夹 48px、常用夹 54px，宽屏常用夹三列；单行预览替代多行预览，打开全部、今日采集、夹详情三个出口全部保留。
- **任务快捷键改落任务全景**：`goto-tasks` 从“直达任务卡池”改为“直达任务全景”，落方向台第 6 层，清空筛选、展开战略骨架、按项目分组，并把空项目与悬空项目统一收进唯一的“未归属项目”组。

## 二、功能改动

### A. 时间轴事件口径

- `PiTimeline.vue` 的追踪集合收窄为 `create / status`。
- 事件对应的卡片不存在或 `deletedAt` 非空时，该卡的所有历史记录一并跳过。
- 时间轴摘要与 AI 洞察使用同一存活卡集合，避免“时间轴已隐藏、摘要仍在计数”的口径分裂。
- 不再渲染 `.pit-card.deleted`，也不再输出“已删除”状态。

### B. 时间轴点击语义

- 单击进入 260ms 判别窗口，超时后打开详情；同一卡片连续第二次点击会取消待开详情。
- 双击资源卡直接走统一资源打开通道；资源卡有链接就开链接，没有链接只提示，不打开详情。
- 带链接的非资源卡仍保留“双击打开卡片链接”的既有能力；无链接的非资源卡双击不做事。
- 组件卸载时清理待执行的单击计时器，避免路由切换后延迟弹出旧详情。

### C. 资源 / 好奇心归属收口

- 时间轴小卡的 `metaOf()` 对资源与好奇心返回空串，不再出现“未关联项目”。
- 详情抽屉的归属区只在任务卡与选题卡上渲染，资源与好奇心不再出现“所属项目 / 成功指标”两行。
- 其他卡型、其他详情事实与定位回卡片池的入口保持不变。

### D. 画像首屏压缩

- 两块面板标题改为同排 eyebrow + 标题，去掉重复说明句。
- 四个 KPI 由“数值 + 标签 + 说明”压成“数值 + 标签”，保留四格下钻与 tooltip。
- 选题成果收成单行：四个数字格 + 右侧“全部 ›”，保留五个下钻出口。
- 主攻项目改为双列紧凑卡，保留项目名完整换行、状态、进度与点击进入项目的能力。
- 1440×900 视口下时间轴首张卡片进入首屏，E2E-69 实测 `.pi-overview` 高度不超过 260px。

### E. 四类卡片池控制条与资源夹

- 任务卡池控制条改为单行不换行：搜索框最大 270px，排序 / 分组 / 月历看板同排；窄于 1260px 时只让搜索框独占一行。
- 资源卡池沿用 `DeckControls` 的紧凑控制条：搜索 160–260px、最小高度 28px，筛选与视图按钮同步降一档字号和 padding。
- 好奇心卡池与资源卡池共用同一套紧凑控制条。
- 选题卡池搜索 180–240px、筛选与新建按钮 30px。
- 资源系统夹 48px、常用夹 54px；常用夹宽屏三列、1200px 以下两列、900px 以下单列。
- 常用夹由“标题 + 数量 + 多行预览”改为“标题 + 数量 + 单行预览”，点击出口与 title 提示全部保留。

### F. 任务全景快捷键

- `manifest.ts`、设置页快捷键文案、共享快捷键名册与内置手册统一改为“直达任务全景”。
- `background/index.ts` 的 `goto-tasks` 改为打开 `/compass?layer=6&fresh=1&freshAt=...`，`freshAt` 用于重复触发时仍执行“打开”而不是被路由去重。
- `useCompassTree.ts` 监听 `layer=6`：切项目塔、清空方向筛选与风险筛选、设置第 6 层、展开战略骨架并滚动到任务列表。
- 第 6 层列表按所属项目分组；无指标任务只认真正存在的项目 id，历史方向 id / 已删项目 id 与空项目统一进入唯一“未归属项目”组。
- E2E-69 实测列表行数与库内存活任务数一致，且“未归属项目”组恰好 1 个。
