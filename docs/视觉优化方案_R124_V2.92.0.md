## 一、盘点结论（先对齐事实）

| # | 用户判断 | 盘点实况 |
|---|---|---|
| 1 | 黑底发闷、卡全靠弱描边 | ✅ 实况：暗色 `--bg` 近纯黑（linear `#010102` / raycast `#0A0A0C`），`--border: #23252A` 为**实色硬线**；无 3 级 elevation 色阶 |
| 2 | 红黄绿滥用 | ✅ 大头是**光速黑主题 accent 本身就是珊瑚红 `#FF6363`**——主攻条/CTA/进度条/选中框全被染红；叠加「中优先=黄胶囊」（`ProjectCuration .tag.warn`）、绿胶囊（低优 `tag.ok`） |
| 3 | 排印呼吸感 | ✅ 实况：小字无统一字距；胶囊 `padding: 2px 8px` + `border-radius: 99px`（"肉感"来源）；正文层级 4 档但未按透明度体系 |
| 4 | 调度台首屏挤压 | 部分：R120 已合流为单行，但**非玻璃质感**、内距与数字层级仍重；三件事编号为普通文本（text-4/700）；选中态=实线 accent 边框（光速黑下=红） |
| 5 | 项目调度双主角 | ✅ 实况：`.cur-groups` 双列任务树**恒展开**，首屏右半被占满 |
| 6 | 资源台卡大而空 | 部分：R123 已定 86px 骨架，但**标题两行钳制**在无描述卡上会拉高空洞感；高度未锁上限 |
| 7 | 策展台空态冰冷 | ✅ 实况：空态=通用 EmptyState（folder 图标 + "暂无资源卡"），无论点占位/金字塔骨架引导 |

## 二、设计令牌层（Tokens Checklist 落地映射）

### 2.1 暗色 Elevation 色阶（本轮核心）

| 令牌 | 现状（linear / raycast） | **新规范** |
|---|---|---|
| `--bg`（画布） | #010102 / #0A0A0C | **#0D0E11** |
| `--surface`（卡/容器） | #0F1011 / #111113 | **#14161B** |
| `--surface-2`（hover/内嵌） | #141516 / #161619 | **#1A1D24** |
| `--surface-3`（active/浮层） | #191A1B / #1C1C20 | **#1F232B** |
| `--border`（发丝线） | #23252A 实色 | **rgba(255,255,255,0.08)** |
| `--border-strong` | #34343A | **rgba(255,255,255,0.14)** |
| 选中态描边 | — | **rgba(94,106,210,0.40)** |
| `--accent` | linear #5E6AD2 / raycast **#FF6363** | **#5E6AD2**（hover `#828FFF`；发光 `#6D5CE8` 40%） |
| 文本 4 档 | 实色 #F7F8F8/#D0D6E0/#8A8F98/#62666D | **rgba(255,255,255,.92 / .70 / .50 / .32)** |
| 圆角 | 大小混用 | 标签·小按钮 **4px** · 卡片 **8px** · 大容器 **12px**（`border-radius: 99px` 胶囊退役） |

### 2.2 排印参数（**全主题统一**，含浅色）

| 项 | 现状 | 新规范 |
|---|---|---|
| 小字号（11–12px） | 各自为政 | 统一 **letter-spacing: 0.04em**（英文小标 `PROJECT SPOTLIGHT / TODAY'S FOCUS` 同步收紧） |
| 标签胶囊 | `2px 8px` + 99px 圆角 | **`2px 6px` + 4px 圆角**（精致化） |
| 正文字重 | 500–600 偏多 | 正文 400 / 强调 600 两档为主；数字保留 tabular-nums |

### 2.3 按钮纪律（暗色）
- 全页仅 **1 个实心 accent 主 CTA**；次级一律「`--surface` 底 + 发丝描边」幽灵按钮。
- 焦点环统一 `--shadow-focus`（accent 50% → 本轮改 40% 更柔）。

## 三、四台逐页方案

### 3.1 调度台（CompassHome）

| # | 改法 |
|---|---|
| P1 | **合流条 Glass Bar**：主攻胶囊 + 四指标 + 右侧周报入口合流为 **40px 锁高单行**；背景 `color-mix(surface 72%, transparent)` + `backdrop-filter: blur(12px)` + 底部发丝线；数字 15px/700、标签 10px 弱化，中间态数字去彩色 |
| P2 | **三件事**：编号 `01/02/03` → **28px 水印字**（`rgba(255,255,255,.12)` / 700 / 右上角），取代实心文本；选中态 → **半透明紫蓝光晕**（`border: 1px solid rgba(94,106,210,.4)` + `box-shadow: 0 0 0 3px rgba(109,92,232,.14), inset 0 0 12px rgba(109,92,232,.06)`），红实线退役；勾选方块保持 accent 但改 4px 圆角 |
| P3 | **项目调度默认收拢**：任务树 `.cur-groups` 默认折叠，卡顶提供「**展开关联任务树 (N) ▾**」；**向下展开**（保持左右栏布局，零跳变风险）；左半聚焦看板保留；进度条改 accent 紫、2×2 数值方格去彩色（`surface` 底 + 发丝线，数字 text/700） |

### 3.2 方向台（CompassShell + 展板）

| # | 改法 |
|---|---|
| P1 | **中性档全面退色**：`.tag.warn`（中优先）与 `.tag.ok`（低优）→ 新增 `.tag.plain`（无底 / `text-3` / 4px 圆角）；**默认仅显 4px 灰点**，行 hover 时弹出完整标签；高优保留 `danger` 警示色（唯一警示） |
| P2 | **展板沉浸感**：聚焦项目展板顶部加**极低纯度紫调光带**（`linear-gradient(180deg, rgba(109,92,232,.06), transparent)`）+ 展板容器 `box-shadow: inset 0 1px 0 rgba(255,255,255,.04)` 内阴影提层；大标题同行光带对齐 |
| P3 | 行内 hover 态：`.btask:hover` 提为 `surface-2` ✓（已符合），hover 时才显操作图标（复用现有 `tct-acts` 范式） |

### 3.3 资源台（Hub）

| # | 改法 |
|---|---|
| P1 | **卡片锁高 84–88px**：`min-height: 86px; max-height: 88px`；标题**单行截断**（`-webkit-line-clamp: 1` + 原生 title 全文）——（与 R123 原型两行口径的取舍见 Q2）；desc 11px 单行；页脚左分类 / 右 🔥 + 附件三档微徽标（已具备） |
| P2 | 工具栏：唯一实心 CTA「＋新建卡片」✓（已符合，仅主题色归紫）；导入/批量幽灵按钮底色改 `--surface` + 发丝线；列数方片与搜索**右端紧靠**（间距 8px 规约）、筛选气泡入口保留 |
| P3 | 网格间隙 10px ✓；卡片 hover 上浮保留；镜像虚线卡保留 |

### 3.4 策展台（Workspace）

| # | 改法 |
|---|---|
| P1 | **论点占位横幅**（未设态强化）：文案升级为「**＋ 点击确立本策展台的 L1 中心论点，让研究从判断出发**」，badge 灰化 + 整条可点即建 |
| P2 | **空态金字塔骨架**：卡片视图空态由通用 EmptyState 换成专属 **虚线金字塔示意**（L1 论点框 → 竖线 → L2 论据框 ×3），中央提示「从资源台拖入或新建镜像卡以支撑论点」+ 双 CTA（去资源台选取 / 新建卡片）；保留筛选空态时的通用 EmptyState（两态分流） |
