## 二、REQ-042 搜索抽屉升级

### 2.1 为什么从"只读预览"升级

上一轮的 ResourceDetailDrawer 是**只读预览**，想改一个卡片的工作台/分类必须走「全屏编辑 → 跳工作台 → 改 → 回来」，链路太长。用户拍板：**搜索单击的抽屉 = 工作台单击的抽屉**，能直接编辑。

### 2.2 落地

| 改动 | 说明 |
|---|---|
| 容器 | 弃用自绘 `.rdd-*` 遮罩/抽屉，改用共享 `Drawer.vue`（`rgba(0,0,0,.25)` 遮罩 + `.3s` 滑动 + Esc 关闭），与 ProjectDetailDrawer 同款 |
| 表单 | 复刻工作台内联抽屉完整字段：标题 textarea（Ctrl+Enter 保存）、链接类型三选（URL/本地文件/Obsidian）、链接输入 + file 路径警告、**所属工作台 select（切换即跨台迁移，分类联动重置）**、分类 select（层级化）、TagPicker、注解 textarea（拖拽调高记忆）、被任务挂载（只读可点击跳转）、创建/更新时间 |
| 保存 | 深拷贝副本 → 校验标题 → 写回 resources → persist → Toast（跨工作台迁移有专门提示） |
| 删除 | `deletedAt = Date.now()` 软删 + 4 秒内「撤销」（按 id 定位当前树，REQ-030 模式），撤销后重新 persist |
| 打开/复制 | 打开走统一 `toOpenableUrl` + `openExternalLink` + `recordResourceOpen`（与工作台同口径）；复制链接 Toast 反馈 |
| 保留 | 抽屉总线（kind='res'）、搜索定位高亮（accent 描边 1.8s） |

### 2.3 第三方页就地抽屉 —— 调研结论

**不可行**（无低成本绕过）：
1. content script 与 newtab 是两个隔离 JS 世界，抽屉组件无法注入第三方 DOM；
2. newtab 的 bundle 不在 `web_accessible_resources`，第三方页拿不到；
3. iframe 方案引入权限/样式/通信新坑，性价比极低。

**现状已满足备选预期**：第三方页单击 → 新开/聚焦工作台标签 → 路由 + 抽屉总线 → 落地即展开抽屉 + 高亮卡片。用户确认按此验收，本轮不为此写新代码。

## 三、REQ-043 命名体系调整（方案 A）

### 3.1 决策依据（用户拍板 + 调研）

| 层 | 旧名 | 新名 | 装什么 | 语义 |
|---|---|---|---|---|
| 1 | 首页 | **知源罗盘** | 知源灯塔 + 北极星 + 好奇心 | 定方向（where to go） |
| 2 | 知源罗盘 | **知源引擎** | 今日行动 / 项目策展 / 方向树 | 生动力（how to move） |
| 3 | 工作台 | 工作台（不变） | 资源卡 | 承资源（what you have） |

**"策展中心"方案被否的两个硬伤**：① 策展在你的产品语义里对应工作台（资源策展），顶层再叫策展中心会双策展并存，且今日行动/方向树名不副实；② `Compass*` 代码前缀与"策展中心"长期错位。方案 A 让 `CompassHome`（首页）与"知源罗盘"天然对齐，错位最轻。

### 3.2 改动清单（约 32 处）

| 类别 | 处数 | 关键位置 |
|---|---|---|
| 导航 Tab | 2 | `App.vue`：首页→知源罗盘、知源罗盘→知源引擎 |

## 四、REQ-044 定位文案深化

### 4.1 新定位（三处统一口径）

> **知源 · AI 时代的个人资源调度台与认知增强系统 —— 收得进、看得见、找得到、信得过、带得走。**
>
> AI 让"产出"变得前所未有的廉价，于是个人认知的真正瓶颈不再是"能不能创造"，而是**"能不能把散落各处的产出，在正确的时刻重新调度回来"**。知源不生产内容——它经营你的**认知周转率**。

**为什么弃用"你有 17 个 AI 工具入口，却没有一个总调度"**：它只描述了现象（工具多），没说出本质（**瓶颈已从"生成"转移到"调度"**）。新表述把产品锚在"认知周转率"这个可感知的价值点上，且与"调度台与认知增强系统"的定位动词一致。

### 4.2 竞品对比增强

**手册新增 `quick-3「它与同类相比 · 独特价值」`**（速览篇第 3 节）：

| 竞品 | 知源的不同 |
|---|---|
| Notion | 知源不做笔记与数据库，只做调度台；"库越建越重、找回越来越慢"正是知源的三秒进出 |
| Obsidian | 互补而非竞争：收录并直达 `obsidian://` |
| Flomo | 好奇心同源，但好奇心只是六层链一环，知源把它接进方向/项目/北极星 |
| Raindrop.io / Eagle | 它们收藏"链接"，知源调度"资源+任务+好奇心+方向"四类对象 |
| Raycast / LaunchBar | 同频三秒召回，但知源有方向、有策展、有北极星 |
| 浏览器书签 / AI 对话框收藏 / 稍后读 | 只存不找 / 内容锁在对话里 / 读完没下游——知源各有解法 |

**根 README「与同类产品的本质区别」**重写为直接竞品 + 间接竞品两表，收尾结论：**通用工具比知源"更能装"，知源比通用工具"更能调"**。
