## 问题一：指标读数「不在模块里 / 溢出到模块外」→ ✅ 已按读法 A 修复

### 症状（按红框）
一周的节奏模块里，五枚指标（采集 / 有效动作 / 加权 / 调出 / 节奏波动）读数视觉上没有落在自己的药丸与模块容器里，看起来浮在模块外。用户原话「**依旧**」——与 V3.8.16 W12-B 那轮「数字读不出属于这个模块」是同一类观感，说明当时的修法没有把观感收干净。

### 已核实的代码事实
| 事实 | 位置 |
|---|---|
| 指标行是等宽网格：`.pi-strip`（标签表头，纵向 flex）+ `.pi-strip-row`（`grid-auto-flow:column / auto-columns:1fr`） | `pi-timeline.css:81-82` |
| `.pi-chip`：`height:36px` + **`align-items: baseline`** + `justify-content:center` + `overflow:hidden` | `pi-timeline.css:90-95` |
| 模块卡壳 `.pi-mod { overflow: hidden }` ⇒ 读数**在几何上不可能真的飞出卡片边框**，「模块外」必然是**视觉错位**，不是裁切失败 | `pi-timeline.css:50-53` |
| 三个模块共用同一套 strip（今日 4 枚 / 近期 5 枚 / 全年 4 枚），只此一处定义 `.pi-chip`，无第二处样式覆盖 | 全仓 grep，唯一定义 |
| 本地复现（1440px，深色 linear + 浅色 apple 两套主题，直接链 tokens.css + pi-timeline.css 渲染同款 DOM）：读数**在药丸内**，但因 `baseline` 对齐**整体偏上**，药丸下沿留约 8~14px 空白（复现页与截图是一次性量具，用完即删，未入库） | 一次性无头复现 + 截图实测 |

### 两种读法（需你一句话确认是哪种）
- **读法 A · 药丸内错位**：`baseline` 顶对齐 ⇒ 读数贴在药丸上沿、下沿空一截，浅色主题下对比一强，看着就像"字掉在药丸外面、没进模块"。
  - 修法：`.pi-chip` 改 `align-items: center`（垂直居中），三模块一起收；不动列数、不改宽度（W12-B3 已钉网格形态，`center` 不在它的断言清单里，**不触发判据红**）。
- **读法 B · 整行真的越界**：某档窗口宽度下指标行超出模块内边距/把列撑破。
  - 我在 1440px 复现不出；若你看到的是这种，需要你给一条信息：**当时的窗口宽度**，或该区域的放大截图，我按真实断点修（R173 那套扫描断点的做法）。

### 验收标准
1. 五枚（及今日/全年同款）读数在药丸内**水平垂直双居中**，不再贴上沿。
2. 1440 / 1280 / 1100 三档页面横向溢出 0px（沿用 theme-audit 的量法）。
3. W12-B3 判据仍绿（网格形态、hover/active、标签表头行一字不动）。

## 问题二：今日战报模块头两枚入口重复 → ✅ 已按方案 A 修复

### 症状
模块头右上角「打开战报」文字按钮与旁边蓝色圆形 ▶ 图标，打开的是**同一个** DayDetail 弹窗 —— 同一根 emit 通道，功能完全重复。

### 已核实的代码事实
| 事实 | 位置 |
|---|---|
| **两枚都 `emit('open-battle')`** | `PiToday.vue:49`（`.pi-btn line`「打开战报」）、`PiToday.vue:50`（`.pi-btn pri`「▸」） |
| 宿主只有一条处理：`@open-battle="openTodayBattle"` | `ProfileInsights.vue:479` |
| 这是 V3.8.18（N9）那轮收敛的**遗留**：N9 退役了 strip 里两枚重复 chip，但**模块头这两枚当时被明确保留**，判据 ③ 现在钉的是"模块头**两枚**战报按钮仍在位（≥2）" | `scripts/regression/04-w12-restore.cjs:564,577-578` |
| 页头（PiHero）的战报入口已在 W12-B 收敛掉，**全页唯一重复就剩这两枚** | `PiHero.vue:65-70` |

### 方案选项
| 选项 | 内容 | 判断 |
|---|---|---|
| **A（推荐）** | 保留文字主按钮「打开战报」，删除 ▶ 图标按钮 | 可读、明确；模块头留一枚主入口，与 W12-B 收敛原则一致 |
| B | 保留 ▶ 图标，删除文字 | 省 4 字宽，但纯图标可读性差，与全页其他 `.pi-btn line` 风格不齐 |
| C | 两枚都留、但做主次分工（图标改为另一种能力） | 违背"同一弹窗不给两个入口"，等于新增能力，不在本轮范围 |

### 影响面（选 A 必然触发，按纪律处理）
- **N9 判据 ③ 会红**（`emit('open-battle')` 从 2 枚降到 1 枚）→ 改判据**正文**写翻转理由（用户 2026-10-15 拍板"模块头只留一枚战报入口"），**不删断言**；①②④⑤ 四条照旧。
- 无其他判据钉"两枚入口"；`W12-B3`、`R44-7`、theme-audit（按钮少一枚）需复跑确认全绿。
- 文档同步：N9 判据文字、`PiToday.vue:69-78` 注释里"模块头那两枚仍在用"的措辞要改成"一枚"。

### 验收标准
1. 模块头 `.pi-mod-acts` 只剩 **1 枚** `open-battle` 入口；strip 四枚读数 chip 与四条 drill 键一字不动。
2. 回归全绿（含改写后的 N9），typecheck / dead-css / theme-audit / entry-matrix 全过。
