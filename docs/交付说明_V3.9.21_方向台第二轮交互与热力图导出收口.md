# 交付说明 · V3.9.21 方向台第二轮交互与热力图导出收口

> 发布日期：2026-10-26
> 版本真源：`v2/src/manifest.ts` → `version: '3.9.21'`
> 本批性质：交互闭环 + 导出正确性修复 + 门禁治理 + 过时材料清理

## 一、本批交付

### 1. 方向台编辑链路闭环

- 新建战略目标后切回项目塔，立即聚焦标题编辑；层级列表行内「编辑」也先切回项目塔再聚焦。
- 抽出一份 `focusEditField()`，避免两处各写一套聚焦时序。
- 第 3 层行本体改为 `div role="button" tabindex="0"`，行尾编辑 / 删除保持为真 `button`，不再产生非法按钮嵌套。
- 分组头的编辑 / 删除入口接通，不再只有视觉按钮没有行为。

### 2. 项目舱与项目全景入口分权

- 项目舱头整块点击 = 展开 / 收起，保留 `aria-expanded` 与键盘可达。
- 「全景」改为独立显式按钮，与折叠动作分属不同点击面。

### 3. 主攻项目打开完整只读全景

- 调度台主攻 1 / 主攻 2 点击后打开「项目全景 · 只读」，不再跳路由。
- 弹窗按方向 → 项目 → 指标 → 任务铺开，并给出下一步、断链、停滞、进度。
- 下一步仍走 `resolveProjectNextStep()` 唯一解析；任务归属仍走 `tasksOfProject()` / `tasksOfMetric()`，不复制第二套口径。

### 4. 年度热力图单行全年与导出同坐标

- 热力图改为周列 × 7 天行的单行全年；窄屏横向滚动，不压缩格子。
- 导出 `gridCells` 直接消费 `yearCells` 的 `col/row` 并过滤 `future`，不再保留 12 月块 `bx/by` 算法。
- `buildZyCard()` 改为 `cols: weekCount, rows: 7`。
- `zyCardHtml()` 补齐 `spec.grid` 渲染，HTML 分享页不再只有 PNG 才有格子图。

### 5. 更新日志长历史跳转稳定

- 目录跳转以 `scrollend` 为主信号，1800ms 超时为兜底。
- 新增 `pendingJumpVersion` / `pendingJumpTop` 待落定目标：滚动结束时若目标仍对齐，保留用户点击的版本；只有真实滚离后才恢复正常位置同步。
- 卸载时清理计时器与监听，避免长历史平滑滚动超过 900ms 后高亮回弹。

### 6. 工程门禁与仓库清理

- 新增回归分片 `v2/scripts/regression/105-v3921-compass-round2.cjs`，锁定舱头折叠 / 全景独立按钮 / 项目全景只读 / 热力图导出 / 更新日志跳转与落定高亮。
- 重指 99-recent 中随单行全年形态退役的旧月块断言，理由写进断言体，不删除断言。
- 清理临时浏览器画像与探针残留；保留 2026-10-15 历史 `v2/tmp-*`、当前 census 与当前实拍目录。
- 过时材料按引用与体积盘点：`docs/视觉归档/` 旧日期目录、`docs/原型预览_R167` 与 `R169D` 先做引用核对，不删当前 census / 当前实拍。
