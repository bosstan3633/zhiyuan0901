## 一、Markdown 模板导入实装（T1-T3）

### T1 · 解析器 `shared/utils/mdImport.ts`（纯函数）
- `parseGoalTemplate`：H1=项目（可多个）/ H2=成功指标 / H3=任务 / H3 之下正文=任务详情（多段合并，H4+ 并入详情）；容错：H2/H3 先于 H1 自动建项目承接、H3 直属 H1 自动建指标「通用执行」；
- `parsePyramidTemplate`：H1=中心论点（多余忽略记 extraH1）/ H2=L2 / H3=L3 / H4=L4（严格层级嵌套）；容错：跳级提升至最近合法父级（promoted 标记）+ 虚拟论点承接；
- **TS 在此轮抓到两个真 bug**：H3 最先出现时 thesis 仍为 null（提升分支漏 thesis 承接）、H4 先于 H2 时 cur2 为 null——承接链补全后编译通过。

### T2 · 方向树入口（CompassTree.vue）
- 战略目标节点操作区新增「📋 导入模板」（＋ 添加项目旁）；
- `ImportTemplateModal`（goal 模式）：左栏粘贴 / 右栏实时解析预览树 + 统计；确认后写入——`addProjectToDir` 建项目 → 指标 push（`{ id, title, taskIds }`）→ 任务双挂（projectId + metricId + taskIds 回写）→ 单次 persist；
