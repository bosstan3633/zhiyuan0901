## 一、交付明细

### E1 · 标签体系体检（标签管理页头「🤖 标签体检」）

- 投料：三卡在用标签+用量 top、标签树全路径；契约：只出两类动作——**同义合并**（保守：歧义不并）与**裸标签归位**（toParent 必须树内真实存在）。
- ★parse 消毒：from/to/tag/toParent 任一不在真实用量/树路径 → 该行直接丢弃（端到端实测：mock 故意给不存在的目标标签，行被拦下不落库）。
- 采纳：三卡（资源/任务/好奇）tags 双口径替换（`from` 与 `leaf(from)` 并除、Set 去重）+ 标签树节点剪枝/挪父（findTagNode 路径定位，缺叶补建），一次 persist。

### H2 · 回收站捞回（回收站页头「🤖 值得捞回」+ AI 页同款钮）

- 投料软删清单（删前分类/标签/打开次数/删除日期 + 与现存卡的疑似重复标记）+ 活跃目标参照。
- 采纳语义保守三分：**recover=deletedAt 置空恢复**（与手工恢复同字段）；**purge 只回报不动刀**（真清空仍归回收站手动操作）；keep 不处理。

### G2 · 跨台镜像发现（AI 页「🧭 库内治理 → 🔁 跨台镜像发现」）
