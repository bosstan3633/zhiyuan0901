## 一、体检工具先修，否则结论全是假的

上一轮那份体检有三处方法错误，本轮先修工具再谈发现——**否则"发现问题"只是换种方式骗人**：

| 错法 | 修正后 |
|---|---|
| 把 `overflow:hidden + ellipsis`（**按设计的省略号**）当成"溢出 BUG" | 拆成两栏：**真溢出**（`overflow:visible`，会挤兄弟）与**按设计截断**，只有前者算 BUG |
| 把 `cursor:pointer` 继承来的 `<span>` 当点击目标 → 一堆"点击区 16×21"假阳性 | 只量真交互元素（`BUTTON/A/[role=button]`，且祖先不是交互元素） |
| 对比度把 `color(srgb …)` 写法当读不懂、半透明底色直接回落成白 → 满屏"白字白底 ratio=1" | 底色沿祖先链**自下而上逐层合成**，前景 alpha 也先合成再算 |

修完的真实结论：**上一轮我报的"卡片横向溢出 178~216px、摘要截掉 85~91%"里，摘要那条是按设计截断，不是 BUG**；真溢出只有一处（见下）。

## 二、当场修掉的（有确证、不改设计语言）

1. **卡片页脚标签真溢出**（`.rc-footer` 溢出 32~227px）：标签 chip 是 `flex-shrink:0 + nowrap`，撑破卡片后被 `overflow:hidden` 硬切——截图上就是"最后一列标签断在半截、连省略号都没有"。改成可缩 + 单行省略，页脚自身 `min-width:0 + overflow:hidden` 兜底。**复检：真溢出条目归零。**
2. **检索面板底部键位条换行成三行**（1440 宽下"↑↓ 选 择 / 打开链 接"这种断字）：`flex-wrap:nowrap` + 提示不许断行，空间不够先挤掉右侧品牌语。
3. **命中区过小**：任务 ✦/🤖 菜单钮 **20×17 → 26×26**、分组头排序下拉 **高 15px → min 26px**、列数钮 **20 → 24px**（密集行的现实下界）。
4. **中性小字低于 AA**：`cf-pct`「0%」、`cf-open`「待办 4」、`mb-denom`「/29」在 10~11px 下只有 **3.14:1**（AA 要 4.5）→ 从 `--text-3` 抬到 `--text-2`，复检这三条已从名单消失。
5. **空态必须能自证**（这条是给 A1 收尾的）：抽屉 0 行时以前只说"模型没有给出可采纳的建议"。现在给 **「看模型原文（N 字）」折叠 + 复制**，一眼分清"模型真没答"还是"答了但被消毒丢掉"。开关每轮 run 自动收起，不拿上一轮原文糊弄这一轮。
