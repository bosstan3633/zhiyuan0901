# 交付说明 · V3.9.29 策展台页头审核原型对齐

> 日期：2026-10-28
> 基线：V3.9.28（`9003255`）
> 原型：`评审交接包/原型_策展台页头重设计_审核稿_V1.html`
> 性质：修复 V3.9.28 页头未完整落地的问题；不改数据模型、策展树结构或四主题令牌。

## 一、问题与根因

V3.9.28 的页头重设计只完成了部分状态：有中心论点时已进入新结构，但空论点态仍保留旧灰卡和卡内按钮；成果 HTML 与模板仍平铺成两个入口；分享仍是 ghost 次级按钮。结果是同一套页头在不同数据状态下呈现两代设计，视觉层级与动作优先级都不稳定。

根因不在构建或样式加载，而在实现与验收两端：

1. **实现只改了“有数据”分支**：空态模板未随主舞台一起重写，旧按钮和旧卡片尺寸继续存在。
2. **入口只做了视觉分组，没有完成职责收口**：两个导入能力仍各占一个一级按钮，分享也未恢复为行动条唯一主行动。
3. **回归只验证字符串存在**：旧断言没有检查空态实际高度、主舞台字号/渐变/圆角、分享按钮层级、导入菜单收口和菜单互斥，因此“元素在、结构不对”仍能通过。

## 二、修复结果

### 2.1 中心论点

- **空态**：收为约 42px 单行轻引导，由虚线 L1 图标、一行说明和文本式“开始确立”组成；整卡负责创建，不再出现旧灰卡和卡内按钮。
- **有论点态**：恢复为镇台主舞台，22px 主句、轻径向渐变、14px 圆角和 18/20px 留白；移除左侧粗色条与卡内第二动作。
- **单一动作**：整卡只负责打开论点详情，编辑与 AI 继续留在详情内。

### 2.2 行动条

- 画布读数、内容导入、检索与成果保持三组职责。
- “导入成果 HTML”和“导入模板”收进同一个“导入”菜单，两项能力仍是一级可达。
- 导入菜单触发器阻止冒泡，document 级关闭监听仍能正常关闭菜单；导入菜单与设置菜单互斥。
- “分享成果”只在行动条行尾保留一次，并恢复为 `primary` 主行动；论点卡内不再重复。
- 金字塔 / 树状布局切换继续只归画布头，不在页头复制第二入口。页头“策展画布”是静态画布标识，不承担切换。

## 三、实现范围

- `v2/src/newtab/views/Workspace.vue`：空态、论点主舞台、导入菜单、分享层级与菜单互斥。
- `v2/src/newtab/views/workspace.css`：42px 空态、22px 主句、径向渐变、14px 圆角、行动条与移动端规则。
- `v2/scripts/regression/115-v3929-curation-head-prototype.cjs`：新增 7 条结构契约，锁住上述状态、动作与版本同步。
- `v2/scripts/regression.cjs`：注册新分片。
- 版本、更新日志、手册、README、架构总览与产品认知基线同步到 V3.9.29。

未改：`AppData` / `ResourceCard` / `Category` / 策展树父子关系 / 金字塔与树状布局算法 / 四主题令牌 / 分享产物格式。
