# 知源调度台视觉优化方案（OPPO 官网风格贯彻到底）

## 一、现状盘点（事实与根基）

当前结构语言已是 Token 化（`v2/src/shared/styles/tokens.css`），实体感较强：四级表面阶梯 + 发丝线 + 弱阴影；`[data-theme='oppo']`（tokens.css L325-379）是知源 Logo 蓝的生态绿，但现状距 OPPO 风格仍有三点明确放大空间：

1. **全局有氛围渐变**：`tokens.css` L386-389 的 `html, body { background: radial-gradient(...) }` 在全主题（默认含 oppo）生效，以绿色氛围漂浮在白底上。
2. **oppo 调色系为冷绿阶梯**，缺一套可辨的“暖/冷白 + 蓝系”对比度（用户明确要 OPPO 官网风格）。
3. **UI 密度较高**：卡片 `--card-gap: var(--sp-3)`（12px）、圆角阶梯 8/12 等，没有“低密度、大留白”的表达。

## 二、设计口径（定义“OPPO 风格”在知源产品里的具体形态）

1. **实体感+质感，来自：1px 发丝线 + 深投影（`--shadow-sm/shadow/shadow-hover` 口径随 OPPO 重校），无内阴影、无多层阴影叠加**。
2. **主色与对比色**：`--accent`（生态绿）只用于主行动与当前态；背景层级用纯白阶梯 + 灰绿阶梯，不用饱和块色。
3. **圆角按容器分级**：卡片/按钮 8-12px，标签/小控件 4-6px。
4. **留白节奏**：容器 16/24px，卡片 12-16px，局部呼吸 12px+。
5. **动效保持 Token 化**：`--ease-out-soft` 标准、`--ease-emphasis` 弹层、`--dur` 150ms（保持快，性能优先）。

## 三、五个台面的具体建议

### 知源品牌区（画像洞察页 · `/profile`，文件：`v2/src/newtab/views/ProfileInsights.vue` + `pi-timeline.css` + `PiHero.vue`）

- **布局**：Hero 缩回窄“卡片”，低边框 + 圆角 8px，顶部左侧加层级标（如“品牌圈/今日品牌”）；操作按钮 `pi-btn line` 换为 pill（radius-full）+ 4px 内距。
- **交互**：操作按钮用 accent 次级底 + `--accent-ink` 文字；键盘焦点用 `--focus-ring`（已有全站契约）。
- **视觉基底**：从 `PiHero` 重新排版“页头三件套（刷新/导出/全部记录）”，每个按钮在主图上保持 8px 角。

### 调度台（`v2/src/newtab/views/CompassHome.vue`、今日三件事、四卡池页签、`TodayBattleHost`、`HomeResourceFolderGrid`）

- **布局**：页头大字（`--fs-display`）叠加 kicker，首行视觉焦点在今日三件事；三槽卡等宽堆叠 2 列（≤1440px 双列，≤768px 单列）。
- **交互**：卡状态纯靠颜色 + 勾选框（已有），新增 8px 角整体 + 1px 发丝线。
- **视觉基底**：容器用 `--surface` 白 + 细线 + hover 缩放 1.5%，整体按 OPPO 敢白色质感。

### 方向台（`v2/src/newtab/views/CompassTree.vue`、`CompassSpine.vue`、`CompassTower.vue`、`CompassLane.vue`、`CompassPano.vue`）

- **布局**：骨架线降阶为 `--hairline`；任务行从“按钮化卡”收成“面包屑 + 标题 + 三分列账本（完成热区/标题/优先级+删除）”。
- **交互**：节点 hover 细放大 1-2px，发丝线相邻行连接。
- **视觉基底**：“质感”落在结构：进度条内在部位 + 细线，不加外层阴影，按“轻结构”口径。

### 策展台（`v2/src/newtab/views/Workspace.vue`、`thesis-banner`、`ws-curation-console`、`v2/src/newtab/components/compass/CurationTreeLayout` 等）

- **布局**：中心论点卡按“标题 + 一句话 + 三枚徽标（论据/附件/导入）”三段长卡，顶部 2px 边框 + 8px 角；节点 4px 圆角 + 细放大阴影。
- **交互**：节点“关联卡片”面板 pill 按钮，画布背景加微弱网格/水印（一点点氛围渐变，二选一）。

### 设置页（`v2/src/newtab/views/GlobalSettings.vue` + `views/settings/*.vue`）

- **布局**：顶部导航 pill（8px 胶囊 + active 底色）；页头 2 档高度收窄；左侧导航 pill。
- **交互**：卡片页头加扩展动作右上角，按钮 8px 角。
- **视觉基底**：保持 Token 化，OPPO 风格下更稳、更白，背景留白 ≥20%。

## 四、全局基座建议（文件：`v2/src/shared/styles/tokens.css` L381-398）

- 从全局 `html, body` 的 `radial-gradient` 移除；让 `--lv-*` 等令牌的柔色替代，或在 `[data-theme='oppo']` 加微量半径感 `box-shadow`。
- 重校 oppo 调色系为：冷白底 `#F5F5F7`/`#FFFFFF`、轻暖边框、用 `#168457` 作主色。
- 首屏判定：全局氛围去除为自检基线（`theme-audit` 四主题实拍 + 对比度门禁）。

## 五、实施顺序与门禁（按性能优先）

1. 全局氛围去除 + OPPO 调色系定格（文件：`tokens.css`）→ `npm run gate:theme` + `node scripts/theme-contrast.cjs`。
2. 知源品牌区 + 调度台页头（首屏）→ `npm run build`、`node scripts/regression.cjs`。
3. 方向台读数收紧（不动视图结构）。
4. 策展台节点结构 + 设置页 pill。
每步在最终回复展示实拍（四主题实拍）。

## 七、口径说明与风险

- **截图口径**：四主题实拍以 `node scripts/theme-audit.cjs --tag=R<轮次>-after` 为标准（需 dist + 本机 Playwright Chromium；没有就写“视觉未验证”）。
- **性能保证**：全部只动样式，不动逻辑；实际“第一命脉”由 M1/M14 等体验线同口径验收。
- **可能触及门禁**：改通用样式令牌 → theme-contrast/theme-audit/gate:theme；改设置/存储/交互 → e2e；新增 UI 类 → token 对比 + dead-css 检查，避免硬编码色值。
