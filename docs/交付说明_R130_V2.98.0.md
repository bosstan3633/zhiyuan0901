## 一、八项交付明细

### T1 · 标签树角标与右列卡片数口径合一（原：8 vs 6 对不上）

**缺陷**：左树 `tagUsage()` 与右列 `ttRows` 是两套判据——树按「路径+叶子」双口径统计且**含回收站软删卡**，右列只按「精确路径」匹配且排除软删卡；同一标签两处数字必然错位。

**实现**：新增唯一判据 `cardHasTag(tags, name)`（路径+叶子双口径，沿用 R129-B4 定案）；`tagUsage` 与 `ttRows` 三类卡过滤全部改走该函数，且树角标排除 `deletedAt` 软删卡（用户拍板口径）。树角标 = 右列「N 张」恒成立。

### T2 · 标签管理双击详情抽屉修复（★结构性 BUG：抽屉挂错面板）

**缺陷**：R127 把 `ttDetail` 详情 Drawer 写进了「资源台全景」面板（`v-if="activePage==='panorama'"`）内部——切到标签管理页时该面板整体不渲染，**抽屉组件根本不存在**，双击只是给一个没人消费的 ref 赋值，永远无反应。

**实现**：Drawer 整块迁入标签管理面板（`activePage==='tags'` 段内）。双击 → 详情抽屉（标题/链接/描述/类型/标签 + 打开链接）即刻可用。

### T3 · 多选卡片拖到标签的选中视觉效果（原：全程零反馈）

**缺陷**：标签树行只有 `@dragover.prevent @drop`，没有落点高亮（全景页树有 `.drop` 样式而标签树没接线）；被拖拽的卡片行也没有拖拽中样式。

**实现**：`ttDropTarget` 状态接入根/子标签行的 dragover/dragleave/drop/dragend 全链路；落点行加 `.gs-tt-row.drop`（accent 底 + 1.5px 实心内环，与选中态 active 可分辨）；被拖卡片行 `.gs-pan-card.dragging` 降透明度至 .45。

### T4 · 资源台页头/指标/卡区左缘对齐线（源码不变量确认 + 断言锁死）

**结论**：`.ws-page`（1440 居中）+ `.ws-content`（左右 36px）与顶栏 `align-page`（1440+36）本就是同一条对齐线，与调度台/方向台 `.page`（1440+36）一致；截图上的「错位感」实为 T7 右缘空白带 + T5 直角渲染所致，已随两项修复消除。新增 R130-6 断言把三处锚点锁死，防后续改版再漂。

### T5 · ★`--radius-md` 令牌补齐（R124 遗留历史 BUG：全站 14 处圆角静默失效）

**缺陷**：R124 建立圆角体系时只定义了 `--radius/--radius-sm/--radius-xs` 三档，但全站 **14 处**（资源台 `metric-box`、论点横幅、调度台 `today-card/cur-goal/cur-group`、任务卡 `tm-card`、灯塔面板、CompassTree…）引用了**从未定义**的 `--radius-md` → CSS 变量无效 → 圆角回退为 0，用户看到的「矩形直角硬边」正是这个静默失效。

**实现**：tokens.css 补 `--radius-md: 10px`（介于 8 与 12 之间），14 处消费点一次性全部生效——资源台指标三格/卡片区、论点横幅、调度台三件事卡等统一恢复圆角 + shadow-sm 质感，与其他台风格一致。

### T6 · 策展台金字塔居中留边（原：R127 全幅铺满左右顶到边）

**实现**：`.py-board` 加 `max-width: 1120px; margin: 6px auto 0`——保留 R127 的列自适应 `minmax(170px, 1fr)`（不坍缩）与画布 `width:100%`，网格整体居中、左右自然留白；列数多到 1120 放不下时走画布 `overflow-x:auto` 横向滚动。真全屏态口径不变。

### T7 · 列表视图右缘撑满（★根因：flex 项收缩到内容宽）

**缺陷**：`.ws-columns`（flex 行）内右侧视图列没有 `flex:1`——宽度按内容 max-content 收缩，标题不够长时右缘留下一条空白带（截图红框），行无法右对齐。

**实现**：卡片/列表视图容器挂 `ws-view` 类，CSS 统一 `.ws-view, .kanban, .pyramid { flex: 1; min-width: 0; margin-left: 14px }`——四个视图列全部撑满到容器右缘。

### T8 · 分类树与内容区呼吸间距

**实现**：同上规则附 `margin-left: 14px`，内容区不再与分类树/分隔条贴死。
