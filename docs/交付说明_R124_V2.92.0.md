## 五、偏差与说明（4 条）
1. **光速黑主题语义变更**：accent 由珊瑚红改为统一紫——该主题从「红色强调」变为「中性黑 + 品牌紫」，与深空薰衣草色值一致（同规范双主题）；如后续要合并可再简化。
2. **任务树默认折叠非新增**：R94（B2）已实现默认收拢 + 门控；本轮按提案仅更新按钮文案与确认默认态。
3. **中性档灰点交互**：默认仅 4px 灰点，行 hover 才显示「中优/低优」文字（提案「默认隐去、hover 显现」的落地）。
4. **空态「去资源台挑选」**：直接跳转资源台（跨台引用选择器不存在独立入口；资源台侧仍可用 📡 单卡/📤 分类镜像进入策展台）。
