## 四、根因备忘（防复发）

1. **导入合并必有范围遗漏**：初始实现只处理用户可见实体，罗盘/引擎隐藏数据被静默丢弃——比报错更危险。凡"导入/合并/迁移"类代码，先穷举**数据根的所有分支**再写 merge。
2. **视图不同 v-for 结构导致分组失效**：分组标签与内容卡拆成并列 v-for，视觉标签浮顶、卡片连排。分组交互必须**同区块内渲染**。
3. **多入口共享搜索状态**：检索面板复用组件时 query 状态跨次残留。弹层类交互默认"每次打开 = 全新会话"。
