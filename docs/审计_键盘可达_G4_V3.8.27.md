# 键盘可达审计（G4 · V3.8.27）

> 生成方式：`node v2/scripts/a11y-tab-audit.cjs`（人读）/ `--md`（表格）/ `--count`（棘轮）
> 本报告是**清单**，不是"当批全修"的承诺——B2 已拍板「审计报告 ≠ 当批全修」，先看清家底再定批次。

## 一、为什么做静态审计，而不是只跑 Tab

Tab 遍历只能覆盖"当前这一屏、这一份数据"。一个 `<div @click>` 只要数据里出现就永远不可达，
**不需要真的打开那个页面也能判**。所以本工具对模板做静态普查，`theme-audit` / `e2e` 的
Tab 走查作为交叉验证，两者不互相替代。

## 二、口径（写死在脚本里）

| 条件 | 处置 |
|---|---|
| 只算模板段 | `<script>` 里拼的 HTML 字符串不收 |
| 只算点击入口 | `@click` / `v-on:click`（含 `.stop` 等修饰符） |
| 原生可聚焦豁免 | `button` / `a[href]` / `input` / `select` / `textarea` / `summary` / `details` / `label` / `option` |
| 已声明即豁免 | 有 `tabindex`（非 `-1`）或 `role=` |
| `tabindex="-1"` | 单独列"假修复"——移出 Tab 序列但无键盘处理等于没修 |
| 遮罩层 | `overlay` / `scrim` / `mask` / `backdrop` 单独计数，键盘通道是 ESC，**不计缺口** |
| 先剥注释 | 注释里举例的 `<div @click>` 不算 |

## 三、总量（V3.9.16 最终口径）

**0 处 / 0 文件**；遮罩层 **32 处**已豁免；`tabindex="-1"` 假修复 **0 处**；
`outline: none/0` 焦点杀手 **54 处**。后两项口径不同，不能互相抵消：

- **0 处 / 0 文件** 表示静态模板中已没有“只挂 `@click`、却无法通过 Tab 到达”的入口。
- **假修复 0 处** 表示也没有“只写 `tabindex="-1"`、却不提供键盘处理”的表面修复。
- **54 处 `outline: none/0`** 是另一类残余风险：其中多数用 `border-color` 或 `box-shadow`
  做了替代焦点态，仍需逐条判断替代是否真的可见。**不能把缺口归零写成“无障碍全部通过”。**
- **遮罩层 32 处** 走 Esc 关闭通道，不计入口缺口；它们仍属于浮层键盘行为，需由交互回归继续覆盖。

全量清单：`node scripts/a11y-tab-audit.cjs --md`；机器读数：
`node scripts/a11y-tab-audit.cjs --json`。

## 四、V3.9.16 修复范围

| 范围 | 修法 | 为什么必须先修 |
|---|---|---|
| 全站非原生点击面 | 统一 `v-pressable`：Tab 可达、Enter / Space 触发同一点击；编辑态与嵌套交互不被劫持 | 这不是局部补丁，而是把旧模板里反复出现的同一种缺口一次收口 |
| 顶栏 / 页签 / 卡片 / 列表 / 详情控件 | 补齐键盘桥；关闭按钮优先改原生 `<button>` | 共用组件与三卡列表是覆盖面最大的入口，一处修复能救多屏 |
| 动态链接与容器 | 审计器识别 `:href` / `v-bind:href`，并排除只负责阻止冒泡的 `data-a11y-container` | 避免真链接被误报、纯容器被塞进空 Tab 停靠点 |
| 审计输出 | `a11y-tab-audit.cjs --json` 输出缺口、假修复、`outline` 与遮罩计数 | 让回归读取机器可读口径，不再靠人眼抄报告 |
| 门禁阈值 | G4-2 从 `≤352` 收紧为 `=0` | 缺口既然已经归零，基线就必须钉死，防止回流 |

## 五、历史修复起点

| 处 | 修法 | 为什么它必须先修 |
|---|---|---|
| `Toast.vue` 的「撤销」与「关闭」 | `<span @click>` → `<button>` | 它是**唯一的撤销入口**。不可聚焦 = 键盘用户删错东西后没有退路，这已经不是"便利性"问题 |
| 全局焦点环 | 抽 `--focus-ring` / `--focus-ring-offset` 令牌，`:focus-visible` 消费它 | 原来 2px/40%/1px 是散落在一条规则里的字面量，谁都能再写一条 `outline:none` 盖掉；成令牌后"改一处全站生效"，四主题随 `--accent` 自动跟随 |

## 六、剩余风险与下一批

1. **54 处 `outline: none/0`**：优先检查共享输入、卡片行和树画布，确认每一处都有可见替代焦点态；
   没有替代态的，恢复焦点环或改成 `:focus-visible` 局部规则。
2. **32 处遮罩层**：继续验证 Esc 关闭、焦点圈定、关闭后焦点回归；遮罩本身不需要 Tab 停靠点。
3. **树画布方向键模型**：`CompassTree` / `CompassTower` 的层级导航是另一套交互，不能只靠
   Tab 顺序冒充完成；下一批单独设计方向键 / Home / End / Enter / Space 的完整契约。

## 七、棘轮

G4-3 同时守住报告中的当前口径，避免“数字归零、残余风险却被写成全绿”。
