## 三、功能清单（拟）

### 方向台
1. 页头视觉对齐（摘要文案「主航线与项目全景 · …」+ toggle 文案 + 链接箭头）
2. 愿景/使命锚点条 → 中性卡样式（tag + 分隔 + 进入方向树 ›）
3. 主攻聚焦条 → selected 态 + 选中联动展板（含无主攻空态）
4. 主航线容器标题区对齐（((•)) + 看主线 + 右侧「N 战略目标 · N 攻坚项目」）
5. 战略目标 **3 列网格**（目标卡头：名 + 「期限 · N 项目 (主攻 n) · pct%」）
6. 项目**行卡**（🎯/名称/`pct% · done/total` + 迷你进度条 + selected 态）
7. 项目详情展板重排：单行面包屑（愿景›使命›目标›项目）+ 标题行（名/主攻/大 pct）+ 统计条（4 值）+ 指标块（头 + 任务行[方框/文本/优先级]）
8. 保留能力就地安置：见 Q1/Q3（拖拽排序、跨指标归属、置顶、项目切换、编辑/删除、附件、新建）

### 完整方向树
9. 页头对齐（统计入副标题；返回 + 健康度 badge 保留）
10. 左导航视觉对齐（六层锚点）
11. L1&L2 合并单卡
12. L3~L6 **三列分支网格**：目标列卡 → 项目分支盒（主攻 accent 边框）→ 发丝缩进指标分支（◈ 名称 (done/total)）→ 任务叶（○/✓）；**空指标警示条**（⚠ 暂无支撑任务）
13. 保留能力就地安置：见 Q6/Q7（展开/收起、节点操作、编辑、导入、抽屉/详情入口）
