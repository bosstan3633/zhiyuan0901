# 交付说明 · V4.7.2 行动回流与画像时间轴

> 发布日期：2026-11-23
> 版本：V4.7.2
> 主题：行动回流 · 画像时间轴 · 云同步稳定性

## 一、本版交付

### 1. 今日三件事允许已完成卡回流

- 已完成的任务卡与选题卡可以再次被选择，并填入“今日三件事”的任一空槽。
- 只有当前三个槽位中已经存在的卡片置灰，避免同一槽位重复加入。
- 支持按卡型、项目、状态和关键词选择；已完成卡与未完成卡共用同一套选择器。

### 2. 安排历程补齐创建时间

- 任务与选题详情的“安排历程”模块新增卡片创建时间。
- 时间轴同时呈现“创建卡片 / 写入卡片池”与后续主动安排节点。
- 创建时间只读，不改变既有安排记录、改期链和撤销逻辑。

### 3. 快捷键直达一级卡片池看板

- 任务快捷键直达调度台“任务”页签。
- 选题快捷键直达调度台“选题”页签。
- 两个入口默认进入看板视图，并复位为“全部项目 + 全部状态”，不受上次筛选残留影响。

### 4. 任务清单区分未落图与已落图

- 任务清单在不分组时按“未落图 / 已落图”两层呈现。
- 卡面继续用左侧状态轨与计划日期胶囊区分，不额外增加优先级或评分字段。
- 已落图任务保留原计划执行日期；未落图任务明确提示可拖入日历。

### 5. 画像洞察改为时间轴 / 热力图双视图

- “观察范围”改为双 Tab，默认进入时间轴。
- 时间轴按自然日倒序聚合卡片的写入、状态变更、恢复与删除事件。
- 每张卡带卡型角标和业务状态色；点击卡片打开右侧详情。
- 详情提供“定位回卡片池”，按卡型与卡片 id 回到对应一级页签。
- 热力图继续复用原年度视图、月度日历布局、生命周期与资源唤醒能力。

### 6. 云同步自动探测稳定性

- 云同步自动关系探测失败时只写入错误态，不再向上抛出未处理 Promise。
- 页面保持可用；网络、代理、VPN 或 Supabase 地址异常由云同步面板给出可读提示。

## 二、交互与数据边界

- 不改变六层方向模型、五类卡片对象和四类卡片池。
- 不改变本地优先、邀请制 Supabase 手动快照同步和卡间镜像白名单。
- 不新增自动上传、后台拉取或静默覆盖。
- 生命周期筛选、主题、页面布局和抽屉宽度继续只保存在本机界面偏好。
