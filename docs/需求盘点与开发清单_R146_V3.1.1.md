## 二、沉淀资产（下轮直接复用的规矩）

1. **回退契约三拍**：动手前报数 → 3 秒内可撤销（按原坐标插回）→ 回执点名对象。凡新增删除类路径，按这三拍写，别再各造一套。
2. **真源优先**：跨视图重复的破坏性操作（删节点/删台/归档）一律下沉 `shared/utils/compassCrud.ts`，视图只调用。断言从此用"入口零就地 splice"反向锁，防止有人图快又写一遍。
3. **撤销的边界要如实**：结构节点（目标/项目/指标）**不进回收站**，只有 3 秒撤销窗口；卡才进回收站。文案与手册都按这个口径写，不给"随时能找回"的错觉。
4. **「知」徽标语义**：静止=可点，转圈=在跑，**跑动中再点=取消**。新加 AI 入口必须带 `:spin` 与互斥锁（R146-5 把"全部 .vue 零 🤖"钉成硬线）。
5. **等待类交互的验收口径**：不是"必须有转圈"，而是"要么看得见进度，要么快到不需要"。早停做到 13ms 时，逼测试去抓转圈就是刻舟求剑。
6. **mock 网关要能演坏行为**：流式 + 在 JSON 之后继续拖废话尾巴 + 关键词触发挤牙膏（「慢」），才测得出早停与取消。**测试夹具的保真度决定门禁的说服力**。
7. **`page.evaluate` 里不能引用 Node 闭包变量**：需要页内工具函数就走 `addInitScript` 挂 `window.__xxx`。
8. **浮层类断言先等离场动画**：`TransitionGroup` leave 期间旧节点仍在 DOM，读 DOM 计数要么等 700ms，要么读状态层。
