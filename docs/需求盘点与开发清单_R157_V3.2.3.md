## 五、本轮实踩（施工中记录）

1. **负向自检首版恒不红**：`capsCheck`/`entryRegion` 的 `bad()` 推模块级 `errors` 数组，而 `accounting` 返回局部 `errs` —— 负向自检拿到空壳。修法：`let sink = []`，`accounting` 进场先 `sink = errs`。**教训：断言脚本自己的"失败通道"也要被负向用例覆盖。**
2. **键型证据正则被三元冒号骗**：`chain.ts:86` 的 `bag.steps : bag.items` 让「步骤条」误判为已接。修法：键型证据统一加 `(^|[^.\w'"])` 守卫排掉 `.prop` 前缀。
3. **`autoReport`/`resave` 的证据是 `withReport(`**（实现侧统一挂），裸词对账会漏掉 deliver——恰是文档没记的那一处。
