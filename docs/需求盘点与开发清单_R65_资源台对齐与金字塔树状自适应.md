## 四、关键实现口径

- **资源台批量**：勾选/全选作用域=当前视图可见原生卡；批量删除软删可撤销；移动目标=资源台分类树（层级化下拉）。
- **资源台导入书签**：前 2 级文件夹生成分类（同名同级复用，标准根文件夹跳过），第 3 级+转标签；真身 workspaceId=CURATION_WS_ID。
- **策展台数据包导入**：仅并本台段（workspaces/categories/resources/curationProjections 中指向本台部分），按 ID 覆盖合并并打 importedAt；version 非 2.x 拒绝；全局段不走此入口（走设置页导入）。
- **关联资源卡选择器**：候选=资源台全部未删资源卡，关键词匹配标题/链接；已镜像到本台的标记「已在该台」不可重选；确认逐张 projectCardToBoard 镜像到目标节点分类。
- **金字塔尺寸规则**：列数从上到下单调不减（下限继承父层），保证子模块宽度 ≤ 父模块；DFS 先序决定同层排序。
- **KeepAlive**：include=CompassHomeView/CurationCenterView/WorkspaceView；Workspace 监听 route.params.id 变化复位 activeCategory/搜索/批量勾选/分组折叠，防跨台残留。
- **指标条单行**：标题+日周累计档位+四指标（标签+主数字+副文）一行排布；副行语义保留在 title tooltip；下钻抽屉与口径不变。
