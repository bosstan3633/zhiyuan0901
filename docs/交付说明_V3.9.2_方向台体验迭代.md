# 交付说明 · V3.9.2 方向台体验迭代

**日期**：2026-10-20
**版本**：V3.9.2
**性质**：沿用现有方向台布局与信息架构做体验迭代，不推翻结构。
**原型**：`评审交接包/原型_调度台首页体验重构_审核稿_V6_按键边界修正.html`（桌面副本 `~/Desktop/compass-refinement.html`）

---

## 一、一句话

方向台保留「战略目标 → 攻坚项目 → 成功指标 → 任务」原骨架，补上“下一步”这一层行动提示、项目详情三页签和项目→指标→任务连续下钻，让用户从“看见方向”直接走到“知道现在做什么”。

---

## 二、三项产品决策与落地方式

| 决策 | 落地 | 判据 |
|---|---|---|
| “下一步”采用**新增可选字段 + 任务自动回退** | `Project.nextStep?: string`，零迁移；用户填写优先；为空时取未完成任务中 `doing` 优先、再按 `updatedAt`，并显式标注“按任务推导” | 自动推导只读，不反写字段；旧库/旧备份无需迁移戳 |
| 项目详情第一版固定**概览 / 指标 / 任务**三页签 | 三页签带 `role="tablist"` / `aria-selected`，支持左右方向键切换；切换项目时回到概览 | 概览首屏回答完成度、下一步、断链与推进中任务数 |
| 指标详情入口采用**标题单击改名 + 明确“详情 ›”按钮** | 标题单击仍进入就地改名；新增“详情 ›”打开 `MetricDetailDrawer`，不改变既有编辑习惯 | 项目塔、项目全景、项目详情三处入口一致 |

## 三、改了什么

### 3.1 数据与口径

| 项 | 改动前 | 改动后 |
|---|---|---|
| 项目下一步 | 无此概念 | 新增可选字段；`resolveProjectNextStep` 统一解析用户填写 / 任务回退 / 空态三态 |
| 项目任务归属 | 以 `projectId` 为主，指标任务另算 | `tasksOfProject` 三路并集：`projectId`、`task.metricId`、`metric.taskIds`，按 id 去重 |
| 指标任务归属 | 只认 `task.metricId` | `tasksOfMetric` 双路并集：`task.metricId`、`metric.taskIds`，按 id 去重 |
| 无归属任务 | 只看 `task.metricId` 是否命中 | 只要被任一指标通过任一路径认领就不算无归属；历史单侧关联不再被误报 |
| 旧数据脏值 | 无收敛 | `normalizeLegacyCards` 把非字符串 `nextStep` 收敛为空串，避免模板渲染出 `[object Object]` |

### 3.2 界面与交互

| 项 | 改动 |
|---|---|
| 项目塔舱头 | 增加“下一步”一行，带左侧项目色条；任务推导时出弱标签“按任务推导” |
| 项目全景 | 项目头同样展示“下一步”，与项目塔共用 `compassMeta`，不另算一套 |
| 项目详情 | 概览页“下一步”可点击就地编辑，清空即回到任务回退；三页签分别承载概览、指标、任务 |
| 指标详情 | 新增 `MetricDetailDrawer`：验收标准、目标值、进度、支撑任务均可在此查看与编辑；任务标题继续打开共享任务详情 |
| 连续下钻 | 项目详情 → 指标详情 → 任务详情三层抽屉可叠加，遮罩与抽屉按打开顺序分层 |
| Esc 行为 | 共享 `Drawer.vue` 增加模块级抽屉栈，只有栈顶响应 Esc，一次只关最上层；此前多个抽屉同时监听会一次连关三层 |
| 视觉降噪 | 项目舱与项目全景去掉常驻全局阴影，改用边框、左侧色条、`surface-2` 与间距建立层级；阴影只留给 hover / 拖拽等临时状态 |
| 窄屏 | 方向树左栏在 800px 以下改为可横向滚动项目条；项目塔、全景、详情抽屉补齐换行与宽度回落 |
| 点击热区 | 调度台勾选框、“查看全部”、页脚齿轮、右栏文字钮统一达到 28px 热区；勾选框保留 20px 视觉方块 |

### 3.3 组件拆分

新增三个方向台组件，避免 `CompassTower.vue` 与项目详情继续膨胀：

- `CompassTowerNext.vue`：项目舱“下一步”展示与来源弱标签。
- `CompassTowerOrphans.vue`：无归属任务收容区。
- `MetricDetailDrawer.vue`：成功指标详情与任务下钻。

## 四、顺带修掉的真缺陷

1. **任务归属双写导致“总数对、明细少”**：项目总数按 `projectId` 算，指标页只按 `task.metricId` 算，历史 `metric.taskIds` 单侧关联的任务会进项目总数却在指标页消失。本批统一为双路并集，并在概览直接报“指标缺任务 / 任务未归属”。
2. **三层抽屉一次 Esc 全关**：每个 `Drawer` 各自在 `document` 上挂捕获监听，`stopPropagation` 挡不住同节点更早注册的监听。改为模块级栈后只有栈顶处理 Esc，且关闭时立即出栈，不会吞掉后续按键。
3. **窄屏小热区**：响应式实拍在 1440 / 1024 / 800 三档发现 3 处 24px 热区（页脚齿轮、右栏文字钮），连同调度台勾选框与“查看全部”一并修到 28px，并补进 M6-2 / M6-3b 回归判据。
4. **未来版本注释**：`repository.ts` 中一处 `V3.10.0` 注释改为本版 `V3.9.2`，避免版本语义漂移。
