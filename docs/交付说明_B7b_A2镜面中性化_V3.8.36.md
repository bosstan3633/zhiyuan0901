## 二、A2-1 · 精力落主攻补中性进度条（本批唯一结构件）

**改前**：第四格只有一个孤零零的 `80%`。读者看到它既不知道在占什么的分母，也无从判断算高还是低——"用百分比 + 中性进度条表达"的后半截一直空着。

**改后**（`PiHero.vue` + `pi-timeline.css`）：

- 第四格加 `hero-kpi-bar` 类，下挂 `.hero-kpi-track`（轨）与 `.hero-kpi-fill`（条）。
- **轨 = `--surface-3`，条 = `--accent`，两种中性色**；不设分段、不设阈值线、不随数值换色相。
- 宽度做 `Math.max(0, Math.min(100, focusShare))` 夹取，数据越界撑不破轨道。
- **负锚**：另外三格是计数与熵值（无「占多少」语义），一律不给轨。

**为什么进度条最容易变回鞭子**：一旦有人按高低分段染色（<60 绿 / <80 黄 / else 红），镜子立刻带上鞭子，**而且比原来的裸数字更具说服力**——人会不自觉地把长度读成评分。所以 `A2-2` 把"不许出现阈值色令牌、不许出现分段选择器"钉成了负锚。

**四主题实拍**（读数 50% 的种子）：

| 量 | 值 | 判读 |
|---|---|---|
| 四格数 / 带轨格数 / 轨数 | 4 / **1** / **1** | 只有第四格有轨 |
| 轨宽 × 轨高 | 177px × 3px | 细轨，不抢读数 |
| 条宽 | **89px** | = 轨宽的 50% |
| **宽度与读数一致** | **是**（实测占比 50% vs 读数 50%） | ★进度条真的在表达那个数 |
| 其他格误带轨 | **0** | 负锚守住 |
| 轨色 / 条色 | linear `rgb(28,31,38)`/`rgb(94,106,210)`、raycast `rgb(27,27,33)`/`rgb(30,111,217)`、apple `rgb(234,234,239)`/`rgb(132,82,224)`、notion `rgb(238,234,227)`/`rgb(158,63,175)` | 随主题变，但都是中性色 |
| 四主题一致性 | **零漂移** | — |

## 三、A2-2 · 清掉两处「镜子带鞭子」的残留

### 修法一：评价式措辞

`PiRhythm.vue` 的分区标题是 **「偏离预警」**。「预警」是替用户宣布"你偏离了"——那是**评价**，不是事实。A2 原文明令"删除任何『值得警惕』式视觉"。

改为 **「规则对照」**：只陈述"哪条规则的实测值和阈值不一样"，好不好由用户自己判断。**规则一条没删**，展开看阈值与实测照旧（判据 A2-3 把"内容不许被删空"也钉住了）。

### 修法二：名不副实的类名

原 `:class="{ warn: openRule !== r.id }"` 的 `warn` 表达的是**未展开态**，与"这条规则有警告"毫无关系——纯粹借用了警告语义。读者会把"还没点开"读成"这条有问题"。

改为 `collapsed`（已折叠），说的是它本来的意思，并给中性灰度。

## 四、★ 门禁当场打回的一处（值得单列）

折叠态我初版把 `.pi-rule-text` 与 `.ar` 降到 `--text-4`，**`theme-contrast` 的 W12-G 当场判红**：

```
✗ 交互控件用了最淡档 --text-4（notion 主题 ≈2:1，真机隐形）2 处
```

按门禁给的修法提到 `--text-2`。**三档同色后折叠怎么表达**——靠**正文块 `.pi-rule-body` 的有无**（展开才渲染），不靠文字深浅；弱化交给 hover。

这正是 AA 护栏的价值：**"降噪"最容易滑向"降对比度"，而这条闸会当场拦住**。已把备案写进 CSS 与判据正文（R153-4：降噪只能动字号与间距）。

## 八、★ 实拍踩的两个坑（复用脚本前必读）

B7-b 的实拍脚本第一版**四主题全 0**——但那不是"一致"，是**四主题都没渲染出来**。这类假绿比假红更危险。两条根因：

1. **种子数据模型错了**：我把卡片塞进顶层 `resources` / `eventLog`，而真实模型是 `curiosities` / `tasks` / `activityLogs` / `stats` / `tagTree` 分表。数据没进模型，页面直接空。**修法：直接复用 B7-a 那份经实拍验证的种子**，只换量测内容。
2. **迁移戳不全**：只写 `hubMigratedAt` 时，启动迁移会把卡洗掉（须齐 `hubMergedAt` / `subtasksFoldedAt` / `hotStatsSplitAt` / `tagsVisibleMigratedAt`）。

另加两条纪律（已写进脚本注释）：**host 必须从 `serviceWorkers()` 动态取**（硬编码扩展 ID 一旦 manifest 改 id 就整批全 0 且不报错）；**等选择器真的出现，不等固定时长**。
