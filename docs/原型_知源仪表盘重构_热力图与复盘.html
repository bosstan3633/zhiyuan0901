★ 关于「调出维度」的事实更正

我 R1 的说法不准确，更正如下：

  • 日志功能确实存在：zy_event_log + 调度台「写入记录」+ 设置「操作记录」三处都在记，这点你说得对。
  • 但它记录的动作枚举只有 新增 / 删除 / 恢复 / 清理 / 状态变更 五类（eventLog.ts:36）；快照 diff 只比 createdAt / deletedAt / status（SnapshotEntry），不含 callCount / lastCalledAt。
  • 你在「写入记录」里看到的"调出"，是拿 lastCalledAt >= 今日零点 现算的（CompassHome.vue:97）—— 所以今天看得到、历史看不到。
  • 结论不变：要补 call 事件（Q4 你已同意）。这是"补一类记录"，不是"从零建日志"。
