## 三、豁免清单（裸色值审计）

全仓 `#hex` 审计（排除 `tokens.css`）共 25 处命中，其中 **12 处豁免**、13 处本轮治理完毕（含 5 处幽灵令牌）：

| 豁免项 | 位置 | 理由 |
|---|---|---|
| 主题色板定义（4 处） | `App.vue` `themes[].dot` | **主题标识色本身**——主题选择器需要在切换前就显示各主题的代表色 |
| 数据层默认值（5 处） | `App.vue` / `defaults.ts` ×2 / `migration.ts` / `curationMigration.ts` 的 `Workspace.color` | **数据字段的默认值**，非样式；且是用户可改的初始值 |
| 注释中的历史 hex（2 处） | `CompassHome.vue` / `workspace.css` 的 R118 说明注释 | 记录「原值是什么」，被注释剥离后不参与渲染 |
| 透明棋盘格（1 处） | `AssetPreview.vue` `repeating-conic-gradient` | 表达「此处是透明背景」，必须中性深色、与主题无关 |
| 开关旋钮（3 处） | `CompassTree.vue` / `GlobalSettings.vue` ×2 的 `background: #fff` | iOS 风格开关的白色圆钮，**任何主题下都是白钮**（与轨道形成对比），非「白底白字」 |
