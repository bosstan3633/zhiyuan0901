# 交付说明 · R4-Dl · ⌘K 面板进视觉门禁 + 截图可复现两闩

**日期**：2026-10-01 · 基线 V3.7.1（`5dc79b4` R4-Dk）· **未升版**
**来源**：#114 挂账里的门禁基建部分（R4-Dj 记下的"截图跨时间不可复现这件事本轮只记录未修"，以及 R4-Pa/R4-Dk 两轮都写在边界里的"⌘K 面板在 theme-audit 里仍零场景"）。

## 一、为什么"只拍一张图"不算覆盖

⌘K 面板这条链在 R4-Pa 之前是**运行时与像素双重零覆盖**；R4-Pa 补了 E2E-37、R4-Dk 补了 E2E-38，把数据路径与召回钉住了，但像素层仍然没人看。这一屏要抓的四件事，全都属于"源码文本断言里表现为什么都没变"的那类：

| 判据 | 为什么文本断言看不见 |
|---|---|
| 面板真开（`opacity > 0.9`）且宽 680、**不越视口** | `.gp-overlay.open { opacity: 1 }` 在 CSS 里写着，规则有没有作用到盒子上看不出来（R4-Dh 的同一条教训） |
| 高亮真渲染：`mark.gp-hl` 数量 ≥1 且**它的底色 ≠ 面板底色** | `hlTitle()` 存在不等于 `<mark>` 出现了；`v-html` 失效时行还在、字还在，只是没黄底 |
| 输入框不吃浏览器白底（透明随面板或等于面板底色） | 这正是 R4-Dh 在设置页抓到的失效形状，面板里同一族控件此前没核过 |
| **hover 才露出的那排动作钮真能露出**（可见钮 ≥3） | ⭐/🗑/↗/🔄▾ 只在 hover 时可见。E2E-37/38 与 /tmp 探针走的都是 DOM 级 click（`btn.click()` / 直接点 handler）而不是坐标点击，"鼠标移上去看不看得见"这件事两轮都留在盲区 |

还有一条是探针留下的经验：**hover 判据必须在 `resetView` 把鼠标挪走之前测完**（本脚本 R4-Dj 起就在截图前 `mouse.move(0,0)` 清 hover 残留）。所以这一屏的 hover 测量放在 `act` 里、结果挂到 `window.__gpHover` 交给 judge——判据把这条时序本身也钉住了，将来谁把 hover 类测量搬到截图前，测到的必然是未悬停态，那条断言就会红而不是"永远绿"。

检索词面故意**从当前结果流第一行取**（截两个字符）：写死词会随用户库内容变化而搜不到，那一屏就退化成一张空态图，判据还会绿——这就是"静默量空"在视觉门禁里的样子。

## 二、★截图可复现：两道闩，实测 13/24 → 24/24

R4-Dj 量过这件事：同一份代码连采两次，仍有 **25-26/92 张逐像素不同**，于是"改前改后截图对比"只能同会话双构建做，跨时间拿归档当基线会淹死在噪声里。当时只记录未修，这轮修的是两个噪声源：

1. **分钟级相对时间文本** ⇒ `ctx.addInitScript` 把 `Date` 冻到本次运行的 **UTC 日起点**（只冻无参构造与 `Date.now()`，`new Date(x)` 原样透传，性能计时完全不碰）。同一天内任何时刻重采，"X 小时前"这类文案恒定。
2. **动画窗口** ⇒ `resetView` 注入 `*,*::before,*::after{animation:none;transition:none}`（只注一次，靠 `window.__ZY_CALM__` 防重复）并把非循环动画 `finish()` 掉。静照里本来就没有"正在动"这件事；**终态类判据（hover 露出、选中变色）不受影响**，因为 `transition:none` 让终态瞬时生效。

**两道闩都留了逃生阀**（`--no-freeze` / `--no-calm`），这不是装饰——关掉它们才能在**同一会话同一构建**上量出"没有它会怎样"：

| 套 | 配置 | 同码重采字节一致 |
|---|---|---|
| raw | 两闩都关 | 24 张里 **13/24 字节一致**，11 张不一致：`dashboard / deck / deck-pool-list / deck-batch / drawer-resource / dz-day / dz-drill / dz-entry / dz-hl / dz-overview / gp-search` |
| det（单主题） | 两闩都开（默认） | **24/24 字节完全一致** |
| det（全量 4 主题 × 24 场景） | 两闩都开，两次独立跑 | **90/96 字节一致**；对余下 6 张再做像素比对：**4 张逐像素一致**（差在 PNG 编码抖动，img-diff 报「包围盒：无」）⇒ **逐像素口径 94/96**；2 张有真差：`linear-dz-hl` 11 px / `raycast-dz-day` 20 px，各占 0.001%，包围盒同落在 `y=285-290, x=260-630` 那条 5px 横带（仪表盘同一行）|

两点要如实写下：
1. **字节级比像素级更严**（PNG 编码器只要输入像素相同就应输出相同字节），所以 90/96 里那 6 张的差异其实是**同一张图的两种合法编码**——img-diff 逐像素比对的结论是 94/96 可复现。
2. **剩下的 2 张本轮没修**：都在仪表盘，各 11 / 20 个像素、最大通道差 9-11、集中在同一条 5px 横带上。这个量级比改前的噪声小三个数量级，但它不是零——继续追需要看清那一排是什么（像是热力格/摘要卡的一行边框做了子像素舍入）。**口径也顺便纠正：A/B 应当用 img-diff 逐像素比，不该拿 md5 当判据**（这条 R161 就写过，本轮又验证一次）。

## 三、还有一处污染必须堵住：收尾认不出 ⌘K 浮层

theme-audit 的台面/场景之间**只切 hash 不整页重载**（脚本自己的注释就写着"浮层是全局的 ⇒ 上一主题没关掉的评审面板会一路盖住后面所有台面图"）。而 `overlayOpen()` 原先只认 `.md-panel, .drawer`——**⌘K 浮层不在里面**，所以这一屏一旦开拍，开着的面板会漏进后面每一张图，且没有任何一条判据会红。现已把 `.gp-overlay.open` 纳入检测，并在兜底里加一条：面板**没有关闭钮**，点遮罩盒子左上角（`position: {x:6,y:6}`）触发 `@click.self`；点中心会命中结果行、反而打开详情。

## 四、判据 +4 与门禁

判据：gp-search 场景在位且判据核到那四件 + 越视口（不许退化成"只拍不核"）· hover 测量的时序（`act` 内、早于 resetView，经 `__gpHover` 交回）· `overlayOpen`/`closeOverlays` 认得 ⌘K 浮层 · 两闩在位且**可关**（逃生阀 + 只冻无参 Date + 终态判据不受影响的实现细节都点名）。

活性变异六条（各还原复跑回绿，且每轮都断言"还原后 R4-Dl 侧全绿 + 文件与备份逐字节一致"）：
`.gp-overlay.open` 从 `overlayOpen` 选择器里摘掉→判据③红；`window.__gpHover` 改名（等于把 hover 测量搬出 act）→判据②红；
`if (calm && …)` 改成无条件常开（逃生阀消失）→判据④红；从 `const ok` 表达式里删掉高亮底色那条→判据①红；
删掉 `hover.acts && hover.vis >= 3`→判据①红；把 `!overflow` 换成 `true`→判据①红。

★**H4 第一轮跑出来是"没红"，而那正是判据①自己的缺陷**：我最初整段 grep 场景体，而 `markBg !== panelBg` 这类串在**打印明细的模板字符串**里也出现一遍——把判据从 `ok` 表达式里删掉、只留明细，断言照样绿。这就是本仓库反复记的"断言还在、证据已空"，只不过这次是**我自己刚写的断言**。修法是把判据收进 `const ok =` 到 `return {` 之间那一段（`okExpr`），并加一条 `okExpr.length > 40` 防"切片为空恒真"。修完三条逻辑级变异才全部响。

门禁：回归 **1603/0**（R4-Dk 基线 1599+4）· theme-audit **96 图 0 个 ✗**（92→96，归档落 `docs/视觉归档/2026-10-01`）· contrast 全绿 4×14 · 导入兼容 7/0 · 循环 0 · 入口字面量双向 15 项全 0 · 索引一致 178 文件 / 42,846 行（本轮 `src/` 一字未改，行数与 R4-Dk 相同）。**本轮没有重跑 e2e/perf，理由不是省事**：改动全在 `scripts/theme-audit.cjs` 与断言里，`git diff -- v2/src` 为空 ⇒ dist 与 R4-Dk 提交时那份完全同一，而 E2E 38/0 与 perf 的 M5c/M5d 就是跑在它上面的（`find src -newer dist/manifest.json` 会列出两个文件，那是变异探针 `shutil.copy` 还原刷新的 mtime，不是内容变了——判据用 `git diff -- v2/src` 而不是 mtime）。ZIP 未重打包、未 push。

## 五、边界如实

- **冻结的是"日"不是"永恒"**：冻到 UTC 日起点意味着跨日重采仍会不同（相对时间往前跳一天），这是数据本身应有的变化，不是噪声；归档目录名本来就按 UTC 日命名。
- **`--no-calm` 关掉的动画闩不影响 e2e/perf**：它们各有自己的等待策略；本闩只作用在 theme-audit 的截图前。
- **hover 那排钮仍然只核了"能露出、数得清"**，没核它们**长得好不好看**（尺寸/间距/与行重叠）。版式细节属于"要改就改"的那类，不在这一屏的判据里。
- **本轮没动任何产品代码**：`src/` 一字未改，改的全在 `scripts/theme-audit.cjs` 与断言；因此 e2e/perf/contrast 的读数与 R4-Dk 一致，未重跑 perf。
- 面板遮罩 `backdrop-filter: blur(20px)` 带来的那条 ~100ms 阻塞仍在（#114 的②），它是设计决策，需要用户拍板，本轮没碰。
