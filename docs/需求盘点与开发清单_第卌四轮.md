## 2. 功能点明细

### F1 知源北极星重构（首页，布局保持 2×3）

- **F1.1** 上排三卡原样保留（DHI/WCE/WRR，含周期切换）。
- **F1.2** 下排「📈 今日新增」「📉 今日删除」卡：大数字 + 分类型副标（资源x·任务y·好奇z），computed 实时派生（createdAt/deletedAt）；点击开抽屉逐条明细（时间+类型+标题），条目单击打开卡片详情。
- **F1.3** 未归档任务卡（N/M）：下钻抽屉 = 待归档清单 + 原因徽标（未挂项目/未挂指标/⚠引用失效）+ 级联归档。
- **F1.4** 撤出：模块分组卡、链接卡片卡（逻辑迁往工作台全景/仪表盘）。

### F2 知源仪表盘（设置页默认首屏，三段式）

- **F2.1** GlobalSettings 打开默认落在仪表盘，侧栏第一位；章节「📊 知源仪表盘 DASHBOARD」。
- **F2.2** 核心指标 5 卡（可下钻）：总卡片（含今日 +N 小标）/ 资源 / 任务 / 好奇 / 链接卡片（跨全部工作台口径）。
- **F2.3** **动态条（可点击）**：今日 +N/−N · 本周 +N/−N · 累计删除；每段点击 → **右侧抽屉明细列表**，交互对齐北极星抽屉（时间+类型+标题，条目可打开卡片）。
- **F2.4** **操作记录时间线**：行 = 时间 | 增/删徽标 | 类型 | 标题 | 详情▸，点击行展开（归属/链接/标签/附件/摘要）；筛选 = 卡片类型（全部/资源/任务/好奇）× 动作（新增/删除/恢复/永久删除）× 时间范围。
- **F2.5** **CSV 导出（按筛选）**：导出**操作记录时间线当前筛选结果**；列 = 时间/动作/卡片类型/标题/摘要/归属/卡片ID；UTF-8+BOM，文件名 `zhiyuan_操作记录_YYYYMMDD.csv`；筛选变化 → 导出范围随之变化。
- **F2.6** **事件日志 `zy_event_log`**：append-only 独立 key（不进主 JSON），写入点 4 处（创建/软删/恢复/永久删除），标题快照保证 purge 后可溯，**5000 条滚动淘汰**（≈0.6MB）；旧数据日志为空时回退纯派生（createdAt/deletedAt），新旧无缝。

### F3 工作台全景（设置页第二屏，双栏 Master-Detail）

- **F3.1** **左栏 · 全景计数树（默认全展开）**：工作台（卡数）→ 分类（卡数）→ **子分类**（卡数）——`Category.parentId` 第八轮已支持 2 级分类，树纯派生零迁移；当前分类蓝色高亮；拖拽悬停目标绿虚线高亮"投放至此"；顶部小计"X 工作台 · Y 分类 · Z 卡"；**只列资源工作台，不含知源罗盘/知源引擎**。
- **F3.2** **右栏 · 卡片列表**：面包屑「工作台 / 分类（/ 子分类）· N 张」+ ☐全选本分类 + 「移动到▾」；行 = 复选框 + 标题 + 来源/日期副标；滚动加载。
- **F3.3** **批量操作条**：勾选后浮现「已选 N 张 · 移动到▾ · 取消」。
- **F3.4** **移动双通道**：①拖拽——勾选后拖到左栏目标分类/子分类节点，松手即移动（跨工作台 = 改 workspaceId/categoryId，零新数据模型）；②「移动到▾」工作台/分类级联下拉兜底。
- **F3.5** 交互统一：单击详情、双击打开；移动只改归属，不触发软删。

### F4 设置页导航五组重组（12 项一项不减）

| 组 | 项 |
|---|---|
| 总览 | 📊 知源仪表盘（默认）/ 🗺 工作台全景 |
| 卡片与字段 | 📇资源卡 / ✅任务卡 / 💡好奇心卡 / 🏷**标签管理（上移）** |
| 数据 | ⬇导入数据 / ⬆导出数据 / 🔄重置与回滚 |
| 系统 | 🔌扩展设置 / ⌨快捷键设置 / 📖使用手册 / ✉️一封信 / ℹ关于 |

### F5 BUG 修复：未归档任务

- 双校验：`metricId`/`projectId` 必须指向真实存在对象，悬挂引用计入未归档；抽屉原因徽标；R44 断言锁死。

### F6 PDF 新标签页打开（方案 A，不做 Office）

- **F6.1** 泛化 `htmlAsset.ts` → `fileAsset.ts`：落盘 + 路径记忆（`zy_file_paths` 同模式）+ `tabs.create(file://…)`，Chrome 内置 PDF viewer 渲染（已真机实证）。
- **F6.2** `AssetMeta.kind` 增 `'pdf'`；四宿主接入：AssetManager `guessKind`、AssetBadge 图标、Workspace 双击 zy-asset 分支、AssetPreview。
- **F6.3** 上限：单文件 **100MB**；**单卡 PDF 唯一、重复上传 = 替换**（沿 HTML 模式）。
- **F6.4** manifest 无需新增权限；已落盘副本纳入设置页占用统计。
