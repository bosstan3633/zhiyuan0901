## 二、任务明细

### A · 方向台二级导航闭环（方案 A，已拍板）

- **A1 来源感知返回 + 面包屑**：项目详情/完整方向树页头统一「← 返回{来源} ｜ 方向台 / 页名（上下文）」；跳转携带 `?from=`（`proj`/`tree`），无来源默认方向台。
- **A2 断链补全**：方向树项目节点加「进入项目详情 ›」（带 `from=tree`）——此前只有抽屉无页面直达。
- **A3 定位跳转**：项目详情 4 处「完整方向树」跳转带 `?hl=<dirId>`；方向树接收后滚动+闪烁定位（复用 R51-F15 的 goal-flash 视觉）。
- **A4 Esc 返回**：全局 Esc 在方向台二级页（无浮层可关时）= 返回来源/方向台，与全产品「逐层关闭」语义对齐（App.vue 全局键统一实现，避免双监听）。

### B · 项目调度增强（新 #1）

- **B1 分栏拖拽**：`.cur-cols` 固定 38% 改为可拖拽分隔条（30–75%），宽度持久化 `UIPrefs.curSplit`；
- **B2 指标下钻**：左列 4 指标卡（成功指标/任务总数/已完成/进行中）可点击 → 弹窗列明细（指标清单含进度 / 对应任务清单），单击任务打开详情抽屉。

### C · 任务调度快捷键（新 #2）

- manifest 新增 `open-tasks` 命令（无默认键，chrome://extensions/shortcuts 自行分配）；background 照 open-tree 模式分发 `/?zone=task`（CompassHome 已有 `query.zone` 监听，直达任务调度面板）；设置页快捷键中心补文案。

### D · 策展中心拖拽修复（新 #3，R53 回归 bug）

根因分析：① 卡对卡 drop 只支持「同分类排序」，跨分类拖到卡上无反应（`onCardDrop` from<0 直接 return / `onProjDrop` 要求同分组）；② **源镜像卡区（📡 源分类实时镜像）完全没有拖拽实现**；③ 拖拽中断（拖到无效区）后 `dragId` 残留。修复：

- **D1 卡对卡统一语义**：任何卡拖到任何卡上 = 同分类内排序 / 跨分类移动+插入落点（原生↔投射混合同样处理）；
- **D2 源镜像卡可拖**：拖到分类/卡上 = 自动创建投射记录落该分组（「拖拽即镜像入组」），已有记录则移动；
- **D3 dragend 清理**：dragId/dragCatId/dropMark 统一复位，杜绝状态残留；
- **D4 拖拽视觉反馈**：卡片拖过树节点时复用 drop-into 高亮。

### E · 设置导航重组（新 #4）

- navGroups 五组 → 四组：`总览 = 知源仪表盘 + 工作台全景`（并列）；删除「整理」组；其余组不动。

### F · 工作台名图标去重（新 #5）

- GlobalSettings 5 处 `{{ w.icon }} {{ w.name }}`（name 自带 icon 前缀 → 图标×2）改为 `w.name.replace(/^[^\s]+\s/, '')`（对齐 547 行既有正确写法）；全仓 grep 排查同类组合。

### G · 手册更新（新 #6）

- 方向台二级导航（返回/面包屑/Esc）、项目调度分栏拖拽与指标下钻、任务调度快捷键、策展拖拽语义（拖源卡=镜像入组）、设置四组导航、图标修复说明。
