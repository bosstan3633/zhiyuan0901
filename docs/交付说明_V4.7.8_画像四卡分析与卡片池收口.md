## 一、本轮改了什么

### 1. 画像洞察：全库指标汇总 + 四卡分析

- 年度热力图下新增「全库卡片总览」：在库总量、近 12 个月活跃资产、高价值冷却、任务有效资源支撑率、近 30 天精力落主攻；次级读数含本月新增、四类卡构成、标签熵、活跃天、最长连续、有效动作、单日峰值与 P90。
- 原「卡片分析」改为任务 / 资源 / 好奇心 / 选题四页签。每个页签统一为「首层读数 → 项目与指标分布 / 状态构成 → 行动与质量 → 明细清单」，所有汇总数字都能点击收窄明细。
- 任务卡分析回答：在库、完成、挂项目或指标、已落图 / 未落图、曾进入今日三件事、平均与最高进入次数、无有效资源支撑、归属冲突、项目指标分布。
- 资源卡分析回答：链接可用率、被活任务引用、零引用、近 30 天真实调出、从未调用、高价值冷却、链接构成。
- 好奇心卡分析回答：状态构成、计划、来源、附件、资源支撑、超过 30 天未动与已转化；不伪造项目 / 指标分组。
- 选题卡分析回答：状态构成、项目指标分布、成果出口、资源支撑、计划执行、本月新增与近 30 天新增。
- 任务与选题详情抽屉补齐安排历程、今日三件事时间轴、关联资源与项目指标，画像分析里的卡可直接打开同一套完整详情。

### 2. 今日得分可解释

- 热力图下新增今日得分行：显示当日总分、档位与「采集 / 调出 / 状态 / 修改 / 三件事 / 关联」逐项得分。
- 同一卡片同日的重复状态事件按最终态只计 1 次；正序与倒序事件流得分一致。
- 采集后 24 小时内删除的卡片按折后分计入拆解明细；三件事完成与任务完成可以叠加，不设 100 分封顶。
- 零权重动作单独列示并计入零分动作数：任务 / 好奇心回到待办、选题状态变更、子任务勾选均不改变总分与各项和，也不产生假残差。
- 提供可展开的完整计分规则，说明每个动作的计分条件与上限。

### 3. 今日三件事与任务状态联动

- 任务进入今日三件事时，无论来自手动落槽、自动推荐还是启动 reconcile，都统一从「待开始」切到实际进行中状态；已完成任务保持完成，不降级。
- 详情、任务列表、看板、项目全景与今日卡槽统一读 `taskStatusOf()`，不再出现卡槽外显示进行中、详情仍显示待开始的双口径。
- 移出卡槽或取消排期不回滚状态；只有用户点击显式撤销且任务仍停在本次写入状态时才恢复。
- 存量「槽位已在今日、任务镜像仍为待开始」的精确脏签名做一次性修复，修复版本戳避免覆盖用户后续手改。

### 4. 卡片池日历与时间轴

- 任务月视图固定 830–860px，周视图独立 660–730px，左右栏拉伸同高、左栏内部滚动；选题日历 820–840px，好奇心日历 700px。
- 月视图当日格优先展示今日三件事前三条，普通任务收进 `+N`，不再让普通任务挤掉今日焦点。
- 任务、选题与好奇心时间轴按每张卡的最新记录保留类型色；同一张卡更早的记录统一虚线灰阶，不响应悬停上浮，避免旧记录干扰当前任务阅读。

### 5. 八个确定性修复

| # | 修复 | 口径与验收 |
|---|---|---|
| 1 | 有效资源支撑统一口径 | 全库总览、任务分析、下钻明细与说明文案统一按「活任务 × 活资源 × 资源当前有可用链接」计算，支撑率与对账条共用同一份任务证据索引。 |
| 2 | 「最高进入」精确 | 任务与选题均按 `focusCount === focusMax` 精确命中，不再用「曾进入」泛筛选冒充最高进入；两页汇总都接 `focus-max`。 |
| 3 | 选题本月新增按自然月 | 「本月新增」从自然月 1 日起算；另保留独立的滚动 30 天新增读数与筛选，不再混用两套时间窗。 |
| 4 | 选题指标分布与筛选 | 选题页签补项目 / 指标分布；指标 chip 可下钻到 `metric:*` 明细，歧义卡不重复计数，未归属固定置底。 |
| 5 | 今日得分零权重动作补算 | 任务 / 好奇心回到待办、选题状态变更与子任务勾选进入零分动作数并单独列示，不改变总分、各项和与残差。 |
| 6 | E2E-42 重指 | 用例从旧「四格 KPI」重指到 V4.7.8 的全库总览四读数，继续验证卡片清单、知识熵解释与主攻动作记录抽屉真实响应。 |
| 7 | 手册首章版本 | 使用手册首章标题与页内版本标识同步到 V4.7.8，不再停留在上一轮版本。 |
| 8 | 文档与门禁回填 | 回填文档中心 INDEX / README 与本轮交付三件套的版本、读数、包体与截图引用；门禁基线按 630 / 2,591 / 80 / 128 / 1,519 / 6,402 等实数对齐。 |

### 6. 兼容与边界

- 未新增运行时依赖、埋点、遥测或外部上传。
- 画像聚合为纯派生层，不改写主数据；资源支撑只读活任务 × 活资源 × 可用链接，解绑立即回落。
- 时间轴历史降噪只改展示语义，不删除事件、不改写卡片状态。
- 今日三件事状态写入统一收敛到一个写入器；手动、自动推荐与启动 reconcile 都只在任务实际落槽时推进状态。
