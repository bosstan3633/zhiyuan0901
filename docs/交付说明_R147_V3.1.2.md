## 一、弱相关建议行默认不勾（不再拿勾选率装准确）

**病根**：评审抽屉过去把**所有**建议行默认勾上，"采纳 6 条"里的 6 是模型给的数，不是你判断过的数。模型在凑数的时候，勾选框是站在它那边的。

**改**：`AiRow` 新增 `weak`，抽屉初始化 `picked` 时剔除 weak 行，行上挂**「低置信」**徽标 + 一行说明「N 条判为弱相关，已默认不勾——要采纳请自己勾上」，并给**「只留高置信」**一键收口；**「全选」仍可整批勾上**（判定权在人不在模型）。

**判弱只准用客观信号**，四条都写死在工厂里，没有一条是"模型觉得"：

| 场景 | 判弱条件 |
|---|---|
| 推荐资源卡（A3） | 模型没给 `why` |
| 找佐证（G3′） | 同上 |
| 好奇心研判（G2） | 没给判词（转任务/搁置都会真的动卡，没判词等于替你做决定） |
| 论点骨架（G1） | 该支一张佐证卡都没 cite 到 |
| 罗盘链式生成（四层） | 该条没给 `why` |
| 打标补全（三处） | 建议的标签**不在既有体系**里（AI 造词）——单独成行、默认不勾、写明"勾了才进体系" |

「既有标签体系」口径收进 `shared/utils/tags.ts` 的 `knownTagSet(d)`（树上路径 ∪ 叶子名 ∪ 活卡在用标签），单卡补全 / 批量补全 / 详情抽屉三处共用，不再各猜各的。

**冒烟实证**（V1b）：mock 回三行——有据行勾着、缺理由行不勾且带「低置信」、编造 id 的行根本没出现（进消毒账）。

## 二、投料与耗时改在**线路处**结算（run 型 job 不再是「投料 0 字」）

**病根**：抽屉自己按 `job.build()` 的 messages 算字数——可**多批归架、多专家会诊、按需抓正文**这些自定义 `run` 根本不走 `build()`，于是显示"投料 0 字"。那是假账，而且是最容易看的假账。

**改**：`llm.ts` 加 `setLlmFeedSink()`，`chat()` / `chatStream()` 在**真正发出请求的那一刻**回调上报（含网关回 `usage` 时的真 token）；抽屉开跑前挂 sink、结束（含中止/卸载）必摘。于是：

- 跑动中：`专家思考/生成中… 已 5s · 已发 1 次请求 / 投料 594 字`
- 完成后：`投料 1162 字 · 2 次请求 · 产出 36 字 · 5s`
- 失败时：`⚠ …（本次已投料 1162 字 / 5s）`——**失败了也知道自己花了多少**

**冒烟实证**（V3）：深度诊断（两位专家 = 2 次调用）报出 `1162 字 · 2 次请求`；旧的 `inputChars` 路径已删除，断言反向锁死"抽屉里不许再出现 inputChars"。

## 三、消毒账与空态真因点名

**病根**：`parse` 会静默丢掉幻觉 id、缺名字、重复点名的行——用户只看到"3 条建议"，不知道模型其实回了 5 条；**空态更是一句空话**：「模型没有给出可采纳的建议」，既不说是没回还是全被丢了，也不说下一步该干什么。

**改**：`AiJob.audit?: () => string | null`——计数由工厂闭包自己攒（每次点击新建 job，天然按次隔离），抽屉在工具条下方显示一行 `消毒：…`，**空态直接把它接上**：

```
模型没有给出可采纳的建议——1 行没给或编造 cardId（消毒后不认）、1 行缺理由（已判弱）。
换专家执笔、把卡片描述补一句，或换个更具体的关键词再问一次。
```

接入五处：推荐卡 / 找佐证 / 好奇研判 / 论点骨架 / 批量补全 + 链式生成。顺带修一条**勾了什么都不发生**的行：拆解的「思路」行原先算采纳项，现改判 `advisory`（只读参谋）。

## 四、任务级「知」菜单共享化 + 跨视图落位

R146 把菜单写在项目详情页里，本轮抽成 `TaskAiMenu.vue`（按钮 + 浮层菜单 + 评审抽屉 + 样式 + AI 懒栈全自包含），**同一套三选一**铺到：

- 项目详情页：指标下任务行 + 未归类任务行（2 处，页面侧删掉了本地菜单实现与样式）
- 任务面板：卡片视图 + 列表视图 + 分组视图（6 处行位）

"打开任务详情"走宿主 `@detail` 通道（各视图抽屉实现不同），拆解/荐卡走组件内的既有工厂。断言 R147-5 锁"两处 + 六处、且项目页不再残留 `openAiMenu`"，Workspace 物理行数仍 1499。

## 五、论点骨架结构化只读预览

`ThesisBlock.vue`：把主题卡描述里那段 `🤖 中心论点 / 🤖 论点骨架（MECE）` 文本**读成**「一句论点 + 依据 + 分论点列表（佐证几张 / ✓已建架 ○未建架）」，挂在资源详情抽屉顶部。

三条边界：

1. **只读零写入**——组件里没有 `persist`/`saveData`，断言反向锁死；落架仍必须走提炼抽屉底部的显式次通道「🗂 分论点建成分类并归架」。
2. **写读同源**——前缀字面量抽到 `shared/models/aiMarks.ts`，写方（batchG）与读方（ThesisBlock）吃同一常量；否则论点一改格式，预览会**静默失效**。该模块单独存在是因为消费面挂在启动链上，绝不能再把 `shared/ai/*` 静态引回详情抽屉（R134-2 的 248KB 教训）。
3. **解析不出就不渲染**——没有中心论点行整块不出现，原文照旧在描述里可见；宁可少显示，不编一个看起来像结论的东西。

与金字塔 L2 的"打通"本轮**只做到只读对照**（同名一级分类标 ✓已建架 / ○未建架），写路径不动——两套结构的合并是设计题不是实现题，留给下一刀拍板。

## 七、备案：本轮踩到的坑（含一条测试夹具的自摆乌龙）

1. **mock 网关的流式分支把 JSON 发了一遍又发一遍**——`pieces.forEach(send)` 之后 interval 又从同一个数组里 `shift()`，抽屉拿到的是"两段 JSON + 废话尾巴"，`extractJson` 取首 `{` 到末 `}` 直接解析失败。表现是"点了推荐卡没反应"，**真因在测试夹具不在产品**；改成 `while (pieces.length) send(pieces.shift())` 后 13 点全绿。
2. **V2 首跑量错页面**：任务面板在**调度台首页 `#/`** 的底部 tab，`#/compass` 是方向台壳；且 keep-alive 会让上一个视图的行留在 DOM 里。改为进 `#/` 后按 `.trow/.tm-card` 逐行数入口，量到 2/2。
3. **"1 行 cardId 不在库"报成了"没给 cardId"**：`sanitizeRefs` 会把幻觉 id 直接 `delete`，工厂里已分不清"没给"还是"编造"。文案改诚实：`没给或编造 cardId（消毒后不认）`。
4. **`R146-5「全部 .vue 零 🤖」被 ThesisBlock 的注释破掉**——把前缀字面量抽到 `shared/models/aiMarks.ts`（而不是在 .vue 里豁免），既保住硬线也顺手做到写读同源。
5. **改写断言时把标题的收尾引号删掉了**，`node --check` 当场抓到（承 R139/R144/R146 教训：批量改 regression.cjs 后必过 `node --check` + 全量跑）。
6. **未做**：抽屉侧的"JSON 一闭合就早停"没推广（评审型 job 的产出常带正文，早停会截断），列入 §九。

## 八、请你真机复核的 5 个点

1. **低置信行是否判得准**：接你自己的网关跑一次「推荐资源卡 / 找佐证 / 拆解」，看被判弱的行是不是真的弱——判得太松你会一直点全选，判得太紧等于没有。
2. **`消毒：…` 那行有没有说人话**：数字对不上你的直觉就是措辞问题。
3. **投料/次数/耗时**：多批归架（几百张卡）时这行数字是否可信、是否太吵。
4. **任务面板每行一颗「知」**：400 任务规模下会不会太密（备选：收进 ⋯ 菜单，或只在 hover 时出现——与 R146"常态可见"的决定相反，需要你拍）。
5. **论点预览卡**：结构化后是否比读一整块文本快；`○ 未建架` 的提示有没有让你想去落架。
