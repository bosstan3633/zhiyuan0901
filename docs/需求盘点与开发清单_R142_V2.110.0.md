## 二、本轮沉淀的可复用资产

- **`shared/utils/maturity.ts`**：评分真源（任务/好奇/指标/项目/目标五函数），任何新视图加徽标只接一行；调权重改一处。
- **`MaturityBadge` / `MountCountBadge`**：跨视图呈现范式的第三、四枚徽标（与 NewBadge/AssetBadge 并列），hover 语义（title 承载扣分构成）已成惯例。
- **好奇资源并集口径 `curioResIds`**：直接关联 ∪ 经挂载任务传导——后续 G2 好奇心研判投料可直接用。
- **`convertToTask` 资源随迁**：转化不再丢查证材料，为 G 批「好奇→任务→成果」链路补缝。
