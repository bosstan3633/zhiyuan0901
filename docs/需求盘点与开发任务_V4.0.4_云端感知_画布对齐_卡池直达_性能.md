# V4.0.4 需求盘点与开发任务

日期：2026-11-04
基线：V4.0.3（`7b94f8d`，`main` / `v4.0.3` 同点）
开发分支：`codex/v4.0.4`

## 一、目标

本轮不改变“本地优先、手动云同步”的产品边界，重点解决七件事：

1. 让用户随时看得见云同步入口、最近同步时间和执行结果。
2. 修正策展台上半部分与画布的横向对齐。
3. 让三个浏览器快捷键真正直达对应卡池，并稳定落在“最新采集优先”的列表。
4. 建立真实性能基线，治理启动、检索、切换、筛选和详情打开中的明显卡顿。
5. 为云同步增加浏览器快捷键入口。
6. 补齐移动端采集记录的打开、删除和全部清空能力。
7. 让用户随时看懂本机与云端当前是待上传、待拉回、冲突还是无变化。

## 二、需求与验收

### R1 顶栏云同步入口

- 页面右上角常驻云同步入口，不因未配置或未登录而消失。
- 入口展示最近一次实际同步时间，口径为上传与下载时间的较新值，不把“检查时间”冒充同步时间。
- 单击即执行一键同步，过程中显示明确的处理中状态，结束后给出成功、已是最新或失败反馈。
- 未配置 / 未登录时点击进入“设置 -> 云同步”，完成配置或登录。
- 一键同步先保存本机数据，再检查云端：
  - 无云端快照：上传本机。
  - 版本一致：提示“已是最新”。
  - 版本不同：必须让用户选择“云端恢复本机 / 本机覆盖云端 / 取消”，禁止静默覆盖任何一端。
- 云端恢复沿用现有原子恢复、附件回挂和下载时间记录流程。
- 云端模块保持动态加载，不进入首屏关键路径。
- 顶栏、首页状态栏和设置页复用同一云状态来源，避免重复探测与重复 Toast。

验收：

- 四种状态（未配置、未登录、可同步、处理中/异常）在顶栏均有可辨识反馈。
- 最近同步时间在成功上传或恢复后立即刷新。
- 冲突时必须出现三选一确认，取消后云端和本机内容均不改变。
- 启动首屏不因云模块或网络请求被阻塞。

### R2 策展台横向对齐

- 策展台上半部分（台身份、中心论点卡、行动条）与下方画布使用同一左右边界。
- 桌面端左右对齐；移动端现有紧凑布局不回退。
- 顶栏、页面容器、页头和画布间不产生横向滚动。

验收：

- 真实浏览器测量页头、论点卡、工具条与画布的 `left/right`，误差不超过 1px。
- 1440px、1280px、1024px、768px、390px 视口均无横向溢出。

### R3 三个卡池快捷键

保留现有命令 ID，避免用户已绑定键位失效，只调整名称与落点：

- `goto-curiosity` ->“直达好奇心卡池”-> `/deck/curiosity`
- `goto-tasks` ->“直达任务卡池”-> `/deck/task`
- `open-tree` ->“直达资源卡池”-> `/deck/resource`

统一首次落点为：

- 列表视图。
- 清空搜索和筛选。
- 状态范围回到全部。
- 按采集/创建时间倒序，最新在前。
- 重复触发同一快捷键时，再次应用默认状态。

验收：

- 命令管理页显示新名称，旧命令 ID 和用户键位仍有效。
- 从任意页面、任意卡池滚动/筛选状态触发，均落到目标池的默认最新列表。
- 好奇心置顶逻辑不得把较旧卡片排在较新采集卡片之前。
- KeepAlive 缓存下重复触发仍有效。

### R4 性能第一生命线

覆盖以下高频路径：

- 冷启动到可交互。
- 全局检索唤起、输入和结果更新。
- 调度台 / 方向台 / 策展台切换。
- 好奇心 / 任务 / 资源卡池切换。
- 列表、网格等视图切换及筛选。
- 卡片详情抽屉打开。

验收：

- 改动前后使用同一构建方式、同一测试机、同一数据规模。
- 记录 P50 / P95 / 锁预算和长任务。
- 不引入超过现有 SLO 预算的回归；发现明显热点时以证据驱动优化。
- 不以删功能、降低视觉质量或延迟必要反馈换取数字。

### R5 云同步快捷键

- 在浏览器扩展快捷键管理页增加“打开云同步”入口，不占用默认键位，由用户自行分配。
- 触发后复用已打开的知源标签页，并直达“设置 -> 数据管理 -> 云同步”。
- 保留现有命令 ID，新增入口使用稳定命令 ID，后续调整文案不得让用户已绑定键位失效。

验收：

- `chrome://extensions/shortcuts` 能看到“打开云同步”。
- 新标签页直达 `/settings?page=cloud`；已有新标签页也能通过路由消息切换。

### R6 移动采集记录管理

- 登录云同步后自动加载移动端待导入记录，并按采集时间倒序展示。
- URL 地址可单击打开；整行支持双击、Enter、Space 打开，避免只有单一鼠标入口。
- 支持单条删除及全部清空，清空属于破坏性操作，必须明确不可恢复并走二次确认。
- 支持单条导入与全部导入；同一采集记录不得重复导入。

验收：

- 打开、键盘打开、单条删除、全部清空、单条导入、全部导入均有可验证行为。
- 拉取记录去重且最新采集排在最前。
- 导入成功后记录具备已消费/不可重复导入反馈，不产生重复卡片。

### R7 本机与云端关系感知

云同步页面必须用用户可理解的语言明确当前关系，而不是只显示“已连接”：

- 无变化：本机与云端一致。
- 本机有改动：需要上传到云端。
- 云端有新增：需要拉回本机。
- 双端都有改动：存在冲突，必须让用户选择保留哪一端。
- 云端为空：可上传本机建立首份快照。
- 未知/不可比较：说明尚未检查或无法判断。

验收：

- 页面同时展示本机修订、云端修订、最近检查时间和最近一次实际同步时间。
- 建议动作与关系状态一致，不把“检查时间”当成“同步时间”。
- 关系变化后，顶栏、首页状态和设置页使用同一状态来源。

## 三、开发任务

1. 抽取共享云状态 / 手动同步服务，统一状态、时间口径与冲突结果。
2. 在顶栏增加云同步入口及进行中、成功、异常反馈。
3. 首页底部改为“最近同步”口径，移除 App 启动重复 Toast。
4. 修正策展台页头桌面缩进并保留移动端规则。
5. 更新三条快捷键文案、背景跳转和卡池深链参数。
6. 三个卡池恢复默认列表并处理 KeepAlive 下重复触发。
7. 增加“打开云同步”浏览器快捷键及路由复用。
8. 补齐移动采集记录的打开、键盘操作、单条删除、全部清空和防重复导入。
9. 建立本机/云端六态关系模型，并在云同步页给出建议动作。
10. 建立 V4.0.4 性能基线，定位并优化热点。
11. 新增 V4.0.4 回归分片，更新受影响的旧断言。
12. 同步版本号、手册、README、changelog。
13. 执行类型检查、构建、全量回归、主题与无障碍门禁、真实浏览器与性能复测。

| 搜索输入更新 | 97 | 99 | 400 | PASS |
| 调度台 / 方向台切换 | 52 | 96 | 800 | PASS |
| 三卡池切换 | 190 | 227 | 800 | PASS |
| 卡池筛选 | 44 | 159 | 500 | PASS |
