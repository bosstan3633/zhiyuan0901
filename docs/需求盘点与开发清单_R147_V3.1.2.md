## 二、沉淀资产（下轮直接复用）

1. **置信度必须有客观出处**：判弱只能引用"没给理由 / id 不在库 / 一张卡都没 cite / 体系外新词"这类可核对信号。任何"模型自评置信度"都不许进 `weak`。
2. **用量类数字要在线路上结算**：凡"消耗/耗时/条数"，在真正发生的那一层回调上报（`setLlmFeedSink` 模式），别让上层自己按输入猜——自定义 run 一多，猜的账必错。
3. **静默消毒 = 撒谎**：丢弃行必须计数并可点名（`audit()`），空态尤其要接上真因。这条适用于一切"清洗后展示"的场景。
4. **跨视图入口先抽组件再铺**：R146 在项目页写了一份菜单，本轮搬进 `TaskAiMenu` 才铺到面板——同类交互第二次出现就该组件化，别等到第三次。
5. **字面量写读同源**：AI 写进正文的前缀（`🤖 中心论点：` 等）集中到 `shared/models/aiMarks.ts`；写方与读方共用常量，格式一改预览不会静默失效。
6. **性能结论要 A/B 佐证**：M3 +13% 先怀疑自己新加的 6 处入口，拆掉重测反而更高——同码不同轮 19.6s~24.4s 是噪声带。**没有 A/B 不要把抖动写成回归**。
7. **测试夹具也会自摆乌龙**：mock 的流式分支重复吐同一段 JSON，能把产品测成"点了没反应"。夹具改动同样要过一遍已知绿的用例。
