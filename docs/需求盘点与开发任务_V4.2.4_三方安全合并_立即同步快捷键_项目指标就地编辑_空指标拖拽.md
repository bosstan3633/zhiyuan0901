## 一、本轮目标

| 组别 | 用户问题 | 验收口径 |
|---|---|---|
| 多端安全同步 | A、B 两端在共同基线上分别修改后，不能再用整端覆盖导致另一端改动丢失 | 不同记录与字段自动并集；同字段或删除 / 修改冲突逐项确认 |
| 自动同步 | 自动同步遇到双端改动时必须安全处理 | 可安全合并时自动执行；存在逐字段冲突时暂停并保持黄色待处理 |

| 同步明细 | 同步范围需要更清晰、规范 | 只显示业务数据；界面偏好与主题不进入同步与待上传计数 |

## 二、已确认的产品语义

### 1. 三方合并

- 共同基线 = 最近一次成功同步的业务快照。
- 本机相对基线的变化与云端相对基线的变化分别计算。
- 不同记录的变化全部保留。
- 同一记录不同字段的变化全部保留。
- 同一记录同一字段出现不同结果时，用户必须逐项选择。
- 一端删除、另一端修改时，同样逐项确认，不做静默删除或恢复。

### 2. 同步范围

进入云端：

- 卡片数据的新增、修改、删除。
- 策展台、节点、分支顺序与资源镜像。
- 方向台项目、成功指标、任务归属与方向树结构。
- 今日三件事槽位内容与日期状态。
- 资源常用夹及其他业务关系。

只留本机：

- 主题与密度。
- 页面布局、排序与筛选。
- 抽屉宽度、文本框高度等界面偏好。
- 快捷键与设备侧显示状态。

### 3. 方向台编辑

- 项目名有明确的悬停编辑入口。
- 成功指标双击标题进入编辑；详情按钮仍打开指标详情。
- Enter 或失焦提交，Esc 取消；空值恢复原值。
- 所有入口统一调用方向台现有 `saveEdit()` 与 `store.persist()`，不建立第二套写库路径。

### 4. 空指标拖拽

- 任务拖拽的落点判定以成功指标卡为容器，不再只挂任务列表。
- 有任务、无任务两种指标卡行为一致。
- 跨项目拖拽仍被拒绝。
