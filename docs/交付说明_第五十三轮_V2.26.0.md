## 一、策展中心统一树（A 组，本轮最大项）

### A1 · 镜像分类物化（架构级调整）
- `Category` 新增可选溯源字段 `curFrom?: { wsId, catId, projId }`——**镜像分类物化为真实策展分类**，与原生分类同构；
- 新增 `shared/storage/curationMigration.ts`：启动期把遗留 `kind='category'/'workspace'` 投射记录一次性物化为镜像分类并移除记录（幂等，仅剩单卡记录时零操作）；同步把 R51/R52 的 `'mirror:'` 前缀键（投射卡 targetCatId / 原生卡 curCatId / 镜像子分类 parentId）重映射为真实分类 id，**curCatId 机制退役**（归属统一 categoryId）；
- `app.ts init` 接线，变更即 persist。

### A2 · 统一树重写（CurationCenter.vue 全量重写）
- 侧栏**一颗树**：未分类/待分类（系统节点）+ 原生分类与镜像分类（📡 虚线标识 + hover 显示溯源）**自由混排**；
- **树节点拖拽**：三段位判定（上 35% = 排到其前 / 下 35% = 排到其后 / 中段 = 拖入成子级），跨父级拖拽 = 移动到目标同级位置；**最多两级** + 防环守卫（子不能含父）；
- **卡片自由拖拽**：原生卡/投射卡均可拖入任意策展分类（含镜像分类，同为真实分类）——原生卡写 categoryId（源零影响）、投射卡写 targetCatId；详情弹窗「所属分类」可自由重选（含镜像分类）；
- **镜像分类视图** = 源分类实时卡片（含源子分类，📡 源实时镜像区）+ 停入的原生卡 + 停入的投射卡三区合一；
- 镜像分类操作：＋子分类 / ✎ 改名（源分类不受影响）/ ✕ 移出投射。

### E2（P0-1 修复）· 删除/清空引用回落
- **删除分类 / 移出投射**：停入的原生卡 → 未分类；停入的投射卡 → 待分类；子分类提为根——三类引用零孤儿；
- **清空投射**：全部单卡记录删除 + 全部镜像分类删除（同样的回落链）+ 视图复位；
- E2E-10 真机验证迁移物化 → 源卡实时 → 原生卡 → 清空回落全链（本轮曾抓到 clearProjections 漏删镜像分类本体，已修复）。

### A3 · 镜像入口物化与删除级联
- App.vue 整工作台镜像 / Workspace 分类镜像 → 物化带 curFrom 的策展分类（不再写 category/workspace 投射记录）；
- **删除工作台 / 删除源分类**级联清理对应镜像分类（同样的回落链）——消除盘点报告 P1「镜像残壳」。
