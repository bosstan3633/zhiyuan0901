## 二、云同步关系与冲突口径

| 状态 | 用户可理解的含义 | 建议动作 |
|---|---|---|
| `in_sync` | 本机与云端一致 | 无需同步 |
| `local_changed` | 本机有改动，需要上传云端 | 本机覆盖云端 |
| `remote_changed` | 云端有新增，需要拉回本机 | 云端恢复本机 |
| `both_changed` | 本机与云端都有改动 | 先让用户选择保留哪一端 |
| `empty_remote` | 云端尚无快照 | 上传本机建立首份快照 |
| `unknown` | 尚未检查或当前不可比较 | 检查云端版本或完成登录 |

双端冲突时只允许三个结果：

1. **云端恢复本机**：先校验版本，再原子恢复，并保留附件回挂流程。
2. **本机覆盖云端**：先落盘本机最新数据，再上传完整快照。
3. **取消**：本机与云端均不改变。

“最近检查时间”和“最近一次实际同步时间”分开记录；后者只取上传与恢复时间的较新值，不用检查时间冒充同步时间。

- **实体手机**：未在实体 iOS / Android 浏览器上验收；390px 结果仅为桌面 Chromium 的响应式视口，不等同真机测试。
