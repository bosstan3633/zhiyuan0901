## 一、三条交付明细

### 1.1 W7 · 金字塔层级折叠（仅 L2 / 到 L3 / 全部）

- `pyFold = ref<'l2'|'l3'|'all'>('all')`，映射 maxDepth 0 / 1 / ∞；**本地视图态不进 UIPrefs**（视图态持久化会造成「每次打开都被折叠」，与 D-B 拍板同口径）；
- **在布局层收口，不是渲染层隐藏**：`placeCat` 在 `depth >= maxDepth` 时按叶子布点——父节点的 colSpan 只跨**可见**子组的列，折叠后居中树几何仍然自洽（R66-F5 的「父恒等于子组横向」不破坏，也不会留下空跨列）；环形兜底循环同受 maxDepth 约束；
- 控制条置于论点根与金字塔板之间（`.py-fold` 三档分段按钮），**仅 `pyramidLevels.length >= 2` 时渲染**——只有一层没有可折的东西。

### 1.2 W8 · 策展台指标条 5 → 3 格

- **「来源构成」删格**：其数据（台内 native / 镜像 mirrored）与「卡片总数」格的 hint **同源同文**（R62 起就在），并入动作 = 删格；`openDrill('source')` 全文件仅该格一处引用，下钻抽屉的 source/recent 模式与代码**保留**（`recent` 迁移入口后仍可达）；
- **「🕐 最近更新」降页头摘要**：`.wsh-summary` 追加 `<span class="wsh-upd"> · 更新 {{ lastUpdateText }}</span>`（仅非 hub），**可点**进 `openDrill('recent')`——降的是占位，不是能力；
- `.ws-metrics` 列模板 `1.4fr 1fr 1fr 1fr 1fr` → `1.4fr 1fr 1fr`（hub3 的 `repeat(3,1fr)` 不变，两台自此同为三格）。

### 1.3 W9 · 分组标题补「含 N 个子分类」

- 组内 count 是**直属**口径（`resourceGroups` walk 只 push 有直属卡的组），与左树聚合计数不同源——同屏「左树 A 显示 5 / 分组 A 显示 3」会被当成对不上账；
- 新增 `groupChildCount(key)`（`catIdx.childrenOf.get(key).length`，uncat 恒 0）；卡片视图与列表视图两处组标题同款呈现「· 含 N 个子分类」（子分类各自的卡有自己的组，walk 递归）。
