触发：R3-Cc 交付时我报了一处有意偏离（"工具条那一排差异是值域不是结构重复，不建议收进组件"），用户拍板 **「要形式上在一个组件里」**——那就按原计划做，理由让位于决定。

## 一、做了什么

新增 `components/compass/DeckControls.vue`，三张卡（资源卡池 / 任务调度 / 好奇心培育）的控制行由它渲染，**顺序固定**：

```
搜索 → 筛选 → 视图 → 排序 → 排序方向 → 分组 → 面板自带控件(默认槽) → 计数(#count 槽) → 批量 → 新建
```

值域全部以数据传入，**差异不再是三份模板**：

| 面板 | 传入的值域 |
| --- | --- |
| 资源卡池 | `poolViews`（▦ 网格 / ☰ 列表）+ `poolFilters`（全部 N / 🏷 待打标 N，胶囊带计数）+ 槽内放「📥 导入本地文件」 |
| 任务调度 | `TASK_VIEWS`（卡片/列表/看板）+ `TASK_FILTERS`（下拉五档状态）+ `TASK_SORTS`（手动/最近/优先级）+ `TASK_GROUPS`（列表视图才出现的三档分组）+ 槽内放 `ColsPicker` |
| 好奇心培育 | `CURIO_VIEWS`（▦/☰/▥）+ `curioFilters`（状态胶囊带计数）+ 槽内放 `ColsPicker`、「→ 已转化 N」读数、AI「转化研判」钮 |

顺带两处结构性收敛：**好奇面板的「☑ 批量管理」从模块标题行（`ModuleCard #actions`）搬进控制行**（与任务/池一致）；**池的「待打标」从独立开关按钮变成筛选胶囊**（与好奇的状态胶囊同一形态，语义也更准——它就是个筛选值）。

## 二、三条踩出来写进代码的纪律

1. **样式必须组件自带，不接受父面板传类名。** 上一轮抽批量栏时踩过：scoped 边界下父组件的 `.mini-btn:disabled` 选不到子组件模板里的节点，传类名只会得到一排浏览器默认按钮。`DeckControls` 自带 `.dk-btn / .dk-select / .dk-search / .dk-count`，槽内内容（父作用域）继续用各面板原有类，两边同一套令牌所以外观一致。
2. **`panel` prop 落到 `data-panel`。** 三张卡同页挂载，共用组件后裸类名一次命中多枚（Playwright 严格模式直接抛，`isVisible()` 也抛）——E2E 与排障都需要按卡型稳定的锚点。本轮 E2E 的 8 处定位因此从 `.pcp-btn` / `.cz-batch-btn` 改成了 `.dk-row[data-panel="pool"] .dk-batch` 这种形式。
3. **胶囊筛选没有"再点一次取消"的语义**（点谁选谁），池的「待打标」因此会点回去时关不掉——面板侧补 `onPoolFilter()`：再点同一枚 = 回到全部。这条是 E2E-30 抓出来的（全选只选到 1 张，因为筛选根本没关掉）。
