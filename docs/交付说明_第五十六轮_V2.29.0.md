## 四、PERF · 丝滑度体检与修复（a~f 全项）

- **a 体检打点**：新增 `scripts/perf-longtask.cjs`（Playwright + PerformanceObserver longtask），压测规模 = 2000 资源 / 600 任务 / 120 好奇 / 300 投射 / 400 镜像源卡，覆盖 home（三件事联动+指标下钻）/ compass（任务检索）/ curation（分类切换 ×6）三路由，空闲段与交互段分开计量。脚本入库，后续轮次可复跑。
- **b 策展 O(n²) 修复**：`mixedCardsOf` 排序前预建 `cardId→createdAt` Map + `pairs` 预计算权重数组，比较器 O(1)（旧实现每比较全量 `cardById` 线性扫描）。
- **c isProjectDone O(P×T) 修复**：`compass.ts` 新增 `projectTasksIndex`（数据版本号失效的单次遍历索引），`isProjectDone` / `isProjectStalled` / `projectProgress` 共享 `projectTasksOf`；`repository.ts` 新增 `getDataVersion()`（saveData / saveDataNow / syncCache 三处自增）作为 memo 失效键。
- **d MetricBar memo**：`northStarMetrics` 按 `period+数据版本号` memo（迁调度台后常驻首页，数据不变不重算）。
- **e 呼吸灯移除**：`tcBreathe` 动画 + keyframes + class 三处全无（选中/完成态以恒定样式表达）。
- **f 前后对比**（同机同规模 A/B，V2.28.0 构建 vs 本轮构建）：

| 路由 · 段 | V2.28.0（修复前） | V2.29.0（修复后） |
|---|---|---|
| home · 空闲 / 交互 | 0 / 0 帧长任务 | 0 / 0 帧长任务 |
| compass · 空闲 / 交互 | 0 / 2 帧（127ms，最差 73ms） | 0 / 2 帧（130ms，最差 74ms） |
| curation · 空闲 / 交互 | 1 帧（52ms） / 0 | 1 帧（51ms） / 0 |

  **结论**：压测规模下两版均无 >50ms 长任务劣化（首屏挂载的 1 帧为策展树首次渲染，与排序无关）；本轮修复的价值在**渐进复杂度保障**——比较器每比较 O(n)→O(1)、项目完成判定 O(P×T)→O(T) 共享索引、北极星免重复全量重算；且 R56-A 混排网格在镜像分类扩容（400 源卡）后依然零长任务，证明新功能未引入性能回归。

## 八、A-修 · 策展镜像视图真混排（拖动即物化）

- **一张混排网格**：镜像分类视图合并为 `mixedCardsOf` 单网格 = 已排序卡（原生+投射，curOrder 序）+ **未投射源卡**（`live` 类型，`LIVE_BASE+源序` 恒垫后，📡 弱标识）；
- **拖动即物化**：未投射源卡拖到卡上（`onLiveDrop`/`onAnyCardDrop`）或树节点（`onTreeDrop`）→ `projectSourceCardTo` 物化为投射记录并 `reorderMixed` 落位（获得 curOrder，源数据零影响），此后与原生卡完全平权；拖到其他源卡上同样可落位（live 卡补 @drop 绑定，目标键 = 镜像分类自身，修正源卡 categoryId 语义错位）；
- **独立「源分类实时镜像」分区取消**（文案与 viewLive 计算属性移除，统一网格唯一呈现）；
- **双计修复**：`nodeCount` 与区块计数（`viewLiveCount`）不再把已投射源卡计入源镜像数（树计数 = 原生 + 投射 + 未投射源卡）；
- 依赖 PERF-b 排序修复 ✅。

## 九、I · 标签体系跟随导入导出

- **根因确认**：工作台菜单「导出工作台数据」为自定义形状 `{workspace, categories, resources}`——缺 `version`（导入端 `version===2` 校验**直接拒绝**）、缺 `tagTree`（且缺 tasks/curiosities/compass/stats/dailyFocus/fieldConfig/activityLogs），「导出→换机导入」整链路不通，标签体系随之丢失；
- **修复**：改为 **AppData 子集同构导出**——`...d` 全量展开（全局段随行）+ 工作台段（workspaces/categories/resources）按当前台过滤；导出物可直接走设置→导入数据并集合并。

**导入导出全链路核查表**：

| 入口 | 形状 | 标签树随行 | 可导回 |
|---|---|---|---|
| 设置 → 导出全部数据 | AppData 全量 | ✓ | ✓（原有） |
| **工作台菜单 → 导出工作台数据** | **AppData 子集同构（本轮）** | **✓** | **✓（修复点）** |
| 设置 → 导入数据 | `version===2` 校验 + 并集合并 | ✓ | — |
| 书签 HTML 导入 | 顶层文件夹归组为标签 | ✓ | — |
| CSV / Markdown 导出 | 表格/文本形态，不适用 | — | — |
