# 知源调度台 V3.0.0 · **AI 版**（架构升级）

> 发布日期：2026-09-20 · 提交 `a93a08e` · 标签 `v3.0.0` · Chrome MV3 扩展（本地优先，零服务端）

**为什么是主版本**：V2.x 把「收纳与召唤」这台机器做到了能用自己的词描述它（三秒召唤 / 信息失血症 / 认知周转率）。V3.0.0 补上的是这台机器的**认知层**——AI 不再是又一个功能按钮，而是一层贯穿方向台、资源台、策展台、任务台与设置页的**协作者**，并且这一层的架构边界是从零立的，不是补丁摞出来的。

---

## 一、AI 层架构升级了什么

新增 `src/shared/ai/` 八件套，严格分层、单向依赖：

| 模块 | 职责 | 硬边界 |
|---|---|---|
| `config.ts` | 接入配置与档位 | 密钥只存独立键 `zy_ai_v1`，**绝不进 AppData / 导出 / 备份 / 合并链** |
| `llm.ts` | OpenAI 兼容协议传输（SSE 流式 + 回退 + JSON 提取） | baseUrl 必须 http(s)，地址异常直接拒发 |
| `job.ts` | 建议契约类型（`AiRow` / `AiJob`：主采纳 · 次采纳 · 换专家 · 处理对象） | 契约与 UI 解耦，`.ts` 侧可造任务书 |
| `scenarios.ts` | 全部系统提示词契约 + 专家角色库 | 每条契约写死"不许编造"与输出 schema |
| `project.ts` | 上下文投影器（把真实台账压成 2~12KB 文本） | 只读组装，附件本体永不进投影 |
| `select.ts` / `chain.ts` / `govern.ts` / `batchG.ts` | 场景工厂（推荐类 / 生成类 / 治理类 / 判断类） | 采纳一律走既有字段通道，零新增数据模型 |
| `linkFetch.ts` | 网页正文抓取（点击才抓） | 仅 http(s) 白名单、10s 超时、失败降级为"未读正文"照常分析 |

**三条不变量（比功能更重要，全部有断言与产物级复核锁死）**：

1. **AI 是认知协作者，不替你做决定**——建议只活内存态，逐条勾选采纳才落库；全手动触发，零轮询。
2. **不做云端黑盒，数据主权在你手里**——内容浮层（content 侧）永不持密钥，AI 调用集中在新标签页侧；换网关只是改三行配置。
3. **三秒极速响应不能被 AI 拖慢**——启动 chunk 零 AI 字面量（懒化 + 产物级复核），AI 全在懒路由或点击时的动态 import 之后。

## 二、20 个 AI 场景（17 个任务书工厂 + 搜索重排 + 划词补全 + 深度诊断）

- **生成类**：方向台逐层生成（战略目标 / 项目 / 成功指标 / 任务）· 任务拆解（建子任务 / 写进详情双通道）· 金字塔**论点提炼 + MECE 骨架**
- **判断类**：好奇心**转化研判**（转任务 / 继续养 / 可搁置）· 金字塔分支**找佐证** · **成果文稿**成文（可下载 .md）
- **治理类**：标签体检 · 回收站捞回 · 跨台镜像发现 · 主题漂移检测 · **标签整体梳理**（盘点全卡→蓝图评审→全卡归架打标 + 快照一键还原）
- **提效类**：自然语言录入任务 · 按目标推荐资源卡 · 搜索意图重排 · 收藏理由补全 · **全方位优化**（读网页正文改写标题/描述/标签）· 划词补全 · 周回顾草稿 · 周报深度洞察
- **专家体系**：角色库（内置两员可改人设与关注面 + 自建专家）· 默认执笔专家 · 抽屉内随时换人重跑 · 参谋建议行（评估合理性 + 推荐落地方式）
- **评估底座**：成熟度规则引擎（任务四维 → A/B/C/D，**上行聚合到指标 / 项目 / 战略目标**，零联网即时可见）

## 三、同期完成的底座重构

- **两种「离开」语义统一**：`taskLinks.ts` 真源区分挂载语境的**解绑**与本体语境的**软删进回收站**，全站五路删除入口收口 + 启动期脏引用消毒。
- **子任务软层级**（V3.0 新增）：拆解步骤真正挂父，父删 / 父解绑子不陪葬，完成状态永不联动，⤴ 就地升顶层——零迁移。
- **宿主瘦身**：Workspace 拆到 ≤1500 行 + 九域 composable + 组件自带样式的自包含入口（`CardAiEntry` / `ThesisAiBtn` / `EvidenceMenuItem` / `CatNodeName`）。
- **四主题令牌化**（深空 / 纸墨 / 松墨 / 鲑鱼墨）+ 徽标体系（成熟度 / 弹药计数 / 附件 / NEW）。

## 五、安装

1. Chrome 地址栏 `chrome://extensions` → 右上角开「开发者模式」；
2. 「加载已解压的扩展程序」→ 选 `知源调度台_V3.0.0/` 目录（或 zip 解压后的同名目录）；
3. 新开标签页即接管；快捷键 `Ctrl/Cmd+Shift+K` 开调度台，`Alt+1` 方向台、`Alt+2` 资源台、`Alt+3…9` 各策展台；
4. 用 AI：设置 → 🤖 AI 助手，填你自己的 OpenAI 兼容 API 地址 + Key + 模型，⚡ 测试连接通过即可（密钥只留本机）。

## 六、已知不足（发版同时说清）

1. **真实网关实测为零**：所有 AI 场景的契约与消毒都在 mock 网关验过，**没有一次真实模型调用**——论点味道、研判尺度、文稿可否直发，需真机点头。
2. **ZIP 607KB 超预算 7KB**：V2.80 之后 11 轮 AI 场景使文件数 48→60；压回路径＝拼音字典分段（305KB 最大单项）与手册全文外置，预算数未改。
3. **perf 的 M5 指标口径与 V2.80 不可直接比**（本轮把唤起与键入并进同一标签），已列 R146 拆名。
4. **金字塔骨架与论点卡描述目前是两套结构**，"按骨架预演分支"的只读预览待做。
5. 浏览器仅支持 Chromium 系（MV3）；无移动端、无协作。

## 七、边界（不会变的部分）

不做云端黑盒、不替你选方向、不做第二个"什么都能记"的盒子；不为任何模型供应商改数据主权边界；不为任何指标牺牲三秒响应。**万卡可控，召之即来；万卡归源，源驭万卡。**
