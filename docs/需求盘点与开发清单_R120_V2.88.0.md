## 一、需求 A：全局搜索的键位与点击语义

### A-1 现状（V2.85 代码核实）

| 入口 | 单击 | Enter | Ctrl+Enter | 双击 | 行内 ↗ |
|---|---|---|---|---|---|
| 网页浮层（任意网页 Ctrl+K，`overlay-impl.ts`） | 打开链接（无链接→定位） | 打开链接 | 定位 + **打开详情抽屉** | 打开链接（去重） | — |
| 应用内搜索（新标签页 Ctrl+K，`GlobalPopups.vue`） | **定位高亮** | **定位**（注释却写"Enter=开链接"，为 R117 反转遗留） | 定位 + 打开详情抽屉 | 定位（同单击） | 打开链接 |

### A-2 目标行为（定稿 · 两入口统一）

| 操作 | 行为（两个入口一致） |
|---|---|
| **单击** | **打开卡片链接**（无链接/不可打开 → 定位到卡片所在处） |
| **Enter** | 同单击（打开链接；无链接→定位） |
| **Ctrl+Enter** | **仅定位到卡片所在处**（高亮），**不打开详情抽屉** |
| 双击 | **不定义**：沿用 300ms 同项去重，效果等同单击（不重复打开） |
| 行内 ↗（应用内） | 保留（"打开链接"显式入口，等价单击） |
| 策展台 `ws` / 项目 `proj` 条目 | 保持现状语义：ws→打开该台/定位分类；proj→打开项目详情 |

### A-3 开发任务

| 编号 | 任务 | 涉及文件 |
|---|---|---|
| T-A1 | 网页浮层：Ctrl+Enter 改为**仅定位**（去掉打开详情抽屉的部分），保留 hk 分派与高亮 | `overlay-impl.ts` |
| T-A2 | 网页浮层：单击/Enter = 打开链接（现状一致，仅补文案与去重边界核对） | `overlay-impl.ts` |
| T-A3 | 应用内：单击/Enter = **打开链接优先**（有可打开链接→外开+WRR 计数；否则定位） | `GlobalPopups.vue` |
| T-A4 | 应用内：Ctrl+Enter = **仅定位高亮**（去掉 `emitOpenDrawer`），保留 hk 分派 | `GlobalPopups.vue` |
| T-A5 | 应用内：双击统一为与单击同路径（去重保证不双开），清理"单击=详情"旧逻辑 | `GlobalPopups.vue` |
| T-A6 | 文案统一：结果行 `title`、底部键位提示、行内按钮提示 | `GlobalPopups.vue`、`overlay-impl.ts` |
| T-A7 | 手册同步：搜索章节与快捷键表 | `manual-data.ts` |
| T-A8 | 断言：新增 R120 搜索语义断言；更新受影响的 R117"搜索点击反转"遗留断言 | `regression.cjs`、`e2e.cjs` |

### A-4 验收标准
- 两入口一致：有链接资源卡「单击/Enter」→ 新标签打开且 `callCount+1`；「Ctrl+Enter」→ 跳转定位高亮、**不弹详情**；双击不产生双开
- 无链接/本地路径不完整 → 降级为定位，并给出既有 toast 提示
- 门禁全绿
