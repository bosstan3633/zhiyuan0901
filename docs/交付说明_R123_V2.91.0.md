## 七、偏差与说明（4 条）
1. **策展台 CTA 保留「＋ 新建卡片」**：原型写「＋ 引用资源卡」，但现有能力是新建台内卡（引用入口在金字塔节点「🔗 关联资源卡」）；为避免文案与行为不符，本轮不改文案。
2. **卡片描述行保留启用字段（链接/日期/自定义）**：R122-Q2 拍板字段配置仍生效；原型未画该行，属配置驱动差异。
3. **调度台/方向台容器**：原型 1400/1440 → 按 Q1 全局 1560；如后续要严格复刻原型的 1400/1440，可单点回改。
4. **密度档位语义调整**：卡片固定原型值后，密度改为作用于列表/看板（原作用于卡片网格）。
