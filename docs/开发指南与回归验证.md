# 知源调度台 V4.7.1 开发指南与回归验证

> 面向智能体与开发者的工程操作手册。配合 `技术架构与数据模型.md` 使用；硬性契约以仓库根 `AGENTS.md` 为准。
> 本文档于 **2026-11-21（V4.7.1 后文档盘点轮）全量勘验回正**：此前正文停在 V2.1 时代（168 项断言 / 六主题 / toast 硬编码色值等均为退役口径）。各节读数以 `v2/README.md` §十与 `评审交接包/01_项目透视卡.md` 为准。

## 1. 环境与构建

```bash
cd v2
npm install          # Node ≥ 18
npm run dev          # 开发模式（HMR 输出到 dist/）
npm run build        # vue-tsc --noEmit 类型检查 + vite build（交付必须两者通过）
npm run typecheck    # 仅类型检查
npm run pack         # 仅用户明确要求发版时执行（默认输出到桌面）
```

- **构建前必须清空 `v2/dist`**：`vite.config.ts` 使用 `emptyOutDir:false`，不清理会累积历史残留，包体积读数也会失真。
- 加载测试：`chrome://extensions/` → 开发者模式 → 加载已解压的扩展程序 → 选 `v2/dist`
- 改代码后必须在扩展详情页点「重新加载」+ 刷新新标签页
- 本地文件双击打开需在扩展详情页开启「允许访问文件网址」
- `npm run build` 全绿不等于功能可用；静态回归是字符串/结构断言，也代替不了编译检查，两者缺一不可。

## 2. 工程规范

| 项 | 规范 |
|---|---|
| 组件 | `<script setup lang="ts">`；禁止 `any`（确需时注释） |
| 样式 | 颜色一律用 `tokens.css` 语义令牌，**禁止硬编码色值**；scoped CSS；新增 UI 必须在四套正式主题下逐一走查 |
| ⚠ scoped 陷阱 | **父组件 scoped 样式无法作用到子组件内部元素**——新子组件必须自带样式；`v-html` 内容的样式必须非 scoped |
| 交互 | 原生 `prompt()` / `confirm()` 全面禁用——用现有 Modal / Toast / 行内编辑；**删除必须可撤销**；路由切换零动画 |
| 状态修改 | 全部走 store 数据 + `store.persist()`（300ms 防抖自动落盘） |
| 拖拽排序 | 原生 HTML5 DnD；**支持拖拽排序的列表，渲染 computed 禁止原地 `.sort()`**——必须回写源数组的排序字段；标记排序统一走 `shared/utils/marksort.ts` |
| 删除 | 一律软删 `deletedAt`（回收站依赖它；**没有 30 天自动清除**——只有用户点永久删除或清空才真正离开本机） |
| 数据 | 新字段必须可选（`?`）+ 读取处兜底；老数据在载入、导入、云恢复边界统一走 `normalizeAppData()`，不要在组件里各补一套 |
| 存储键 | 所有 `chrome.storage` 键必须经 `shared/storage/keys.ts` 的 `K` 引用；`src/**` 内不得出现裸 `zy_*` / `lm_*` 键名；IndexedDB 库名与导出包标识分别走 `IDB_NAMES` / `EXPORT_MARKERS` |
| 卡间挂载 | 四卡本体互不持有对方 id；豁免只限独立记录表（`SupportLink` / `CurationProjection` / 常用夹成员镜像 / `topicResourceLinks`）；六层归属（`projectId` / `metricId`）不受限 |
| 版本号 | 唯一来源 `src/manifest.ts`，改版同步 **7 处**（见根 `AGENTS.md` 硬性规则 1） |
| 依赖 | 新增依赖先问；运行时只有 `vue` / `vue-router` / `pinia` |

## 3. 回归验证与门禁

```bash
npm run build                  # 交付前必须（vue-tsc 0 错误 + vite build）
node scripts/regression.cjs    # 静态回归必须 0 失败
```

- 静态回归按分片组织（`scripts/regression/`，注册于 `regression.cjs` 的 `SHARDS`），V4.7.1 基线为 **100 分片 / 2,474 断言**；**新增功能同步追加回归分片，只增不减**；被新拍板覆盖的旧断言重指而非删除，重指要备案。当前基线数字以 `v2/README.md` §十为准。
- **不允许为了变绿删断言或放宽负锚**；发版后必须真跑 `node scripts/regression.cjs` 并读退出码——`typecheck` 绿不等于门禁绿（V3.8.18 实录：一条判据的正则语法错误让整套门禁在加载阶段静默崩溃）。
- **按改动范围追加验证**：

| 改动 | 门禁 |
|---|---|
| UI / 样式 / 主题 | `npm run gate:theme` · `npm run gate:a11y` · `node scripts/theme-audit.cjs --tag=R<轮次>-after`（四主题实拍；需 `v2/dist` 与本机 Playwright Chromium，没有浏览器链时明确写「视觉未验证」） |
| 交互 / 路由 / 弹窗 / 存储 / 云同步 | `node scripts/e2e.cjs`（MV3 真机 E2E；沿用 `pollUntil` / `waitForLocator` / `waitForStorage`，不用固定 `wait(ms)` 掩盖竞态） |
| AI 入口 / AI 文案 / 内容侧浮层 | `node scripts/entry-literals.cjs`（入口 chunk 与源码闭包的 AI 字面量双向扫描；AI 密钥只活在 `zy_ai_v1`，内容侧浮层永不持钥） |
| 性能敏感路径 | `node scripts/perf-slo.cjs`（首屏不新增同步重活；不引入虚拟滚动、UI 框架或新运行时依赖） |
| 重构 / 拆文件 / 改入口 | `node scripts/check-cycles.cjs` · `node scripts/orphan-check.cjs` · `node scripts/dead-css-scan.cjs` · `node scripts/gen-code-index.cjs --check` |

- **census 新鲜度闸**：`dead-css-scan` 只认全量实拍写下的权威普查（`docs/视觉归档/_census/class-census.json`，带 `src最新` 戳，源码更新即拒绝出清单并要求先重跑全量 `theme-audit`）；纯文案数据文件（如 changelog）可豁免但必须打印理由。「零死样式」必须是真查过的结果。

## 4. 主题系统

四套正式主题经 `data-theme` 属性切换（`tokens.css` 定义全部语义令牌；默认主题光速黑）：

| id | 名称 | 参考 |
|---|---|---|
| raycast | 光速黑（默认） | Raycast |
| apple | 极简白 | Apple |
| notion | 纸墨白 | Notion（暖白纸面） |
| oppo | OPPO 绿 | OPPO 品牌绿 |

- 主题真源：`newtab/App.vue` `themes` 数组 + `tokens.css` `[data-theme=…]` 全令牌块；应用经 `applyTheme` / `resolveTheme`（`stores/app.ts`，缺省回落 `raycast`）。
- 新增 UI 必须只用令牌：`--bg/--surface(-2/-3)/--border(--strong)/--hairline/--text(-2/3/4)/--accent(…)/--success/--warning/--danger/--info-blue/--radius(…)/--shadow(…)/--fs-*` 等；**禁止硬编码色值**。
- **每个新界面必须在四主题下逐一走查**（`theme-audit.cjs` 全量实拍 + `gate:theme` 对比度门禁）；强调色统一走 `applyThemeAccent`，不做主题特判。

## 5. 常见任务速查（智能体向）

| 任务 | 步骤 |
|---|---|
| 加一个设置子域 | `views/settings/` 新建子域组件（宿主 `GlobalSettings.vue` 有行数闸，接线从简）；判据走 `read()` 聚合层的搬移可零断言改动 |
| 加一个卡片字段 | `defaults.ts` fieldDef + 老数据兜底（`legacy-normalize.ts` / 读取处 `|| []`）+ `FieldEditor` + 视图 `fieldValue` 分支 |
| 改任务状态语义 | **V4.7.1 起任务状态是业务数据**：`shared/utils/taskStatus.ts` + `AppData.taskStatuses`（`TaskStatusDef`：名称/颜色/顺序/`bucket` 三桶/`terminal` 完成语义），看板、详情、日历、筛选与项目全貌共用一份定义 |
| 加全局快捷键语义 | App.vue `onGlobalKeydown`（注意 isEditableTarget 守卫）；系统级命令改 `manifest.ts` `commands`，**默认键位最多 4 个**，新增命令不配 `suggested_key` 即可 |
| 加路由 / 台面 | `router.ts` 声明（路由级懒加载）；台签顺序即 Alt+数字切台顺序 |
| 加存储键 | 只在 `shared/storage/keys.ts` 登记（`K` / `IDB_NAMES` / `EXPORT_MARKERS`），引用处一律 `K.xxx` |
| 新弹窗 / 抽屉 | 对齐现有 overlay(mask+点击关闭)+panel 结构；快捷键挂 document 级（Teleport 内焦点不经过组件树）；Esc 两段式；删除类操作挂 Toast 撤销栈 |
| 加 AI 入口 | 全部 AI 调用发生在 newtab 侧；密钥只读 `zy_ai_v1`；**入口 chunk 不许出现模型名/密钥/供应商字面量**（`entry-literals.cjs` 双向扫描） |
| 动云同步 | `shared/cloud/sync.ts` 三方安全合并：不同记录取并集，同字段/删除/修改冲突**必须人工逐项确认**，绝不静默整端覆盖；普通卡片附件与 AI 凭据不上云 |

## 6. 已知地雷（改前必读）

1. **`chrome.tabs.query` 不返回 hash**——定位扩展页路由必须走 `zy-where` 询问机制（background 逐个问新标签页「你在哪个路由」）。
2. **`chrome.commands` 默认键位上限 4 个**——新增命令可以，但不要再加第 5 个默认键位；无默认键命令由用户在 `chrome://extensions/shortcuts` 分配。
3. **本地文件拿不到真实完整路径**（浏览器安全）——只能存文件名让用户补全。
4. **content script 是纯 Vanilla JS**——不能 import Vue/共享模块，工具函数（normalizeUrl 等）就地复制；浮层注入在宿主页普通 DOM（Shadow DOM 隔离挂账），http 页里没有 `chrome.storage`，跨上下文读写全走消息。
5. **`stats.lastVisits` 只经 `recordResourceOpen` 更新**——打开计数勿直接 `++`。
6. **工作台 `name` 字段含 icon 前缀**（`💼 事业工作台`）——展示时剥离前缀。
7. **删除卡片一律软删**（`deletedAt`），回收站依赖它；策展台删除也软删卡片，恢复时孤卡回落。
8. **构建前清空 `v2/dist`**；`dist` 不入库，不要把构建产物、截图归档、备份包或临时探针提交进仓库。
9. **Service Worker 会被随时回收**——所有状态落 storage；门禁脚本对 SW 求值必须走 `scripts/browser.cjs` 的 `swReady(worker)`。
