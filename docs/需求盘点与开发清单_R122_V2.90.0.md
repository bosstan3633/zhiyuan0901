## 五、待确认问题（请逐条答复）

- **Q1** 论点横幅：原型要求「彻底移除」。资源台现恒显空态横幅；策展台的论点横幅是「金字塔 L1 + 指标条第一格」之外的第三个入口。
  **建议：仅移除资源台（hub）的横幅；策展台保留**（避免牺牲策展台信息入口）。或按原型「全部移除」？
- **Q2** 卡片骨架 vs 字段配置：原型卡为固定骨架（标题/描述/页脚）；现状由「卡片字段设计（visibleFields）」驱动（链接/日期/自定义字段等）。
  **建议：骨架按原型固定（标题+描述+页脚）；字段配置继续生效——已启用字段（链接/日期/自定义）渲染在描述与页脚之间，未启用不显示**（能力不删、外观对齐原型）。确认？
- **Q3** hover 动作收敛：原型只有 `📋 挂载` + `⭐`；现状 7 个。
  **建议：一级 hover 按原型只留「📋 挂载 + ⭐」；打开/置顶/移动/镜像/删除保留在右键菜单**（打开仍可用双击）。确认？
- **Q4** 「挂载」语义：现状 = 挂到任务（弹窗多选任务，写 `task.mountedResourceIds`，单向挂载红线）。原型文案「挂载到今日三件事或进行中项目」。
  **建议：保持现有挂载弹窗（挂到任务）不动**，仅对齐按钮文案与位置。若你要「一键挂到今日三件事/主攻项目」的快速通道，那属新增功能，请另说明。
- **Q5** 工具条分级：原型一级 = 视图 + ＋新建 + ⬇导入 + ☑批量 ｜ 列数 + 搜索 + 状态筛选。
  **建议：按原型提权这四类；排序与密度不移除**——保留在「筛选」气泡（原 R88-W3 的分级精神保留，仅把原型强调的控件提上来）。确认？⚙ 菜单保留台设置项（重命名/图标/描述/导出/删除/清镜像）。
- **Q6** 状态筛选下拉（一级）：原型 4 项 = 全部状态 / 有附件的卡片 / 高频调用🔥 / ⚠待补全路径。
  其中「高频调用」现无此筛档（只有"调用最多"排序）。
  **建议：新增筛档「高频调用（callCount ≥ 3）」**并映射原型 4 项；完整 8 档（url/file/obsidian/hasLink/starred/unmounted）继续留在「筛选」气泡。确认口径（≥3 还是 >0）？
- **Q7** 默认列数：**建议资源台默认 5 → 6**（与原型一致；已自定义过列数的用户不受影响）。确认？
- **Q8** 容器与字号：原型 max-width 1560 / 标题 16px；现状 1440 / 19px（R108-F10 + R51-F11 三页统一规范）。
  **建议：保持 1440 + 19px**（跨页一致性优先），仅改描述合并与右端提示。确认？
- **Q9** 分组头排序入口：原型「按首字母排序 ▾」在分组头右侧。
  **建议：分组头右侧放排序入口（默认显示当前排序名，如「手动拖拽 ▾」），筛选气泡内排序保留（同源双入口）**。确认？
- **Q10** 版本号：本轮命名 **V2.90.0（R122）** 是否 OK？
