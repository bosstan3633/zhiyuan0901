# 交付说明 · R3-Cb —— 三张卡的批量选择与批量打标签合一（未升版）

日期：2026-09-30 · 基线：`e8f36e8`（R3-Ca 池面板补齐）· 归属：轮次 C 第二刀。

## 一、这一刀修的是两个既存缺陷，不只是"统一代码"

盘点三面板批量实现时挖出两条真 bug，都不是"代码重复"那么无害：

1. **任务与好奇的「全选/反选」按钮是假的。** 文案写「全选/反选」，函数体只做满选↔清空（`20-req39-64` 那批断言只核"按钮在不在"，所以一直没红）。**反选从来没实现过。**
2. **好奇面板退出批量态不清空 `selected`。** 下一轮进来上一轮的勾选还在，而两次之间可见集合可能已经变了——批量动作里就有删除，这是"我以为没选"的误删配方。
3. 顺带一条：任务与好奇的批量栏条件是 `v-if="batchMode && selected.size"`——**不先勾选，整栏不渲染**，于是"全选"按钮要把每张卡先点一遍才会出现。池面板（R2-⑧）本来就是 `v-if="batchMode"`，三面板口径不一致。

## 二、做法

新建 `v2/src/newtab/composables/useBatchSelect.ts`，导出两件事：

- `useBatchSelect(visibleIds: () => string[])` → `{ selected, size, allSelected, has, toggle, selectAll, invert, clear, setMode }`。
  语义铁律：**所有动作只在 `visibleIds()`（当前过滤结果）里发生**，不做"全量取反"。`setMode(false)` 一律清空。
- `addTagToCards(items, ids, tag)` → 批量打标签的唯一写入式：只加不减、软删卡跳过、`updatedAt` 置当前、返回命中数。

三面板全部接上，`selected` 用就地增删（与各面板既有的 `.forEach/.size/.has/.clear` 调用点兼容，不做破坏性改写）：

| 面板 | `visibleIds()` 传什么 | 本轮补上的入口 |
| --- | --- | --- |
| 资源卡池 | `poolCards`（过滤后 + 待打标筛选后） | 已有全选/反选，改为消费同一份实现 |
| 任务调度 | `filteredTasks` | **全选/反选拆成两枚**、**批量打标签**（输入框 + 回车/应用） |
| 好奇心培育 | `filtered` | **全选/反选从无到有**、**批量打标签**、退出批量清空 |

批量栏改为 `v-if="batchMode"`（三面板一致），动作按钮一律 `:disabled="!selected.size"`；同时给任务与好奇面板补 `.mini-btn:disabled { opacity: var(--opacity-disabled); cursor: not-allowed; }`——原来这条只在 `CompassHome.vue` 的 **scoped** 样式里，面板里的禁用按钮"看起来能点其实点不动"，正是 F38 那轮在治的那类问题。

## 三、断言与实测

- **新增 4 条**（`99-recent.cjs`【R3-Cb】）：★批量选择唯一实现（三面板都 import，且面板内不得再留 `function selectAll` / 自建 `selected` 容器）、★批量栏进来就在 + 禁用态有令牌化反馈、★退出批量必清空（三处同一句 `setMode`）、★三类卡批量打标签齐全且同一写入式（`只加不减` + `回车应用` 三处逐条核）。
- **重指 2 条**（R2-⑧ 批量口径、R3-Ca 反选判据）：实现从面板搬进 composable，判据跟着搬到新落点，**口径一字未变**（只加不减 / 软删带撤销 / 只在过滤结果内取反）。
- **E2E 新增 E2E-31**：任务 tab → 点「☑ 批量管理」→ 未选状态下批量栏即可见且「已选 0 项」→ 点全选 → 4 项选中 → 批量打标签 → 逐张核 `tags` 落库数量与选中数一致 → 退出再进，勾选不残留；好奇 tab（先种两张卡，避免"库里一张不剩"被误读成反选生效）→ 全选「已选 2 项」→ 反选「已选 0 项」。
  本轮在 E2E 里连踩三条自己的坑，都记进注释：**① 按钮文案是「☑ 批量管理」不是「批量」**，按文案找不能按 `.cz-batch-btn` 第一枚（那是 AI 转化研判钮）；**② `chrome.storage.local.set` 不会回灌内存 store**，种完必须 reload，否则面板看到的还是旧列表；**③ 同一作用域内变量名与前面场景冲突**（`selAll` 在 E2E-30 已声明），node 加载期直接报语法错。
