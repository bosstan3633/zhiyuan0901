## 四、根因备忘（防复发）

1. **异步就绪重排 = 列表交互竞态源**：任何"某资源异步就绪后重算列表"的逻辑（拼音字典、远程数据），若渲染行靠行号索引取数，就绪窗口内点击即错位。铁律：**渲染行绑定实体 id，交互按 id 寻址**；就绪补跑只追加不改既有顺序。
2. **回归断言是活文档**：断言内嵌 class/文案字符串守护旧结构；UI 结构演进（如详情重设计、滚动加载→翻页）后，引用该文件的旧断言必失败。铁律：**重构文件前先 grep regression.cjs 引用**，改结构同时更新守护断言的意图（保留语义、更新字面）。
3. **重构删模板必清死 CSS**：Vue SFC 模板删掉旧 class 后 `<style>` 段常残留（本轮 ts-status-row / detail-status-row / gs-ev-more 三处死代码触发 `!includes` 断言）。铁律：重构后 `grep` 旧 class，模板与样式一并清理。
4. **vite build 清空 dist 会撞沙箱批量删除守护**（>50 文件触发确认）：改名 `dist_old_<ts>` 让构建走新目录，构建后删旧目录（第卌七/卌八轮同法）。
5. **同文件并行 Edit 静默互相覆盖**（报成功但内容丢失）：同文件编辑必须串行（第卌七轮教训再现，本轮 GlobalSettings 再次发生并被 typecheck/断言抓回）。
6. **UI 数字口径必须先问来源**：任何"今日/本周 +N"统计，先确认按 createdAt 还是按事件流——导入类批量数据会瞬间淹没真实新建数（本轮拍板双口径并显根治）。
