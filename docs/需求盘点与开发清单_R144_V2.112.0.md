## 二、沉淀资产（后续可直接抄）

- **`shared/ai/batchG.ts`**：批次 G 四工厂同一骨架（投影→run/parse→行→apply/secondary），新场景照抄一个函数即可。
- **入口净增 0 行的组件化范式（第二次验证）**：`ThesisAiBtn.vue` / `EvidenceMenuItem.vue` 自带按钮+抽屉+懒栈+样式，宿主只把标签并到既有行——`workspace.css` 是 scoped 且 fragment 根不继承父 scope，**组件必须自带样式**（本轮新踩并写进断言 R144-6）。
- **判决式契约（G2 型）**：白名单 verdict + 缺关键字段即丢行 + 写入动作交宿主回调——凡「AI 给分类判断、落地方式各不相同」的场景适用。
- **`flattenTaskTree`（taskLinks 真源）**：软层级展平带悬空兜底与递归封顶，任何树/列表要显示父子关系都可用，不必各写一遍。
- **G1 的 🤖 块替换纪律**：模型产出的结构化正文一律「整段替换不堆积」，与 R135 行动方案、R139 步骤清单同族。
- `reviseSnips` / `SNIP_CAP` 已导出为跨场景共用（论点提炼与好奇研判直接复用 R143 的抽读缓存）。
