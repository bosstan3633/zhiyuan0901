# V4.3.3 交付说明

> 版本：V4.3.3
>
> 日期：2026-11-14
>
> 基线：V4.3.2（`dfa490f`）

## 一、交付结论

V4.3.3 在 V4.3.2 的月历排期与常用夹基础上完成七项体验收口：

1. 任务日历支持月视图 / 周视图切换，并修复日详情文字叠压。
2. 左侧待排期只按“是否已有计划执行日期”判断，已完成任务交给上方筛选。
3. 资源卡常用夹与“今日采集”点击后直接打开中央明细弹窗。
4. 卡片池页签角标降低视觉强调，0 继续隐藏。
5. 今日战报提升为页头主入口，并新增可自定义的浏览器快捷键。
6. 今日战报改为先打开弹窗、后读取日志，显著缩短点击后的等待感。
7. 今日三件事槽位按内容高度收口，减少大面积空白。

同时修复老库 `dueAt` 与数字型 `dueDate` 导致任务日历崩溃的问题。移动采集 PWA、PC Inbox 与周期 AI 分析继续保持退役。

## 二、任务日历

- 月视图保留完整月份、相邻月份日期、跨月浏览与任务排期。
- 周视图固定展示当前 7 天；前后按钮按周移动。
- “今天”同时校正当前月份与周起点。
- 月视图与周视图共用同一任务池、状态色、拖入排期、取消排期与日详情链路。
- 日详情改为稳定三栏行布局：标题、项目 / 指标元信息和关闭动作各自占位，不再互相覆盖。
- 左侧待排期列表只判断任务是否没有计划执行日期，不再暗中排除已完成任务。
- 已完成任务是否显示，统一交给上方项目、状态与快捷筛选决定。
- “计划执行日期”继续复用任务既有 `dueDate`，没有新增第二日期字段。

## 三、资源常用夹

- “今日采集”与常用夹模块点击后直接打开中央明细弹窗。
- 文件夹明细支持打开单张资源卡、一键打开全部可访问原链、从当前常用夹移出镜像，以及进入常用夹管理。
- 移出常用夹只删除当前夹的镜像关系，不删除资源真身，也不影响其他常用夹和策展台镜像。
- “今日采集”仍是当天资源的虚拟筛选，不复制资源卡，不写入常用夹成员。
- 卡片池页签今日新增角标改为继承文字颜色，不使用红色、高对比底色或描边；数字为 0 时不渲染。

## 四、今日战报

- 今日战报提升为调度台页头主入口，AI 推荐降为次级入口。
- 点击后先显示战报弹窗和本机已有数据，再在后台读取事件日志与云端账号操作记录。
- 云端校正失败或较慢时继续使用本机缓存，不阻塞弹窗打开。
- 浏览器扩展命令新增“打开今日战报”，默认不占用键位，由用户自行分配。
- 未打开知源页时可直接打开并进入调度台；已打开知源页时复用当前页面并打开战报。
- 设置页、后台命令、页面消息与一次性 URL 动作使用同一条打开链路。

## 五、数据兼容修复

- 载入与导入边界新增 `legacyPlanDate()`，把旧库 `dueAt` 和数字型 `dueDate` 统一收敛为 `YYYY-MM-DD`。
- 修复旧演示数据触发 `e.split is not a function`、导致任务日历无法渲染的问题。
- 兼容转换只处理计划执行日期，不改任务状态、项目归属、成功指标、附件或其他业务字段。
- 新增 `V433-10` 行为级回归，旧数据夹具和任务日历共同覆盖该路径。

## 十、事实边界

- 本轮交互和视觉验证覆盖桌面 Chromium；未做实体手机验收。
- 周视图只改变日历展示周期，不新增第二套排期数据。
- 日详情弹窗只负责查看与取消排期，任务删除仍只在卡片池任务管理入口完成。
- “今日采集”是虚拟筛选视图，不复制资源卡，也不产生新的云端记录。
- 今日战报可以后台补齐云端记录，但跨设备数据是否完整仍依赖用户已登录同一账号并完成同步。
