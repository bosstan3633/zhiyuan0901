## 三、REQ-037「打开全局设置」命令落地说明

**需求澄清过程**：用户最初表述为「产品的全局设置能否在浏览器里配置快捷键」，经截图澄清确认——原意是在 `chrome://extensions/shortcuts`（浏览器快捷键管理界面）为知源工作台**新增一个命令项**，由用户手动分配按键，任意场景（含扩展外）按该键一键进入工作台设置页。**不是**在工作台内提供快捷键录制器。

**Chrome 限制验证（不超限）**：
- Chrome 命令**数量无上限**，仅限制 4 个 `suggested_key`（manifest 预填默认键）；截图显示当前已有 5 个命令项（4 带键 + 1 未设置「激活该扩展程序」），新增第 6 个不配 suggested_key 完全合法。
- 命令 `description` 必填（非 action 类命令缺描述不显示在 shortcuts 页）。

**落地方案**：
1. `manifest.ts` commands 新增：
   ```ts
   'open-settings': { description: '打开全局设置' }   // 不配 suggested_key，用户自行分配
   ```
2. `background/index.ts` onCommand 新增 `case 'open-settings'`：复用 open-dashboard「聚焦已开新标签页 + `zy-route` 消息路由 /settings」模式；无已开标签则 `chrome.tabs.create` 直达 `#/settings`。

**用户操作路径**：`chrome://extensions/shortcuts` → 找到「打开全局设置（未设置）」→ 点击输入框按下想用的组合键（如 Alt+S）→ 生效。
