## 一、REQ-038 数据持久化加固

### ① 申请 unlimitedStorage · `manifest.ts`

| 项 | 内容 |
|---|---|
| 类型 | 能力开通 |
| 现状 ❌ | `permissions: ['storage', 'tabs', 'activeTab', 'commands', 'scripting']`——未声明 `unlimitedStorage`，`chrome.storage.local` 硬上限 **10 MB** |
| 风险 | 知源单根 JSON（`zy_data_v2`）随资源卡增长，触顶后**所有写入静默失败**，用户毫无感知，下次打开回到旧版本 |
| 改动 | permissions 追加 `'unlimitedStorage'`；新增 `hasUnlimitedStorage()` 运行时自检 |
| 验收 | 设置 → 关于 → 显示「权限 unlimitedStorage ✅」 |

### ② 保存失败告警 · `shared/storage/repository.ts`

| 项 | 内容 |
|---|---|
| 类型 | 健壮性（**真 Bug**） |
| 根因 ❌ | 防抖保存 `cs.set(payload)` 返回的 Promise **完全没有 `.catch`**；`saveDataNow()` 无 try/catch。写入失败时异常坠入 void，界面照常显示，数据实际未落盘 |
| 改动 | ① `emitSaveError(e)` 分类 `quota`/`serial`/`unknown` 并异步取 `getBytesInUse`；② 新增 `subscribeSaveError` / `getLastSaveError` / `clearLastSaveError`；③ `App.vue` 订阅转 Toast（带「查看」跳设置页）；④ 设置页「关于」新增红色异常行可「已处理」；⑤ `saveDataNow()` 包 try/catch，成功后清错误态 |
| 验收 | 制造写入失败 → 弹 Toast；设置页可见异常行；成功保存后自动清除 |

### ③ 容量水位显示 · `getBytesInUse()`

| 项 | 内容 |
|---|---|
| 类型 | 可视化 |
| 现状 ❌ | 无任何容量反馈，用户对"离触顶还有多远"完全无感 |
| 改动 | `getBytesInUse()` 封装 `chrome.storage.local.getBytesInUse`；设置页「关于」新增「数据存储」行（已用容量 + 权限状态）；`App.vue` 监听 `chrome.storage.onChanged` 实时刷新 |
| 验收 | 打开设置页可见实时容量数字 |

### ④ 自动备份提醒 · UIPrefs 扩展

| 项 | 内容 |
|---|---|
| 类型 | 功能新增 |
| 模型 | `UIPrefs` 新增 `backupReminderEnabled?` / `lastBackupAt?` / `backupReminderSnoozedAt?` |
| 触发 | 顶栏设置按钮红点 = **30 天未导出** 或 **容量 > 5 MB** |
| 消除 | 四处导出入口（全量 JSON / CSV / 单工作台 / Markdown）成功后统一 `markBackupNow()` 写 `lastBackupAt` |
| 开关 | 导出页「备份提醒」卡片（开关 + 上次导出时间） |
| 验收 | 导出后红点消失；关掉开关后不再提醒 |

## 二、REQ-039 全局搜索交互统一（P1 方案）

| 入口 | 文件 | 运行环境 | 现状 ❌ |

| 6 | newtab 弹层单击/双击分离：`selectResultLocator()` / `runFlatLocator()`（单击）vs `selectResult()` / `runFlat()`（双击） | `newtab/components/GlobalPopups.vue` |
| 7 | Enter 键统一走**单击**行为（`runFlatLocator`） | 两个入口 |
| 8 | 结果项 `title` 加提示：单击=查看详情，双击=直接打开 | 两个入口 |

### 2.3 路由映射（单击定位目标）

| 结果类型 | 单击跳转路由 | drawer.kind |
|---|---|---|
| 资源卡 | `/workspace/{workspaceId}` | `res` |
| 任务卡 | `/compass/actions` | `task` |
| 好奇心卡 | `/`（罗盘首页） | `curio` |

### 2.4 验收

1. newtab 内搜索：**单击** → 跳目标页 + 抽屉展开 + 卡片高亮；**双击** → 直接打开链接
2. 第三方页搜索：**单击** → 新开/聚焦工作台标签，落地即展开抽屉 + 高亮；**双击** → 新标签打开链接
3. Enter 键走单击行为（不直接跳走）
4. 四类结果抽屉都能正确展开
5. 资源抽屉三个动作（复制链接 / 打开 / 全屏编辑）可用
