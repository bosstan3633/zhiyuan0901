## 三、REQ-047 本地图片/HTML 上传 · 调研结论（✅ 拍板立项）

### 核心结论

1. **可行**，图片弹窗预览（`URL.createObjectURL`）、自包含 HTML 新标签打开均为扩展常规能力。
2. **但绝不能塞进主 JSON**：几百 MB base64 进 `zy_data_v2` → 每次防抖保存全树序列化/启动全量读/跨页 onChanged 全树替换全部劣化 → **打开与交互速度必然崩**。
3. **正确路线 = IndexedDB 附件库**：Blob 二进制按 key 存取，卡片只存 `{assetId, kind, name, size}` 元数据 → 主 JSON 体量不变（KB 级），附件按需读取 → **对主链路速度零感知**。
4. 单文件 HTML 天然限制：**只有自包含 HTML 能完整打开**；依赖相对路径资源的本地页面应继续用 `linkType='file'` 链接卡片。

### 待细化（第卅九轮计划确认）

三类卡（资源/好奇心/任务）先支持哪些 / 单文件上限 / 总数上限 / 导出是否打包附件 / 软删清理策略 / 第三方页浮层不预览附件（跨 origin 读不到扩展 IndexedDB，只定位）。
