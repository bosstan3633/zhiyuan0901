## 1. 技术栈

| 层 | 选型 |
|---|---|
| 框架 | Vue 3.5（Composition API / `<script setup>`）+ TypeScript strict |
| 构建 | Vite 5 + @crxjs/vite-plugin（MV3 打包 + HMR） |
| 状态 | Pinia（`useAppStore` 单一数据仓 + `useCompass`/`useCuriosity` 组合式） |
| 路由 | Vue Router（hash 模式，路由级懒加载） |
| 样式 | 原生 CSS Variables（tokens.css 六主题语义令牌）+ scoped CSS；UnoCSS 仅引入 |
| 扩展规范 | Manifest V3；Service Worker + Content Script（纯 Vanilla JS，不引入 Vue 运行时） |
| 存储 | 主数据 `chrome.storage.local` 单根 JSON（`zy_data_v2`，unlimitedStorage）+ **附件二进制 IndexedDB 库 `zy_assets`**（第卅九轮起，单文件 ≤20MB；主 JSON 绝不存 base64）；无云端、无账号 |

## 4. 存储结构

| 键 | 内容 |
|---|---|
| `zy_data_v2` | AppData 单根 JSON（见下） |
| `zy_ui_v2` | UIPrefs：theme / sortPrefs / density / cardCols（R72 列数偏好）/ wsViewMode（R84 台视图）/ curSplit / tcSplitRatio / drawerWs / taHeights / showDoneProjects / backupReminder* / projRailW·H / wsSwitchMod / compassTab |
| `zy_capture_pref` | 采集默认工作台等偏好 |
| `zy_qc_prefill`（session） | 降级弹窗预填（标题/URL/mode） |
| `zy_event_log` | 事件日志（repository 快照 diff，5000 条滚动） |
| `zy_html_paths` | HTML 附件落盘路径记忆 |
| IndexedDB `zy_assets` | 附件二进制（objectStore `assets`，key=assetId，value=Blob；单文件 ≤20MB） |
| `lm_data_v5` | 旧版数据（检测到则自动迁移至 zy_data_v2，并备份为 `lm_data_v5_backup`） |

### AppData（TypeScript 摘要，完整定义见 `shared/models/index.ts`）

```ts
interface AppData {
  version: 2
  compass: {
    vision: CompassNode; mission: CompassNode   // content/pinnedToLighthouse/linkedResourceIds?/linkedCuriosityIds?
    directions: Direction[]                      // { id, name, status, term?, pinnedToLighthouse?, projects: Project[] }
  }                                              // Project: { id, name, isFocused(主攻), pinnedToLighthouse?, order?, status, metrics: Metric[] }
  workspaces: Workspace[]                        // { id, name(含icon前缀), icon, desc?, order, archived, hotkey? }
                                                 // 含资源台真身 zy-curation（hub；store.workspaces getter 对外排除它）
  categories: Category[]                         // { id, workspaceId, name, order, parentId?(≤4 级), pinned? }
  resources: ResourceCard[]                      // linkType: url|file|obsidian；starred/callCount/lastCalledAt/deletedAt/assets?: AssetMeta[]…
  tasks: TaskCard[]                              // projectId+metricId 双挂；mountedResourceIds/mountedCuriosityIds（单向）；tags?
  curiosities: CuriosityCard[]                   // question/sourceUrl/status(todo|doing|done|shelf)/pinned/tags?/assets?
  curationProjections?: CurationProjection[]     // 策展台镜像记录（引用资源台源卡，不复制数据）
  dailyFocus: Record<'YYYY-MM-DD', FocusSlot[]>  // ≤3 槽：{ id, sourceType, sourceId?, text, done }
  tagTree: TagNode[]                             // { id, name, children? }（最多 3 级）
  fieldConfig: { resource: FieldDef[]; task: FieldDef[]; curiosity: FieldDef[] }
  stats: { weekly; lastReuse; lastVisits; wrr }  // lastVisits 跨周自动重置
  activityLogs: ActivityLog[]
  airtableSync?: AirtableSyncState               // Airtable 单向同步配置（含 pat；导出/备份时剥离，R70）
}
```

**红线**：① Resource / Curiosity / TagNode 的 Schema 中**禁止出现 taskId**（单向挂载：只有 Task 持有 mounted* 数组；愿景/使命的 linked* 为持有方引用，同样单向）；② 删除一律软删 `deletedAt`（回收站可恢复，硬删仅回收站 purge 路径）；③ 主 JSON 绝不存 base64，附件只存 AssetMeta 引用；④ `stats.lastVisits` 只经 `recordResourceOpen` 更新。

## 5. 关键数据流

### 5.1 读写链路
```
组件 → useAppStore.data（响应式）→ store.persist() → repository.saveData()
  → 300ms 防抖 → JSON 纯化 → chrome.storage.local.set → storage.onChanged
  → 其他上下文 syncCache + data.value 替换（跨页同步；卡片三数组 LWW + dailyFocus 槽级合并）
```
- content script / popup **直接读写** storage（不经 Pinia）；新标签页通过 `storage.onChanged` 感知外部写入（`syncCache` 保持 cache 一致）
- 导入前自动备份与全量导出均**剥离 `airtableSync`**（令牌不出包，R70）

### 5.2 工作台单例定位（G）
```
发起方 sendMessage('zy-locate-workspace',{wsId,hl})
→ background：query 所有扩展新标签页 → 逐个 sendMessage('zy-where') 询问路由
→ 命中 /workspace/{wsId} → 激活窗口+Tab → tabs.sendMessage('zy-locate')
→ 未命中：发送方是新标签页则本页跳转；否则任一新标签页跳转；无 → tabs.create
```
⚠ 注意：`chrome.tabs.query` 的 URL 匹配**不含 hash**，因此必须用询问机制而非 URL 过滤定位 hash 路由。

### 5.3 通用路由跳转（B4）
`zy-open-route {route}` → background 复用任一新标签页 → `zy-route {route}` → App.vue `router.push`。

### 5.4 打开资源（WRR 口径，七入口统一）
`recordResourceOpen(data, resource)`（`shared/storage/stats.ts`）：callCount++ / lastCalledAt / stats.lastVisits[id]++（跨周自动重置并滚动 weekly）/ WRR 累计。资源台单击详情、双击打开、搜索打开、关联卡片、抽屉「↗ 打开」、北极星下钻等入口**全部走本函数**（第卅二轮 B40 下沉；R70 修复详情抽屉写深拷贝副本问题）。

## 6. 消息协议汇总

| 消息 | 方向 | 载荷 | 语义 |
|---|---|---|---|
| `zy-ping` | SW→Tab | — | 探测 content script 存活 |
| `zy-open-search/capture/curiosity/task-capture` | SW→Tab | — | 唤起对应浮层（搜索/采集/好奇/任务采集） |
| `zy-locate-workspace` | 任意→SW | wsId, hl | 工作台单例定位请求 |
| `zy-locate` | SW→新标签页 | wsId, hl | 页内路由到工作台并高亮 |
| `zy-open-route` | 任意→SW | route | 通用路由打开（复用新标签页） |
| `zy-route` | SW→新标签页 | route | 页内执行 router.push |
| `zy-where` | SW→新标签页 | — | 回答当前路由 path（单例询问用） |
| `zy-qc-prefill` | storage.session | title,url,mode | 降级弹窗预填 |
| `zy-open-drawer` | 应用内总线 | { kind, id } | 详情抽屉打开（res/task/curio，`shared/utils/bus.ts`） |
