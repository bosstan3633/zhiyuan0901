## 1. 技术栈

| 层 | 选型 |
|---|---|
| 框架 | Vue 3.5（Composition API / `<script setup>`）+ TypeScript strict |
| 构建 | Vite 5 + @crxjs/vite-plugin（MV3 打包 + HMR；`emptyOutDir:false`，构建前须清空 `v2/dist`） |
| 状态 | Pinia（`newtab/stores/`：`app` 数据仓 / `compass` / `curiosity`） |
| 路由 | Vue Router（hash 模式，路由级懒加载 + KeepAlive 缓存主视图） |
| 样式 | 原生 CSS Variables（`tokens.css` 四主题语义令牌）+ scoped CSS；无 UI 框架 |
| 运行时依赖 | 仅 3 个：`vue` / `vue-router` / `pinia`（拼音检索走自生成两层表 `shared/utils/pinyinTable.ts`） |
| 扩展规范 | Manifest V3；Service Worker + Content Script（纯 Vanilla JS，不引入 Vue 运行时） |
| 存储 | 主数据 `chrome.storage.local` 单根 JSON（`K.DATA`，unlimitedStorage）+ **附件二进制 IndexedDB 库 `zy_assets`**（单文件 ≤20MB；主 JSON 绝不存 base64）+ 可选**邀请制 Supabase 手动快照同步**（本地优先，默认关闭；三方安全合并，冲突人工逐项确认） |

## 4. 存储结构

**键名唯一字面量出处是 `shared/storage/keys.ts`**（`K` 存储键 / `IDB_NAMES` IndexedDB 库名 / `EXPORT_MARKERS` 导出包标识）；`src/**` 内出现裸 `zy_*` / `lm_*` 键名即红。主要分组（此处只列用途，不复制键值）：

| 组 | 内容 |
|---|---|
| `K.DATA` | AppData 单根 JSON（见下） |
| `K.UI` | UIPrefs：主题/布局/筛选/抽屉宽度等本机偏好（**只留本机，不上云**） |
| `K.STATS` / `K.DAILY_STATS` | 热度统计（R148 拆键）/ 按日快照（战报与热力图） |
| `K.EVENT_LOG` / `K.ERROR_LOG` | 事件日志（快照 diff 滚动）/ 运行错误留痕 |
| `K.AI_CONFIG` 等 AI 族 | AI 凭据与指令（**只活此键；不进导出/备份/合并链路，内容侧浮层永不持钥**） |
| `K.CLOUD_*` 族 | 云同步元数据 / 共同基线 / 操作记录 / 锁 / 环境 |
| `K.CAPTURE_PREF` 等偏好族 | 采集默认台、树折叠、项目诊断缓存等 |
| IndexedDB `IDB_NAMES.ASSETS`（库 `zy_assets`） | 附件二进制（objectStore `assets`，key=assetId，value=Blob；单文件 ≤20MB） |
| `K.LEGACY`（`lm_data_v5` / `lm_data_v5_backup`） | 旧版数据（检测到则自动迁移并备份） |

**并发写语义**：多窗口 / 浮层并发是真实场景。外部写入到达时——本地无未落盘修改则整树替换；**有**则走 `mergeExternalData`：卡片按 `id + updatedAt` **LWW 合并**（平手取本地，保护输入中的表单），其余段「本页动过留本页」。自身写入回环由 writeId 指纹抑制。

**云同步边界**（`shared/cloud/sync.ts` 三方安全合并）：不同记录/字段自动取并集；同字段或删除/修改冲突**必须人工逐项确认**，绝不静默整端覆盖。普通卡片附件与 AI 凭据不上云；策展节点附件登录后默认进用户私有 Storage；主题、布局、筛选、抽屉宽度只留本机。

### AppData（TypeScript 摘要，完整定义见 `shared/models/index.ts`）

```ts
interface AppData {
  version: 2
  compass: {
    vision: CompassNode; mission: CompassNode
    directions: Direction[]                      // 愿景 → 使命 → 战略目标 → 项目 → 成功指标 → 任务/选题
  }                                              // Project: { id, name, isFocused(主攻≤2), nextStep?, status, metrics: Metric[] }
                                                 // Metric: { id, title, target?, acceptance?, taskIds, topicIds? }
  workspaces: Workspace[]                        // 策展台 ×N（kind:'curation'）；资源池真身实体 zy-curation 仍在原始数组，
                                                 // 由 store getter 过滤——"按实体找池"的写法全是巧合，显示名单源在 shared/utils/wsName.ts
  categories: Category[]                         // 策展台内分类（池卡 categoryId 置空串，组织维度只有 tags）
  resources: ResourceCard[]                      // 真身统一入池（workspaceId=zy-curation）；linkType: url|file|obsidian
                                                 // linkSlots?（三槽备用值）/ tags / starred / callCount / deletedAt / assets?: AssetMeta[]
  tasks: TaskCard[]                              // projectId+metricId 双挂；statusId→taskStatuses（V4.7.1 自定义状态）
                                                 // dueDate / subtasks（父卡内嵌，不进任务池）/ tags?
  curiosities: CuriosityCard[]                   // question/sourceUrl/status(todo|doing|done|shelf)/dueDate?/convertedAt?
  topics: TopicCard[]                            // 选题卡（V4.5.0）：statusId→topicStatuses / dueDate 与任务共用日历口径
  topicStatuses: TopicStatusDef[]                // 选题状态定义（业务数据，参与云同步）
  taskStatuses: TaskStatusDef[]                  // 任务状态定义（V4.7.1）：{ id, name, color, order, bucket: todo|doing|done, terminal? }
  planScheduleEvents?: PlanScheduleEvent[]       // 安排历程（V4.7.0）：任务/选题/好奇共用；removedAt 墓碑；来源枚举
  topicResourceLinks?: TopicResourceLink[]       // 选题→资源独立关联记录（带快照）
  supportLinks? / curioSupportLinks?             // 任务→资源、好奇→资源「支持」记录（独立表，卡本体零挂载）
  curationProjections?: CurationProjection[]     // 池→策展台投射引用（引用式镜像，不复制数据）
  resourceFolders? / resourceFolderMirrors?      // 常用夹（V4.2.2）与成员镜像（独立 snapshot）
  argCards?: ArgumentCard[]                      // 论证节点卡（策展台专用，独立表，不进四卡池）
  dailyFocus: Record<'YYYY-MM-DD', FocusSlot[]>  // 今日三件事 ≤3 槽：{ slotIndex, sourceType: task|topic|resource|curiosity|text, sourceId?, text, done }
  tagTree: TagNode[]                             // { id, name, children? }（最多 3 级；tagTreeRevision 整树替换版本号）
  fieldConfig: { resource: FieldDef[]; task: FieldDef[]; curiosity: FieldDef[] }
  stats: { weekly; lastReuse; lastVisits; wrr }  // lastVisits 跨周自动重置；只经 recordResourceOpen 更新
  activityLogs: ActivityLog[]
}
```

**红线**：① **卡间零挂载**——四卡本体互不持有对方 id；豁免只限独立记录表（`SupportLink` / `CurationProjection` / 常用夹成员镜像 / `topicResourceLinks`），六层归属（`projectId`/`metricId`）不受限；② 删除一律软删 `deletedAt`（回收站可恢复，**无期限自动清除**，硬删仅回收站 purge 路径）；③ 主 JSON 绝不存 base64，附件只存 AssetMeta 引用；④ `stats.lastVisits` 只经 `recordResourceOpen` 更新；⑤ 新字段必须可选并在读取处兜底，老数据在载入、导入、云恢复边界统一走 `normalizeAppData()`。Airtable 同步已退役：载入/导入/导出边界剥离遗留 `airtableSync` 字段。

## 5. 关键数据流

### 5.1 读写链路
```
组件 → useAppStore.data（响应式）→ store.persist() → repository.saveData()
  → 300ms 防抖 → JSON 纯化（Vue Proxy 过不了结构化克隆）→ chrome.storage.local.set → storage.onChanged
  → 其他上下文 syncCache + mergeExternalData（卡片三数组 LWW + 其余段本页保护）
```
- content script 直接经消息跨上下文读写（http 页没有 `chrome.storage`）；新标签页通过 `storage.onChanged` 感知外部写入
- 导入前自动备份与全量导出：普通卡片附件与 AI 凭据剥离，导出包带 `EXPORT_MARKERS` 标识

### 5.2 云同步（邀请制 Supabase，手动快照）
`shared/cloud/` 全族：手动「立即同步云端」（命令 `sync-cloud-now` + 顶栏按钮）+ 可选自动档（alarms 驱动）。上行为本地→云端快照，下行拉取后与本地、共同基线（`K.CLOUD_SYNC_BASE`）做**三方安全合并**：不同记录/字段取并集；同字段或删除/修改冲突弹**逐项选择**清单，用户确认前绝不落库。同步明细/回执/历史走 `K.CLOUD_SYNC_ACTIONS` 与设置页同步事实面板。

**今日三件事同步（V4.7.7 明确）**：`dailyFocus` 是主快照业务数据，按日期与槽位整体上传；`sanitizeSnapshot()` 用 `preserveDailyFocus()` 保留槽位内容、顺序、完成态与 `doneAt`，`mergeDailyFocus()` 拉回时按日期键与槽位 id 合并。单边修改时另一设备与源设备一致；同日同槽双边同时修改时按现有冲突策略保留本机值，不静默覆盖。

### 5.3 工作台/卡片单例定位（zy-where 询问链路）
```
发起方 sendMessage('zy-locate-workspace',{wsId,hl})
→ background：query 所有扩展新标签页 → 逐个 sendMessage('zy-where') 询问路由
→ 命中目标 → 激活窗口+Tab → tabs.sendMessage('zy-locate')
→ 未命中：发送方是新标签页则本页跳转；否则任一新标签页跳转；无 → tabs.create
```
⚠ 注意：`chrome.tabs.query` 的 URL 匹配**不含 hash**，因此必须用询问机制而非 URL 过滤定位 hash 路由。

### 5.4 通用路由跳转（B4）
`zy-open-route {route}` → background 复用任一新标签页 → `zy-route {route}` → App.vue `router.push`。

### 5.5 打开资源（WRR 口径，七入口统一）
`recordResourceOpen(data, resource)`（`shared/storage/stats.ts`）：callCount++ / lastCalledAt / stats.lastVisits[id]++（跨周自动重置并滚动 weekly）/ WRR 累计。资源详情打开、搜索打开、关联卡片、抽屉「打开」、下钻等入口**全部走本函数**；打开记账在确认可打开之后置位（失败分支零记账）。

### 5.6 安排历程（V4.7.0）
任务 / 选题 / 好奇每次主动安排（详情、日历、快捷菜单、今日重点、导入）写一条 `PlanScheduleEvent`（安排时间、目标日期、改期前日期、来源）；单条删除写 `removedAt` 墓碑（同步时不并回）；撤销经 Toast 撤销栈。不新增第二套计划字段——日历落图统一读各卡 `dueDate`。
