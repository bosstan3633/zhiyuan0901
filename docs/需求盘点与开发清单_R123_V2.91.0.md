## 五、风险与说明

1. **密度默认值变化**：卡片 padding 14×16 → 9×11 会让所有既有用户的资源台/策展台卡片变小变密（符合原型意图）；列表/看板密度档位保留兜底。
2. **hover 动作口径推翻 R122-Q3**：R122 的「置顶/镜像/补全」将改为「置顶/移动/删除」——📡 镜像与 ✏ 补全（非断链卡）收进右键菜单（右键菜单已有全部项，零新增）。
3. **镜像卡专属样式**：虚线卡是策展台新视觉，镜像语义（只读引用）借此显性化；不影响数据链路（单向挂载红线不动）。
4. **金字塔「深度」指标为新计算**：仅读 pyramid 结构（论点 + 分类树高度），零新增存储字段。
5. **R122 断言将有一批改写**：hover 动作、卡片尺寸、工具条结构相关断言（预计 15~20 条）+ 新增 R123-1~N；E2E 卡片 hover 相关步骤同步。
