## 一、这条口径要验的是什么

R4-Et 留下的 22 条里有一类特殊：**基类还在、祖先类已经死了**（`.node .node-title`、`.metric-item.expanded`、`.gs-mc-content .mc-flow`）。
旧口径是"选择器里任一 token 活着就整条留下"——所以删掉基类之后，这些**孤儿兄弟**一条都没被报出来。
要清它们就得改用新口径：**复合段 `.a.b` 要求元素同时带 a 与 b ⇒ 任一类名四票全零，整段就匹配不到**。
新口径更狠，也更可能误伤，所以先把它推到极限看它错在哪。

## 二、新口径先给出 54 条候选，其中四处是它自己错的（先修口径，再谈删）

| # | 误判 | 现场 | 修法 |
|---|---|---|---|
| ① | **逗号列表被当成一条链** | `body .module-title .name, body .tc-module-title .tc-name`：第一段断了就把整条报成祖先断，而第二段活着 | 先按**顶层逗号**拆段（括号内的逗号不算），**每段都判死**才算这条规则死 |
| ② | **括号剥得不配平** | `:is(button, …, [tabindex]:not([tabindex="-1"]), .dz-ov-card, …)`：`[^)]*` 在第一个右括号早停，`:is` 的尾巴被当成祖先段 | 按**深度**剥括号组（`stripParens`），`:is/:not` 的参数一律不参与段判定 |
| ③ | **运行时插值的类名看不见** | Heatmap 里 `const cls = [\`l${lv}\`]` ⇒ `.dz-cell.l4` **是活的**，但 `l4` 这个 token 全仓库不存在 | 新增"插值前缀"票：整串形如 `前缀${…}` 时认这个前缀，且要求尾巴 ≤3 字符（免得把整片 `l*` 都救活） |
| ④ | **类名值来自别的文件** | `.cz-status.exploring` 的 `exploring` 出自 `curiosity.ts` 的 `cls: 'exploring'`；`.ai-clickable` 出自 `:class="{ 'ai-clickable': … }"`（token 带着撇） | scoped 也吃**全站精确字符串**这一票（不是子串）；class 属性 harvest 同样要**剥引号与冒号** |

四处修完，候选从 54 收到 **40**（死 18 + 祖先断 22），逐条复核过：`.ai-badge.b-*` / `.ai-chg-tag.t-*` 基础类在模板里零引用；`.nd-btn.ghost` / `.nr-v.link` / `.ts-status-chip.active` / `.gs-mn-item.active` 是被 R4-Et 删掉基类后留下的孤儿；`.rc-action.mount.on` 随挂载选择器退役（R82-7 已判零命中）。

## 三、行号也是口径的一部分（按行号删时才暴露）

扫描器报的行号有**两处系统性偏移**：`.vue` 的 `<style scoped>` 自己占一行（旧算法整体少 1），规则上面压着注释时又报到注释那一行（多 1）。
第一次按行号删 40 条时，**3 条被跳过**——正是因为它们上面都有注释。修成"从 `{` 前向跳过空白与注释块，落到选择器第一个字符，再按**整份文件**数换行"，并加 `--explain <选择器>` 让它能自证：现在 7 个抽样（含跨行逗号列表、`:is()` 长选择器、注释压顶的三种）全部 `吻合:true`。
