- 勾选态持久化到 `zy_ai_v1.captureEnrich`（一次勾选长期生效）；★GP 属启动 chunk——抽屉 defineAsyncComponent、ai 栈全部点击时 dynamic import，产物级复核入口 chunk 零 AI 字符串。
