# V4.5.0 · 选题卡系统与今日行动联动

## 交付范围

- 新增独立选题卡品类：标题、项目 / 成功指标、可编辑状态、计划执行日期、关联资源卡与成果链接。
- 默认状态为构思中、制作中、待发布、已发布；仅“已发布”为完成态，用户可改名、改色、排序、增删，系统始终保证有且只有一个完成态。
- 任务卡与选题卡严格共用今日三件事的三个槽位，并同步进入今日日历；支持关键词、项目、任务状态、选题状态以及全部 / 任务卡 / 选题卡卡型过滤。
- 选题详情与任务详情保持同一套克制结构，以完整标题为第一视觉；项目、指标、状态、计划日期清晰可扫，关联资源卡成为核心面板，“AI 找资源”紧邻主操作，说明字段限高。
- 调度台卡片池扩展为任务 / 选题 / 好奇心 / 资源四类；选题工作面提供可折叠清单、月 / 周日历与按状态分组的看板，支持拖拽排期和拖拽改状态。
- 方向台加入选题成果层，以“成果”标记与任务区分；项目塔、项目全景与策展模式均可定位选题。
- 策展节点关联入口升级为“关联卡片”，支持全部 / 资源卡 / 选题卡筛选。
- 选题卡接入云同步、三方合并、事件流水、日报统计、画像洞察、回收站、数据包、附件索引与快捷键设置。
- 无引用附件只提供用户手动清理入口，不增加自动清理。

## 联动规则

- 今日三件事与今日日历使用同一任务 / 选题集合，最多三个槽位；满额时拒绝第四项，不覆盖已有槽位。
- 进入今日三件事时写入当天计划执行日期；从槽位移出时清空对应计划执行日期。
- 槽位复选框与卡片完成状态同源；完成 / 取消完成优先恢复此前状态，无历史状态时恢复待开始或第一个非终点选题状态。
- 从任务或选题详情安排到今天、拖入今日日历、在三件事选择器中选中，三个入口使用同一套持久化路径。
