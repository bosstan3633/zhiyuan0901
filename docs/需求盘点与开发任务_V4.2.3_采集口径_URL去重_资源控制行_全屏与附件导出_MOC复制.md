## 二、已确认的产品语义

### 1. 采集入口

- 桌面浏览器快捷键是正式采集入口，可分别直达任务卡池、好奇心卡池和资源卡池。
- 手机 PWA 的文本与链接采集进入 Inbox。
- Inbox 是“移动采集与待处理收件箱”，保留转为任务卡、好奇心卡或资源卡的能力，但不是全产品唯一采集入口。
- 转化成功后原采集记录离场；已有同 URL 资源卡时复用原卡，不重复新建。

### 2. 资源 URL 唯一

- 唯一性只约束有效资源卡池中的 `http(s)` 链接。
- 统一归一化域名大小写、锚点、追踪参数与尾斜杠。
- 浮层保存前重新读取最新数据树复核；资源详情新建 / 编辑、Inbox 转化和书签导入共用同一判定。
- 重复命中时定位或复用已有卡，不提供“仍然新建一张”的旁路。

### 3. 存量安全合并

按以下顺序执行：

1. 同一 `capture id` 的活卡合并。
2. 同一规范 HTTP(S) URL 的活卡合并。
3. 没有 URL 身份可判时，仅在“标题完全一致 + 创建时间相差不超过 60 秒 + 一侧缺 URL”且候选取向唯一时兜底。

纯标题相同不会全局去重。重复卡软删进回收站；常用夹、任务支持、好奇心支持、策展投射与旧愿景 / 使命引用迁到保留卡。

### 4. 资源控制行

- 状态筛选用下拉，默认“全部”。
- “全部 / 待打标 / 已调出 / 从未调出”保留原计数值。
- 常用夹入口位于控制行最右侧，使用强调色与数量徽标。

### 5. 策展图片与导出附件

- 应用内图片预览的全屏层自身请求原生全屏；原生 API 不可用时仍进入固定沉浸层。
- 全屏中保留上一张 / 下一张、缩放、重置、拖动、下载，并优先接管 Esc。
- 导出 HTML 不再显示底部附件清单。
- 图片附件以图库打开，保留切换、缩放、全屏和下载；HTML / PDF 等非图片附件点击“下载并打开”；本体缺失显示“本体缺失，无法下载”。
- 中心论点关联卡、中心论点附件和节点资源卡附件均使用同一规则。

### 6. 今日三件事复制

固定模板：

```text
推进[[MOC-项目名]]项目，任务内容，助力【指标名】指标落实到位
```

- 项目名已有 `MOC-` 时不重复添加。
- 缺少有效项目、成功指标或任务时禁用，并说明原因。
- 不生成半截句。
