## 一、为什么是 V3.8.0 而不是补丁号

V3.7.1 是"6 轮攒一次补丁"。这一次不一样：**运行入口少了一个、数据出网口径变了一次、文档口径整批换过**——三件都是用户能感知的变化，按项目自己的规则（架构级变化走小版本）该进 minor：

| 变化 | 用户怎么感知 |
|---|---|
| 撤掉 `src/popup/` 独立弹窗（从未进过构建） | 在 `chrome://` 按快捷键不再得到一个**空白窗口**，而是被带进应用打开同一块面板 |
| Airtable「所属工作台」列值剥图标 | ★**第一次同步会覆盖远端已有的带图标值**（`💼 事业台名` → `事业台名`），按该列做筛选/分组/着色的视图要改条件 |
| 手册与界面文案按新世界收口 | 「资源台」「主航线」「项目总览」这些退役名不再出现在界面里 |
| 像素 A/B + DOM 态记账成为可交付证据 | 内部质量账，用户不直接感知，但决定了"改前/改后到底变了没有"能不能被证明 |
