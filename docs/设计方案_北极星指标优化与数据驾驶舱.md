## 1. 首页知源北极星：五卡双排（瘦身后）

### 1.1 定位口径

- **上排 = 质量指标**（系统运行得好不好）：DHI / WCE / WRR，原样保留，周期切换（周/月/累计）不动。
- **下排 = 状态指标**（今天有没有在动、操作有没有保存）：**今日新增 / 今日删除** 两张卡。

### 1.2 布局（3 上 2 下，下排加宽）

```
┌ 知源北极星                 [周|月|累计] ┐
│ 🧭 DHI      💡 WCE      🟢 WRR        │ ← 质量 · 分期
│ 📈 今日新增        📉 今日删除          │ ← 状态 · 不分期（各占半行，卡宽 1.5×）
└───────────────────────────────────────┘
```

### 1.3 两张状态卡设计

```
┌────────────────────┐  ┌────────────────────┐
│ 📈 今日新增 ↗       │  │ 📉 今日删除 ↗       │
│      5             │  │      2             │
│ 资源3 · 任务1 · 好奇1│  │ 资源1 · 任务0 · 好奇1│
└────────────────────┘  └────────────────────┘
```

- **数值实时派生**：新增 = 三卡 `createdAt ≥ 今日0点`；删除 = 三卡 `deletedAt ≥ 今日0点`；副标 = 分类型小计。采集一张资源卡 → 数值与副标**即时 +1**（Vue computed 响应式），正面回答"我的操作是否保存了"。
- **点击 → 右侧抽屉明细**：逐条列出 时间 + 类型图标 + 标题，单击条目打开该卡详情（复用北极星现有卡片详情抽屉）；空态文案："今日暂无新增——去工作台采集一张卡"。
- 模块分组、链接卡片、未归档任务**全部撤出首页**，下沉仪表盘（第 2 节）。

### 2.4 操作记录（版块 ⑤）与事件日志

- 明细时间线 = 上轮"历史操作记录"调研的落地：时间/动作/类型/标题/展开详情。
- 数据来源分层：新增/删除靠 createdAt/deletedAt **纯派生**；**恢复/永久删除靠事件日志 `zy_event_log`**（append-only 独立 key，5000 条滚动 ≈0.6MB），否则"清空回收站后删除历史全丢"。
- 时间线与首页状态卡、版块①②共用同一套 computed，数字永远一致。

## 3. BUG 修复（不变项）：未归档任务 3/10 → 10/10

- 根因：`NorthStarPanel.vue` L203 只判 `!t.metricId`，不校验引用有效性 → 悬挂 metricId（指标已删/导入残留）被假归档。
- 修复：归档 = **项目有效 + 指标有效**双校验；悬挂引用计入未归档。该指标现居仪表盘核心指标行（版块①），点击下钻"待归档清单"，每条标注原因徽标（未挂项目/未挂指标/⚠引用失效）+ 级联下拉归档操作（现有能力保留，随卡片迁移）。
