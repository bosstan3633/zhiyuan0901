# 交付说明 · V4.2.0 顶栏收敛、自动同步、同步历史、Inbox 与镜像独立

> **日期**：2026-11-06 ｜ **版本**：V4.2.0 ｜ **基线**：V4.1.3（`104660d`）

## 一、本次交付

V4.2.0 在 V4.1.3 主线上完成七组体验与数据语义收口：

1. **顶栏收敛**：右侧只常驻“云同步、搜索、更多”。云同步主按钮用短状态与绿 / 黄 / 红呼吸灯表达“一致 / 待同步或待选择 / 断线或异常”；完整关系、最近同步与设置入口收进面板。
2. **自动同步**：默认关闭，登录后可主动开启。约每 60 分钟检查一次，只在本机有改动且云端 revision 未变化时安全上传；远端变化、双端冲突、登录或网络异常时暂停，不静默覆盖。
3. **同步历史与可操作回执**：云同步面板和设置中心均可进入历史；默认保留最近 20 次、最长 30 天。每次同步可打开完整明细；新增记录可删除、删除记录可恢复、修改记录在指纹未变时可回退。动作载荷过期后仍能看明细，但降级为只读。
4. **Inbox 唯一转化入口**：Inbox 支持时间正倒序、单击详情、双击 / Enter / Space 打开链接、编辑、单条删除和二次确认清空；任务 / 好奇心 / 资源三卡转化只从 Inbox 发起，转化后立即离场。
5. **好奇心入口退役**：移除好奇心 AI“研判要不要转”以及全部一键转化入口；存量数据继续兼容读取。
6. **资源镜像独立生命周期**：任务卡和策展节点挂载资源时生成独立只读快照。删源卡不影响已挂镜像，删某个镜像也不影响源卡或其他镜像；资源卡无反向任务入口。
7. **策展台空间收口**：隐藏 / 溢出台统一收进固定“策展台库”；中心论点区压缩；左侧“台数据”菜单改为顶层定位，修复向下溢出裁切。

## 二、关键数据口径

- 同一 Supabase 项目、同一登录账号下，多台设备共享同一套按 `user_id` 隔离的云快照；产品版本号不是云端数据命名空间。
- 不同 Supabase 项目或不同账号才是不同数据体系。V4.1.1、V4.1.3、V4.2.0 使用同一项目与同一账号时，会继续读取同一套云端快照并走迁移兼容。
- 自动同步只选择安全上传方向，不自动拉回远端版本，也不在后台猜测冲突。
- 回执动作只修改本机并进入待同步状态，不擅自发起下一次云端覆盖。
- 资源镜像是挂载时快照，不随源卡后续修改自动传播；需要新内容时重新挂载。
