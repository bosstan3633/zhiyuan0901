## 四、T5 · 左树空指标接收任务拖拽（Bug 根因修复）

- **根因**：左树指标节点的 `@drop` 绑定 `treeMetricDrop`，而它只处理**指标排序拖拽**（`treeDragMetric`）——任务拖拽（`treeDragTask`）落到节点上被静默忽略；此前跨指标拖任务只有拖到**目标指标下已有任务行**上才生效，空指标因此永远接不到。
- **修复**：`treeMetricDrop` 前置路由——`treeDragTask` 存在即走 `treeTaskDropOnMetric`（改归属 + taskIds 双写）；任务拖拽悬停指标节点给 **drop-into 虚线高亮**（空指标同样可见落点）。
- E2E-20 全链路实证：满指标任务拖到空指标节点 → `metricId` 变更 + 目标指标 `taskIds` 双写 ✓。
