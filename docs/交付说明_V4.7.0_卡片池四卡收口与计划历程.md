## 二、逐项落地

### 2.1 AI 诊断空指针

- **根因**：`AiSuggestionDrawer.vue` 把建议行数组第一行当作判词行直读 `shown[0].data.__verdict`，而项目诊断的建议行没有 `data` 字段。
- **修复**：按内容查找带字符串 `__verdict` 的行，不再默认首行；每次 `run(job)` 清空上一 job 的 `verdictPick / verdictTitle`，避免串判词。
- **守卫**：`144-v470-ai-diagnose-guard.cjs` 四条（AI470-1…4），包含"建议行无 data"的契约反向验证。

### 2.2 任务卡池

- **快捷筛选只新增两个**：`未挂项目`（无 `projectId`）与 `未落图`（无 `dueDate`）。保留既有的未归档、主攻项目与全部；不引入第三个新概念。
- **默认排序**：全部项目、全部状态，按最新入池在前；`未落图` 优先展示。
- **分组与看板**：列表支持按项目分组；新增 `TaskBoardView.vue` 三列看板（待开始 / 进行中 / 已完成），拖拽改状态接入一级任务池。
- **逾期退役**：类型、计数、筛选链、日历红色推导、图例与徽标全部移除；空日期统一称「未落图」。

### 2.3 计划执行日期与安排历程

- **共用组件**：`PlanScheduleHistory.vue`。
- **共用纯函数**：`shared/storage/planSchedule.ts`。
- **数据契约**：独立 `planScheduleEvents` 记录，字段 `id / cardType / cardId / at / date / fromDate / source / removedAt`。
  - `at`：本次安排动作发生时间；
  - `date`：本次安排到的计划执行日期；
  - `fromDate`：改期前的日期（首次安排为空）；
  - `source`：`detail` / `calendar` / `focus` / `quick` 等入口；
  - `removedAt`：用户手动删减该条历程的墓碑时间。
- **写入纪律**：所有入口统一走 `scheduleCardDate()`；撤销回滚不记第二次历史。
- **删减**：删除只写墓碑，不改当前计划日期；可撤销。
- **同步**：独立记录类型进入云同步 manifest、计数与三方合并归一化；按 id 合并，墓碑随记录同步。
- **覆盖范围**：任务、选题、好奇心三处详情均展示安排历程。

### 2.4 选题卡

- 选题详情补齐计划执行日期与安排历程，与任务卡同构。
- 选题可继续拖入日历、进入今日三件事；计划日期与历程同源。

### 2.5 好奇心一级工作面

- 新增 `CuriosityWorkbench.vue`：左侧清单，右侧日历 / 看板，三视图同源。
- 可拖拽落图、改状态；计划日期与安排历程接入同一套 `planScheduleEvents`。

### 2.6 项目弹窗全貌树

- 新增 `views/projectTree.ts` 的 `buildProjectTree()` 作为唯一取数入口：
  - 任务复用 `compassTaskMeta`，选题复用 `compassTopicMeta` 的双写口径；
  - 未归属任务 / 选题按指标认领结果统一归组。
- `ProjectDetailDrawer.vue` 删除「概览 / 指标 / 任务」三页签与四格统计，改为单页纵向：
  - 项目头（名称 / 主攻 / 战略路径 / 下一步 / 一行摘要 / 导出）；
  - 指标默认全展开、可折叠；
  - 指标下任务与选题，点击打开现有详情抽屉，不关闭项目弹窗；
  - 未归属分组。
- 导出补选题并保持树顺序；旧字段、断链与附件说明不变。
- 守卫：`148-v470-project-modal-tree.cjs` 五条（TREE470-1…5）。

### 2.7 卡片池二级界面退役

- `/deck/*` 全部重定向到一级卡片池 `/?tab=<kind>`，保留 `hl / hk / fresh` 旧参数。
- `CompassDeckView.vue` 留在孤儿白名单，**保留一个版本**用于旧深链 / 旧分片对照；V4.8.0 复核。
- 任务与选题在一级页签内完整承接：默认列表、全部项目 / 全部状态、最新入池在前、按项目分组、日历 / 看板。
- 资源卡新增「全部资源卡」默认文件夹：点击右侧滑出 `PoolCardsPanel`，批量选择、镜像、右键等能力原样保留，不复制第二套实现。

### 2.8 策展台页头

- 中心论点模块瘦身，论据卡与佐证附件移入右侧「全局功能」。
- 右侧全局功能重排：
  - 「分享成果」固定右上主按钮；
  - 「台数据」「打开全部资源」缩小；
  - 「搜索」缩小，不再独占大块空间。

### 2.9 全局搜索任务页签

- 新增任务页签，搜索选中任务后：
  - 有项目：`/compass?pano=1&proj=<id>&task=<id>`，项目全景首挂载即定位并高亮；
  - 无项目：回任务卡池并打开详情兜底。
- 守卫：`149-v470-cardpool-plan-history.cjs` 覆盖筛选、历程、好奇心、资源抽屉、搜索定位、路由重定向与同步契约。
