## 一、这刀只合"真重复"的那一段，并且把理由写在代码里

R3-Cb 把批量**语义**（选谁、怎么打标）收进 `useBatchSelect` 之后，三张卡的批量栏已经长成同一个形状：`已选 N · 全选 · 反选 · 标签输入 · 应用标签` + 卡型专属动作。留着三份的后果不是难看，是**会再漂回去**——C-b 修掉的那三条缺陷（假反选、退出不清空、先勾选才出栏）正是三份各写各的写出来的。

所以本轮新增 `components/compass/DeckBatchBar.vue`：共享段一份，卡型动作走默认槽。

**同时如实报告一处有意偏离**（★下一刀 `R3-Cc2` 已被用户推翻：拍板「要形式上在一个组件里」，工具条已收进 `DeckControls.vue`，见 `交付说明_R3-Cc2_三面板控制行合一.md`）：计划里 R2 第 3 项写的是「控制行组件（视图/排序/状态/分组/快速过滤/计数/批量/新建，值域按类型配置化）」。**工具条那一排当时没有收进组件**，理由：三者的差异是**值域**不同（任务有状态与分组下拉、好奇有状态胶囊 + 计数、池有「待打标」与导入），不是结构重复；每处也就 3–6 行模板。强行合成一个组件，实际收益是把 `class="mini-btn"` 变成 `:class="btnClass"` 这类动态绑定——**源码文本断言全部要重指，而真实的重复并没有少**。这一条与计划不一致，摆在这里请你定：要"形式上四件都在一个组件里"，我按你点头再做一遍。

## 二、过程中踩到的一条真问题（值得单独记）

批量栏刚抽出来时，我把按钮类名做成 `btnClass` prop 传面板的 `.mini-btn` / `.pcp-btn`。typecheck 和断言都不会红，但**渲染出来会是一排浏览器默认按钮**：Vue 的 scoped 样式只作用于**本组件模板里的节点**，槽内（slot）内容带父组件的 scope id，而组件自身模板里的节点带子组件的 scope id——父面板写的 `.mini-btn:disabled { … }` 选不到子组件模板里的按钮。

处置：`DeckBatchBar` **自带按钮样式**（按同一套令牌复刻 `.mini-btn` 的外观），删掉 `btnClass` 这个假开关；槽内的卡型动作按钮仍由父面板作用域样式负责，两边外观一致。并把这条写进组件注释与断言（判据要求组件内有 `.dkb-bar button:disabled { opacity: var(--opacity-disabled)… }`）。

**这类问题只有看图能发现**：typecheck 过、断言过、E2E 也只数"按钮在不在"——四主题 `deck-batch` 截图里按钮若是浏览器默认样式，一眼就看得出来。本轮截图实测：栏底 `accent-light`、五枚按钮带边框与 hover 态、输入框与「已选 0 张」读数同色语言。

顺带统一了一处观感：池面板的批量栏底色原为 `surface-2`（与常态工具条同色，看不出"进了批量态"），现与任务/好奇一致取 `accent-light`。

## 三、断言与实测

- **新增 1 条**：★批量栏唯一实现（三面板都 import DeckBatchBar；面板内不得再留第二份「反选 / 应用标签」按钮 DOM 或自建 `tagDraft` 输入）。
- **重指 2 条**（都是上一轮 R3-Cb 我自己写的）：★批量栏进来就在 + 禁用态反馈、★三类卡批量打标齐全——判据跟着实现搬到 `DeckBatchBar.vue`，**口径一字未变**（反选看 `total`、打标与应用看 `size`、只加不减、回车应用）。
- **E2E**：E2E-27 / E2E-30 / E2E-31 三条走真实点击的池/任务/好奇批量流程，选择器由 `.pcp-batch` / `.batch-bar` / `.cz-batch-bar` 统一改指 `.dkb-bar` / `.dkb-count` / `.dkb-tagin`，判据本身一字未改（其中「全选本池」文案随组件统一为「全选」，定位改用 `/^全选$/` 免得误命中「取消全选」）。
  ★合成一份 DOM 就带来一个新的选择器陷阱：**三张卡同时挂在同一页**，裸 `.dkb-bar` 一次命中多枚，Playwright 严格模式直接抛（`isVisible()` 也抛）——首轮 E2E-30/31 就红在这里，而功能本身是好的。所有批量栏定位一律加面板根作用域（`.pcp .dkb-bar` / `.mgr-body .dkb-bar` / `.cz-body .dkb-bar`）。这条也说明"共用组件"要把**根类名留得住**，否则调用方连稳定的选择器都没有。
- **theme-audit 76 → 80 图**：新增 `deck-batch` 场景（四主题各一张），现场量「共用栏渲染 / 全选·反选·应用标签三枚齐 / 卡型动作在槽内」，量完当场退出批量免得串染后续截图。
