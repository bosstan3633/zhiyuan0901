## 三、④ 骨架屏「就绪即过渡」（main.ts）

- 原 R49-H：快加载补足 360ms 完成态 + 220ms 淡出 ⇒ **580ms 硬地板**。
- 现：`SKELETON_MIN_SHOW=150`（防白闪最短展示）+ `DONE_FADE_MS=160`（完成态淡出）⇒ 快加载 **≥310ms**，结构性 **-270ms**；慢加载行为不变（就绪即切完成态）；Esc/单击跳过保留；`__zySplashMs` 探针口径不变。

## 四、③ M3 复测归因（口径说明——重要）

- 本轮共采样 4 次（large ×3、medium ×1，全部**非独占、单次采样**）。medium 档：M1 930ms / M2a 176ms / M3 17.2s·129 次·最大 538ms；large 档 M3 31.7~32.3s·171 次。
- **禁跨档对比**（perf 纪律）：R114 的 M1 904ms / M3 4.6s·44 次均为 medium 档；本轮 medium 数据与 R114 的差异无法在非独占环境下归因（环境负载与拆分回归不可区分）。e2e 22/0 + 回归 1064/0 + vue-tsc 0 保障**功能等价**；**性能等价的最终确证移交独占采样窗口**（连同移交项② V2.79.0 起点重测一次做掉）。
