设计说明（为什么这么改）

0. 沿用已确认的方案 A 标准

  • AI = 标题行右侧主上下文动作（outline-accent），三态：未跑 / 跑中 / 已跑（chip 时间戳 + 文案翻「↻ 重新…」）。
  • 动作跟着对象走：链接的「↗ 打开 / ⧉ 复制」贴在链接输入框右侧。
  • 页脚收敛两钮：左 ghost 删除（二次确认）+ 右 primary 提交。
  • 降噪：附件说明收进 ? tooltip；时间戳降为 10.5px 一行。

0.5 卡间挂载全退役（2026-09-24 拍板 · 本原型已按新边界出图）

  • 三卡不再互相挂载：任务→好奇（TaskCard.mountedCuriosityIds）与好奇→资源（CuriosityCard.relatedResourceIds）一并删除（任务↔资源已于 R162 退役）。任务→项目/指标的六层归属保留，不属卡间挂载。
  • 因此本原型：任务详情无「挂载好奇心」区；好奇详情无「挂载资源卡」区；成熟度「弹药」维度、周报经挂载的转化数、转卡回指、批量/单卡挂载 UI 全部随迁（见开发任务清单）。

1. 任务卡（对照 TaskDetailDrawer.vue 现状）

  • AI「拆解步骤」从页脚移到标题行（它改的是说明/子任务，离页脚最远）；跑完翻「↻ 重新拆解」+ chip。
  • 页脚原 4 控件（删除/拆解/spacer/完成并关闭）→ 2 钮；删除补二次确认（现状单击即删，仅靠回收站兜底）。
  • 优先级从 select 改 3 段 segment（仅 3 值，单击直达，省一次开合）。
  • 项目/指标保留双列级联（真级联，非零信息控件）；链接升整行 + 动作贴边。
  • 头部保留：完成勾选 / 状态 chip / 成熟度徽标 / 父子软层级 chip（↳ 父名 ⤴ / N 子任务）。
  • 附件保持折叠（低频）；「挂载好奇心」区整块删除（卡间挂载退役，见 §0.5）。

2. 好奇心卡（对照 CuriosityPanel.vue 详情现状）

  • AI「研判」从页脚移到标题行；跑完 chip「已研判 · 时间」+「↻ 重新研判」。
  • 「转为任务 / 归档为资源」是卡级生命周期动作，无处可"贴对象"——从页脚移到正文末尾「流转」区，带一句话后果说明（转任务=拆步骤进方向台；归档=进资源台长期调用），页脚因此仍能收敛两钮。
  • 「📌 置顶」从页脚移到头部图标钮（看板卡角上已有同款，页脚那份是重复入口）。
  • 详情补「🗑 删除」ghost + 二次确认（现状详情不能删，只能回看板点卡角）。
  • Hero 文本框实绑 question（现状标签写「摘录」名实不符）→ 正名「问题原文」。
  • 来源链接升整行 + ↗/ 贴边；状态四态 chip（待探索/探索中/已求证/已搁置）保留头部下拉。
  • 「挂载资源卡」区整块删除（卡间挂载退役，见 §0.5）；卡面「🔗N 关联」角标与「经任务挂载」并集口径同退。

验收口径（若采纳）

  • 四主题走查（theme-audit）· 小字对比度过 4.5 · AI 入口仍走 CardAiEntry 真源 · 转化仍走 convertToTask/convertToResource 弹窗 · 回归断言随迁 R152-A2 / R48。
