## 一、REQ-048 卡片附件（最小版本）

### 交付内容

| 层 | 交付物 | 要点 |
|---|---|---|
| 模型 | `AssetMeta { id; kind:'image'\|'html'; name; size; mime; createdAt }` | 三类卡 `assets?: AssetMeta[]`；只存引用不存二进制 |
| 存储 | `shared/storage/assets.ts`（新） | IndexedDB 库 `zy_assets`（key=assetId, value=Blob）；put/get/delete/stats/list/cleanupOrphans/assetIdsOf；惰性单例 + 不支持环境安全降级 |
| 组件 | `shared/components/AssetManager.vue`（新） | 上传（校验类型 + ≤20MB）→ putAsset；chip 展示；图片 `createObjectURL` 全屏弹窗预览；自包含 HTML 新标签打开；删除联动 deleteAsset |
| 资源卡 | Workspace 内联抽屉 + ResourceDetailDrawer | 经共享 ResourceEditForm 内嵌 AssetManager；变更即时持久化（新建暂挂保存入库） |
| 任务卡 | CompassActions 任务侧边栏 | `selectedTask.assets` + onTaskAssetsChange → touchTask |
| 好奇心卡 | CuriosityPanel 详情抽屉 | `detailItem.assets` + onCurioAssetsChange → update |
| 回收站 | RecycleBin | 硬删（purge）先清附件 `purgeAssetsOf`（三类 + purgeAll）；软删不碰附件 |
| 设置页 | GlobalSettings 导出页 | 附件 count/bytes 统计卡片 + 孤儿清理入口 + watch 自动刷新 |

### 验收口径
见《交付说明_第卅九轮_V2.15.0.md》§四验收清单 1~7。

## 二、#61 共享资源编辑表单 ResourceEditForm.vue（技术债清偿）

### 背景
Workspace 内联抽屉（dr-*）与 ResourceDetailDrawer（red-*）字段表单双份实现 → 抽取单份共享组件，两处行为保持一致。

### 抽取结果

| 项 | 内容 |
|---|---|
| 共享组件 | `newtab/components/ResourceEditForm.vue`（222 行）：标题行 + 链接类型/输入 + 工作台 + 分类联动 + TagPicker + 描述(拖拽高度) + 附件 + `<slot name="extra">` + 被任务挂载 + 时间戳 |
| emit 收敛 | `save`（Ctrl+Enter）/ `goto-task` / `close`；**footer 动作条留在宿主**（新建/编辑差异、deleting 锁差异在宿主） |
| Workspace.vue | 内联抽屉字段区整体换 `<ResourceEditForm>`；删 10 个已迁入本地函数（isFullPath/drawerWsOptions/drawerCatOptions/onDrawerWorkspaceChange/fmtTs/onResAssetsChange/noteH/mountedTasks/linkPlaceholder/removeTag 死代码）+ 40+ 行 dr-* 死样式 |
| ResourceDetailDrawer.vue | 表单主体迁共享组件；清理 3 个死 emit 绑定；保留 Drawer 容器 + 统计 extra + footer |
| 行为一致性 | 两入口同字段同交互；高度记忆键延续（ws-note / res-drawer-note）用户设置不丢 |
