## 一、交付明细

### 1. 成熟度规则引擎（反馈 #4，拍板「规则即时分 + AI 深看」）

- 真源 `shared/utils/maturity.ts`：纯函数零副作用（零联网、零等待、毫秒级），四维打分——**可执行**（说明/估时/标题质量）· **可归属**（截止/项目/指标）· **弹药**（挂载资源×递进加分/好奇/附件）· **新鲜度**（停滞惩罚，done 免疫）→ 0-100 分 + **A 就绪 / B 可派 / C 缺件 / D 空壳**，`reasons` 逐条点名扣分处。
- 分工说死：规则分负责「每张卡随时可见」，AI 深看（🤖 拆解/优化/诊断）负责「这一条怎么办」——手册 ai-2 写明。

### 2. 徽标全视图落位（反馈 #4 上半：跨视图体现挂载/附件）

- `MaturityBadge`（hover 展开扣分构成；lg 档带标签+分数）：**方向树四层行（目标/项目/指标/任务叶）、任务面板卡片+列表+看板全行、调度台今日三件事与任务树、策展页指标头与任务行、项目详情抽屉、任务详情头部大徽标**。
- `MountCountBadge`（🔗资源数 · 💡好奇数，仅有挂载时出现）：与既有 AssetBadge（附件）互补——任务「带着什么」在任何视图一眼齐。

### 3. 上行评级（反馈 #5）

- 指标分 = 下属任务成熟度均分×0.5 + 任务覆盖/目标写法/完成推进/无停滞；项目分 = 指标均分×0.5 + 结构/进度/停滞/主攻活跃；目标分 = 项目均分×0.6 + 分期/期限/收口健康。全链滤软删，同一真源零漂移——树上自上而下一列徽标，**哪层先空心一眼看出来**。

### 4. 好奇心「挂载资源」死字段激活（反馈 #4 配套）

- 卡详情新增「🔗 挂载资源卡」区：搜索即挂、✕ 撤直接关联；「经任务挂载」的资源并集只读展示（`curioResIds` = relatedResourceIds ∪ 挂它任务的 mountedResourceIds），点标题直达资源卡。
- 卡/列表/看板行加 🔗n 计数 + 成熟度徽标；**convertToTask 随迁**：转任务时直接关联（含存活校验）变成任务挂载——查证材料不再丢。

### 5. 内置两员可编辑（反馈 #6）

- `personas[]` 新增 `brief/focus` 覆盖字段：⚙ 面板里目标管理/知识管理两专家可就地改人设与关注面（留空=内置默认），「↺ 恢复内置默认」一键回退；会诊提示词、拆解执笔、默认执笔下拉全部消费合并后名单，改完即生效。
