# V4.2.1 交付说明

> 版本：V4.2.1  
> 日期：2026-11-10  
> 基线：V4.2.0（`main` / `023395f`）

## 一、交付结论

V4.2.1 修复了“同步已经成功，但用户侧显示失败并切成断线”的主链路问题，同时收窄云同步范围、补齐今日计划复制与 Inbox 行内操作，并修正 AI 助手成功态。另完成三项用户反馈修复：采集资源卡重复、策展 HTML 证据 / 附件图库、同一资源卡不能挂到同台不同节点。

## 二、功能变更

### 1. 云同步成功回执

- 上传 / 拉回成功先确认云端 revision、指纹与本地基线一致，再生成同步明细。
- 回执载荷缺失时安全降级为 `null`，对应行只读，不影响主同步成功态。
- 回执生成失败通过 best-effort 收口，不再把绿色一致性状态覆盖成红色断线。

### 2. 云同步边界

- `sanitizeCloudSnapshot` 固定写入 `ui: null`，指纹只基于业务数据树。
- 主题、布局、排序筛选、抽屉宽度等 `UIPrefs` 只写本机 `K.UI`。
- 资源、任务、好奇心、Inbox、策展台和分支顺序、方向台项目 / 指标、今日三件事正常进入云端。

### 3. 今日三件事复制

- 固定句式为：`今天计划推进{项目}项目下{指标}成功指标的{任务}任务`。
- 缺项目或成功指标时按钮禁用，悬停显示具体原因。
- 生成器收敛到 `shared/utils/focusCopy.ts`，视图不自行拼句。

### 4. Inbox 行内处理

- 完整 Inbox 行提供任务 / 好奇心 / 资源三卡转化、打开原链、编辑、删除。
- 调度台预览提供三种转化与打开原链。
- 转化后立即离开 Inbox；目标卡写入来源采集标识。

### 5. AI 助手状态

- 成功、警告、错误拆成三态。
- 模型拉取成功或连接验证成功显示绿色勾；只有错误态显示再次测试。
- 修改配置后旧结果清空，避免错误态滞留。

### 6. 采集资源卡幂等

- 新增统一采集身份工具与存量去重模块。
- 启动加载、云恢复、数据包导入三个入口执行同一套幂等规则。
- 旧卡优先复用并补齐 URL、标签、描述；无采集标识的同名卡不合并。

### 7. 策展 HTML 证据图库

- 中心论点关联卡进入导出内容，可打开原链接。
- 中心论点附件和分支节点附件进入阅读版、树状版与 ZIP。
- 同节点图片使用独立 CSS 图库：缩略图打开大图、上一张 / 下一张、计数与下载。
- ZIP 使用相对附件路径；不向分享 HTML 注入可执行脚本。

### 8. 同台多节点资源关联

- 判重从“整个策展台”收窄为“本台 + 本节点”。
- 同一资源卡分别挂到 A、B 节点会产生两条独立投射。
- 回到 A 节点显示“已在本节点”，同一节点重复提交保持幂等。
