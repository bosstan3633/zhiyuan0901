## 二、沉淀资产（下轮直接复用的规矩）

1. **先立尺子再动手**：性能需求进来第一件事是给它一个能测的指标（M7-M13），并取改前基线。没有基线的"优化"等于没做。
2. **首帧 ≠ 代价**：切台类指标必须量"目标出现之后 3 秒内的主线程阻塞"，只量到第一个元素出现会把排版成本整段漏掉。
3. **拆键三口径**：主树仍是唯一消费口径 / 一次 get 取多键 / 整库写入必同步子键。缺任何一条都会长出"两份真相"的 bug（回滚不清子键 = 旧统计复活）。
4. **派生缓存的失效依据用内存脏计数**，不要用"写盘成功后才自增"的版本号——防抖窗口内必然读到旧索引。
5. **任务与视图解绑**：长耗时交互（AI、批量、抓取）的状态一律放模块级注册表，视图只做绑定；"关掉面板 = 杀掉任务"是最伤用户的默认行为。
6. **自动落卡的边界要能用一句话说清**：只新增不改既有 → 可自动；会改既有 → 必须勾选。并且要检查"自动落卡"与"采纳=存卡"是否重复落两张（本轮就因此只给诊断接了自动落卡）。
7. **判定不做也要留证据**：面板增量渲染经 M1/M11 实测判停，写进断言 R148-7，避免下轮重复讨论或被误认为漏做。
