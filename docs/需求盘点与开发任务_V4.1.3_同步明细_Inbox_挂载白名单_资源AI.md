# V4.1.3 需求盘点与开发任务

日期：2026-11-05
基线：V4.1.2（`50dccd6`，`main` / `github/main` / `v4.1.2` 同点）
开发分支：`codex/v4.1.3`

## 一、目标

本轮在 V4.1.2 主线上完成五组体验收口，不改变本地优先和手动云同步的产品边界：

1. 云同步事实可解释：用户能看懂本机待上传、同步基线和最近一次实际同步分别包含什么。
2. 同步完成有回执：顶栏和设置页同步成功后，直接展示本次新增、修改、删除与字段变化。
3. Inbox 成为完整操作面：可转三类卡、可切换时间顺序、可打开原链接、可删除和清空。
4. 卡间关系只保留两条白名单：任务卡挂资源卡、策展节点挂资源卡。
5. 资源 AI 从“补空”改为全字段复核：读取完整卡面和链接正文，重新评估全部内容字段。
6. 顶栏呼吸灯必须明确表达同步关系：绿色一致、黄色待同步、红色断线或异常。

## 二、需求与验收

### R1 云同步事实可解释

- “本机有改动待上传”可点击，从右侧滑出本次待上传的具体记录。
- “本机同步基线”可点击，展示基线的记录级明细与字段变化。
- “最近实际同步”可点击，展示最近一次上传、拉回或一致性检查实际写入或确认的内容。
- 明细按全部 / 卡片 / 策展台 / 方向台 / 今日三件事 / 关系 / 系统记录分组。
- 明细支持搜索、时间正倒序、字段差异查看，并明确区分“待上传”与“历史回执”。

验收：

- 三张事实卡都有可点击入口，鼠标和键盘均可操作。
- 未同步、同步中、失败、无回执等状态均有可理解说明，不把检查时间冒充同步时间。
- 最近 20 次同步回执按最新在前保留。

### R2 同步完成回执

- 从顶栏右上角或设置页触发上传、拉回、已是最新或一致性检查后，成功时弹出“本次同步明细”。
- 回执展示方向、触发来源、修订范围、新增数、修改数、删除数和记录级明细。
- 双端都有改动时仍必须先选择保留本机、拉回云端或取消，禁止静默覆盖。

验收：

- 上传、拉回和“已是最新”均有明确结果反馈。
- 同步完成后可再次从“最近实际同步”打开同一份记录级内容。
- 取消或失败不生成误导性的成功回执。

### R3 顶栏同步状态呼吸灯

- 顶栏同步入口左侧显示呼吸灯，并带可读的无障碍状态说明。
- 绿色：本地与云端一致。
- 黄色：本机待上传、云端待拉回、双端待选择或同步方向待确认。
- 红色：断线、同步异常、未配置、未登录或不可用。
- 系统启用减少动态效果时，灯保留颜色语义但停止呼吸动画。

### R4 Inbox 操作面

- Inbox 默认按最新采集在前展示，并可切换为最早在前。
- Inbox 卡片可转化为任务卡、好奇心卡、资源卡。
- 单击打开采集详情；双击、`Enter` 或 `Space` 打开原始链接。
- 支持单条删除、二次确认全部清空；清空不得误删已转化目标卡。
- 导入与转化应有防重复机制。

### R5 卡间挂载白名单

- 仅允许任务卡挂载资源卡。
- 仅允许策展台节点挂载资源卡。
- 资源卡不提供反向关联任务入口。
- 好奇心卡、愿景、使命不提供卡间挂载。
- 旧反向关联能力退役，但既有数据清理、镜像投射和六层归属不受影响。

### R6 资源 AI 全字段复核

- AI 入口文案明确为“AI 优化 / 重新优化”，不再承诺只补空缺。
- 投喂完整卡面、标签、来源、分类、已有自定义字段、附件清单和可读取的 http(s) 链接正文。
- AI 重新评估并给出标题、描述、标签、来源类型、分类和已有自定义字段的完整建议。
- 用户可在采纳前逐项取消。
- AI 不修改链接、附件、ID、创建时间、置顶、星标、归档和同步字段；不新增或删除自定义字段键。

## 三、开发任务

1. 扩展云同步回执数据模型、差异分类与最近 20 次历史。
2. 新增同步变化表格、右侧明细抽屉与同步完成回执弹窗。
3. 在顶栏与设置页接入事实卡、回执和绿 / 黄 / 红状态灯。
4. 补齐 Inbox 时间排序、详情、键盘打开、单条删除、全部清空与防重复转化。
5. 删除资源侧反向关联任务入口与相关任务面板。
6. 将任务挂资源、策展节点挂资源收敛为唯一两类挂载关系。
7. 重写资源 AI 提示与采纳面，支持全字段复核和已有自定义字段更新。
8. 恢复并更新“打开云同步”和“打开方向树策展模式”两个无默认键命令。
9. 同步更新手册、版本号、更新日志、README、产品事实与质量文档。
10. 执行类型检查、构建、全量回归、E2E、四主题实拍、死样式、性能、无障碍、响应式和打包门禁。

## 四、工程验收口径

- 不为性能删除功能、压低必要反馈或放宽 SLO 预算。
- 新增回归分片必须进入 `regression.cjs` 的 `SHARDS` 并被 Git 跟踪。
- 全量视觉普查完成后才能运行死样式扫描；不得用残缺 census 删除样式。
- 性能只用本机桌面 Chromium 的真实采样，不引用历史读数或模拟数据。
- 390px 是响应式视口，不作为实体手机验收。
