## 一、本轮交付

### 1. 策展台：先读判断，再读画布

- 台身份与中心论点合并成一条紧凑上下文带，论点不再独占一整行；工具条紧随其后，释放首屏纵向空间。
- 金字塔与树状的父子连接线由 1px 提到 2px，并混入更高比例的强调色；金字塔按首末子节点中心生成真实总线，不再按四等分画一条与实际节点脱节的横线。
- 节点标题与说明分行显示：标题使用正文级字阶，说明增加发丝线与辅助字阶；长说明不再挤进标题基线。
- 中心论点仍可打开论点卡详情；金字塔 / 树状仍共享同一棵 `Category` 树，本轮不改数据与键盘建支、拖拽、关联资源等既有交互。

### 2. 设置页：与其他台面共用一条页轴

- `gs-page` 改为 `min(1440px, 100%)` 页宽，补 24px / 36px 内边距与 24px 双栏间距，与调度台、方向台的页轴一致。
- 左侧导航保留 sticky，但增加最大高度与独立滚动，窗口较矮时不再把底部菜单项推出视口。
- 更新日志仍为左目录线 + 右侧内容：目录可点击定位、滚动同步高亮；正文改为自适应双列，每列保持独立可读行宽，消除右侧大面积空白。720px 以下自动回落单列。

### 3. 使用手册与写给用户的一封信

- 手册已按现役产品重写相关段落：单一策展画布、金字塔 / 树状同一棵树、`Tab` / `Enter` 建支、整棵子树拖拽、资源 chip 解除关联、成果 HTML 分享与回导、顶部三项动作。
- 用户信补一段当前产品形态：三卡进入同一条可召回、可推进的工作流，方向树负责从属，今日三件事负责每日投入，策展台负责把证据组织成可分享的判断；界面继续以“一眼看清、顺手完成”为准。

### 4. 画像洞察：页头不再多占一层

- 今天 / 本周 / 本月 / 本年周期切换并入 `PiHero` 同一工具行，独立 `PERIOD` 提示带退役。
- 页面从页头直接进入「产品使用状态 + 个人方向状态」双面板，减少一层只承担导航说明的横向容器。
- 720px 以下周期页签回落为整行并可横向滚动，不遮挡刷新 / 导出 / 全部记录。

### 5. 调度台：主攻项目两行常驻，详情只读可复制

- 右栏「今天的状态」固定呈现主攻 1 / 主攻 2 两行：完整项目名 + 进度；项目不足两项时显示空位，不再把第二个藏进 `+1` 弹层。
- 点击任一行打开只读项目详情：所属方向、下一步、成功指标与任务状态、未挂指标任务；文本可选中复制。
- 详情复用 `tasksOfProject / tasksOfMetric` 与 `resolveProjectNextStep`，不另建项目、指标、任务口径；修改仍需前往方向台。
- 旧页头主攻胶囊与 `+1` 浮层退役。

## 四、边界与遗留

- **全站键盘与读屏仍未清零**：`a11y-tab-audit` 仍报告 250 处可点击但不可聚焦元素、54 处会掐掉焦点环的样式；本轮只对设置更新日志、策展节点和主攻只读弹窗做专项覆盖，不能写成全站可访问性通过。

- **性能与视觉仍是单轮或按批次样本**：不把一次实拍或单轮 SLO 写成长期稳定性结论；连续 7 天采样、慢机 / 大库分档、真实用户可用性测试仍未完成。
- **方向台项目全景仍是下一轮视觉重点**：本轮不推翻现有布局，下一轮继续减少并列容器与重复信息，让「项目—指标—任务」形成更清晰的纵向阅读路径。

## 五、UI 设计层面的优化方案

### 1. 一条页轴，三个台面

调度台、方向台、设置页统一 `min(1440px, 100%)` 与 36px 内边距。页轴不是装饰，它决定用户在不同台面之间切换时，标题、工具栏与内容列是否“站在同一条线上”。下一轮继续保持这条纪律，不再给单页另起宽度。

### 2. 用发丝线与留白替代层层套卡

策展台本轮把“台身份 / 论点 / 读数 / 工具”从四层横条收成上下文带 + 一条工具条；设置页去掉内容列额外的卡片壳。下一轮在方向台项目全景继续做减法：同一信息只保留一层容器，层级靠字阶、间距与一条发丝线表达，而不是靠卡中卡。

### 3. 每个区域只保留一个视觉主句

- 策展台：中心论点是主句，节点标题是分支主句，说明与资源是辅句。
- 设置更新日志：版本号与标题是主句，分段要点是正文。
- 画像页头：周期页签是导航，不再另起一条说明带。
- 调度台右栏：主攻 1 / 主攻 2 是状态主句，其他计数退为辅助读数。

### 4. 标题 / 说明 / 元信息建立三级字阶

标题用正文级或标题级字号并允许换行；说明退一档，用发丝线与标题分开；元信息使用 micro 字号与弱色。下一轮所有新增节点、卡片和抽屉都按这个三级结构落，不靠“全部加粗”来伪造层级。

### 5. 低频动作收进「⋯」

高频动作保持在主路径，低频动作（导入模板、AI 建议、诊断、设置）收进「⋯」或就地菜单。这样画布与项目摘要只留下用户此刻真正要做的事，减少工具条横向噪声。

### 6. 下一轮方向台项目全景

保留现有「项目切换 → 项目摘要 → 横向泳道」架构，重点不是换布局，而是收口阅读路径：

1. 项目摘要只保留“现在怎么样 / 下一步做什么 / 哪里断链”三个信息块，去掉重复的项目名与重复计数。
2. 泳道内先给指标标题与进度，再给任务行；任务行不再嵌套第二层卡片，避免“卡里还有卡”。
3. 无归属任务收容道固定在最后，与正常泳道使用不同底色和边框，不抢主路径。
4. 多项目 / 多指标时优先保证单泳道可读宽度，必要时横向滚动，不把所有列压进一屏。
5. 所有项目、指标、任务详情共用同一套抽屉与 Esc 栈，避免“换了视图就换了交互语言”。
