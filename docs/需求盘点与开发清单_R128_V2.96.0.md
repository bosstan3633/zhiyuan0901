## 批次 C｜P2 性能

- **C1 保存链路（收益最大）**：`repository.ts` 每次保存整树 `stringify+parse`（千卡 40–100ms），`isSelfWrite` 又把 onChanged 新值整树 stringify。→ 写载荷带 `writeId`（`__wid`）令 `isSelfWrite` 退化 O(1)；再走分键增量写（resources/tasks/curiosities/compass/workspaces 各 key，`zy_data_v2` 保留兼容读 + 启动合并）；>500KB 序列化搬 Web Worker。门禁：`perf.cjs` 增「保存耗时」探针（当前未覆盖）。
- **C2 全局搜索键入**：`GlobalPopups.vue` 浮层仅 opacity 隐藏恒挂载；`searchQuery` 无防抖，每键重算 counts/allResults/wsTree/filteredResults；逐卡 `find`（900×200）。→ `useDebouncedRef` 120ms；`byId` Map + 「分类→卡」bucket（随 `dataVersion` 失效，复用 `catIndex.ts`）；`hitRank` 移出比较器（装饰-排序-去装饰）；结果区 `v-if`。目标 100–150ms → <20ms。
- **C3 大列表渲染**：设置页全景树 O(分类×卡) 且一次渲染 900 行；金字塔/看板/回收站非增量（全站仅 `useResourceView` RENDER_STEP=80）。→ bucket 计数一次成型；`panCards` 复用 RENDER_STEP；`flattenPanCats` 提为 computed。
- **C4 每行重复计算**：`TaskManagerPanel` 每行 `projectName()`（内含 `allProjects()` flatMap）+ `metricName()`；`kanbanGroups` 非 computed 且模板 6 处各调 2 次；`tShort` 每行新建 `Intl.DateTimeFormat`。→ name Map + `kanbanGroups` 改 computed；日期格式化提模块级单例。
- **C5 内存**：`store.data` 全树深响应式（编辑一次物化数万 Proxy 且驻留）；`compass.ts wceEvents`、`GlobalSettings eventLog` 把 5000 条事件塞进深响应式 ref；`eventLog.ts` 每次保存整档读-改-写。→ 事件/流水类只读大数据改 `shallowRef`；`zy_event_log` 改 IndexedDB 增量 append。**整库降 `shallowRef` 风险高（大量视图依赖深层触发）→ 列为观察项，先做事件侧**。
- **C6 启动**：`App.vue` 每次开新标签页 idle 预热 312KB 拼音字典（与「按需加载」交付报告相悖）；`stores/app.ts` 串行 4 迁移 + 最多 4 次 `saveData`。→ 字典改首次 Ctrl+K 动态 import；迁移合并为单次全树遍历、只在真改动时落 1 次盘。
