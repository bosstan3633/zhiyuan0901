## 二、合并决策：为什么放同一版本

| 维度 | 判断 |
|------|------|
| 组件重叠 | **零重叠**：P5/F6/F7 改 `CompassHome`/`CompassTree`/`CompassSpine`（调度台+方向台）；W13 改 `profile/` 七组件 + `reviewReport.ts`（画像洞察页）。无共享源文件 |
| 判据重叠 | **零重叠**：P5/F6/F7 翻转 R45-9/R51-F10/R51-5/R169-14/15/W12-1/R17-4/W11-3/W11-9 + e2e E2E-8；W13 翻转 W12-B3 + 新增 W13-1~8 + 核查 E2E-21。两组判据分属不同分片 |
| 门禁成本 | 全门禁链（typecheck→regression→index→matrix→dead-css→contrast→build→pack）跑一轮约 5-8 分钟；合并发包只跑一次终检，比分两版省一轮 |
| 风险隔离 | 两批改不同页面，中间态互不污染；即使一批实现中回归红，不影响另一批开发 |
| 结论 | **合并 V3.8.22**。若实现中任一批出现不可控返工，可降级拆分（P5/F6/F7 先发 V3.8.22，W13 顺延 V3.8.23）——排期已预留此退路 |
