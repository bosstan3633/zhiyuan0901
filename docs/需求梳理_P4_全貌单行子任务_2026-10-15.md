## 二、为什么删（不是"看着不爽"，是首屏被自己挡住了）

旧版（V3.8.18 N1 三栏横排，实测约 470px）把「属于哪 / 走过什么 / 下一步 / 属性带」压在首屏里，
真正要看的「三张卡」被顶出一屏之外 —— 于是 **"看选中项"反而挡住了"选下一件事"**。
这个模块的本职是帮用户快速确认"下一步做什么"，却成了首屏减负的对象本身。

## 三、删掉的能力去哪了（逐条核对，属迁移不属丢）

| 删掉的 | 去向 |
|--------|------|
| 属于哪（六层链：愿景/使命/目标/项目/指标/任务） | 卡片已有 🏷 项目/指标；抽屉里有完整六层链 |
| 走过什么（事件流水） | 抽屉里本来就有历史 |
| 属性带（状态/优先/成熟/截止/预估/支撑/标签） | 卡片徽章 + 抽屉全有 |
| 下一步（本地规则建议） | **D4 整体退役**：AI 诊断（单项目五维度）+ 卡片停滞标已承担 |
| ⑥ 本地判断标题 / 限高内滚动 | 随块退役 |

## 四、保留与新增

- 保留：单击选中 / 双击滑出抽屉两条交互；四种非任务槽的引导态（空位 / 源卡已失效 / 装的是卡片 / 自由文本）—— 压成同一行文案
