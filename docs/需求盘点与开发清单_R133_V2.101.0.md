# 需求盘点与开发清单 · R133 V2.101.0（批次 E · 视觉令牌体系升级）

**日期**：2026-09-19
**来源**：appica.dev/ui 设计体系分析结论（92 枚 :root 令牌逐项比对）→ 用户拍板「要」成立批次 E。

## 一、定案（本轮范围与口径）

| # | 项 | 定案 | 口径备注 |
|---|---|---|---|
| E1 | 语义色三档阶梯 | success/warning/danger 各补 `-bg-soft` + `-border`，四主题齐挂；tokens.css 之外硬编码 rgba/hex 清零 | appica 是六档（subtle→intense），**不照抄**——我们消费点只用到 soft/border/主色三档，按需建档 |
| E2 | 圆角体系 + 完备性守卫 | 补 `--radius-lg: 14px`（抓到 CompassTree 引用悬空=R130-T5 同族新例）；全站悬空令牌清账 7 族；新增「引用必先有定义」回归守卫并金丝雀实证 | 12/10/8/4 既有值不动，**不采** appica 的 calc(n/7) 九档派生（对我们过密） |
| E3 | 选区 + 禁用档 | `::selection` = accent 18% color-mix；`--opacity-disabled: 0.5` | 禁用档**不采** appica 的 .65：现众数 .5，取众数防整体对比度漂移 |
| E4 | 运动令牌 | `--dur-fast/--dur/--dur-slow` + `--ease-out-soft`；219 处字面量收敛；卡片入场逐行 20ms 错峰第 8 行封顶 | .2s 抽屉弹簧与闪烁动画为有意异构曲线，保留；src/content 浮层 --zy 体系豁免 |

## 二、延后 / 不做

- **不做**：Geist 字体接入（系统字体栈是 R123 原型拍板）、大圆角胶囊化、hero 渐变、密度放松（与「深色画布即留白」的 Linear 规范冲突）；
- **延后批次 D（性能）**：与批次 C 尾项合并考虑——C1b 分键增量写、C5b 事件日志 IDB 增量、C5c 整库 shallowRef；
- **候选后续**：抽屉/浮层弹簧曲线是否统一收进 `--ease-*` 家族（需先真机复核本轮入场递进的接受度再议）；`--fs-*` 字号档是否补 -2/-1 细分档（现无散点痛点，不立项）。

## 三、门禁与惯例（不变项）

typecheck → regression（只增不改义；改写断言须注明）→ build → 版本六处同步 → 本二文档 → commit + 轻量标签；push / 打包仅在用户明示时执行。纯视觉/交互批次交付须附**真机复核点位清单**（见交付说明第四节）。

## 四、R133 复核焦点

1. 卡片入场递进的「感度」——太闹则退役 stagger、保留令牌；
2. 浅色主题 danger 消费点（回收站/dup 环）换档后的协调性；
3. 选区色 accent 软底在阅读场景的对比是否足够。
