## 一、交付明细

### 1. 主攻图标定稿（反馈 #2）

- 符号分工钉死：**🚀=主攻、🎯=成功指标专属、📦=项目**；原 ⚑（旗帜）全量退役，全站 `grep ⚑` 零命中。
- 改动触点：方向树（tp-mark/节点动作钮/图例）、灯塔面板（fs-badge/fp-hint/pr-mark/行动卡）、项目策展（toast/徽标/tag accent）、全局浮层 chip（🚀 主攻）、compass store toast、手册与 models 注释。
- 断言：改写 R83-6 / R126-5 锚点至 🚀；新增 R139-1 把「⚑ 绝迹 + `>🎯 主攻` 不再出现」锁死，防回潮。

### 2. 拆解双通道（反馈 #5：小任务不该被迫建子任务）

- **AiJob 新增 `secondary` 通道**：同一批勾选行的另一种落法——评审抽屉 footer 出现次按钮（label 由 job 给、勾选 0 时禁用、复用 picked 勾选集），与主采纳、只读三形态并存。
- breakdown 场景接入：「**📝 步骤写入任务详情**」把勾选步骤合并成 `🤖 步骤清单：` 段落写进原任务描述——**替换段重复采纳不堆积**（实测二次采纳仍只有一份）、plan 思路行不入清单、原任务被删拒写；主通道「✓ 采纳勾选项」建子任务的链路一字未动。
- 抽屉 hint 同步改写「勾选后二选一」，用户第一次就能看懂两条路的分野。

### 3. 拆解专家执笔（对账问答 #1：角色提示词可干预拆解）

- `chainSystem(level, personaText?)`：专家文本**顶替**默认执行教练角色（rules/schema 契约不变）；`chainPersonaText()` 把内置∪自建专家的 brief+focus 与 `personas[].style` 风格覆盖合成执笔人设。
- 拆解 job 挂 `persona` 三段（options/current/onPick）：评审抽屉工具栏出现专家下拉（默认=执行教练，列表=角色库全员含自建），**换专家=重建 job 自动重跑**；其他四层（目标/项目/指标/任务）暂不挂下拉，保持生成面收敛。

### 4. 周报深度洞察（反馈 #6：AI 赋能、深度洞察未体现）

- 投料扩容：`projectWeekDigest` 新增两段——**本周调用分布（按工作台聚合，top6）**与**主攻项目投入对照（isFocused ≤3：进度/未完成/本周完成/停滞）**，为"重心偏离"提供本地证据；无主攻/无调用时整段缺席不凑数。
- 新契约 `deepInsightSystem`：认知参谋四段 markdown（**重心体检 / 信号与异常 / 资产与目标错位 / 下周一个动作**），明文要求"不复述数字、结论必须指回台账条目、材料不足就直说看不出"。
- 入口=调度画像浮层头部「**🤖 深度洞察**」钮：浮层属 CompassHome 宿主——AI 栈全懒（defineAsyncComponent + 点击时 dynamic import），产物级复核入口 chunk 零 `chat/completions`/`zy_ai_v1`；rawText 流式出稿，**采纳=存「🤖 深度洞察」资源卡**（tags ['深度洞察']，不动既有数据）。
- 顺手修一层级 BUG：周报浮层 z-index 320 会压住评审抽屉（201），降浮层至 190 解决（冒烟 U2d 实测 dr=201 > wr=190）。
- 台账全空时正确拒跑（toast 引导先干活）。

### 5. 附带修复
