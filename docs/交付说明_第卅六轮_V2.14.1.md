## 二、REQ-038 数据持久化加固（3 个真问题，逐条根治）

### ① 10 MB 上限 —— 已解除

`chrome.storage.local` 未声明 `unlimitedStorage` 时硬上限 10 MB。知源单根 JSON 随资源卡增长，一旦触顶，**所有写入静默失败、用户毫无感知**。

```ts
permissions: ['storage', 'unlimitedStorage', 'tabs', 'activeTab', 'commands', 'scripting']
```

配套提供 `hasUnlimitedStorage()` 运行时自检（读 `chrome.runtime.getManifest()`），设置页可确认权限是否真的生效。

### ② 保存失败静默吞掉 —— 已补告路径

**根因**：防抖保存 `cs.set(payload)` 返回的 Promise **完全没有 `.catch`**；`saveDataNow()` 也无 try/catch。写入失败时异常坠入 void，数据丢了界面照常显示，下次打开回到旧版本。

**修复**（`shared/storage/repository.ts`）：

| 层 | 改动 |
|---|---|
| 采集 | `emitSaveError(e)` 分类为 `quota`（配额超限）/ `serial`（序列化失败）/ `unknown`（未知 IO），异步取 `getBytesInUse` 一并上报 |
| 订阅 | 新增 `subscribeSaveError` / `getLastSaveError` / `clearLastSaveError` |
| 呈现 | `App.vue` 订阅后转 Toast：`⚠ 数据保存失败：配额超限（已用 10.2 MB），请清理或导出后重试`，带「查看」按钮直达设置页 |
| 诊断 | 设置页「关于」卡片新增红色 `⚠ 写入异常` 行，可点「已处理」清除 |
| 兜底 | `saveDataNow()` 包 try/catch；成功后自动清除上一次错误态 |

### ③ 容量水位 + 备份提醒

- 设置页「关于」新增**数据存储**行：`已用 3.4 MB / 权限 unlimitedStorage ✅`
- **备份提醒红点**：顶栏设置按钮出现红点，触发条件 = **30 天未导出** 或 **容量 > 5 MB**（`backupReminderDot` computed）
- 导出页新增「备份提醒」卡片（开关 `backupReminderEnabled` + 上次导出时间）
- 四处导出入口（全量 JSON / CSV / 单工作台 / Markdown）成功后统一写 `lastBackupAt`，红点自动消失

> 按用户拍板：**仅提醒，不做云同步**。数据主权 100% 留在本机，导出动作由用户掌握。

## 三、REQ-039 全局搜索交互统一（P1 跨场景方案）

### 3.1 认知纠正（重要）

用户原话是「**依旧**统一为单击抽屉、双击跳转」——但技术调研后确认：**当前两个搜索入口都没有这套逻辑**。旧行为是「单击 = 直接打开链接」。

所以这不是"保持统一"，而是**新增行为**：单击改为"先看后开"，双击保留"直接开"。已在需求确认阶段向用户澄清并获拍板。

### 3.2 方案：P1 跨场景统一

| 场景 | 单击 | 双击 |
|---|---|---|
| newtab 内启动搜索（`GlobalPopups.vue`） | 跳目标路由 + 打开详情抽屉 + 卡片高亮 | 关闭浮层 + 直接打开链接 / 跳详情 |
| 第三方页面启动搜索（content `search-overlay.ts`） | 新开（或聚焦）工作台标签 + `zy-route` 带 drawer 参数 → 落地即展开抽屉并高亮 | 直接在新标签打开链接 |

**两个入口单击语义完全一致**：都是"定位到卡片所在位置并展开详情"，不因启动地点不同而分裂。

### 3.3 落地要点

1. **极简事件总线** `shared/utils/bus.ts`（30 行，避免引入 mitt 依赖）：`onOpenDrawer` / `emitOpenDrawer`，payload = `{ kind: 'res'|'task'|'curio'|'project'|'ws', id }`
2. **新建 `ResourceDetailDrawer.vue`**：资源卡只读预览抽屉（标题/URL/关键词/分类/调用次数/最近调用），底部三个动作 = 复制链接 / 打开 / **全屏编辑**（跳 Workspace 带 `hl` 高亮参数）
3. **zy-route 协议扩展**：消息从 `{type, route}` 扩展为 `{type, route, drawer?{kind,id}}`；`App.vue` 先 `router.push(route)`，80 ms 后 `emitOpenDrawer(drawer)`
4. **5 个视图/组件接入总线**：`ResourceDetailDrawer`(res) / `CompassActions`(task) / `CuriosityPanel`(curio) / `CompassTree`(project)
5. **双入口单击/双击分离**：
   - content 浮层：`openSearchLocator()`（单击）vs `openSearchResult()`（双击）
   - newtab 弹层：`selectResultLocator()` / `runFlatLocator()`（单击）vs `selectResult()` / `runFlat()`（双击）
6. **Enter 键**统一走**单击**行为（`runFlatLocator`），避免回车直接跳走丢上下文
7. 结果项 `title` 属性加提示：单击=查看详情，双击=直接打开

## 六、验收走查清单（建议按序点一遍）

1. **权限生效**：设置 → 关于 → 「数据存储」行显示 `权限 unlimitedStorage ✅` 与已用容量。
2. **备份红点**：导出一次 → 红点消失；等 30 天（或把容量做到 > 5 MB）→ 红点重现。可在导出页关掉「备份提醒」开关验证。
3. **保存失败告警**：在 `chrome://extensions` 关闭扩展的 unlimitedStorage（或用 DevTools 注入写入异常）→ 触发保存，应弹 Toast「⚠ 数据保存失败：…」并可在设置页看到红色异常行。
4. **newtab 内搜索**：`Ctrl+K` 唤出全局搜索 → **单击**结果 → 跳到对应工作台/罗盘页并展开详情抽屉、卡片高亮；**双击** → 直接打开链接。
5. **第三方页面搜索**：在任意网页唤出搜索浮层 → **单击** → 新开/聚焦工作台标签，落地即展开抽屉并高亮卡片；**双击** → 新标签打开链接。
6. **Enter 键**：搜索结果高亮后回车 → 走单击行为（不直接跳走）。
7. **抽屉类型覆盖**：分别搜到 资源 / 任务 / 好奇心 / 项目 四类，确认抽屉都能正确展开。
8. **资源抽屉动作**：复制链接 / 打开 / 全屏编辑（跳工作台并高亮）三个按钮可用。
9. **版本一致**：设置页「扩展版本」与「关于」页均显示 **V2.14.1**；使用手册头部同。
10. **手册新篇**：使用手册 → 速览 → 出现「它是什么·给谁用·解决什么」与「六个核心动作」两节。
