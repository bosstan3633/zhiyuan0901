## 二 · 本批最值钱的一条：切片退化不报错，只是悄悄地不判了

### `R4-Dg` 一直是坏的（搬移前 grep 发现）

```js
fnBody(gs, 'function exportMarkdown', 'function dateStr')
```

终点标记 `function dateStr` 位于**起点 `function exportMarkdown` 之前** ⇒ `indexOf(…, iFn)` 恒为 **−1** ⇒ `slice(iFn, -1)` 静默退化成"从起点取到全文末尾"，实测扫了 **81,821 字符**（本该只扫 ~1,256）。

它之所以一直绿：那条负锚 `r.workspaceId === ws.id`（1383 行）**恰好落在起点（1394 行）之前**，所以从未被扫到。

重指为同域下一函数 `function csvEscape` 后，切片收到 **1,256 字符**，两条负锚仍不命中。

> **教训**：`fnBody` 只在**两个标记都找得到**时才正确。终点找不到时它不报错，只是变成"到文件尾"——这正是 `R4-Et②` 立"账本为空"硬门禁的原因。本批证明那条门禁还不够：**光记"终点找不到"不够，还要盯"终点在起点之前"这种反向命中**。

### `R4-Dc` 是承重锚跨文件失效

原终点 `watch(activePage, (p) => { if (p === 'export')` 在 export 子域，搬移后会跨文件。改指同域下一函数 `async function exportAssetPack`。

> **纪律 17 的又一次兑现**：搬移前 grep 判据是否在读被搬走的正文，不只是删之前。**读注释不算**。

### `R171-3` 重指时最容易漏的是**语义**不是锚

数据体检卡随导出子域迁入 `SettingsExportPanel.vue`。旧锚钉的是宿主里的 `<DataCheckupCard v-if="activePage === 'export'" />` 字面串。组件内 `activePage` 不可达，那行**必须摘成恒真**，于是：

- 只改锚不改语义 ⇒ **子域里的卡片会常驻挂载，四个设置页都冒出一张体检卡**；
- 新锚同时钉住三件事：① 卡片在子域里恒真挂载 ② 子域无 `v-if` 挂载 ③ **子域真被宿主 `activePage === 'export'` 门控**。

**负锚还踩了一次纪律 18 的镜像形态**：`gs` 是**聚合读**（宿主 + `settings/` 全目录），拿它判"宿主内不得残留裸挂载"必然假红 —— 子域那份挂载自己就把字符串喂进来了。正解不是改去读宿主本体，而是把语义写准：**聚合全文里这张卡的模板挂载点恰好 1 个**（回迁宿主或两边各挂一份都会变成 2 ⇒ 红）；正则只吃模板形态 `<DataCheckupCard[\s/>]`，import 行与注释提及都不算。

## 三 · 两条搬移纪律（本批新学）

### ① 组件之间不得互相 import —— 会成环

附件包 `<input>` 在**导入页**，处理函数 `handleAssetPackImport` 在**导出子域**。直接 import 会形成 `ImportPanel → ExportPanel` 的环（而后者本就该是宿主的中转目标）。

**解法三层**：`emit('asset-pack', e)` → 宿主 `onAssetPack(e)` → `exportRef.value?.handleAssetPackImport?.(e)`（目标组件 `defineExpose`）。

### ② 共用纯工具函数抽真源，不走 props 也不复制

`downloadFile` / `dateStr` 两个子域都要用。三条路里：props 双向传 → 会成环；复制两份 → **口径分叉**（以后改一处忘另一处，就是两个"看起来对"的实现）。抽 `settings/io-utils.ts` 是第三条。

### ③ `v-if` 摘成恒真时，**外壳随组件走**

第一版把 `.gs-panel` 外壳留在宿主、只搬内部，实拍报「标题=导入数据 panel=false」，看似没渲染、实则整页正常渲染，只少那层壳。**外壳改为随组件走，壳上的 `v-if` 摘掉**。
