# V4.2.4 交付说明

> 版本：V4.2.4
>
> 日期：2026-11-12
>
> 基线：V4.2.3（`main` / `e0f1a9a` / 标签 `v4.2.3`）

## 一、交付结论

V4.2.4 将云同步从“整端覆盖、冲突二选一”升级为本机、云端与共同基线的三方安全合并；新增直接执行同步的浏览器快捷键；补齐方向台项目与成功指标的就地改名入口，并修复空成功指标无法接收任务拖拽的问题。

## 二、功能变更

### 1. 三方安全合并

- 新增独立共同基线存储，记录最近一次成功同步时的业务快照。
- 同步时分别比较共同基线、本机数据和云端数据。
- 不同记录、不同字段的修改自动取并集。
- 只有同一条记录的同一字段被两端改成不同值，或删除与修改发生冲突时，才要求用户逐项选择。
- 冲突弹窗展示共同基线、本机值与云端值，支持逐项选择“本机”或“云端”。
- 自动同步仅在能够安全合并时执行；存在逐字段冲突、账号异常或网络异常时暂停，不静默覆盖任一端。
- 上传或拉回成功后更新共同基线，避免下一次同步重复识别旧差异。

### 2. 同步范围与明细

- 云同步只处理卡片、策展台及节点、方向台项目 / 指标 / 任务关系、今日三件事、资源镜像与常用夹关系。
- 主题、页面布局、筛选排序、抽屉宽窄及其他界面偏好只留在本机。
- 同步回执继续按卡片、策展台、方向台、今日三件事、关系与系统记录分组，并标明“合并同步到云端”及触发来源。

### 3. 立即同步云端

- 原“打开云同步”浏览器快捷键退役。
- 新命令“立即同步云端”使用独立命令 id，不设置默认键位，由用户自行分配。
- 触发后优先复用已打开的知源新标签页并直接执行同步。
- 未登录、未配置或页面尚未接住消息时，进入云同步设置完成必要操作。

### 4. 项目与成功指标就地编辑

- 项目塔与项目全景都提供项目重命名入口。
- 成功指标在两个视图都可双击标题进入就地编辑。
- Enter 或失焦保存，Esc 取消；空标题不覆盖原值。
- 保存统一经过方向台 store 与 `persist()`，保存后全局生效。
- 成功指标的详情入口保持独立，不再依赖“先打开详情才能改名”。

### 5. 空成功指标拖拽

- 项目塔把任务拖放的 dragover、dragleave 与 drop 热区从任务列表扩大到整张成功指标卡。
- 零任务指标也可以接收其他任务，并继续显示落点反馈。
- 仍只允许同一项目内跨成功指标调整归属，跨项目继续拒绝。
