# V4.3.5 需求盘点与开发任务

> 版本：V4.3.5
> 日期：2026-11-17
> 基线：V4.3.4（`42f5b25`）
> 范围：调度台今日三件事与日历联动、今日战报 AI 洞察、卡片池排序、云同步明细、方向台项目塔与策展模式、树状视图 OPPO 视觉重构、Logo 替换

## 一、本轮已确认口径

以下口径来自本轮反馈，作为开发和验收的统一依据：

1. 今日日历严格最多 3 项，并与今日三件事保持同一集合、双向联动。
2. 从今日三件事移出任务时，同时清空该任务的今日计划执行日期。
3. 取消任务的完成勾选时，优先恢复勾选前的任务状态；没有历史记录则恢复为“待开始”。
4. 卡片池首页预览以“最近采集”为绝对优先；进入完整卡片池后继续保留置顶机制。
5. AI 洞察只在当前今日战报弹窗内临时生成和展示，不自动保存，不写入任务真源。
6. 今日三件事的完成状态与任务卡状态同源，复选框只是任务状态的呈现和操作入口。
7. 今日三件事、今日日历、任务卡状态与计划执行日期都需要进入云同步范围。
8. 方向树树状视图需要按 OPPO 设计语言重新组织结构与美感，同时保证 1440 / 1000 / 800 / 390 宽度下都不出现横向溢出。

## 二、功能需求清单

### A. 今日三件事与今日日历联动

1. 今日三件事固定为 3 个槽位，最多 3 项；今日日历中属于今天的任务集合与三件事完全一致。
2. 三个槽位固定存在，删除第 1 个槽位后第 1 个槽位留空，不把第 2、3 个槽位前移。
3. 空槽位提供“选择任务”入口，可从任务池搜索并选择；选择后填入当前槽位。
4. 从今日三件事移除任务时：
   - 当前槽位变为空槽；
   - 任务卡的计划执行日期清空；
   - 任务回到待排期任务清单；
   - 不删除任务卡本体。
5. 从今日日历取消排期时，如果任务在今日三件事中，也同步释放对应槽位。
6. 任务进入今日三件事时，自动写入今天作为计划执行日期；任务安排到今天日历且三件事未满时，自动进入三件事。
7. 任务完成状态以任务卡为唯一真源：
   - 勾选复选框后，任务状态改为已完成；
   - 取消勾选后，恢复勾选前状态；没有记录时恢复为待开始；
   - 任务卡状态变化后，三件事复选框和日历状态同步刷新。
8. 今日三件事与今日日历的任务、状态、计划执行日期和空槽状态，跨设备同步保持一致。

### B. 今日战报 AI 洞察

1. 今日战报弹窗在指标数据前增加“AI 洞察”模块。
2. 用户点击后，AI 以专业数据分析师视角读取当前战报已有事实，输出不超过 200 字的中文分析。
3. 文案结构固定包含：
   - 一条行为洞察；
   - 对行为背后深层原因的分析；
   - 一条下一步行动建议。
4. 分析只使用当前战报和事件数据，不编造数字，不做人格评价。
5. AI 洞察只在当前弹窗临时展示：
   - 不自动保存；
   - 不写入任务、卡片或云端数据；
   - 关闭弹窗后清空；
   - 用户可手动重新分析。
6. AI 未接入时显示明确入口提示；生成失败时显示错误和重试入口，不阻塞战报统计。

### C. 卡片池与任务选择

1. 调度台卡片池首页预览：
   - 任务、好奇心、资源卡均按最近采集时间优先，不因置顶改变首页预览顺序；
   - 完整卡片池继续保留置顶机制。
2. 任务选择弹窗的搜索框需要优化：
   - 搜索输入、清空、结果刷新不产生闪烁或布局跳动；
   - 搜索结果继续受项目、状态筛选约束；
   - 已完成、已入选任务不可重复选择；
   - 空结果、无匹配和加载状态有明确反馈。
3. 卡片池任务页签角标维持轻量风格：
   - 数字为 0 时隐藏；
   - 数字不为 0 时与页签文字同色；
   - 不再使用高压力红色强调。

### D. 云同步与同步明细

1. 今日三件事槽位、任务完成状态、计划执行日期和空槽墓碑状态进入云同步。
2. 同一账号多设备之间的今日三件事与今日日历保持一致。
3. 同步合并需要避免旧设备快照把已删除的任务重新回填到空槽。
4. 同步明细页去除“卡片变更信息 + 同步事件信息”的重复表达：
   - 一条业务记录只展示一次；
   - 展示卡片名称、变更类型、变更字段、同步原因和时间；
   - 同步事件只作为后台诊断数据，不重复占据用户可见明细。
5. 删除、修改和新增都要能说明“为什么同步”，避免只显示技术 ID。

### E. 方向台项目与成功指标

1. 项目塔和项目策展中，不再要求用户填写或展示“验收标准”字段。
2. 历史数据中的 `metric.acceptance` 保留兼容，不执行破坏性清空；旧数据仍可导入、导出和同步。
3. 项目创建、项目编辑、指标卡片和指标编辑界面不再把验收标准作为必填项或主展示信息。
4. 需要保留成功指标的其它信息：指标名称、目标值、期限、任务挂载、进度和完成百分比。
5. 项目塔中的项目、指标和任务进度呈现继续保持同源；本轮不新增第二套进度数据。

### F. 方向树策展模式筛选

1. 金字塔和树状两种布局都提供筛选区，支持按：
   - 战略目标；
   - 项目名称。
2. 两个筛选默认均为“全部”。
3. 选择某个战略目标或项目后：
   - 同层级内容只呈现匹配的战略目标或项目；
   - 被选项目上方的战略目标、愿景、使命等祖先层级继续全部呈现；
   - 项目下的指标、任务和附件跟随项目过滤后呈现；
   - 不匹配的分支隐藏，不复制或改写原始数据。
4. 筛选条件只影响展示，不修改方向树、任务、指标或附件真源。
5. 筛选结果为空时显示空态，并提供“清除筛选”入口。
6. 切换金字塔/树状布局时保留当前筛选条件。

### G. 项目塔进入项目策展

1. 项目塔模式下，每个项目提供“项目策展”入口。
2. 点击后进入策展模式，并自动带入该项目作为项目筛选条件。
3. 进入后直接聚焦该项目的完整策展全貌：
   - 项目对应战略目标及祖先层级可见；
   - 项目、指标、任务、资源、附件和挂载关系按项目范围呈现；
   - 默认布局为金字塔模式；
   - 用户仍可切换为树状，或清除筛选查看全量方向树。
4. 返回项目塔时保留原项目塔浏览位置和筛选状态。

### H. 方向树策展模式树状视图

1. 用清晰的层级语言替代连续的纵向套卡：
   - 愿景 / 使命作为树冠；
   - 战略目标作为章节；
   - 项目作为枝干；
   - 成功指标作为节点；
   - 任务作为叶片行。
2. 使用 OPPO 风格的克制视觉：
   - 柔和绿 / 蓝渐变与低对比表面；
   - 较大圆角与留白；
   - 明确的层级轨线和分支端点；
   - 任务行优先服务标题与状态阅读，不让日期、优先级等元信息挤压标题。
3. 项目、指标使用响应式网格；宽屏保持多列，窄屏退化为单列。
4. 1440 / 1000 / 800 / 390 宽度下不得出现页面横向滚动、卡片越界或右侧内容被裁切。
5. 树状视图继续保持只读：点击节点打开既有详情抽屉，折叠和筛选只影响呈现，不写业务数据。
6. 任务状态、项目和指标进度继续使用现有统一口径，不新增第二套统计来源。

### I. 方向台菜单与系统视觉

1. 修复项目塔折叠状态下，项目行最右侧“...”菜单被父容器裁切、无法完整展示的问题。
2. 菜单层级、定位和遮罩需要覆盖滚动容器边界，键盘打开时同样可见。
3. 使用最新知源调度台 Logo 全面替换现有 Logo：
   - 应用顶栏；
   - 浏览器扩展图标；
   - 安装包/PWA 图标；
   - 分享页和导出页中的应用标识；
   - 文档、手册和更新日志中的品牌标识。

## 四、验收标准

1. 今日日历中今天的任务与今日三件事完全同一集合；第 4 个任务不能进入，且不会静默覆盖已有槽位。
2. 删除第 1 个槽位后仍保持 3 个固定槽位，第 1 格为空；空槽可直接选择任务。
3. 移出三件事后任务做计划执行日期被清空，并回到待排期清单；任务卡本体不被删除。
4. 已完成任务复选框与任务卡状态一致；取消完成后优先恢复先前状态，否则为待开始。
5. AI 洞察只在当前战报弹窗出现，最多 200 字，关闭后不进入任何持久化数据。
6. 卡片池首页预览按最近采集优先，完整卡片池仍支持置顶。
7. 同步明细不重复显示卡片变更和同步事件；同步后多设备三件事与日历状态一致。
8. 项目/指标界面不再要求验收标准，历史验收数据仍可兼容读取。
9. 策展筛选默认全部；选择项目后只过滤该项目的后代内容，祖先层级继续呈现。
10. 项目塔的“项目策展”能直接打开该项目的金字塔全貌，并可返回全量视图。
11. 项目塔折叠菜单完整可见，不再被容器裁切。
12. 最新 Logo 在顶栏、扩展、分享/导出页和安装资源中一致生效。
13. 树状视图层级清楚、阅读顺序稳定，宽屏呈现多列枝干，窄屏退化为单列且无横向溢出。
14. 任务标题在最窄指标卡中允许两行；空间不足时优先隐藏日期等次要元信息，不牺牲标题可读性。

## 六、本轮边界

- 不恢复移动端采集、PC Inbox 或已退役的周期 AI 分析模块。
- 不为验收标准新增数据迁移或删除历史字段。
- 不改变方向树、任务、指标和附件的真源归属。
- 策展筛选只做展示过滤，不复制、不移动、不改写原始数据。
- AI 洞察是临时阅读辅助，不作为任务完成、优先级或方向状态的判据。
