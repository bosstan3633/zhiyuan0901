## 〇、总裁判（结论先行）

1. **三块架构是对价值体系的"压缩成拳"**：此前的"收得进、看得见、找得到、信得过、带得走"是功能钩子（拉人进来），三块是价值叙事（让人留下）。以后所有材料：**钩子用五字诀，骨架用三块**。
2. **三块是闭环，不是并列**：调度把世界收进来 → 策展把收的变成体系 → 方向校准决定下一次收什么。第三块给第一块打上了"个人指纹"——这是"千人千面"的结构性原因，也是 AI 替代不了的部分。
3. **第三块市场上无对标**：Notion 有数据库无好奇心机制，任务管理是 KPI 压迫，Obsidian 有图谱无方向校准，大厂 AI 替你思考恰恰消解独特性。**这是知源从"效率工具"升维"成长系统"的支点，也是定价权所在。**
4. **第三块同时是给家庭教育的理念产品**——"AI 时代，护城河是独特性；独特性 = 好奇心持续发芽 + 愿景使命校准"。这个叙事直接服务咨询业务：您对家长讲的教育理念，就是知源的产品哲学。**做我所讲，讲我所做——知源是这句话的物证。**
5. **销售材料全部按三块句式重写**：60 秒 Demo 改三段式、落地页改三栏首屏、《被质询的咨询》加入策展一屏、新增第十件材料《AI 时代，孩子的护城河》理念页。

## 一、三块架构的定位学解读

### 1.1 三块 → 替代现状 → 价值语言（一表拍板）

| 块 | 机制（实装） | 用户真正的替代现状 | 对外价值语言 | 回应的苦楚 |
|---|---|---|---|---|
| **① 无摩擦调度** | Ctrl+Shift+J/I 双浮层采集、Ctrl+K 拼音毫秒召回、多协议直达 | 书签 + 聊天记录 + 记忆：存进去 = 沉下去 | **"任何资源，三秒进出"** | 苦楚一/三：存在性焦虑、成果蒸发 |
| **② 策展** | 工作台 = 策展台，围绕核心主题结构化汇总数据/案例/工具/成果 | 文件夹 + 网盘 + 微信收藏：堆积 ≠ 策展 | **"一屏一个主题，服务自己，也服务客户"** | 苦楚二：试用者漂流；以及**服务交付的现场感** |
| **③ 方向校准** | 好奇心管理体系（四态流转）× 方向树六层思维链（愿景→使命→目标→项目） | 任务管理 / KPI 工具：压迫式目标，无人味 | **"好奇心驱动，愿景校准，走出只有自己的路"** | 苦楚四/五：认知钝化、意义迷失 |

### 1.2 为什么"三块"比"功能清单"高级

Dunford 的框架里，独特属性必须能被翻译成客户在乎的价值主题。三块恰好构成三个互不重叠的价值主题：

- **调度 = 效率主题**（同行都在讲，但知源讲得更极致：采集好奇心也是无摩擦的——同行只采集"确定的东西"，知源连"不确定的念头"都收）
- **策展 = 专业主题**（同行的"收藏夹"服务的是囤积癖，知源的"策展台"服务的是**交付**——给客户看的一屏，就是专业本身）
- **方向 = 意义主题**（同行**完全不讲**这一层）

**三个主题层层升维：效率（值几十块）→ 专业（值几百块）→ 意义（无价）。** 定价 ¥68–128 买断的底气，来自第一块；复购与转介绍的底气，来自第三块。

### 1.3 闭环：第三块给第一块打上个人指纹

```
调度（收进来）→ 策展（成体系）→ 方向校准（决定下一次收什么）↺
```

跑上一年，两个用知源的人，资源网络完全不同——因为好奇心不同、愿景不同。**工具是同一个，长出来的东西是各自的。** 这就是"AI 时代个人护城河"的运作机制，也是第三块的全部意义。这句话本身就是最好的广告文案：

> **"知源不替你思考。它让你思考的轨迹，长出只属于你的形状。"**

## 二、第三块的竞品歼灭战（独家性论证）

| 对手 | 它们怎么对待"方向" | 结果 |
|---|---|---|
| Notion / Obsidian | 目标数据库、双链图谱——有结构无心跳 | 记录过去，不校准未来 |
| 滴答清单 / Todoist 类 | 截止日期、优先级、逾期红字 | KPI 压迫，制造焦虑而非方向 |
| 大厂 AI 工具 | 替你想、替你写、替你选 | **主动消解独特性**——同一个模型给所有人同一种答案 |
| 书签 / 收藏类 | 完全没有这一层 | 不在牌桌上 |

**结论：方向校准这一层，牌桌上只有知源一家。** 宣传中不必贬低对手，只需不断重复一个对比句式：

> "别的工具帮你回答别人的问题；知源帮你守住自己的问题。"
