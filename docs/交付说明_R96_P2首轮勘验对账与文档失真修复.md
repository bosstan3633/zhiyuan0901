## 九、这一轮的教训

**坏账不是孤例，是模式。** R95 清了 P1 的 G7，本轮 P2 一勘验又出来三笔（R9/R11/R12）——四笔坏账的共同点是：**能力交付时清单没跟上，或清单建立时没勘验存量**。本轮的对策是双保险：清单逐项标注证据（下次对账有据可查），能力本体上断言（`R96-1` 让「删了能力」和「清单说没交付」互相锁死）。另外，`R96-2` 首跑即红（被我自己写的句子拦下）提醒我们：**否定断言的「零命中」是全文件语义，写文档的人也是它的约束对象**——这不是误报，这是它该有的样子。
