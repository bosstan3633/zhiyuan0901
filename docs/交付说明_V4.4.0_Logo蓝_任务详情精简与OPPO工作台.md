# V4.4.0 · Logo 蓝、任务详情精简与 OPPO 圆润工作台

- 全局主行动色统一到知源 Logo 蓝；正式主题收敛为光速黑、极简白、纸墨白，旧 `auto` / `linear` 偏好只做确定性迁移，顶栏同步呼吸灯退役。
- 任务详情围绕完整标题、计划执行日期、资源镜像与“AI 找资源”重构；导出、优先级、成熟度评分、预计用时、子任务与 AI 拆解退役，说明收为三行次级上下文。
- 新建任务取消 AI 填表，标题扩大为多行主编辑面；方向台项目内支持成功指标连同下属任务整组排序，空指标新建任务入口改为低干扰引导。
- 方向台、调度台、策展台统一 OPPO 式圆角、阴影、边距与控件层级；策展节点的“关联资源卡”成为正文主 CTA，附件降为次级元数据，中心论点卡与子节点保持资源优先语言。
- 知源品牌区把今天 / 本周 / 本月 / 本年控制与受控模块放在同一区域，并新增仅基于当前模块数据的 AI 洞察；愿景、使命与战略目标支持双击就地编辑。
- 回归辅助器为死样式 JSON 输出显式设置 16 MiB 缓冲上限，修复门禁输出超过 Node 默认 1 MiB 后被误判为进程不可用的假红。
