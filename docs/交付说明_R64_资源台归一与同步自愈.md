## 一、Airtable 同步 Bug 根因与修复（你报的 422）

**根因**：你在 Airtable 端手删了记录 `recAOGukf8MpdYphQ`，但知源本地还存着它的 recordId 映射。下次同步按旧 id 发批量更新（PATCH），Airtable 返回 422「记录不存在」且**整批失败**→ 游标不推进 → 每次同步都撞同一堵墙。

**修复（三管齐下，无需你手工清理）**：
1. 映射优先级反转：以**远端实测存在**的记录为准，本地映射只做兜底；
2. **自愈重建**：批量更新撞到已删记录时自动逐条降级，仍不存在的**转新建**拿新 recordId 写回映射，日志显示「逐条自愈重建」；
3. 单条失败只记日志，不再拖垮整轮同步。
→ **下次打开新标签页后点一次「立即同步」即可自动恢复。**

## 二、同步语义变更（按你拍板）

| 项 | 旧（R63） | 新（R64） |
|---|---|---|
| 镜像卡 | 真身单条记录，wsName 标注「📡镜像至 X」 | **每条镜像独立记录**（幂等键 `卡ID:m:目标台`），各带所属工作台标识 |
| 配额文案 | Free 版 1000 次/月口径 | 已去除，仅显示累计调用次数（你是会员版） |

注意：旧口径已同步的记录会在下次同步时自然对齐（真身行 wsName 变纯「资源台」，镜像行新建独立记录），无需手工处理。

## 三、功能改动清单

**调度台**：
- 「方向状态」不再计算 DHI 百分比 → 显示 **N 战略目标**（使命下拆解的非归档方向数）+ **M 项目推进中**（全部项目中挂有任务≠0 的项目数）；下钻明细同步换口径
- 「同步出错」chip 点击 → 直接跳设置→Airtable 同步分区（日志含具体原因）
- 三件事区与 4 指标卡**保持两个模块**，纵向压缩（删满员提示条/副文案，间距收紧）

**资源台归一（结构迁移，启动自动执行）**：
- 旧工作台（工具库/JS工作/教育AI/内容工程/策展…）分类树整体挂入资源台根下**同名根分类**，原生卡随分类平移，**工作台实体删除**（导航只剩 调度台/方向台/资源台 + 你新建的台）
- 迁移前**自动备份下载**（JSON，沿用 R61 保险机制）；幂等标记 `hubMergedAt`，二次启动零操作
- 所有采集入口默认落**资源台·待分类**

**策展台**：
- 卡片/列表视图改**树状递归分组**：子分类卡不再混入父组平铺，逐级缩进（↳），空分支自动隐藏
- 每张卡卡面显示**完整分类路径徽标**（如 `123 / 123-2`）
- 金字塔：层间 **SVG 结构连线**（父→子细实线，随窗口缩放重绘）；「策展主题」空态**点击弹窗填写**→ 保存自动落 L1 根（右键设论点保留为辅助）
- 顶部瘦身：hero 大标题区（标题/描述/chips）**整块删除**，导入/新建按钮上移工具条，⚙ 菜单补「🎨 更换图标」；5 指标压缩为紧凑单行

## 五、真机验收路径

1. **同步自愈**：加载 dist 打开新标签页 → 设置→Airtable→立即同步 → 应看到「逐条自愈重建」日志、无 422、Airtable 中被删记录自动重建
2. **镜像独立**：镜像一张卡到策展台 → 同步 → Airtable 出现两条独立记录（资源台/策展台各一条，所属工作台列不同）
3. **资源台归一**：重启后导航只剩三个固定台 + 新建台；资源台根下出现「工具库/JS工作/…」同名根分类；Ctrl+Shift+J 默认落资源台
4. **调度台**：方向状态显示「N / M 项目推进中」；三件事无提示条、整体更紧凑
5. **策展台**：卡片视图树状缩进分组 + 路径徽标；金字塔有连线、点空态可弹窗设立中心论点；hero 已删、指标单行
