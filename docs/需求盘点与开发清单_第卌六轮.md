## 四、根因备忘（防复发）

1. **多根组件 + v-show 必失效**：Vue 3 attribute fallthrough 对多根组件不生效。凡被 `v-show`/`v-if` 控制的宿主组件必须单根（Teleport/ContextMenu 类浮动节点须移入根容器内）。
2. **关联写入必须双向完备**：任务↔指标↔项目三角关系中，任何只写 metricId 不写 projectId 的路径都会让"按项目查"的视图断链。新写入点一律同时写全。
3. **computed 插值忘 .value**：`statDrawerTitle` 一类 computed 对象映射里引用其他 computed，`（${totalCards}）` 直接输出对象。review 时重点看模板字符串内的裸标识符。
4. **视觉反馈要过"截图可见"门槛**：6% 光晕这类"代码里有、肉眼无感"的效果等于没有，验收以截图为准。
