## 一、交付明细

### 1. linkFetch · 链接正文抓取地基（反馈 #3，按你拍板三则）

- 新模块 `shared/ai/linkFetch.ts`：**仅 http(s) 白名单**（file/obsidian 一律不抓）、**点击才抓**（抓取只发生在评审抽屉打开、job.build 时——无预取无轮询）、**默认抓**（无需开关）。
- 工程细节：10s 超时 + `credentials: 'omit'`；DOMParser 剥 script/style/nav/footer 等噪音、优先 main/article 容器；正文截 1500 字；会话级 Map 去重缓存（同链接二次分析零重抓）；PDF/图片/非 200/超时/空白页全部**降级为一句 note**，分析照常进行（契约要求模型标「（未读正文）」再谨慎推断）。
- 权限面：新标签页是扩展页，`host_permissions <all_urls>` 已在 manifest——跨域读取不碰 CORS，也不需要代理第三方服务，数据只在你机器与你的网关之间。

### 2. 全方位优化 · 两个入口一套工厂

- 新契约 `fullOptimizeSystem`：读了正文再说话——描述=「这是什么 · 什么时候用得上 · 为什么值得收藏」三段且收藏理由必须有正文依据；tags ≤4 且不与已有重复；标题只在明显名不副实时才建议；**不许编造正文里没有的功能与数据**。
- `buildFullOptimizeJob`（select.ts）：卡投影 + 【链接正文】一体投料；评审行分 标题/描述/标签 三类，与现有等值的行自动缺席（U2 冒烟首跑实为此护栏：已优化的卡不再出建议）；采纳=勾选行才写库（卡片存在且未删二次校验、一次 persist）。与「补全」的分野：补全只填空，优化允许改写——因为是用户主动求改。
- **入口 ①（反馈 #3「卡上没有 AI 入口」）**：资源台卡片 hover 动作条原位追加 🤖——宿主 Workspace.vue 压在 1500 行验收线上，按钮、评审抽屉、AI 懒栈全部收进新组件 `CardAiEntry.vue`，宿主净增 **0 行**（标签并入既有行、import 并入既有行），R115-1 行数门禁原样通过。
- **入口 ②**：卡详情抽屉 footer 新增「**🤖 分析（读网页）**」，与 🤖 补全并排；复用同工厂、apply 换成回填编辑表单，保存仍由你确认。

### 3. 专家编辑面 + 诊断三步上手（反馈 #4）

- AI 页每位专家行新增 **⚙ 行内展开**：「参与会诊与执笔」启停 + 行文风格覆盖（如"直说问题、只给三个动作"），upsert 进 `zy_ai_v1.personas[]`；停诊的专家同步退出本轮勾选。
- **自建专家可改**：名称/人设/关注面三元组就地编辑即存（空名拒绝），不再是只能删了重建。
- 启停全链路生效：深度诊断（既有）→ 拆解执笔下拉（本轮过滤）→ 执笔文本回落（停用即回内置执行教练）。
- 诊断卡顶部新增「**三步上手**」引导条：①接入（⚡测试连接）→ ②勾选/调教出诊专家 → ③一键诊断，采纳=生成跟进任务卡、不采纳纯看。

### 4. 手册 AI 章节

- 使用手册「方法篇」新增「**AI 认知助手**」一节：接入方式与密钥边界、三条硬纪律（建议必过你审阅 / 全手动触发 / 专家可调整）、入口地图（资源台/罗盘/治理/搜索/周报）。
- 周报一节口径更新：💡 洞察段仍是**规则引擎非 AI**；AI 版判断=浮层头「🤖 深度洞察」钮，不点依旧零外发。
