## 三、门禁与验证口径

- 顺序：typecheck → regression（**1204/0**，新增 R132-1~10）→ build（exit 0）→ 页面级 headless → 版本 6 处（V2.100.0）→ 两份文档 → commit + 轻量标签 `v2.100.0`（推送仅在用户明确要求时）。
- 页面级通道（R131 起）：dev-server + playwright-core + 系统 Chrome headless + storage 桩 + pinia 播种；本轮以 DragEvent/DataTransfer 合成事件走真实 handler 链验证 T2——**合成事件不等于真机 HTML5 拖拽**，多窗口/真实装载场景仍列用户复核。
- E2E/perf 本机不可用（待有网/Windows 机）。
