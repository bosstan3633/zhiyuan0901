## 〇、先决决策（✅ 已于 2026-10-13 全部拍板）

### D1 ✅ 焦点契约冲突 —— **选 A：愿景保持 `--fs-display` 22px**

**问题**：原型 HERO 区愿景用 34px（`--fs-hero`），但现役 `tokens.css` 最大字号是 `--fs-display: 22px`；
而 `02-w8-compass.cjs` 的 **W8-5 判据**钉死 `fs-display` 在工作面**必须恰好两处**。

**用户 2026-10-13 拍板：A 案** —— 愿景保持 22px，**不新增 `--fs-hero` 令牌、不动 W8-5 判据**。
主角感靠**版式**而非字号拿到：独占整行 + 上下留白 + `shadow-lg` 重边框 + 与骨架条拉开距离。

**施工约束（判据级，违反即红）**：
- `.tl-text` 必须仍是 `font-size: var(--fs-display)`（W8-1 原样保留）
- **负锚**：全站不许出现 `--fs-hero` 或任何 22px 以上的工作面字号字面量
- W8-5 命中数**不得变化**（仍恰好两处）
- ⚠️ 版式补偿必须真做出来：愿景独占一行、上下留白 ≥32px、卡片 `shadow-lg`。
  **只改字号不改版式 = 没实现**，这是本轮最容易糊弄过去的地方

### D2 ✅ 六舱色相 —— **从 `--accent` 派生六档**

**用户拍板**：不新增 vio/info/amb/stg 四个色系令牌。六个舱用**同一色相的六档明度/饱和度**变化。
- 实现：`color-mix(in srgb, var(--accent) N%, var(--surface))`，N 取六档（如 88/70/52/38/26/16）
- 纪律：四主题各自算档，**文字对比度必须 ≥4.5:1**（过 contrast 硬判据）
- 验收：六舱互相能区分，整体仍读作同一家族——**不能区分与不能统一两头都是不合格**

### D3 ✅ 项目全景 —— **方向台内的第二视图**

**用户拍板**：做成 `viewMode: 'tower' | 'pano'` 切换，**不新建路由、不新建页面文件**。
- 复用同一份 store 数据与折叠状态，数据只取一次
- 视图切换写进 `ui` 偏好（与 `showDone` 同机制，一处切换全台生效）

## 三、回归判据设计（先写判据再施工）

### 必须钉的「结构归属」判据（V3.8.7 教训：判据不能只钉"元素存在"）

| 编号 | 判据 | 钉什么 | 防什么 |
|---|---|---|---|
| W11-1 | 纵向舱序列存在 | `.towers` 是 flex-column；**`.tree-columns-grid` 不存在** | 三列并排复活 |
| W11-2 | 归属轨道容器在位 | `.mgrid::before` 与 `.metric::before/::after` **三条同时存在** | 移植时丢了空容器 div（本项目已踩过） |
| W11-3 | 折叠双向 | 项目与指标的折叠入口**双向可达**（判"收起"字样也在模板里） | 单向门 |
| W11-4 | 焦点唯一 | `fs-display` 全站工作面命中数 == 原值（不多不少） | 焦点契约稀释 |
| W11-5 | 无层级倒置 | 泳道进度数字字号 **< 指标名字号** | 大数压过标题 |
| W11-6 | 空态可见 | 零任务指标占位用 `--surface-3` 且有 `min-height`；**负锚：禁 `heat-0` / 低 alpha** | 亮色主题隐形 |
| W11-7 | 归属完整性 | 骨架条数字由单一聚合函数产出（不散落各处现算） | 两处数字不一致 |
| W11-8 | 全景横向 | `.lanes` 是 flex 横排 + `overflow-x`；**纵向堆叠负锚** | 全景退回纵列 |
| W11-9 | 层级带存在 | `.band` 三段结构 + 箭头 `::after` | 从属关系只靠文字 |
| W11-10 | 过滤联动 | 三处（芯片/目标卡/目录头）都能触发同一过滤函数 | 联动断链 |
| W11-11 | 取数单一 | `tasksForMetric` 在模板内出现次数 **≤ 2**（现 6） | 性能债复发 |
| W11-12 | 主攻次级焦点 | `.is-focused` 旧弱描边规则**不许复活**（W8-4 同款负锚） | cascade 碰巧生效 |
| W11-13 ★ | **版式补偿落地**（D1 配套保险） | 愿景卡 `shadow-lg` + 上下间距 ≥32px + 独占一行；**负锚：全站禁 `--fs-hero`** | 只降字号不做版式 = 变相没实现 |
