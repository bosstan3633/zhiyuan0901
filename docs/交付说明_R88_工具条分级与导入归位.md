## 一、要解决的问题

资源台 / 策展台顶部那一行，已经挤到了 **11 个控件**：

```
① 视图 Tab ×4    ② 排序   ③ 排序方向   ④ 筛选   ⑤ 密度   ⑥ 列数
⑦ 搜索           ⑧ 批量管理            ⑨ 导入   ⑩ 新建   ⑪ ⚙
```

"每次都要用的"（切视图、搜索、新建）和"偶尔才改一次的"（密度、列数、导入、批量）平铺在同一排，**主次不分**。而且这行是被动工自己堆起来的——R72 加了列数选择器、R87 把筛选从 4 档扩到 8 档，越挤。

**W3 要的就是分级**：一级只放每天都用的，把"改看法"的四件（排序 / 筛选 / 密度 / 列数）收进一个「筛选」气泡。

## 三、改了什么

### T1 · W3-①：一级只留五件

```
改前：视图Tab×4｜排序｜方向｜筛选｜密度｜列数｜搜索｜批量｜导入｜新建｜⚙   （11 个）
改后：视图Tab×4 ｜ 🔍搜索 ｜ 🔣筛选 ｜ ＋新建 ｜ ⚙                        （5 个）
      （批量模式激活时临时追加「✓ 完成批量」）
```

- 「＋ 新建」由 `hero-btn ghost` 升为 `hero-btn primary`（一级唯一主色）
- 批量模式激活时 `v-if="batchMode"` 追加「✓ 完成批量」——**退出通道永远可见**

### T2 · W3-②：「筛选」气泡

`.filter-pop` 内四行 + 一个重置：

| 行 | 控件 |
|---|---|
| 排序 | `<select v-model="sortBy">` + 方向按钮（仅 recent/visited 出现） |
| 类型 | `<select v-model="filterBy">`（8 档 2 组，原样搬入） |
| 密度 | `<select v-model="density">` |
| 列数 | `<ColsPicker>` —— **仅卡片视图**（门控挂在**包裹行**上，整行消失，不留一条空标签） |
| 底 | 「重置全部」（四项回默认 + 清空搜索） |

- 关闭复用 `document.addEventListener('click', closeFilterPop)`（与 ⚙ 同处注册，并在 `onUnmounted` 一并摘除）
- **与 ⚙ 互斥**：打开一个就关掉另一个（两个都是浮层，并存只会互相遮挡）

### T3 · W3-③：生效值徽标

`filterSummary` computed 收集**非默认项**：

| 项 | 默认 | 非默认时显示 |
|---|---|---|
| 排序 | `manual` | 档位中文名 |
| 筛选 | `all` | 档位中文名 |
| 密度 | `cozy` | `紧凑` |
| 列数 | `CARD_COLS_DEFAULT.res`（5） | `N 列`（**仅卡片视图计入**） |

- 按钮上**最多 2 枚 chip**，超出显示 `+N`，`title` 给出全量（挤不下时的兜底）
- **全默认时按钮上干干净净**——没有筛选时不喧哗

### T4 · W6：导入收进 ⚙ 并消歧义

- ⚙ 菜单新增「⬇ 导入」，文案 **mode-aware**：`isHub ? '⬇ 导入资源' : '⬇ 导入数据包'`
  - W6 的痛点是**同名不同义**（策展台的"导入"是导入数据包，资源台的"导入"是导入资源）。只改名不区分台身份，仍会有一半场景说错 ⇒ 做成按台分流，从根上消歧义
- ⚙ 菜单同时收进「☑ 批量管理」（**进入**走 ⚙，**退出**留一级）

## 六、建议手测（2 分钟）

1. **资源台 / 策展台**：顶部一行现在只剩 `视图切换 ｜ 🔍搜索 ｜ 🔣筛选 ｜ ＋新建 ｜ ⚙`
2. **点「🔣 筛选」**：气泡展开，含排序 / 类型 / 密度 / 列数四行；点页面别处自动收起

4. **再改密度与列数**：按钮上只显示前两枚 + `+2`，鼠标悬停能看到全部四项

## 八、本轮两个工程判断（值得记住）

### 判断 1 · 浮层定位：相对定位取代 fixed

既有 `.settings-menu` 用 `position: fixed; top:54px; right:28px`，注释理由（避免被 hero 圆角裁剪）**早已失效**——hero 在 R64 就删了。而筛选按钮的宽度会随"生效值徽标"变化（0~2 枚 chip + `+N`），**写死 `right` 算不准**。⇒ 气泡改 `position: relative` 容器 + `absolute`，跟随按钮。已核验父链无 `overflow: hidden`。

### 判断 2 · "收进菜单"不能收走**退出通道**

W3 说一级只留 4 件，照字面把「✓ 完成批量」也收进 ⚙ 是最省事的。但勘验发现 `.batch-bar` 只在"已选中卡"时出现 ⇒ 开了批量却没选卡时，**工具条上的按钮是唯一退路**。⇒ 批量模式激活时在一级临时追加退出按钮。**规格是骨架，可用性是血肉——照字面执行会造出死胡同。**
