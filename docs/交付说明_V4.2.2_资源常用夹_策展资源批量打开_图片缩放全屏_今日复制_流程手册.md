# V4.2.2 交付说明

> 版本：V4.2.2
> 日期：2026-11-11
> 基线：V4.2.1（`main` / `a35c1b9` / 标签 `v4.2.1`）

## 一、交付结论

V4.2.2 恢复并升级资源卡常用夹，新增常用夹与策展台的资源原链批量打开，补齐策展图片在应用内和导出 HTML 中的缩放与沉浸全屏，更新今日三件事复制模板，并把使用手册改为流程优先。

## 二、功能变更

### 1. 资源卡常用夹

- 常用夹数量不限、每夹成员数量不限；同一资源卡可镜像到多个常用夹。
- 分组与成员分表：`resourceFolders` 保存分组，`resourceFolderMirrors` 保存独立快照成员。
- 夹内直接新建、重命名、搜索、多选、添加、逐条移出、删除分组和一键打开全部原链，不需要进入二级成员页。
- 资源池、资源详情和批量栏均提供加入常用夹入口；同一夹内幂等去重。
- 加入、移出或删除常用夹不修改源卡；删除源卡也不级联删除已有镜像快照。

### 2. 常用夹与策展镜像统一生命周期

- 同一资源卡可镜像到不同常用夹、不同策展台和同一策展台的不同节点。
- 每份镜像保存加入时的只读快照，附件纳入统一资产索引、清理和旧数据补水。
- 真身、常用夹镜像、任务资源镜像和策展节点镜像互不级联。

### 3. 策展台批量打开资源

- 策展台行动条新增“打开全部资源 N”。
- 按当前全台资源镜像汇总原始链接；重复 URL 只打开一次。
- 无链接、失效附件和不支持的协议跳过，并在完成回执中说明。
- 超过 15 个可打开链接时先确认；取消不打开任何页面。

### 4. 策展图片浏览

- 应用内图片预览支持同一节点多图左右切换、放大、缩小、重置、拖动和沉浸全屏。
- 键盘支持 `+ / - / 0 / F / Esc`；切换图片和重新打开时复位缩放与位移。
- 导出的自包含 HTML 使用纯 HTML/CSS 提供同一组图库能力，不注入脚本或外部依赖。
- 中心论点关联卡、中心论点附件和分支附件继续可点击查看；旧阅读版、树状版、ZIP 与打印路径保留。

### 5. 今日三件事复制

固定模板：

```text
推进[[项目]]项目，任务，助力【指标】指标落实到位
```

- 每个槽位独立复制。
- 缺少有效项目、成功指标或任务时禁用，并显示具体原因。
- 不生成缺字段的半截句。

### 6. 流程优先使用手册

- 新增“流程篇 · 先看这里（V4.2.2）”，覆盖总流程、Inbox 分流、今日三件事、资源与常用夹、资源镜像、云同步和策展导出。
- 使用产品内 HTML/CSS 流程块，不增加外部运行时。
- 应用内手册和下载分享版继续共用 `manual-data.ts` 单一数据源。

### 7. 云同步与兼容

- 常用夹与镜像关系作为业务数据进入云同步、清单、业务计数、回执和历史。
- 页面布局、抽屉宽度、筛选和常用夹本地选中状态继续只留本机。
- JSON 导入、旧云快照、默认数据和附件恢复对缺失字段安全补水。
