## 一、四条交付明细

### 1.1 M6 · 「更多 N」展开不再撑破网格

`.mgc-projects` 是 flex-wrap 行，展开后全量项目小卡撑高目标卡，而 `.mr-goals-grid` 无 `align-items`（默认 stretch）⇒ 同排邻卡被拉成同样高、内容却顶在头上。修复 = `.mr-goals-grid { align-items: start }` 一行 CSS：**展开只长自己这张卡，邻居保持自然高度**（chips 本就 flex-wrap 自动成行——提案「卡内独立一行 + align-self:start」的落地形态）。零 JS 改动。

### 1.2 M8 · 主航线筛选（与项目总览共用偏好）

- `ovFilter` 留在 CompassShell 持有（D-B 既有本地视图态），**v-model 传入 LighthousePanel**：一处切换两处生效；
- `projectsOf` 叠加状态三分支（stalled/done/active，判定复用 projMeta 预计算，R83 红线）：目标卡的计数/芯片/主攻数**跟随所见**（D-B「所见即所数」口径）；`goalPct` 不受影响（它直算 `dir.projects`，衡量目标本身而非当前视图）；
- 门控与 D-B 同口径（项目数 >12，`toolsGate` prop 单一来源）——**偏离登记 04-48**：M8 原文未写门控；不设门控会造成「主航线有控件、总览没控件却跟着变少」的分裂观感；
- 空态区分「暂无项目」（真没有）vs「无符合当前筛选的项目」（被筛没了，`rawVisibleCount`）。

### 1.3 D-D · 页头主线状态摘要

`.page-head` 面包屑后加 `.mainline-summary`：`X 目标 · Y 项目 · Z 主攻 · W 停滞`。项目/主攻/停滞口径随 showDone（与项目总览 ds 一致）；停滞复用 `projState` 预计算（不在模板里逐项调判定函数，R83 红线）；tabular-nums 防数字跳动。

### 1.4 D-E · 跨区拖拽自动切换 pinned

- 跨区分支：原「toast 拦截」改为**翻 `proj.pinned` → 拖拽卡 splice 进目标区序列 → order 全量规整回写**（拖入置顶区=置顶，拖回全部=取消置顶），toast 改「已置顶（跨区拖入自动切换）」；
- ★ **勘验连带发现（双重锁死）**：`onProjDragOver` 原对跨区目标不 `preventDefault` ⇒ 浏览器不允许 drop ⇒ D-E 只改 onProjDrop 永远触发不了。一并放行（只拦同卡），跨区目标现在有 drag-over 高亮。
