# 交付说明 · V3.9.30 画像年度热力图与策展页头收口

> 日期：2026-10-28
> 基线：V3.9.29（`6279ec6`）
> 性质：体验修复、页头结构对齐与发布包减重；不删除历史版本内容，不改数据模型、策展树结构或四主题令牌。

## 一、本批结论

本批先回仓盘点运行现状，再按已审核原型完成三条收口：

1. **画像年度热力图**：修复“今天”状态类静默失配，今天改用强调色内描边、中心点和月份标签三重识别；年度段压缩纵向节奏，移除重复标题与第二套图例。
2. **策展台页头**：台身份、中心论点主舞台与行动条收进同一个连续页头；金字塔 / 树状切换在普通视图只保留页头一处，画布全屏时补位；分享成果只保留行尾一个主行动。
3. **发布包减重**：消除删除策展台时的重复动态加载；手册 HTML 与 V2 / V3 全量更新日志只在构建期压缩格式，不删正文、不删版本条目。

## 二、问题与根因

### 2.1 今日热力格没有真正高亮

`Heatmap.vue` 用 `cls.join('')` 拼接状态类。今日日期的强度类 `l1` 与状态类 `today` 因此变成 `l1today`，样式选择器与 `aria` 查询都匹配不到；类型检查、构建和普通 DOM 存在性判据都不会报错，属于“元素在、状态没生效”的静默失效。

本批改为空格分隔，并补上 `aria-current="date"`、月份级“今天”标签和独立的内描边 / 中心点样式。

### 2.2 策展台页头仍是拆分结构

旧实现的台身份、中心论点与行动条虽然视觉上相邻，但行动条仍位于 `.ws-head` 之外并带吸附定位；普通视图的画布头又保留一套布局切换，导致“一个动作两个入口”。本批按审核原型把三层收进一个连续容器，并把布局切换归回页头行动条。

### 2.3 包体积增长不能靠盲删

盘点结果：死 CSS `0`、孤儿文件 `0`，无引用的退役组件本来就不会进入 `dist`，删除源码不会减小安装包；历史更新日志仍是产品能力，不能为了压缩体积而删除。因此采用两类真实有效且不损内容的措施：

- 撤销窗口常量改为顶部静态导入，删除删除策展台时对同一模块的二次动态加载。
- 对手册 HTML 与 V2 / V3 更新日志做仅构建期格式压缩，将对象数组收为位置元组，运行时再恢复原有 `ChangelogEntry` 形状。

## 三、实现结果

### 3.1 画像年度段

- 今日格显示强调色内描边与中心点，所在月份同时出现“今天”标签。
- `today`、`sel`、热度等级类互不粘连；今天与手动选中态可叠加且仍可区分。
- 12 个自然月继续全年单行排列；画像内轨道由 `920px` 收紧到 `900px`，月间距、月头、日期格和行距同步压缩。
- 外层重复的“1 年度热力图”标题与第二套色阶图例退役，编号并入热力图自身页头。
- 有效动作、单日峰值、活跃日均、P90 与统计完整起点合并为一行紧凑元数据。

### 3.2 策展台页头

- 连续三层：台身份 → 中心论点主舞台 → 页面级行动条。
- 台身份行保留分类、论据卡、附件与更新时间读数。
- 中心论点卡整卡只负责打开详情，标题、说明与“点击查看论点详情”保持单一阅读层级。
- 行动条按“画布布局 / 读数 / 导入 / 检索与成果”分组；导入继续是一个菜单，分享是行尾唯一主行动。
- 普通视图只有页头一处金字塔 / 树状切换；`CurationMindMap` 内仅在全屏时显示补位入口。

### 3.3 发布包

- 最终解压包：`101` 文件 / `2,208,165 B`，较 V3.9.29 的 `2,214,884 B` 净减 `6,719 B`（`0.30%`）。
- 最大单文件：`285,127 B`，较 V3.9.29 的 `289,291 B` 减少 `4,164 B`。
- ZIP：`759,723 B`，较 V3.9.29 增加 `345 B`（`0.05%`）；原因是本版新增了更新日志与交付内容，构建压缩已抵消大部分新增体积，但不会把 ZIP 增长伪装成下降。
- 发布包仍远低于 `2.25 MiB` 生产包、`900 KiB` ZIP 与 `400 KiB` 单文件预算。
