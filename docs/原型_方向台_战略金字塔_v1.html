设计决策 · 六项

针对旧版四个结构性问题
1
愿景/使命从"平级卡片"升为"页顶唯一主角"
旧版愿景是与项目列同级的一张卡，战略目标只是 8px 徽章，视觉权重完全错位。新版把愿景使命提到 HERO 区，用全页唯一 --fs-hero 34px，往下每层递降：34 → 20 → 17 → 15 → 13 → 12 → 11。字阶本身就是金字塔。
对齐 V3.8.7 已确立的焦点契约：每个工作面只允许一处 display 字号。
2
新增"战略金字塔"架构图，替代左侧数字目录
旧的六层 TOC 只有 1~6 数字，看不出层级关系。新版用六层梯形收敛图，每层带实体计数与英文层级名，配色由上到下递减饱和度——结构本身就是导航。点击任一层，下方画布定位到对应区块。
梯形用 clip-path 实现宽度递增，一行 CSS 即可随容器自适应。
3
项目从"并排列"改为"纵向成舱"
旧版 tree-columns-grid 三列并排，项目间只靠列边界，扫视时容易串行。新版每个项目独占一个圆角舱（--r-card），左侧 4px 专属色条，舱间 40px 大间距。舱内自带项目序号、归属面包屑、进度环、指标数任务数。
项目色相贯穿全舱：舱色条 → 指标连接线 → 任务分叉线，六舱六色，归属一眼可辨。
4
指标升为独立卡，任务内嵌其内
旧版指标只是一行标题加一条竖线，同项目内所有指标的任务混在一条流里。新版每个指标一张独立卡（--r-block），卡内含指标名 / 目标 / 验收说明 / 进度条，任务列表缩进 26px 内嵌，用分叉线从指标轨道分出——"任务属于哪个指标"变成视觉事实而非推断。
呼吸感来源：指标卡间 12px、任务行高 40px、舱内边距 24px，靠留白分层而非靠边框线堆叠。
5
断链显性化：黄标 + 虚线收容区
没有任务的指标打「缺任务」黄标并显示 0/0；无归属任务收进项目底部虚线框「无归属任务 · N 条」。不隐藏、不吞掉——结构自己暴露缺口，用户不必手动排查。
6
双视图：项目塔 / 任务流
「项目塔」是结构视图，回答"我的架构长什么样"；「任务流」是行动视图，一张表列全部 30 条任务并标出所属项目与指标，回答"我现在该干什么"。同一份数据，两种切面。
呼吸感的六条具体做法
·
字阶 9→34px 共 8 级，层与层不同级
旧版层级差异常常只有 1px（14 vs 15），看不出来。新版每层至少跨 1~2 级，缩放截图也能分辨。
·
大间距只在"层与层"出现
战略目标间 40px、项目舱间 64px、指标间 12px、任务间 6px。间距大小直接编码层级差，这是留白的语法。
·
描边极简：只在必要处出现
容器靠 --sh-card 阴影分层，不靠 1px 边框堆叠；指标轨道与任务分叉用 2px 色线，不用虚线不用边框。
·
色彩节制：一个强调色 + 六舱色相 + 三状态色
紫（accent）只用于当前层与关键动作；六舱色相取自既有令牌（accent/vio/info/amb/ok/stg），不新造颜色；状态只用 ok/warn/bad 三色。
·
圆角三档，不多不少
舱 24px / 指标卡 18px / 任务行 14px。同类元素同圆角，一眼看出"谁套着谁"。
·
动效只做"提示"，不做"表演"
160ms + cubic-bezier(.22,.61,.36,1)，仅用于 hover 位移与展开收起，无入场动画、无视差。
落地时需注意的三个坑
!
连接线容器不可省
指标卡左侧的分叉线、归属竖轨都依赖"无内容容器 div"。移植到 Vue 时最容易把这种空容器删掉，元素还在、语义已反（V3.8.7 已踩过一次）。判据要钉"结构归属"而非"元素存在"。
!
亮色主题下低对比底色等于隐形
指标卡用 --surface-2 而非任何低 alpha 色，避免在 notion/apple 上与页底同色读起来像"坏了"。空态要 min-height 兜底。
!
折叠必须双向
项目可折叠、指标可折叠，都要有明确的收起入口。单向门（只给展开不给收起）是已发生过的真实缺陷。

交互指南 · 每一处怎么用

一、战略骨架条（页面上方那一条）
→
点「1 愿景 / 2 使命」→ 回页顶看全页唯一主角
这两个层级是整页的视觉原点。回顶看它们在整条链里的位置；再点一次取消聚焦。
→
点「3 战略目标」→ 展开/收起下方目标芯片行
战略目标是从"定方向"转向"分资源"的分岔点。点它把目标芯片行展开或收起——芯片行是下方项目分组头的同源镜像。
→
点「4 / 5 / 6」→ 滚动到项目塔的第一处对应物并闪一下
点「攻坚项目」滚到第一个项目舱并描边闪烁；点「成功指标」滚到第一张指标卡；点「任务」滚到第一条任务行。让你确认"这层的实体长什么样"。
●
战略目标芯片 → 过滤下方项目塔
点某个目标芯片，下方只留这个目标的项目舱，其余淡出；顶部出现一条筛选态提示条可一键清除。再点"全部"恢复。这是最常用的一次点击。
⚠
「只看断链」→ 只留下有缺口的部分
切到断链模式：无任务的指标保留并高亮、支撑任务未开的任务保留、其他全部隐藏，左侧导航同步收窄。再点恢复。
↗
「无归属任务收容区」→ 跳到虚线框
直接定位到「知识库结构治理」舱底的虚线收容区，那2 条既没挂指标也没进任何指标卡的任务就在那里。
二、项目舱（第 4 层）
▾
舱头右侧 ▾ → 折叠/展开整个项目
折叠的是呈现不是数据——指标数与任务数在舱头常驻，折叠后仍看得见这个项目有多大量。
＋
「＋ 指标」→ 在本项目下新建成功指标
新指标直接落在本舱的指标轨道末端，自动继承项目色相——不需要用户自己选归属。
⚠
「⚠ 断链」→ 报本舱有几处缺口
只在本舱真有缺口时才出现，告诉你"缺任务指标数 + 无归属任务数"。
◷
进度环 → hover 看完成明细
环上数字是本项目全部任务完成占比（跨指标聚合），旁边是「已完成 / 总数」。
▦
舱头面包屑 → 点任一段跳到该层
「愿景 › 使命 › 1 战略目标·名称 › 第 4 层」都可点，逐级回溯定位。
三、成功指标卡（第 5 层）
○
状态点 ○ / ◐ / ✓ → 空 / 进行中 / 已全完成
由该指标下所有任务的状态聚合得出，不必点开就知道这个指标动没动。
▾
「▾ 收起 / ▸ 展开」→ 折叠该指标的任务
指标多的时候用它压缩视线；收起后指标本身、进度、验收说明仍在，不会"消失"。
▥
进度条 → 本指标自己的完成度
与舱头进度环不同：环是项目级，这根条是指标级。数字在条右侧，永不独立成大数（避免层级倒置）。
四、任务行（第 6 层）
☐
方框 → 点一下勾选完成
点了行变灰划线，上方指标点与进度条实时联动。注意完成只改状态，不影响归属。
↳
hover 任务行 → 右侧浮出完整归属路径
平时藏起来保持干净；鼠标移上去才显示「战略目标 › 项目 › 指标」三级路径，专门用来回答"这条到底归谁"。
⚠
黄标「支撑任务（线索未开）」
这条任务本身没做完没关系，它依赖的线索还没打开——先开线索，不算失败。
ABCD
成熟度 A/B/C/D → 就绪 / 可派 / 缺件 / 空壳
规则引擎即时算，零 token、可解释。点它看扣分理由。
五、左侧导航与视图切换
≡
左侧项目导航 → 点击定位、滚动联动高亮
色块即项目色相，与舱左侧色条一一对应。滚动页面时导航自动跟随当前视野所在项目。
⇄
「项目塔 / 任务流」→ 两种切面
项目塔回答"我的架构长什么样"；任务流是 30 条任务的行动表，每行标明所属项目与指标，回答"现在该干什么"。
✦
「✦ AI 建议」→ 只建议不写入
AI 给候选，查重后你点采纳才真正创建。采纳前零写入——AI 不替你决策。
