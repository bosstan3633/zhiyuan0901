# 交付说明 · R68（V2.38.0）搜索口径修复与快捷键体系改造

**发版日期**：2026-09-09 ｜ **版本**：V2.38.0 ｜ **基线**：V2.37.0（1a7cd7d → 本轮待 commit）

## 一、交付内容（F1–F6 全部落地）

### F1 全局搜索「历史版本数据」修复
- **根因**（源码实证）：非缓存陈旧、非存储键错位（两端同读 `zy_data_v2`，onChanged 已实时失效缓存），而是**分组口径漏洞**——
  - 工作台分组：两端均只过滤 `archived`，资源台本体实体（固定 Tab，非台签工作台）与历史遗留工作台混入；
  - 项目分组：网页浮层自认「已完成项目默认呈现」（与新台「显示已完成项目」开关脱节），已完成/归档旧项目混入。
- **修复**：
  - `overlay-impl.ts`：ws 分组加 `w.id !== CURATION_WS_ID`；proj 分组新增 `isProjDone`（对齐 newtab isProjectDone 口径：status done/archived 或全部任务完成派生）+ 读 `zy_ui_v2.showDoneProjects`（onChanged 实时同步）；计数同口径。
  - `GlobalPopups.vue`：wsTree / counts.ws / counts.all 排除资源台本体。
- 用户数据中若仍有个别「旧工作台/旧项目」出现，即为台签栏同样可见的未归档遗留台——右键删除/归档即可两端同步消失。

### F2 任务卡删除按钮深色主题修复（`TaskManagerPanel.vue`）
- 根因：🗑 为单色深灰 emoji + hover opacity 0.6，近黑卡（#141516）上不可见。
- 修复：6 处删除按钮换 `<Icon name="trash">` 主题色线性图标（currentColor），常态 `--text-3`、hover `--tag-danger-bg` 底 + `--danger` 色，hover opacity 0.6→0.85。

### F3 快捷键体系改造
- **goto-tasks**：描述「直达项目调度模块」→「直达任务调度模块」；路由从调度台改**方向台**，anchor='task'，`CompassShell` 新增 `zy-goto-anchor` 监听（与 `?zone=task` 共用 `flashTaskModule`）。
- **open-compass / open-resource 退役**：manifest 下架（设置页命令列表动态拉取自动消失）；background case 保留兜底注释。
- **数字键切台**（应用内，`switchToIndex` 重排）：**Alt+1=方向台、Alt+2=资源台、Alt+3…9=工作台（按台签顺序，拖拽改序后数字键跟随，不绑定具体台）**；调度台为首页不占号。修饰键沿用既有「wsSwitchMod 五选」设置（默认 Alt）。
- 速查面板（? 呼出）应用内条目同步新口径。

### F4 完整方向树深色按钮修复（`CompassTree.vue`）
- 根因：`.node-action` 硬编码不透明白底 + 浅灰图标，近黑画布下图标对比度 ~2.6:1 看不清。
- 修复：主题感知——`var(--surface-3)` 底 + `var(--border)` 发丝线 + `var(--text-2)` 图标；hover 变 accent 蓝底 accent 色。全局扫描无其他高不透明白底残留。

### F5 加载动画美化 + 旧版残留治理（`index.html`）
- 产品名与 Slogan 之间新增薰衣草渐变分隔线（36×2px）建立对齐轴；Slogan 14px→**15.5px**、颜色 #8A8F98→#C6CBD4、字距 0.06em→0.22em（去句号）。
- 旧文案全量扫描：`知源工作台/控制中心/你不缺信息/DHI/策展中心` 源码 **0 命中**（R66 品牌刷新已清干净）；数据层残留归 F1 口径修复治理。

### F6 性能优化（切台/切视图 + 搜索响应）
- **KeepAlive 补方向台**：`include` 三视图→四视图（+`CompassShell`，defineOptions 显式实例名）——调度台↔方向台切台免重挂 LighthousePanel/项目总览/TaskManagerPanel 三面板（切台耗时主体）。
- **拼音字典启动预热**：App 挂载后 `requestIdleCallback` 后台 `ensurePinyin()`（~300KB），首次 Ctrl+K 拼音/首字母搜索零等待。
- 复核：pinyinOf 已有 LRU 缓存（3000 上限）、content 浮层 idle 预取已在位。

## 三、升级注意事项（给用户）
1. 更新扩展后，原「打开方向台/打开资源台」自定义键位自动失效（命令已下架）——改用 **Alt+1 / Alt+2**（默认，可在设置改修饰键）。
2. 「直达任务调度模块」需在 `chrome://extensions/shortcuts` 重新确认键位（原「直达项目调度模块」自动更名，键位保留）。
3. 数字键在调度台页面内生效（浏览器级 Ctrl+1~9 为浏览器保留，无法注册为扩展命令）。
