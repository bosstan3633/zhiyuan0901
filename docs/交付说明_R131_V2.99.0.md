## 一、N1/N2 体验修复

### N1 · 资源台页头 22px 缩进（★推翻 R130-T4「已一致」误判）

**缺陷**：用户截图实证资源台标题仍比调度台/方向台偏左约 22px。R130-T4 只比对了页面容器的 max-width+padding（三台同为 1440+36），**漏了标题层**——主界面三台的标题都包在 `.page-head { padding-left: 22px }` 里（标题左缘 = 36+22 = 58px），而资源台 `.ws-id-head` 直接贴 36px 渲染。

**实现**：`.ws-id-head` padding 改 `4px 0 6px 22px`，标题左缘并入 58px 对齐线；页头下内容区（指标/卡片）仍走 36px 原线不动（与主界面「标题缩进、内容齐边」的版式一致）。

**验证**：本机 dev-server + headless Chrome DOM 实测——资源台/调度台/方向台三页在 1200px 与 1680px 两档视口下标题左缘均为 58px、内容均为 36px，与用户截图比例（62/84≈0.738 vs 理论 36/48=0.75）互证。

### N2 · 项目详情页左侧项目目录（可拖拽）

**实现**（ProjectCuration.vue，独立态 `!embedded` 生效；嵌入资源台弹窗态不渲染目录）：
- **左栏目录**：按方向分组（🎯 方向名 + 近期/中期/远期角标），组内按 order 列项目，每行「主攻圆点 + 项目名 + 完成度%」，当前项目高亮，点击切换（复用 `openProject`，URL `?p=` 同步可分享）。
- **拖拽分栏**：`.pd-split` 把手 `cursor: col-resize`，拖动宽度钳制 180–420px，**双击复位 220px**；落点宽度经 `saveUIPrefs({ projRailW })` 持久化，重开保持。文档级 mousemove/mouseup 随 onUnmounted 摘除（R129-B6 同口径）。
- **右栏**：`.board-layout.with-dir` flex 撑满，`.board { flex:1; min-width:0 }`，粘性目录（sticky top 64px，超高自滚）。

**验证**：headless 实测目录列渲染（x=156 / w=220）、点击切项目（?p 变更 + pc-current 更新）、拖宽 220→260 且落库 UIPrefs、embedded 态无 `.pd-dir`。

## 二、批次 C 性能（本轮落地范围）

### C1a · 保存链路 `isSelfWrite` 退化 O(1)（repository.ts）

原 R70 内容指纹判定每次 storage 回调对整树 `JSON.stringify` 比对（千卡 40–100ms）。改为**写入载荷打 `__wid` 戳**（上下文随机前缀 + 自增序号，saveData/saveDataNow 两路同构），onChanged 只比一个字符串。跨上下文序号独立不碰撞；无 `__wid` 的存量/外部写入一律判外部（保守正确，走合并路径）。`lastSelfWriteJson` 整串比对机制退役。

### C2 · 全局搜索键入链路（GlobalPopups.vue）

- **120ms 防抖**：`searchQueryRaw` 即时回显、`searchQuery` 延迟计算，定时器随卸载清理。
- **面板态短路**：`searchActive` 非搜索面板时 counts/allResults/wsTree 三个大 computed 直接返回空——收藏/投射/快捷键面板打开时不再全库扫三遍。
- **索引 Map 化**：结果组装期 6 处 `Array.find/filter` 热点改 `wsById/catById/projById/projDirName/wsCardCount` 预建 Map（O(n²)→O(n)）；wsTree 卡片计数改 byWs/byCat/childIds 三桶一次成型。
- **装饰-排序-去装饰**：hitRank/markRank 从比较器内（O(n log n) 次重复归一化+拼音匹配）移到排序前一次性算好。

### C3 · 设置页全景树 + 右栏大列表（GlobalSettings.vue）

- **计数 bucket 一次成型**：`panCountByCat/panCountByWs` 原每个树节点全量扫卡（O(分类×卡)，子分类递归再乘）→ `panCounts` computed 一趟建 `ws|cat` 复合键 + 台级两张 Map，建树查表；**ws 复合键保留 R109 F12-a「悬空分类不串计」收紧语义**。
- **flattenPanCats 提 computed**：模板内直调改 `panFlatCats`（panTree/panCollapsed 不变即命中缓存，折叠一次不再全树重算 N 次）。
- **右栏增量渲染**：`PAN_RENDER_STEP=80`，滚动到底 400px 内追加，切台/切分类复位（与主界面 R112 同构）；「已显示 N / M 张」提示行。

### C4 · 任务面板每行重复计算（TaskManagerPanel.vue）

- `projectName/metricName` 原每行在 directions→projects→metrics 三层数组里 `find`（700 任务 × 全项目）→ `projNameById/metricTitleById` 两个 Map computed，O(1) 查表。
- `kanbanGroups(status)` 原模板 6 处调用每次重跑三列分组 → `kanbanMap` computed 一次成型，薄函数保持模板零改动。
- （审计项「tShort 每行 new Intl.DateTimeFormat」复核发现 R112 dateFmtCache 已修复，无行动作。）

### C5 · 事件流水 shallowRef

`wceEvents`（compass store）与 `eventLog`（设置页操作记录）均为**整组替换、只读消费**——`ref` 曾为最多 5000 条事件逐条建响应式 Proxy，改 `shallowRef` 赋值即触发，语义不变。

### C6 · 启动链路

- **C6a 拼音预热退役**（App.vue）：每开一个新标签页都 idle 后台拉 ~312KB 字典，与「按需加载」口径相悖 → 删除启动预热，字典纯按需动态 import（搜索面板打开时 `ensurePinyin` / 网页浮层唤起时加载 / `pinyinReady` 就绪自动补跑拼音命中——V2.21 既有机制，首屏与多标签页内存不再为预热买单）。
- **C6b 迁移链单次落盘**（stores/app.ts）：init 三段存量迁移/清理原各自 `saveData()`（300ms 防抖会合并但依赖时序巧合）→ 统一 `migrated` 累积标记，链尾真改动才落 1 次盘；「无改动启动」依旧零写入。
