| F4 | **镜像卡需要：单击开详情（只读）/ 双击开链接 / Ctrl+Enter 定位回源卡** | 原单击只弹阻断 toast | 内联抽屉加只读模式：`.dr-readonly`（表单 pointer-events 关闭 + banner 提示 + footer 换「📍 定位到资源台编辑」）；Ctrl+Enter 在只读期 = 定位源卡（document 捕获，焦点在 body 也生效）；`saveResource` 加只读守卫（防 Tab 聚焦写穿）；定位走 `/curation?hl=<源卡id>`（镜像 id 即源卡 id） |
