## 一、问题：主攻是显式分配的注意力，却看不见、也动不了

方向台首屏在 R83 调完信息密度后长这样：

```
┌──────────────────────────────────────────────────────────┐
│ 愿景 让每一位规划师…（单行） │ 使命 …      │ 进入方向树 › │  ← 锚点条（R83）
└──────────────────────────────────────────────────────────┘
┌─ 目标：客户洞察 ───────────────┐ ┌─ 目标：产品重构 ────────────┐
│ 项目 3（主攻 1）  中期   45%ⓘ  │ │ 项目 2（主攻 1）  远期  12%ⓘ │
│ [🎯 客户洞察] [年度规划 停滞]   │ │ [🎯 产品重构]               │  ← 🎯 散在各目标卡里
└──────────────────────────────┘ └───────────────────────────┘
```

**两个问题，都不是"不好看"，是"做不到"：**

1. **主攻没有一览。** 主攻是你显式分配的注意力，是最该一眼看到的东西——但它只以一个小 🎯 标记散落在**各自目标卡内的小卡上**，**跨目标的一览根本不存在**。想看清"我现在押注在哪两件事上"，得自己一张张卡扫过去。
2. **主航线上什么都做不了。** 项目小卡只能整卡点击进详情；想新建个项目，得跑去项目总览或完整方向树；想设主攻，得打开项目详情。主航线是**纯展示**的。

**而最讽刺的是**：数据层早就备好了 `focusedProjects`（含归档过滤），**全代码库零消费**——算好了没人用。

### T0-A · 主攻上限校验下沉（前置修复）

```ts
export const FOCUS_PROJECT_LIMIT = 2

function toggleFocusProject(projectId: string): { ok: boolean; msg: string } {
  const p = projectById(projectId)
  if (!p) return { ok: false, msg: '项目不存在' }
  if (!p.isFocused) {
    const others = allProjects().filter(x => x.isFocused && x.id !== p.id)
    if (others.length >= FOCUS_PROJECT_LIMIT) {
      return { ok: false, msg: `主攻项目最多 ${FOCUS_PROJECT_LIMIT} 个，请先取消其他主攻` }
    }
  }
  p.isFocused = !p.isFocused
  store.persist()
  return { ok: true, msg: p.isFocused ? '🎯 已设为主攻' : '已取消主攻' }
}
```

- **返回结构化结果，由调用方 toast**——store 是数据层，不碰 UI；
- 三处入口（方向树 / 项目策展页 / 主航线）同一口径；方向树**此前无任何提示**，现在补上；项目策展页保留原文案「🎯 已设为主攻，**同步今日行动**」（这个信息不丢）；
- ⚠ **存量已超 2 个的用户不受阻断**：超限只拒绝**新增**，取消与查看一律正常，**不强制裁剪**（避免丢掉用户已经分配好的注意力）。

### T0-B · `addProjectToDir` 共享函数（前置修复）

四处出口改调它，字段以 `CompassShell` 的既有口径为准（最完整）。`dir.projects.push` **全项目收敛到唯一一处**。
⚠ `CompassTree` 的硬编码名「新攻坚项目」**保留**（既有行为，改名属范围外）；`pinned`/`order` 补齐后，方向树新建项目的位置会变（从永远最后 → 按创建顺序）——**这是修 bug**。

### M4 · 主攻聚焦条

- 数据源就是**既有的 `focusedProjects`**（已过滤 `archived`），没另写一份；
- 每项 🎯 + 名字 + `pct%`，**点击直达项目详情**；进度走 `projMeta` 索引（R83 性能红线）；
- **不受 `showDone` 节制**：已完成的主攻也应能看到并**从聚焦条取消掉**，只 `opacity: .55`（对齐 `.chip-proj.done`）；
- 无主攻 → 一行轻引导，**把「最多 2 个」写在上面**——而不是等你点下去才被拒。

### M5 · 就地可操作

**① `＋ 新建项目`（预选该目标）**：点一下 → 卡底出现内联输入框（自动聚焦）→ 回车创建、Esc / 失焦取消。
**不弹窗**——弹窗是"管理"，内联是"预置"，且省掉一次与父组件 `CompassShell` 的跨组件通信。与 chips **同排**，零额外行高。

**② 项目小卡 hover 两动作**：`🎯 设为主攻/取消` + `› 进详情`。常态 `display: none` **零占位**（名字照常占满整行），hover 才 flex；`@click.stop` 防冒泡——否则点 🎯 会顺带跳详情页。

**③ 目标卡 hover `⋯`** = 去完整方向树。**不做目标管理菜单**：`CompassTree` 已有完整的目标级操作，不造第二套。
（原文未定义 `⋯` 的动作集；且方向树不监听定位事件，为它新造一套定位机制属范围外。）
