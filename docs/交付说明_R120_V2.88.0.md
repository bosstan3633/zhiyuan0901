## 五、偏差与说明（3 条）

1. **项目调度折叠态宽度**：原型在任务树收起时左面板固定 340px（右侧留空）；本项目沿用既有交互（收起时左栏占满、展开后与原型一致）——**不改交互**的既定约束优先，避免为了留白牺牲可用空间。
2. **图标细节**：三件事模块仍用产品既有图标（火焰），未替换为原型字符（★）；项目调度头部同理。属可选微调，如需完全一致可下一轮统一。
3. **`?hl=` 消费后清 query**：定位后地址栏会清掉 `hl/hk/cat`（既有消费端行为，用于防重复触发）；"是否定位成功"由**目标卡高亮**判定，真机验证已按此口径通过。
