## 0. 开发原则

1. **不重写已有能力**：`TaskManagerPanel`、`TopicManagerPanel`、`CuriosityPanel`、`PoolCardsPanel` 已有大量现役能力，优先抽共用、加宿主，不复制模板。
2. **所有计划日期只走一个写入入口**：先建 `scheduleCardDate()`，再逐处替换直接写 `dueDate`。否则安排历程一定漏记。
3. **先对齐再退役**：`/deck/task` 的能力多于一级任务页；先补齐批量、AI、删除、分组、看板等，再做重定向。
4. **URL 是唯一状态源**：一级卡片池的 tab/view/quick/group/sort/highlight 全部进 query，避免刷新丢失、深链分裂。
5. **删除用墓碑**：安排历程的“手动删减”写 `removedAt`，不物理删除；否则云同步会把删掉的时间点并回来。
6. **口径单一**：项目弹窗、项目导出、项目全景共用 `buildProjectTree()`；任务/选题计数只允许一套过滤函数。
7. **先功能后美化**：F6 页头与 F5 弹窗先完成信息结构，再调间距、阴影、主题对比度。
8. **旧链接不 404**：`/deck/*` 至少保留一个版本的重定向；老深链、书签、background 快捷命令都要继续可用。

- `v2/src/content/overlay-search.ts` 的“加入今日三件事”

**判定规则**：

- `date` 为空 → 只清当前 `dueDate`，不记事件；
- `date === 当前 dueDate` → 不记事件；
- `date` 与当前不同 → 记一条，`fromDate=旧值`；
- 系统每日自动推荐写入 → 不记事件；
- 用户点“设为今日重点”/采纳 AI → 记事件，来源分别为 `focus` / `ai-adopt`。

**重点改造**：`focusSuggest.ts` 的 `syncFocusTasksToSchedule()` 同时被自动推荐与手动“今日重点”调用，必须新增 `source: 'auto' | 'focus'` 参数；`auto` 只写 `dueDate`，`focus` 才调用 `scheduleCardDate()` 记账。`addManualFocus()` / `addManualTopicFocus()` 的所有成功分支显式传 `focus`，否则会出现“自动推荐刷历史”或“手动重点漏历史”。

## 5. 风险与对策

| 风险 | 表现 | 对策 |
|---|---|---|
| **二级页退役丢能力** | 用户找不到批量、AI、删除、打开链接 | 先做 T2-5 / T4-5 / T5-3 能力矩阵，再开重定向 |
| **重定向打乒乓** | `/deck/task` → `/?tab=task`，首页又把 `?hl&hk=task` → `/deck/task` | T9-0 先拆反向跳转，再做 T9-1；回归里断言最终 URL 不再回到 `/deck/*` |
| **计划历程漏记** | 只有详情里的安排有历史，日历拖拽没有 | E1 先建唯一入口；静态负锚禁止直接写 `dueDate` |
| **历史被云同步并回来** | 删除某条后另一台设备又出现 | 独立事件表 + `removedAt` 墓碑；三路合并按 id |
| **历史被自动推荐刷屏** | 每天首次打开都多一条 | 系统自动写入不记事件；只记用户主动安排 |
| **项目弹窗选题缺失/重复** | `metric.topicIds` 与 `topic.metricId` 不一致 | `buildProjectTree()` 双写合并去重；补一致性校验 |
| **嵌套抽屉层级混乱** | 全部资源抽屉里再开详情/镜像，Esc 关闭错层 | 统一 z-index 栈与 `useOverlayTarget`；逐层测试 |
| **看板性能** | 200+ 任务一次渲染卡顿 | 复用现有增量渲染/分页；看板列内限额 |
| **全局搜索定位时机** | 全景尚未挂载就滚动，报“任务不在项目” | 复用 `onListLocate` 现有等待/重试循环，不另写 |
| **页头重排破坏分享** | 分享按钮被挤到第二行或变弱 | 分享固定右上主按钮；窄屏也第一优先 |
| **范围蔓延** | 项目弹窗改完又改项目塔/全景 | 按非目标清单冻结；项目塔/全景只复用取数，不重排 |

## 6. Definition of Done

每个任务完成必须同时满足：

1. **功能**：验收项逐条通过，含空态、异常态、旧数据；
2. **数据**：不产生第二份计划日期；不丢历史；删除可撤销/墓碑可同步；
3. **路由**：新深链可进、旧深链可回、刷新不丢；
4. **视觉**：四主题 + 1440/1200/1024/800 截图走查；
5. **可访问性**：键盘可达、Esc 可关、焦点回归、按钮 ≥28px 热区；
6. **回归**：新增断言入对应分片；旧断言重指不删；`node scripts/regression.cjs` 全绿；
7. **文档**：手册、changelog、交付说明与代码同口径；
8. **性能**：200+ 任务 / 200+ 资源 / 1000+ 历史事件下无明显长任务。
