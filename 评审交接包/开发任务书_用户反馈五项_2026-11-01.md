## 批次 C · 拖拽（F4 跨指标 + 排序）

### C1 排序键统一（前置，无此拖拽排序不可见）
- `src/newtab/views/compassMeta.ts` `dedupeSorted`：排序键 createdAt → **`metric.taskIds` 轨道序**（在轨者按数组下标，不在轨者按 createdAt 兜底排尾部）——塔/全景/展板三处顺序从此同源；如遇旧锚改钉「重指而非删除」
- 展板树已按 taskIds 渲染，此改动对展板零影响

### C2 共享拖拽组合式（新建 `src/newtab/views/useTaskRelocationDnd.ts`）
- 状态：`dragTask` / `dropTip`（t/b/in 落点提示），模块内局部变量同展板形态
- 数据口径（照抄 `treeTaskDropOnMetric`，含双写）：
  - **同指标排序**：目标行 t/b → `metric.taskIds` splice（只动顺序，不触归属）
  - **跨指标**（同项目）：`t.metricId = 目标` + 双侧 `taskIds` 更新（旧轨摘除、新轨落位）+ `t.updatedAt` + persist + toast「任务已归属『指标名』」
  - **越界拒绝**：目标指标属其他项目 → 不投放 + toast 说明（拍板：不做跨项目）
  - **收容道/空泳道**：in 模式 = 追加到该指标尾部（双写）
- 渲染 computed 零原地 `.sort()`（红线 #4）

### C3 接线（两条链路，均为既有 emit 透传模式的加线）
- 全景：`CompassPanoLane`（`.ltask` draggable + 行 t/b/泳道 in 落点）→ `CompassPano` → `CompassTree`
- 塔：`CompassLane`（`.tk-row` draggable + 落点）→ `CompassTower` → `CompassTree`
- 两链共用 C2 同一实例状态，视觉落点用展板 `dropOn` 同款令牌

## 批次 D · 导出（F5 项目全景 + 详情弹窗）

### D1 生成器（新建 `src/shared/utils/projectExport.ts`）
- `buildProjectExportDocument(d, project, now)`：项目头（名/战略目标链/主攻/下一步/进度/断链警示）→ 指标 ×N（验收标准/期限/进度/⚠缺任务）→ 任务 ×N 按 `metric.taskIds` 分组（标题/优先级/状态/子任务清单/任务链接）→ 支撑资源（`SupportLink` → 资源卡标题+链接，`safeExportLink` 标注不可用）
