## 批 A · F1 方向台策展模式

### A1 全屏二级页面（★拍板定稿：用户 2026-11-01「第三视图模式可以，但要全屏、可为二级页面」）
- 路由新增 `/compass/curation`（name `compass-curation`，懒加载，meta 标题「知源调度台 · 策展模式」）；**不改 `viewMode` 类型**（W11 系锚零触碰）
- 入口：方向台左栏 `.view-seg` 第三按钮「策展模式」→ `router.push('/compass/curation')`；页内左上「← 方向台」返回
- 页头行为：只读操作（返回 / 布局切换 / 折叠展开 / 导出），无任何编辑动作

### A2 策展渲染器（新组件树，全部 ≤400 行）
- 新 `views/CompassCurationView.vue`（宿主：读 compassMeta + tasks，装配树模型）：
  - **树状布局**（默认）：自上而下 愿景/使命 → 战略目标 → 项目 → 指标 → 任务，纵向卡片链 + 连接线，页面上下滑动通览；
  - **金字塔布局**：愿景居顶、逐层收窄的塔形总览（同数据第二投影）；
  - 布局切换：页头分段控件 `setLayout('tree' | 'pyramid')`（策展台同款语言）；
  - 节点卡视觉复用 CurationMindNode 语汇（发丝线、令牌色、状态色：done=success / doing=accent / 停滞=warning / 缺任务=虚线警示）；
  - 每层节点可折叠；页头「全部展开 / 一键折叠至目标层」双动作；
- 树模型构建器抽 `views/compassCurationModel.ts`（纯函数：`buildCurationTree(d) → 节点树`，供渲染与导出共用——**渲染与导出同源，防两套口径漂移**）

### A3 只读详情抽屉（新 `components/compass/CurationReadDrawer.vue`）
- 单一抽屉六形态（愿景/使命/目标/项目/指标/任务），分区呈现：任务含状态/优先级/链接（可点）/完成时间；指标含验收/目标日/进度/缺任务警示；项目含进度/主攻/状态/停滞；
- 底部固定「去方向台编辑 ›」（router 导流）；**全抽屉零编辑控件、零 persist**（判据负锚）

### A4 全树导出（新 `shared/utils/compassExport.ts`）
- `buildCompassExportDocument(d, now)`：树模型（A2 同源 builder）→ 结构化文档：愿景/使命原文 → 目标（期限/读数）→ 项目（进度/主攻/状态/停滞警示）→ 指标（验收/目标日/进度/⚠缺任务）→ 任务（状态/优先级/成熟度/链接/完成时间）；
- `compassExportMarkdown(doc)` / `compassExportHtml(doc, theme=readExportTheme())`：MD 链接 `[标题](url)` 可投喂 AI；HTML 自包含、主题跟随、`safeExportLink` 标注不可用链接；附件不嵌本体；
- 页头 ExportMenu（MD/HTML 双选，与项目导出同款）；文件名 `知源_方向树全景_…_日期`；
- **复用同源断言**：渲染 builder 与导出 builder 必须同一模块（防漂移判据）。

### A5 门禁（批 A 新增判据方向）
- 三态切换 + 三按钮常驻；策展模式零写库负锚；六层投影完整性（节点数=compassMeta 聚合）；折叠双动作；导出双格式/链接真 href/主题跟随/同源断言；新组件行数 ≤400；六主题走查 + 1024/800 断点截图。

## 批 B · F2 手册官网化

### B1 内容重构（`manual-data.ts` 五篇重写）
- 篇一 **认识知源**（WHAT IS OWNWAY）：它是什么/给谁用/四价值（收录·对齐·调用·策展）；
- 篇二 **收录与三卡**（WHAT YOU CAN DO 上半）：三键采集、三卡、卡池；
- 篇三 **方向与行动**：六层思维链、今日三件事、项目与指标；
- 篇四 **调用与策展**：Ctrl+K、策展台、导出分享（含 V3.9.31/32 新导出能力）；
- 篇五 **信任与 FAQ**（TRUST & FAQ）：本地存储/AI 只给建议/指标不制造焦虑 + 常见问题 + 快捷键附录；
- 每篇：英文眉题 + 中文大标题 + 一句副题；操作流程 STEP 卡；价值节用「你卡在哪 → 知源怎么接住 → 之后你能看见什么」三段卡；每篇 ≥1 张真实截图（`宣传片/shots/`）+ 一行图注；
- 事实源=母版/PRD；红线沿用 02-13（不出现「掌控/永不迷失/效率翻倍」，不打焦虑）。

### B2 官网化样式（`ManualPage.vue` + 样式）
- 新组件样式：眉题（letter-spacing 小字）、大标题层级、三段卡、STEP 卡、截图框注、FAQ 手风琴；全部 tokens.css 令牌、六主题走查；
- 保留：滚动目录 + IntersectionObserver 联动 + 分享版 HTML 下载（样式随新风格）；
- 旧锚重指备案（R46-10/R50-7 等）；新分片：五篇结构 + 组件存在性 + 截图路径在库 + 违禁词负锚。
