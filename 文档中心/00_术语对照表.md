## 九、易混淆概念

| 概念 A | 概念 B | 区别 |
|--------|--------|------|
| 资源卡池 | 策展台 | 卡池=平铺管理；策展=金字塔结构化组织。★**资源卡池不是路由**，是虚拟 workspace `zy-curation`，经 ⌘K / 底部 Tab / 采集浮层进入 |
| 方向台 | 调度台 | 方向台=方向管理+指标（`/compass` → `CompassTree.vue`）；调度台=首页+今日任务（`/` → `CompassHome.vue`） |
| 策展台 | 单台详情 | 策展台=项目级金字塔（`/compass/projects`）；单台详情=某个策展台内部（`/workspace/:id`）。★`/curation` 是 redirect 到 `/`，不是策展台 |
| 任务调度 | 任务卡 | 任务调度=三张卡 tab（含任务卡）；任务卡=单张卡 |
| 软删 | purge | 软删=可恢复；purge=永久删除 |
| 采纳 | 保存 | 采纳=接受 AI 建议；保存=手动编辑写入 |
| SupportLink | 挂载 | SupportLink=独立记录（现行）；挂载=卡间引用（已退役） |
| 概览条 | 全年网格 | 概览条=近 26 周压缩呈现（调度台首屏默认）；全年网格=366 格完整年视图（「看全年 ›」展开态）。★折叠的是呈现不是数据 |
