# 05-2 · 本地数据架构

> 对象：研发 ｜ 权威源：`docs/技术架构与数据模型.md` + `v2/src/shared/storage/repository.ts`。本文给结构、红线与并发语义。

## 存储键
| 键 | 内容 |
|---|---|
| `zy_data_v2` | AppData 单根 JSON（全部业务数据） |
| `zy_ui_v2` | UIPrefs（主题/密度/sortPrefs/curSplit/showDoneProjects…） |
| `zy_capture_pref` | 采集默认工作台等偏好 |
| `zy_event_log` | 事件日志（快照 diff 产出，5000 条滚动） |
| `zy_file_paths` | 附件落盘路径记忆（不进主 JSON） |
| `lm_data_v5(_backup)` | V1 迁移源/备份 |

## AppData 骨架
version=2 ｜ compass(vision/mission/directions[].projects[].metrics[]) ｜ workspaces[] ｜ categories[]（≤2 级，策展分类同构含 curFrom）｜ resources[] / tasks[] / curiosities[]（三卡）｜ dailyFocus[日期→≤3 槽] ｜ tagTree[]（≤3 级）｜ fieldConfig（三卡字段目录）｜ stats(wrr…) ｜ curationProjections[] ｜ activityLogs（已退役）。

## 红线（违反即返工）
1. 版本号唯一来源 `manifest.ts`（5 处同步）；
2. **单向挂载**：仅 TaskCard 持有 mountedResourceIds/mountedCuriosityIds；Resource/Curiosity/TagNode 禁止 taskId（fromCuriosityId 为卡→好奇引用，允许）；
3. **删除一律软删**（deletedAt→回收站；工作台删除也软删卡片，恢复时孤卡回落）；
4. 排序 computed 禁止原地 `.sort()`（拖拽序回写 curOrder/sortOrder）；
5. 样式只用令牌；定位不走 tabs.query 的 hash（zy-where 询问）。

## 读写与并发语义（R58）
- 写：组件改 reactive 树 → persist() → 300ms 防抖 → JSON 纯净清洗 → storage.set → dataVersion++ → 存储镜像刷新。
- 外部写入到达：无未落盘修改 → 整树替换（快路径）；**有** → `mergeExternalData`：卡片按 id+updatedAt LWW（平手取本地，保护输入中表单）、dailyFocus 槽级合并、其余段"本页动过留本页"；合并结果与外部全等不回写（断回声写环）。
- 自身写入回环由 isSelfWrite 时间戳抑制。

## 迁移
loadData 内自愈式迁移（补默认/归一化/一次性回填），重大结构变更走 `migration.ts`；导入=版本校验（version===2）+并集合并（同 ID 更新）+导入前自动备份。
