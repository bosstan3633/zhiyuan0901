# 05-2 · 本地数据架构

> 对象：研发 ｜ **最终事实源：源码 `v2/src/shared/models/index.ts`（AppData 定义）与 `v2/src/shared/storage/repository.ts`**；`docs/技术架构与数据模型.md` 为过程文档、部分细节滞后，引用前回源码核对。

## 存储键
| 键 | 内容 |
|---|---|
| `zy_data_v2` | AppData 单根 JSON（全部业务数据，主数据唯一来源，已申请 `unlimitedStorage`） |
| `zy_ui_v2` | UIPrefs（主题/密度/sortPrefs/curSplit/showDoneProjects…） |
| `zy_event_log` | 事件日志（快照 diff 产出，5000 条滚动保留，独立键） |
| `zy_capture_pref` | 采集偏好（默认落点工作台 id + 自动取文件夹名）；采集入口默认落资源台·待分类 |
| `zy_file_paths` | 附件落盘路径记忆（不进主 JSON） |
| `lm_data_v5(_backup)` | V1 迁移源/备份 |

## IndexedDB
- 库名 `zy_assets`，objectStore `assets`；key = `assetId`，value = Blob，单文件 ≤20MB；Blob 绝不进 `zy_data_v2` 主 JSON。

## AppData 骨架
version=2 ｜ compass(vision/mission/directions[].projects[].metrics[]) ｜ workspaces[]（代码实体名仍为 Workspace，对外称"策展台"，其中含固定的资源台实体）｜ categories[]（树状递归分类）｜ resources[] / tasks[] / curiosities[]（三卡）｜ dailyFocus[日期→≤3 槽] ｜ tagTree[]（≤3 级）｜ fieldConfig（三卡字段目录）｜ stats(wrr…) ｜ curationProjections[]（镜像投射清单）｜ airtableSync / airtableMap（单向同步状态与卡 id↔recordId 映射）｜ hubMigratedAt / hubMergedAt（一次性迁移幂等标记）｜ projBackfillFixed（存量回填计数）｜ activityLogs（已无写入方，字段保留）。

## 红线（违反即返工）
1. 版本号唯一来源 `manifest.ts`（5 处同步）；
2. **卡间零挂载**（R165）：三卡互不持有对方 id（R162/R165 两批退役完毕）；六层归属（projectId/metricId）与策展台镜像不受限（fromCuriosityId 为卡→好奇溯源引用，允许）；
3. **删除一律软删**（deletedAt→回收站；策展台删除也软删卡片，恢复时孤卡回落）；
4. 排序 computed 禁止原地 `.sort()`（拖拽序回写 curOrder/sortOrder）；
5. 样式只用令牌；定位不走 tabs.query 的 hash（zy-where 询问）。

## 读写与并发语义（R58）
- 写：组件改 reactive 树 → persist() → 300ms 防抖 → JSON 纯净清洗 → storage.set → dataVersion++ → 存储镜像刷新。
- 外部写入到达：无未落盘修改 → 整树替换（快路径）；**有** → `mergeExternalData`：卡片按 id+updatedAt LWW（平手取本地，保护输入中表单）、dailyFocus 槽级合并、其余段"本页动过留本页"；合并结果与外部全等不回写（断回声写环）。
- 自身写入回环由 isSelfWrite 时间戳抑制。

## 迁移
loadData 内自愈式迁移（补默认/归一化/一次性回填），重大结构变更走 `migration.ts`；导入=版本校验（version===2）+并集合并（同 ID 更新）+导入前自动备份（迁移前自动备份下载 JSON）。并发写入由 R58 合并层（`mergeExternalData`）保护：有未落盘修改按 id+updatedAt LWW 合并，合并结果与外部全等不回写（断回声写环）。

## 云端同步数据流（可选 · 邀请制 Supabase，V4 起）
- **本机是真源；云端是用户主动上传的快照副本，非自动同步**。入口：设置 → 数据管理 → 云同步（`cloud/sync.ts`）。
- 主动登录邀请账号（`login(email, password)`）后，**手动触发** `uploadNow`（上传到云端）/ `downloadNow`（从云端恢复）；覆盖卡片池 / 调度台 / 方向台 / 策展台 / 界面偏好与「今日三件事」指纹。
- 快照指纹 `fingerprintSnapshot` + 修订号 `revision`；启动后非阻塞 `checkRemote` 比对，**两端均有改动时绝不静默覆盖**（先显式提示二次确认）。
- 普通卡片附件与 AI 凭据**不上云**；策展节点附件（图像/HTML/PDF）登录后经 `uploadCurationAsset` 进入用户私有 Supabase Storage（`setCurationAssetSyncEnabled` 可关闭），跨设备按需下载。
- 历史遗留：V3.9 及更早的 Airtable 单向推送（`sync-airtable` 命令、`airtableMap`/`cursorAt`）已随 V4 正式退役并从快照中剥离（见 `sync.ts` 清理逻辑）。
