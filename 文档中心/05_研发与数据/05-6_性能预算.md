# 05-6 · 性能预算

> 对象：研发 ｜ 度量工具：`scripts/perf-longtask.cjs`（PerformanceObserver longtask，2000 卡压测），实测基线见 V2.38.0 交付说明。预算超限=回归门禁失败。

| 度量 | 预算 | 现状 |
|---|---|---|
| 新标签页首屏（启动→可交互） | ≤1s（本地 SSD 常规库） | 达标（554KB→247KB，↓54%；平行加载+动态拼音） |
| 每帧加载体积 | — | 341KB→2.9KB（↓99%，content script 拆分 + 动态 import） |
| 主入口 chunk | — | 198KB（路由级懒加载） |
| 切台耗时 | — | KeepAlive 四主视图免重挂载（基线 595ms 优化） |
| 搜索响应（ keystroke→结果） | 感知即时（<100ms 常规库） | 达标（内存过滤+动态拼音预热 requestIdleCallback） |
| 调出全程（Ctrl+K→新标签打开） | ≤3s 含网络 | 达标（网络时间除外） |
| 长任务（>50ms） | 常规路径 0 帧；压测挂载允许 ≤1 帧 | 2000 卡 A/B 实测达标 |
| 大库渲染（2000+ 卡策展台） | 滚动/切换无卡顿 | content-visibility 达标；虚拟滚动为后续项 |
| 附件读写 | 20MB 上传不冻结 UI | IndexedDB 异步达标 |
| 导入导出 | 10MB JSON 秒级；不丢数据 | 达标（导入前自动备份） |
| persist 写入 | 9ms@100KB 级；防抖 300ms | 达标 |
| 动画 | 界面态切换 ≤150ms；常驻呼吸动画禁止（R56 移除） | 达标 |

构建产物：dist **47 文件 / 1.4M**（V2.38.0）。

治理规则：新增功能若引入 >50ms 长任务，须附打点数据与优化方案方可合入；性能退化按 P1 缺陷处理（见 06-3）。
