# 05-3 · 领域模型与数据字典

> 对象：研发/测试 ｜ 权威源：`v2/src/shared/models/index.ts`（唯一规范来源）。本文列常用字段与语义，未列字段以模型文件为准。

## ID 前缀约定
res-（资源）tk-（任务）cur-（好奇）cat-（分类）proj_/met-（项目/指标，uid 生成）curp-（策展投射）ws-（工作台）rc-（convertCard 资源）。

## ResourceCard（节选）
id/kind='resource'/title/linkType('url'|'file'|'obsidian')/link/workspaceId/categoryId/tags[]/pinned/starred/callCount/lastCalledAt/curOrder/deletedAt/customFields/assets[]/fromCuriosityId?/mountedResourceIds✗（禁）。

## TaskCard（节选）
id/kind='task'/title/status('todo'|'doing'|'done')/priority/projectId?/metricId?/mountedResourceIds[]/mountedCuriosityIds[]/completedAt?/callCount?/lastCalledAt?/sortOrder?/fromCuriosityId?/deletedAt?。

## CuriosityCard
id/kind='curiosity'/question/status('todo'|'doing'|'done'|'shelf')/sourceUrl?/sourceTitle?/tags[]/sortOrder?/deletedAt?。

## Project / Metric / Direction
Project：id/name/isFocused(主攻)/pinnedToLighthouse(投射)/progress/status/order/metrics[]；Metric：id/title/taskIds[]/target?；Direction：id/name/term('short'|'mid'|'long')/status/projects[]。

## CurationProjection
id/kind('card'|'category'|'workspace')/wsId/cardId?/catId?/targetCatId?（空=待分类）/curOrder?/addedAt；镜像分类=Category.curFrom{wsId,catId,projId}。

## FocusSlot（dailyFocus 值）
id/sourceType('task')/sourceId/text/done/doneAt?；每日 ≤3 槽。

## 状态与派生口径
任务完成唯一出口 setTaskStatusOf；isProjectDone=手动 done/archived 或全任务完成派生；未归档=taskArchiveIssue（未挂项目/指标或引用失效）；WCE=激活好奇+fromCuriosityId 转化卡数；WRR 记录唯一入口 recordResourceOpen。
