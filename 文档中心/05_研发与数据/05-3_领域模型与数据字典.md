# 05-3 · 领域模型与数据字典

> 对象：研发/测试 ｜ 权威源：`v2/src/shared/models/index.ts`（唯一规范来源）。本文列常用字段与语义，未列字段以模型文件为准。

## ID 前缀约定
res-（资源）tk-（任务）cur-（好奇）cat-（分类）proj_/met-（项目/指标，uid 生成）curp-（策展投射）ws-（策展台）rc-（convertCard 资源）。

## 固定台面实体
- **资源台**：唯一资源卡存储与镜像源头，代码常量 `CURATION_WS_ID`（原「策展中心」）；路由路径仍为 `/curation`。
- **策展台（原「工作台」；代码实体 `Workspace`）**：用户自建金字塔策展空间，可镜像资源台卡；旧「工作台」实体已归一删除（幂等标记 `hubMergedAt`）。

## ResourceCard（节选）
id/kind='resource'/title/linkType('url'|'file'|'obsidian')/link/workspaceId/categoryId/tags[]/pinned/starred/callCount/lastCalledAt/curOrder/deletedAt/customFields/assets[]/fromCuriosityId?/mountedResourceIds✗（禁）。

## TaskCard（节选）
id/kind='task'/title/status('todo'|'doing'|'done')/priority/projectId?/metricId?/completedAt?/callCount?/lastCalledAt?/sortOrder?/fromCuriosityId?/deletedAt?。

## CuriosityCard
id/kind='curiosity'/question/status('todo'|'doing'|'done'|'shelf')/sourceUrl?/sourceTitle?/tags[]/sortOrder?/deletedAt?。

## Project / Metric / Direction
Project：id/name/isFocused(主攻)/pinnedToLighthouse(投射)/progress/status/order/metrics[]；Metric：id/title/taskIds[]/target?；Direction：id/name/term('short'|'mid'|'long')/status/projects[]。

## CurationProjection
id/kind('card'|'category'|'workspace')/wsId/cardId?/catId?/targetCatId?（空=待分类）/curOrder?/addedAt；镜像分类=Category.curFrom{wsId,catId,projId}。

## FocusSlot（dailyFocus 值）
id/sourceType('task'|'topic'|'resource'|'curiosity'|'text')/sourceId/text/done/doneAt?；今日三件事恒 3 槽，任务与选题共用。

## 状态与派生口径
任务完成唯一出口 setTaskStatusOf；isProjectDone=手动 done/archived 或全任务完成派生；未归档=taskArchiveIssue（未挂项目/指标或引用失效）；WCE=激活好奇+fromCuriosityId 转化卡数；WRR 记录唯一入口 recordResourceOpen。

## 方向读数（现役；DHI 与页面级五格指标条均已退役）
- 方向台页头：**方向健康度**（未停滞战略目标数 ÷ 战略目标总数；某目标下最近一次任务更新距今超过 14 天记为停滞）/ **主攻**（可见项目中 `isFocused` 的数量，上限 2）/ **停滞**（近 14 天无任务推进且已有任务的可见项目数）。
- 战略骨架：**六层计数**唯一账本（愿景 / 使命 / 战略目标 / 项目 / 成功指标 / 任务）；任务按全库未删除任务计。
- 历史注记：WCE / WRR 仍作为数据层口径存在，但 `MetricBar.vue` 自 V3.9.19 起零挂载，不再有页面级方向状态指标条。

## 云端同步实体（可选 · 邀请制 Supabase，V4 起）
- `CloudMeta`：云同步态（`syncedFingerprint` 快照指纹 / 连接环境 / `checkOnStart` 启动检查开关）。
- `CloudCheckResult` / `SyncManifest`：启动与同步时的云端修订比对结果（`in_sync` 等关系态）；上传/恢复含指纹 + 修订号双保险。
- `AssetMeta`（策展节点附件）：携带 `uploadState`（`local/pending/synced/failed`）与私有 Storage 上传状态；登录后可静默同步、可关闭、可重试。
- 历史遗留：V3.9 及更早的 `AirtableSyncState` / `AirtableLogEntry`（cursorAt 增量游标、airtableMap 映射）随 Airtable 退役而被清理，不再作为现状实体。
