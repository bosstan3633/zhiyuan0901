# 05-8 · 开发规范

> 对象：研发 ｜ 权威源：`docs/开发指南与回归验证.md` + `v2/README.md` 硬性规则。本文明细化常用条目。

## 工程铁律（违反即返工）
1. 版本号唯一来源 manifest.ts，静态同步 `package.json` / `src/newtab/views/ManualPage.vue` / `scripts/regression.cjs` 三处；`GlobalSettings` 用动态运行时版本（共 5 处口径）；`vue-tsc --noEmit` 必须 0 错误；
2. 单向挂载红线（见 05-2）；
3. 删除一律软删；
4. 排序 computed 禁止原地 sort；
5. 样式只用令牌，禁硬编码色值；新 UI 四主题走查；
6. 定位不走 tabs.query hash；
7. 新功能同步追加 `scripts/regression.cjs` 断言；
8. 构建前清空 dist；
9. 每轮交付落 `docs/交付说明_*` 并更新回归轮次注释。

## 代码约定
`<script setup lang="ts">`；禁 any（确需注释）；scoped 样式无法作用子组件内部（子组件自带样式）；原生 prompt/confirm 禁用（用 useConfirm/浮层）；抽屉快捷键挂 document 级（Teleport 焦点不经组件树）；数据修改全部走 store+persist；toast 统一深色底白字；新字段可选+读取兜底+loadData 补默认。

## 状态与错误处理
Pinia 单仓（useAppStore）+组合式（useCompass/useCuriosity）；存储层错误走 SaveError 总线（禁止静默 catch——业务 catch 必须补 Toast 或日志）；拖拽落位必须回写持久化排序字段。

## 流程
分支：main 为交付线，特性短分支；提交信息=「V<版本> 第< N >轮：<要点密集摘要> (回归 x/0, E2E y/0, K z/0)」+ tag；交付前门禁：`vue-tsc --noEmit` 0 错 + `node scripts/regression.cjs` 全绿（当前基线 **722**）+ `node scripts/e2e.cjs` 全绿（20）+ K 导入 4/4 + `node scripts/check-cycles.cjs` 循环依赖 0 + 清空 dist 重建（47 文件 / 1.4M）+ 桌面包；代码评审聚焦红线与失败态。
