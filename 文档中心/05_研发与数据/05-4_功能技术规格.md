# 05-4 · 功能技术规格（核心功能如何实现）

> 对象：研发 ｜ 每条给"关键机制 + 所在文件"，细节以代码为准。

| 功能 | 关键机制 | 主要位置 |
|---|---|---|
| 快速采集 | SW 命令→zy-open-capture→content 注入浮层（selection 预填）→直接写 storage；chrome:// 降级 popup（session 预填）；选中网页文字触发「快速采集任务」 | background / overlay-impl / popup |
| 好奇速记 | 同采集通道 mode=curio；转卡走 convertCard（写 fromCuriosityId） | content / utils/cards |
| 全局搜索 | 应用内 computed 过滤（排除资源台本体与已归档台；分组尊重 `zy_ui_v2.showDoneProjects`）；检索 标题/标签/分类/项目名 + 拼音首字母；双击直达；markRank 置顶星标 + 三级兜底；网页浮层与应用中口径一致 | GlobalPopups |
| 拼音与模糊 | pinyin-pro 纯动态 import（ensurePinyin/isPinyinReady/onPinyinReady）；未就绪纯文本兜底、就绪后自动补跑 | utils/pinyin |
| 资源台（原策展中心） | 卡片/列表/看板三视图 + 树状递归分组（子分类逐级缩进、空分支隐藏）+ 完整分类路径徽标；批量浮动栏（全选/批量打开/移动到/批量删除可撤销）；书签 HTML 导入（文件夹→前2级分类、3级+转标签）+ 本地文件；单击右侧抽屉共享表单编辑 ResourceEditForm、双击打开链接（260ms 判别） | CurationCenter.vue |
| 策展台（原工作台） | 金字塔居中树 `pyLayout`（叶子各占1列、父跨子列居中、列宽 minmax(170px,250px)）+ 直角折线 SVG 连线（resize 150ms 节流）；节点双入口（关联资源卡镜像 / 台内新建卡）；数据包 JSON 导入导出（version 校验+按 ID 并集合并本台段+投射清单）；拖拽 canMountInNode 校验 + 防循环 + 4 级上限 | Workspace.vue |
| 调度台（首页） | 方向状态单行指标条（标题+档位+四指标一行，副行收进 tooltip）+ 右端今日记录四格（入台/移出/调出/写入可下钻）；项目调度重排（项目名大字→战略目标行→四指标格）；今日三件事 ≤3 槽；好奇心培育五档筛选 | CompassHome.vue |
| 跨协议直达 | toOpenableUrl：http/file(→file://+中文编码)/obsidian://；附件 zy-asset:// 走 downloads 落盘+路径记忆 | utils/link、htmlAsset |
| 导入导出 | 资源台 书签 HTML + 本地文件；策展台数据包 JSON；「导出全部数据」= AppData 全段 + uiPrefs（zy_ui_v2）段；CSV 带 BOM（尾随列 链接类型/分类/置顶/星标/更新时间，适配 Airtable 多维表）/ Markdown；导入前自动备份 + 并集合并 | GlobalSettings/Workspace |
| 附件 | IndexedDB 库 `zy_assets` Blob；单文件 20MB；卡正面 AssetBadge；硬删清附件 | storage/assets、AssetManager |
| 调用计数 | recordResourceOpen 唯一入口：callCount/lastCalledAt/stats.lastVisits（跨周重置） | storage/stats |
| 拖拽排序 | HTML5 DnD；策展台防循环 + 4 级上限 + canMountInNode 校验；落位后全量重写 curOrder/sortOrder（资源）/sortOrder（任务），计算层消费 | Workspace/TaskManagerPanel |
| 并发合并 | mergeExternalData（卡片 LWW/dailyFocus 槽级/回声不回写） | repository |
| Airtable 同步 | 单向推送（本地→用户自有 Base，绝不回写）：≤10 条/批、批间 200ms、429 退避 30s；幂等键 `卡ID:m:目标策展台ID`、镜像卡独立记录；增量游标 cursorAt + 映射表 airtableMap；自愈（远端实测存在优先、本地兜底，撞已删记录降级转新建、单条失败仅记日志） | storage/airtable |
| 定位协议 | zy-locate-workspace→SW 逐页 zy-where→zy-locate（hash 不入 tabs.query）；通用 zy-open-route | background/App |
