# 05-4 · 功能技术规格（核心功能如何实现）

> 对象：研发 ｜ 每条给"关键机制 + 所在文件"，细节以代码为准。

| 功能 | 关键机制 | 主要位置 |
|---|---|---|
| 快速采集 | SW 命令→zy-open-capture→content 注入浮层（selection 预填）→直接写 storage；chrome:// 降级 popup（session 预填） | background / overlay-impl / popup |
| 好奇速记 | 同采集通道 mode=curio；转卡走 convertCard（写 fromCuriosityId） | content / utils/cards |
| 全局搜索 | 应用内 computed 过滤（blob=标题+台+分类+摘要+链接文本+标签）+ markRank 置顶星标 + 三级兜底（标题命中>callCount>lastCalledAt）+ 拼音 | GlobalPopups |
| 拼音与模糊 | pinyin-pro 按需加载+LRU(3000)；字典未就绪纯文本兜底 | utils/pinyin |
| 跨协议直达 | toOpenableUrl：http/file(→file://+中文编码)/obsidian://；附件 zy-asset:// 走 downloads 落盘+路径记忆 | utils/link、htmlAsset |
| 导入导出 | 同构 AppData 子集导出（...d+按台过滤）；导入=version 校验+并集合并+自动备份；CSV 带 BOM；Markdown；附件包 zip（STORE+CRC32） | GlobalSettings/Workspace |
| 附件 | IndexedDB Blob；单文件 20MB；卡正面 AssetBadge；硬删清附件 | storage/assets、AssetManager |
| 调用计数 | recordResourceOpen 唯一入口：callCount/lastCalledAt/stats.lastVisits（跨周重置） | storage/stats |
| 拖拽排序 | HTML5 DnD；落位后全量重写 curOrder/sortOrder（资源）/sortOrder（任务），计算层消费 | Workspace/TaskManagerPanel |
| 并发合并 | mergeExternalData（卡片 LWW/dailyFocus 槽级/回声不回写） | repository |
| 定位协议 | zy-locate-workspace→SW 逐页 zy-where→zy-locate（hash 不入 tabs.query）；通用 zy-open-route | background/App |
