# 05-7 · 安全与隐私说明

> 对象：研发/客服/安全关注者 ｜ 结论先行：**数据默认 100% 本机，本机是真源；不做自动备份、不做使用追踪。V4 起提供可选邀请制 Supabase 云端快照同步（用户主动登录、手动触发，默认不开启）。**

## 数据位置
主数据：浏览器配置文件内的 `chrome.storage.local`（unlimitedStorage）；附件：IndexedDB 库 `zy_assets`；导出件：用户指定下载目录。云端（仅在用户启用云同步后）：Supabase 私有表（邀请制，覆盖卡片池 / 调度台 / 方向台 / 策展台 / 界面偏好快照）；策展节点附件登录后进入用户私有 Storage。

**出网行为（重点区分为默认与可选）**：
- **默认（未启用云同步前）产品不做任何网络请求来上传你的数据**——本地开箱即用，无行为上报、无用户标识采集，代码可审计。
- **可选云同步（V4 起）**：用户在「设置 → 数据管理 → 云同步」**主动登录**邀请账号后，**手动触发**「上传到云端 / 从云端恢复」的快照同步；本机始终是真源，云端是主动上传的快照，三处缓存（本机/云端/上次记录）差异时**先提示、绝不静默覆盖**。普通卡片附件与 AI 凭据**不上云**。

（历史说明：V3.9 及更早版本不设云同步，唯一出网为用户自备 Token 手动触发的 Airtable 单向推送；该事实已随 V4 云同步落地被取代，此处不再作为「唯一出网」表述。）

## 权限声明（如实）
请求 `storage` / `unlimitedStorage` / `tabs` / `activeTab` / `commands` / `scripting` / `downloads` / `alarms`；host 权限为 `<all_urls>` + `file:///*`。
常驻注入的是 content script **轻量信号层**（约 2.9KB，`all_frames`，仅做选区捕获与消息监听），浮层实现按快捷键命令**动态拉取**——常驻的不是浮层本体；`chrome://` 等受限页不注入，走 Popup 降级。`tabs` 信息仅用于扩展页定位。**权限声明应与 `src/manifest.ts` 保持一致，对外说明不得少于实际申请范围。**

## 敏感数据处理
不做加密存储（与本地文档同等安全模型）；导出文件为明文 JSON——**导出件的安全责任在用户**（建议存入加密盘/私有云）；不采集任何身份/使用数据，无埋点上报。

## 外部协议调用
file://（本地文件，需用户授予"允许访问文件网址"）、obsidian://（用户主动双击才触发）；不自动请求任何外部域——云同步只在用户主动登录并手动触发时出网，非静默自动上传。

## 故障恢复
写入失败→存储 chip 红色告警+一键重试；删除→软删回收站；导入→先自动备份；浏览器崩溃→storage 落盘数据天然存活（未落盘 ≤300ms 窗口由 R58 合并层+下次写入收敛）。长期备份建议：每周导出 JSON。
