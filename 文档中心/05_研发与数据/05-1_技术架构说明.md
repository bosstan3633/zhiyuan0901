# 05-1 · 技术架构说明

> 对象：前端/扩展开发/架构师 ｜ 权威源：仓库 `v2/README.md`、`docs/技术架构与数据模型.md`；本文是面向"接手即懂"的收敛视图。

## 技术栈
Vue 3.5（Composition API/`<script setup>`）+ TypeScript strict ｜ Vite 5 + @crxjs（MV3）｜ Pinia（useAppStore + useCompass/useCuriosity）｜ Vue Router（hash）｜ 原生 CSS Variables（tokens.css）+ scoped ｜ chrome.storage.local（无 IndexedDB 主数据）｜ pinyin-pro（按需加载）。

## 模块划分
```
src/
├── manifest.ts            MV3 清单（版本唯一来源）
├── background/index.ts    SW：命令监听/浮层注入/单例定位/路由中转
├── content/               网页浮层（search-overlay 信号层 + overlay-impl 实现 + selection），纯 Vanilla
├── popup/                 chrome:// 等不可注入页的降级弹窗
├── shared/                models / storage(repository,defaults,migration,stats,assets) / utils / components / tokens.css
└── newtab/                主应用（App/路由/stores/views/components）
```

## 页面与服务关系
- **新标签页**=主应用（全部页面）；**Content Script**=任意网页的搜索/采集/好奇浮层（Shadow DOM，1.5s 内存缓存 + storage.onChanged 失效同步）；**SW**=快捷键命令、zy-ping 探测注入、工作台单例定位（zy-where 询问链，绕过 tabs.query 不含 hash）、通用路由（zy-open-route）；**Popup**=降级。

## 权限设计（最小化）
storage / unlimitedStorage / downloads（附件落盘）/ commands；tabs 仅用于定位扩展页。不做 host_permissions 全站注入（浮层按命令注入）。

## 生命周期与更新
每次新标签页：main.ts 迁移检测 → loadData（含老数据自愈：tags 归一化/URL 解码/字段补行）→ store.init → 挂载 → 固定回调度台（白名单深链除外）。扩展更新不影响数据（存储与代码分离）；构建前必须清空 dist。

## 性能策略
并行加载、拼音字典按需+LRU(3000)、路由级代码分割、content-visibility（大网格屏外跳过）、memo（北极星按 period+日期+数据版本）、写入 300ms 防抖+JSON 纯净清洗。长任务打点脚本 `scripts/perf-longtask.cjs`。
