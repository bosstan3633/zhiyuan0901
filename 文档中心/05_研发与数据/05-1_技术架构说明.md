# 05-1 · 技术架构说明

> 对象：前端/扩展开发/架构师 ｜ **最终事实源：仓库源码 `v2/src`**（清单以 `src/manifest.ts` 为准）；`docs/技术架构与数据模型.md`、`v2/README.md` 为过程文档，版本与部分细节滞后，引用前须回源码核对。

## 技术栈
Vue 3.5（Composition API/`<script setup>`）+ TypeScript strict ｜ Vite 5 + @crxjs（MV3）｜ Pinia（useAppStore + useCompass/useCuriosity）｜ Vue Router（hash）｜ **UnoCSS**（`@unocss/preset-uno` + `@unocss/preset-icons`，配置 `uno.config.ts`）+ CSS Variables（tokens.css，仅主题 token）+ scoped ｜ 主数据 `chrome.storage.local` 单根 JSON（`zy_data_v2`，已申请 `unlimitedStorage`）；附件走 IndexedDB 库 `zy_assets`（objectStore `assets`），**Blob 绝不进主 JSON** ｜ pinyin-pro（纯动态 import：`ensurePinyin`/`isPinyinReady`/`onPinyinReady`，未就绪降级纯文本匹配、就绪后自动补跑）。

## 模块划分
```
src/
├── manifest.ts            MV3 清单（版本唯一来源）
├── background/index.ts    SW：命令监听/浮层注入/单例定位/路由中转
├── content/               网页浮层（search-overlay.ts 信号层 ≈2.9KB + overlay-impl.ts 浮层实现 + selection.ts 选区共享），纯 Vanilla
├── popup/                 chrome:// 等不可注入页的降级弹窗
├── options/               设置页（Airtable 同步入口等）
├── shared/                models / storage(repository,defaults,migration,curationMigration,stats,assets,hub,airtable) / utils / components / tokens.css / uno.config.ts
└── newtab/                主应用（App/路由/stores/views/components）
```

## 五入口
newtab（主）/ background（service worker）/ content script / options / popup。

## 页面与服务关系
- **新标签页**=主应用（全部页面，视图路由级懒加载 + KeepAlive 缓存四大主视图：调度台/方向台/资源台/策展台，切台免重挂载）；**Content Script**=任意网页的搜索/采集/好奇浮层（Shadow DOM，1.5s 内存缓存 + storage.onChanged 失效同步）；**SW**=快捷键命令、zy-ping 探测注入、策展台单例定位（zy-where 询问链，绕过 tabs.query 不含 hash）、通用路由（zy-open-route）；**Popup**=降级；**Options**=设置（含 Airtable 同步）。

## 权限设计（如实声明）
`storage` / `unlimitedStorage` / `tabs` / `activeTab` / `commands` / `scripting` / `downloads` / `alarms`；host 权限为 `<all_urls>` + `file:///*`。
Content script 以 `all_frames` 在 http/https/file 页面**声明式注入轻量信号层**（约 2.9KB：选区捕获 + 消息监听 + 按需拉浮层）；重型浮层实现 `overlay-impl.ts` 在首次唤起时才动态加载——即"常驻的是信号层，不是浮层本体"。`chrome://` 等受限页不注入，走 Popup 降级。`tabs` 信息仅用于扩展页定位。

## 生命周期与更新
每次新标签页：main.ts 迁移检测 → loadData（含老数据自愈：tags 归一化/URL 解码/字段补行）→ store.init → 挂载 → 固定回调度台（白名单深链除外）。扩展更新不影响数据（存储与代码分离）；构建前必须清空 dist。

## 性能策略
并行加载、pinyin-pro 纯动态 import（ensurePinyin/isPinyinReady/onPinyinReady，启动 `requestIdleCallback` 预热；未就绪纯文本兜底）、路由级懒加载 + KeepAlive 四主视图、content-visibility（大网格屏外跳过）、memo（北极星按 period+日期+数据版本）、写入 300ms 防抖+JSON 纯净清洗。长任务打点脚本 `scripts/perf-longtask.cjs`。
