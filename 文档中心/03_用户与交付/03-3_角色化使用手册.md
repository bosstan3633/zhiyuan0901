# 03-3 · 角色化使用手册

> 对象：五类典型用户 ｜ 前提：已完成 [03-1 三分钟上手](./03-1_三分钟上手指南.md)。

## 1. 咨询现场：快速调出证据
- **事前**：按客户建项目；证据卡（政策/案例/数据）入台并打标签；口径卡置顶；
- **现场**：客户提问 → Ctrl+K → 关键词或拼音首字母 → 双击投屏；口径卡直接看；
- **事后**：把现场新产生的承诺记成任务挂到该客户项目 → 今日三件事跟进。
**关键习惯**：任何"稍后找给您"当场入台，不给记忆留任务。

## 2. 研究过程：管理问题与来源
- 问题随手 Ctrl+Shift+I（好奇心卡），来源页一起入台；
- 求证完成 → 好奇心转任务（要做的）或转资源（结论卡）；两者都计入 WCE；
- 结论卡与来源互挂（卡片详情挂载），写作时从结论三秒调出来源。

## 3. AI 协作：成果归位
- AI 对话里的金句/框架/报告：选中 → 入台（自动带选中文本）；
- 给卡打上"来自哪个 AI、什么主题"的标签；重要的转成资源卡归位；
- 复用计数会告诉你：哪些 AI 产出真的在被反复使用。

## 4. 内容项目：工具与素材组织
- 一个内容项目 = 项目 + 选题（成功指标）；素材卡按选题分类归位；
- 常用工具站（编辑器/素材库）置顶工作台首列；
- 成品发布后，把成品链接入台——形成"作品卡"长期复用。

## 5. 长期项目：连接方向与每日行动
- 方向链：愿景 → 使命 → 战略目标 → 项目 → 成功指标 → 任务；
- 每天只看调度台三件事（从任务库选取）；每周五看方向状态四指标校准；
- 未归档任务指标升高 = 快速采集的任务在积压 → 任务卡库筛「⚠ 未归档」就地归档。
