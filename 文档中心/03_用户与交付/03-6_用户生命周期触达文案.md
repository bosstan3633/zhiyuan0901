# 03-6 · 用户生命周期触达文案

> 对象：客户成功/运营 ｜ 渠道：应用内提示/邮件/社群。原则：**只基于产品内可感知的事实触发**（不骚扰、不群发促销）。

| 触点 | 触发条件 | 文案要点（示例口吻） |
|---|---|---|
| 安装欢迎 | 首次打开 | "欢迎来到调度台。三件事：装好 → Ctrl+Shift+J 入台第一张卡 → Ctrl+K 调出它。三分钟，见 [03-1]。" |
| 首次价值达成 | 第一次 Ctrl+K 调出成功 | "这就是调度的感觉——三秒。给它一周，它会成为你的肌肉记忆（七天计划）." |
| 三天未使用 | 3 天无入台/调出 | "卡住的多半是归位：挑 5 张卡拖进分类试试。或回看三分钟指南第 2 分钟。" |
| 七天复盘 | 第 7 天 | "一周了：看看你的调出次数和复用 Top 卡——这是你的调度画像。顺手导出一份 JSON 备份。" |
| 功能更新 | 版本发布 | 只讲用户可感知的 1~3 件事 + 一句"数据不受影响"（模板见 07-5）。 |
| 续用与转介绍 | 高复用用户 | "你的复用 Top 卡已经 30+ 次了。如果知源帮你省下了'找不到'的时间，把它带给一位同样被信息洪流冲着走的同事。" |
