# 03-4 · 功能帮助中心索引

> 对象：全体用户 ｜ 权威帮助：产品内「使用手册」（设置 → 使用手册，或地址 `#/manual`）。本文是**按任务组织的入口索引**，详细步骤以手册与界面提示为准。

## 按页面找
| 页面 | 能做什么 |
|---|---|
| 调度台（首页） | 方向状态四指标（战略目标/推进项目 + WCE + WRR + 未归档，可下钻）、今日三件事、项目调度、好奇心培育、今日记录（入台/移出/调出/写入） |
| 方向台 | 主航线（愿景/使命/目标/项目）、项目总览（主攻/投射/进度）、任务调度（卡片/列表/看板） |
| 资源台（原策展中心） | 默认根节点「全部分类」（聚合全台卡片，进入即见）、卡片/列表/看板三视图、树状递归分组、完整分类路径徽标、批量管理、书签导入 |
| 策展台 ×N（原工作台） | 金字塔居中树、节点双入口（关联资源卡/新建卡片）、策展台数据包导入导出 |
| 全局搜索 | 标题/标签/分类/项目名检索，支持拼音与首字母，双击直达 |
| 设置 | 字段设计、标签管理、导入导出、快捷键、主题密度、Airtable 同步、回收站、手册 |
| 回收站 | 软删卡恢复/永久删除（含附件清理） |

## 按任务找（高频 12 件）
入台（Ctrl+Shift+J）｜记念头（Ctrl+Shift+I）｜调出（Ctrl+K，任意网页可用）｜双击直达链接｜建策展台/分类｜书签导入｜建项目与指标｜把任务挂指标（展板拖拽/左树拖拽）｜今日三件事选取与导出｜策展镜像｜附件上传与预览｜导出 JSON/CSV/Markdown 与恢复

## 快捷键索引
浏览器命令：Ctrl+Shift+K 打开调度台 ／ Ctrl+Shift+J 采集 ／ Ctrl+Shift+I 好奇 ／ Ctrl+K 全局搜索（键位可在 `chrome://extensions/shortcuts` 修改）。
应用内切台：Alt+1 方向台 ／ Alt+2 资源台 ／ Alt+3…9 按台签顺序的各策展台（调度台为首页，刷新自动回，不占数字键；修饰键默认 Alt，设置可改）。
无默认键（需用户自配）：open-tasks 快速采集任务、goto-tasks 直达任务调度、goto-curiosity 直达好奇心培育、sync-airtable 同步 Airtable、open-settings 设置、open-tree 完整方向树。
应用内：Ctrl+Enter 保存并关闭 ／ Esc 逐层关闭（浮层→抽屉→展板）／ Ctrl+←/→ 切三件事日期 ／ Tab 搜索内切换类型 ／ ↑↓ 选择 + Enter 打开 ／ ? 快捷键速查。
> ⚠ 已下架的旧键：R68 起「打开方向台」「打开资源台」两个浏览器级命令不再提供，切台改由应用内 Alt+数字完成；升级后原键位会失效，需按上表重新适应。

## 数据管理
导出（JSON 全量含 uiPrefs/按策展台/CSV/Markdown）、导入（JSON 并集/书签 HTML/本地文件）、自动备份（导入前）、回收站、附件管理——见 [05-7 安全与隐私](../05_研发与数据/05-7_安全与隐私说明.md) 与 [05-2 数据架构](../05_研发与数据/05-2_本地数据架构.md)。
- **Airtable 单向同步**：设置 → Airtable 同步；单向推送（知源 → 用户自有 Base）、用户自备 Personal Access Token、手动触发为主、绝不回写本地；同步范围含资源卡/任务卡/好奇卡/各策展台台内卡。
