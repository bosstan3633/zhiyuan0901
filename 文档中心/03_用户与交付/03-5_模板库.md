# 03-5 · 模板库

> 对象：新用户/客户成功 ｜ 形态：手工搭建指引（结构化"一键套用模板"为路线图项，见 [04-8 版本路线图](../04_产品与设计/04-8_版本路线图.md)）。每个模板给：台/分类/标签/项目 四层结构 + 首批建议卡片。

## 1. 行业研究工作台
- 台：「行业研究」；分类：信源 / 报告库 / 数据集 / 口径定义；
- 标签：#待求证 #已求证 #高置信；
- 项目：在研课题（指标=交付物）；口径定义卡置顶。

## 2. 客户咨询证据台
- 台：「咨询台」；分类：政策法规 / 案例库 / 常用口径 / 现场物料；
- 项目：每客户一个项目；指标=阶段交付；
- 习惯：任何"稍后找给您"当场收录到知源；证据卡挂客户项目指标。

## 3. 内容生产工作台
- 台：「内容工厂」；分类：选题池 / 素材库 / 灵感 / 已发布；
- 流：灵感（好奇卡）→ 选题（任务挂项目）→ 素材归位 → 成品链接回收为"作品卡"。

## 4. AI 工具与 Skill 工作台
- 台：「AI 武器库」；分类：对话工具 / 提示词库 / Skill/Agent / 产出样例；
- 习惯：AI 金句当场入台；提示词卡置顶复用，看调用计数淘汰低频。

## 5. 目标与行动结构（配方向台）
愿景一句 → 使命一句 → 1~3 个战略目标 → 每目标 1~3 个项目（主攻 1 个）→ 每项目 2~5 个成功指标 → 任务挂指标。原则：**指标可衡量、任务 ≤2 周粒度**。首次体验不必填满全链——先从一件正在推进的事开始（见 [03-1 上手指南](./03-1_三分钟上手指南.md)）。

## 6. 每周调度复盘（15 分钟）
① 打开方向状态四指标记录当值 → ② 未归档任务清零/归档 → ③ 复用计数 Top10 标记置顶 → ④ 三件事命中率回顾 → ⑤ 下周主攻项目确认。
