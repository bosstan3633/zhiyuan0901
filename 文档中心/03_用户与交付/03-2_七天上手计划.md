# 03-2 · 七天上手计划

> 对象：新用户 ｜ 目标：第七天形成"入台→归位→调出→复用→校准"完整闭环。每天 10 分钟。

| 天 | 动作 | 完成标志 |
|---|---|---|
| **D1 建立策展台** | 建第一个策展台（如"工作"），建 2~3 个分类 | 有一个属于你的资源域 |
| **D2 练习入台** | 把今天看过的 5 个网页/文件全部 Ctrl+Shift+J 入台并拖进分类 | 每条信息都有归宿 |
| **D3 三秒调出** | 一天之内用 Ctrl+K 调出 ≥3 次；把最常用的 2 张卡置顶 | 第一次"不用找，直接调" |
| **D4 记录好奇** | 遇到问题按 Ctrl+Shift+I 记 3 条好奇心；把其中 1 条转为任务 | 念头不再蒸发 |
| **D5 建立项目** | 方向台 → 新建一个项目 + 1 个成功指标 | 有了第一个"攻坚单位" |
| **D6 今日三件事** | 从任务库选 3 件进明天三件事；完成一件勾一件 | 行动与项目挂上钩 |
| **D7 校准方向** | 打开方向状态四指标看一眼；建愿景/使命各一句 | 看得见"行动↔方向"的关系 |

**第七天检查清单**：能 3 秒调出 ✔ 有卡进了回收站又恢复过 ✔ 三件事至少 1 件挂项目 ✔ 导出过一次 JSON ✔
卡住了？见 [07-1 客服知识库](../07_运营与客服/07-1_客服知识库.md)。
