- [ ] `node scripts/e2e.cjs` → **22 / 0**（原记 20 为 V2.80.0 校准点）
      ★ **浏览器回落（R145）**：三个浏览器型门禁（e2e / perf / test-import-compat）统一
      `pinned Chrome for Testing → 环境变量 ZY_CHROME → 本机 ms-playwright 任一 Chromium → 系统 Chrome`；
      **「本机没钉那个版本的浏览器」不再是跳过门禁的理由**（V3.0.0 前 e2e/perf 因此停摆 30+ 轮）
      ★ **R149 补漏**：e2e.cjs 当年只落了三級里的两级（pinned → 系统 Chrome），漏掉"本机任一 ms-playwright Chromium"，

      ★ **入口字面量口径（R149 改严）**：量 newtab 入口 chunk 的**静态导入闭包**（当前 3 文件），不是单文件；
      闭包内只允许懒 chunk 的 CSS 路径字符串出现（`__vite__mapDeps`）。`zy_stats_v1` 是存储键、本在启动链，不计入 AI 字面量清单。

- [ ] 反例留痕（本条的存在理由）：
      `e2e.cjs` 最后更新停在 **R69**，中断 40 轮，致 13 条断言从未执行、4 条静默失效；

      两者同属「脚本建了但没人跑」——**门禁不跑 = 没有门禁**。
