# 07-1 · 客服知识库

> 对象：客服/自答用户 ｜ 答复口径与 [00 母版](../00_产品事实与表达母版.md) 一致；产品内权威帮助=设置→使用手册（/manual）。

## 安装问题
**加载后新标签页没变？** 确认加载的是 `dist` 目录（含 manifest.json）；扩展详情页点"重新加载"并新开标签页。
**想换浏览器？** 支持 Chrome/Edge/Brave 等 Chromium 系；每个浏览器独立加载，数据各自独立（导出导入迁移）。

## 快捷键冲突
Ctrl+Shift+J/I/K 与其他扩展或系统冲突：到 `chrome://extensions/shortcuts` 重新绑定。应用内切台用 `Alt+1`=方向台、`Alt+2`=资源台、`Alt+3…9`=按台签顺序的各策展台（调度台为默认首页，刷新自动回，不占数字键；修饰键默认 Alt，可在设置→快捷键自定义）。注意：旧版浏览器级命令"打开方向台""打开资源台"已下架，请改用应用内切台；无默认键的浏览器命令（如云同步上/传恢复）需到 `chrome://extensions/shortcuts` 手动分配。

## 数据存储
存在哪：浏览器配置文件（chrome.storage.local + IndexedDB）；默认本机是真源，无行为上报、不做使用追踪。怎么看：顶栏"数据存储""同步状态"两个 chip。怎么备份：设置→导出数据（JSON 全量），建议每周。换电脑：旧机导出 → 新机导入（导入前自动备份）。多设备：V4 起可用**可选邀请制云同步**（设置→数据管理→云同步，主动登录、手动上传/恢复快照；本机真源、不静默覆盖，普通卡片附件与 AI 凭据不上云）。

## 导入导出
JSON 全量=整包（含界面偏好段 zy_ui_v2，导入自动应用）；策展台导出=本台数据包（AppData 本台子集，按 ID 并集合并）；CSV/Markdown 给表格与文档场景；书签 HTML 导入已移交资源台（文件夹→前 2 级分类、3 级及以上转标签）。导入=并集合并（同 ID 更新），先自动备份。

## 文件协议（file://）
本地文件卡双击打不开：扩展详情页开启「允许访问文件网址」；卡内路径需完整（如 D:\docs\file.pdf 或 /Users/x/file.pdf）。

## Obsidian 调用
卡链接填 `obsidian://...`（vault 跳转链接），双击直达；深度内容仍在 Obsidian，知源负责调度入口。

## 升级与恢复
升级=重新加载新 dist（数据不受影响）；误删=回收站恢复；整库异常=最近一次导出 JSON 导入（导入前会再自动备份当前库）。

## 云端同步（V4 起）与历史 Airtable 退出
云同步怎么开：设置 → 数据管理 → 云同步（邀请制 Supabase）。用户**主动登录**邀请账号后**手动触发**「上传到云端 / 从云端恢复」快照，覆盖卡片池 / 调度台 / 方向台 / 策展台 / 界面偏好；本机是真源、三处缓存差异先提示、绝不静默覆盖；普通卡片附件与 AI 凭据不上云，策展节点附件登录后入用户私有 Storage。默认不开启，用不上可完全不用。
（历史说明：V3.9 及更早版本的 Airtable 单向同步——用户自备 Token 手动推送到自己的 Base——随 V4 云同步落地逐步退出，此处不再作为对外主能力表述；如遗留 Airtable 相关问题，以交付说明口径答复。）

## 台面与指标
导航怎么只剩三个固定台：R64 起"工作台"实体归一——旧工作台分类树整体并入资源台根下同名根分类，原生卡随分类平移，工作台实体删除；三大固定页现为 调度台 / 方向台 / 资源台，外加你自建的策展台。DHI 方向契合度去哪了：已退役（不再计算百分比），方向状态第一格改看"战略目标数"（副行"推进项目数"）；四格现为 战略目标 / WCE 探索 / WRR 复用 / 未归档任务。

## 已知边界
附件单文件 ≤20MB；资源台分类树支持递归 N 级（设置→资源台全景）、标签 ≤3 级；chrome:// 等页面采集自动降级独立弹窗。
