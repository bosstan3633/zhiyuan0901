# 07-1 · 客服知识库

> 对象：客服/自答用户 ｜ 答复口径与 [00 母版](../00_产品事实与表达母版.md) 一致；产品内权威帮助=设置→使用手册（/manual）。

## 安装问题
**加载后新标签页没变？** 确认加载的是 `dist` 目录（含 manifest.json）；扩展详情页点"重新加载"并新开标签页。
**想换浏览器？** 支持 Chrome/Edge/Brave 等 Chromium 系；每个浏览器独立加载，数据各自独立（导出导入迁移）。

## 快捷键冲突
Ctrl+Shift+J/I/K 与其他扩展或系统冲突：到 `chrome://extensions/shortcuts` 重新绑定。应用内切台用 `Alt+1`=方向台、`Alt+2`=资源台、`Alt+3…9`=按台签顺序的各策展台（调度台为默认首页，刷新自动回，不占数字键；修饰键默认 Alt，可在设置→快捷键自定义）。注意：旧版浏览器级命令"打开方向台""打开资源台"已下架，请改用应用内切台；无默认键的浏览器命令（如同步到 Airtable）需到 `chrome://extensions/shortcuts` 手动分配。

## 数据存储
存在哪：浏览器配置文件（chrome.storage.local），无账号、无行为上报、不回写本地。怎么看：顶栏"数据存储""同步状态"两个 chip。怎么备份：设置→导出数据（JSON 全量），建议每周。换电脑：旧机导出 → 新机导入（导入前自动备份）。唯一出网行为：用户在设置中显式配置 Airtable 凭证并手动触发的单向推送（推到用户自有 Base，非知源云端）；知源不设服务器、不代持凭证、不做自动云端备份。

## 导入导出
JSON 全量=整包（含界面偏好段 zy_ui_v2，导入自动应用）；策展台导出=本台数据包（AppData 本台子集，按 ID 并集合并）；CSV/Markdown 给表格与文档场景；书签 HTML 导入已移交资源台（文件夹→前 2 级分类、3 级及以上转标签）。导入=并集合并（同 ID 更新），先自动备份。

## 文件协议（file://）
本地文件卡双击打不开：扩展详情页开启「允许访问文件网址」；卡内路径需完整（如 D:\docs\file.pdf 或 /Users/x/file.pdf）。

## Obsidian 调用
卡链接填 `obsidian://...`（vault 跳转链接），双击直达；深度内容仍在 Obsidian，知源负责调度入口。

## 升级与恢复
升级=重新加载新 dist（数据不受影响）；误删=回收站恢复；整库异常=最近一次导出 JSON 导入（导入前会再自动备份当前库）。

## Airtable 同步
怎么开：设置 → Airtable 同步，填入你自己的 Personal Access Token（需 `data.records` 读写 + `schema.bases` 写权限），选择要推送的 Base；手动触发为主，单向推送、绝不回写本地。推到哪：你自己的 Base（知源不设服务器、不代持凭证）。同步报 422「记录不存在」：新版已自愈——映射以远端实测存在优先、逐条降级重建并写回映射，下次同步自动恢复，无需手动处理。同步范围：好奇心卡 / 任务卡 / 资源卡 / 各策展台台内卡。

## 台面与指标
导航怎么只剩三个固定台：R64 起"工作台"实体归一——旧工作台分类树整体并入资源台根下同名根分类，原生卡随分类平移，工作台实体删除；三大固定页现为 调度台 / 方向台 / 资源台，外加你自建的策展台。DHI 方向契合度去哪了：已退役（不再计算百分比），方向状态第一格改看"战略目标数"（副行"推进项目数"）；四格现为 战略目标 / WCE 探索 / WRR 复用 / 未归档任务。

## 已知边界
附件单文件 ≤20MB；资源台分类树支持递归 N 级（设置→资源台全景）、标签 ≤3 级；chrome:// 等页面采集自动降级独立弹窗。
