# 07-1 · 客服知识库

> 对象：客服/自答用户 ｜ 答复口径与 [00 母版](../00_产品事实与表达母版.md) 一致；产品内权威帮助=设置→使用手册（/manual）。

## 安装问题
**加载后新标签页没变？** 确认加载的是 `dist` 目录（含 manifest.json）；扩展详情页点"重新加载"并新开标签页。
**想换浏览器？** 支持 Chrome/Edge/Brave 等 Chromium 系；每个浏览器独立加载，数据各自独立（导出导入迁移）。

## 快捷键冲突
Ctrl+Shift+J/I/K 与其他扩展或系统冲突：到 `chrome://extensions/shortcuts` 重新绑定；产品内"修饰键+数字"（引擎/工作台）在设置→快捷键自定义。

## 数据存储
存在哪：浏览器配置文件（chrome.storage.local），无账号无云端。怎么看：顶栏存储 chip。怎么备份：设置→导出数据（JSON 全量），建议每周。换电脑：旧机导出 → 新机导入（导入前自动备份）。

## 导入导出
JSON 全量=整包；工作台导出=AppData 子集（含标签树/罗盘等全局段）；CSV/Markdown 给表格与文档场景；书签 HTML 导入=顶层文件夹归组为标签。导入=并集合并（同 ID 更新），先自动备份。

## 文件协议（file://）
本地文件卡双击打不开：扩展详情页开启「允许访问文件网址」；卡内路径需完整（如 D:\docs\file.pdf 或 /Users/x/file.pdf）。

## Obsidian 调用
卡链接填 `obsidian://...`（vault 跳转链接），双击直达；深度内容仍在 Obsidian，知源负责调度入口。

## 升级与恢复
升级=重新加载新 dist（数据不受影响）；误删=回收站恢复；整库异常=最近一次导出 JSON 导入（导入前会再自动备份当前库）。

## 已知边界
附件单文件 ≤20MB；分类 ≤2 级、标签 ≤3 级；chrome:// 等页面采集自动降级独立弹窗。
