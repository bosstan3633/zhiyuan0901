# 07-5 · 版本发布材料模板

> 用途：每轮发版对外统一文案模板；只写用户可感知项，技术细节留仓库交付说明。

```markdown
## 知源调度台 V<版本> 更新公告（YYYY-MM-DD）

### 这次为你带来了
- <用户可感知能力 1：一句话说清"你能做什么了">
- <能力 2>
- <能力 3>

### 修复与打磨
- <1~3 条用户可感知的修复（不写代码细节）>

### 你的数据
- 数据仍 100% 存在本机；本次升级不影响任何已有数据
- 升级方式：重新加载新版本目录即可（旧数据自动延续）
- 建议：顺手导出一份 JSON 备份（设置 → 导出数据）

### 已知问题
- <如有，如实列出；没有则删除本节>

—— 万千可调用，自有我方向。
```
填写纪律：每个条目必须通过"用户听懂测试"（不说组件/函数/字段名）；数量克制（≤5 条）；与仓库交付说明事实一致。
