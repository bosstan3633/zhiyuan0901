# 07-3 · 反馈分类体系

> 用途：任何渠道（社群/私聊/评分/访谈）的反馈统一贴此标签，进入对应处置流。

| 分类 | 定义 | 处置流 |
|---|---|---|
| 缺陷 | 行为与设计不符 | 06-3 分级 → 轮次清单 |
| 易用性 | 能用但绕/不懂 | 可用性测试（04-14）→ 文案/交互微调 |
| 新需求 | 现在没有的能力 | 过 04-2 映射表 + 04-6 模板 → 需求盘点 |
| 性能 | 慢/卡 | 05-6 预算对照 → 打点复核 |
| 数据与安全 | 存储迁移导出疑虑 | 07-1 知识库答复 + 产品事实澄清 |
| 同步与数据 | Airtable 单向推送配置 / 报错（422·429）/ 边界疑问 | 07-1 知识库答复 + 产品事实澄清 |
| 文案与认知 | 术语不懂/误解定位 | 04-13 文案修订 + 母版术语增补评估 |
| 付费与服务 | 价格/授权/服务 | 记录（不承诺）→ 08 商业模型输入 |

## 标签纪律
一条反馈只打一个主分类；原话必须保存（用户语言是最好的需求证据）；月度汇总进 [08-2 经营看板](../08_经营与决策/08-2_产品经营看板指标定义.md) 输入。
