# 09-3 · 客户成功 SOP

> 对象：客户成功/销售后续跟进 ｜ 目标：安装 ≠ 价值；本 SOP 把用户送到"七日价值达成"。

| 阶段 | 动作 | 工具/材料 | 完成标志 |
|---|---|---|---|
| T0 安装 | 远程/指引安装（开发者模式加载 dist） | 03-1 指南 | 新标签页显示调度台 |
| T0+10min 首次配置 | 建第一个工作台+分类；过一遍三快捷键 | 03-1 | 第一张卡入台 |
| T0+1h 存量迁移 | 浏览器书签 HTML 导入 / 常用文件入台 | 设置→导入 | ≥10 张卡归位 |
| T0+1d 第一次三秒调出 | 视频通话 5 分钟：现场 Ctrl+K 调出一张 | 02-4 三分钟脚本 | 用户独立完成调出 |
| T0+3d 检查点 | 问三件事是否在建；好奇心试一次 | 03-2 D3/D4 | 任一闭环行为 |
| T0+7d 七天回访 | 用 04-9 闭环指标问询（调出次数/归位率感受）+ 导出 JSON 演示 | 03-2 检查清单 | 七日价值达成确认 |
| 长期 | 问题分级响应（06-3）；案例征集（02-6 六段式） | 07-2 诊断脚本 | 案例/转介绍 |

## 升级/流失风险信号
连续 3 天无入台调出；抱怨归位麻烦（→ 演示批量/拖拽）；问"会不会丢数据"未消解（→ 05-7 事实+现场导出演示）。
