产品架构图

PRODUCT ARCHITECTURE · V4.7.1

现役由三类主工作面组成：调度台负责今天的行动与四卡池，方向台负责六层目标与项目，策展台 ×N负责把论点和证据组织成可分享成果；画像洞察、设置、回收站与手册是支撑面。「资源台」已退役，资源卡的真身住调度台「资源卡池」。

浏览器入口 · 收录与召回 BROWSER

快速采集

网页、选中文本、本地文件与 Obsidian 链接进入对应卡片；任务与选题可直接写入项目 / 指标。

全局搜索

检索已收录资源、任务、选题、好奇心、项目与策展台；支持关键词、拼音和首字母。

四类速记

资源 / 任务 / 选题 / 好奇心各自直达对应卡池；无中间 Inbox。

调度台 · 今天从哪里出发 TODAY + POOLS

今日三件事 · 恒 3 槽

任务卡与选题卡共用；支持卡型过滤与关键词检索。与今日日历严格同源，移出即清计划日期。

手边的卡 · 四卡池

任务 / 选题 / 好奇心 / 资源四个并列页签；今日入库角标、一级工作面、单击详情、双击直达。旧 `/deck/*` 深链只做兼容重定向。

今日日历

任务与选题共用月 / 周日历；拖拽写计划执行日期；满 3 格不再接收第 4 项。

今天的状态

今日战报、最近调出、入库与调出计数；AI 洞察只在弹窗中临时呈现，不写入任务真源。

方向台 · 把行动挂到方向上 DIRECTION

六层目标与行动

愿景 → 使命 → 战略目标 → 项目 → 成功指标 → 任务；选题卡作为「成果」挂在指标下，不计入任务完成率。

页头读数

方向健康度 / 主攻数 / 停滞项目数；六层计数统一收在紧邻的「战略骨架」条。

项目塔 / 项目全景

按目标与项目聚焦；指标可整组排序；新建任务抽屉以标题为主视觉，AI 填表与优先级退役。

方向树策展模式

只读六层全景：金字塔 / 树状双布局，目标与项目过滤，全部展开 / 折叠至目标，单项目聚焦居中。

卡片对象 ≠ 卡池 · 四个卡池 + 一类台内对象 CARDS

任务卡 ↔ 任务卡池

要执行的动作。调度台一级卡片池的「任务」页签；三态、项目 / 指标、计划日期、资源支持。旧 `/deck/task` 深链回 `/?tab=task`。

选题卡 ↔ 选题卡池

面向外界的成果。调度台一级卡片池的「选题」页签；自定义状态、项目 / 指标、关联资源卡、发布 / 成果链接。旧 `/deck/topic` 深链回 `/?tab=topic`。

好奇心卡 ↔ 好奇心卡池

值得追问的问题。调度台一级卡片池的「好奇心」页签；状态推进与资源支撑。旧 `/deck/curiosity` 深链回 `/?tab=curiosity`。

资源卡 ↔ 资源卡池

材料与证据的唯一真身。调度台一级卡片池的「资源」页签；由标签组织和镜像关系复用，没有资源台整页；旧 `/deck/resource` 深链回 `/?tab=resource`。

论证卡 · 仅策展台

策展节点内的观点 / 论据 / 反驳；存 `argCards`，不进入四卡池，也不计入全局四类卡统计。

策展台 ×N · 把成果组织成可分享论证 CURATION

中心论点 + 画布

金字塔 / 树状同一论证结构；页头压成双列控制台，把纵向空间还给画布。

节点「关联卡片」

高频主入口；候选面板提供 全部 / 资源卡 / 选题卡 三档筛选。资源只读镜像，选题以「成果」身份参与。

论证卡与附件

论证卡承接观点正文；附件是次级元数据行，不与关联卡片争夺主 CTA。

可分享成果

全台资源批量打开、HTML 分享、图片预览与下载；画布会话历史保留最近 10 步，云同步恢复不清空。

支撑面 · 理解自己与治理数据 SUPPORT

画像洞察 `/profile`

今天 / 本周 / 本月 / 本年统一控制范围；模块级 AI 洞察基于所选范围数据生成；选题卡指标支持下钻。

设置 `/settings`

卡片字段、选题状态、标签、AI、附件管理、云同步、快捷键、主题与内嵌回收站。

使用手册 `/manual`

解释现役台面、卡池、方向与策展口径；历史能力明确标注退役。

知源品牌区

品牌区点击进入画像洞察；使命文本与方向台同一真源；顶栏同步入口不挂呼吸灯。

数据底盘 · 本机优先，云同步可选 LOCAL-FIRST

本机单根 JSON

`chrome.storage.local`；载入、导入、云恢复统一走 `normalizeAppData()`。

附件 IndexedDB

图片 10MB、HTML 20MB、PDF 50MB；无引用附件由用户在设置中手动清理。

回收站

删除一律软删；没有「30 天自动清除」机制；永久删除再清附件。

邀请制 Supabase

手动上传 / 拉回，自动上传默认关闭且只上传本机改动；UI 偏好与 AI 凭据不上云。

导出迁移

全量数据包、附件包与可读导出；导入先备份，再做版本校验与按 ID 合并。

阅读顺序：先看调度台四卡池，再看方向台如何给任务 / 选题归属，随后进入策展台关联资源卡与选题卡；画像洞察负责复盘，数据底盘负责本机主权与可选云同步。

TECHNICAL ARCHITECTURE · CHROME MV3

Vue 3 + TypeScript strict + Vite / @crxjs + Pinia + Vue Router(hash)。主应用位于 New Tab Page；Content Script 负责网页浮层；Service Worker 负责命令、注入、单例定位与路由中转。

  • ProjectCuration · 项目详情 `/compass/projects`
  • Workspace · 策展台 `/workspace/:id`

Content Script · 网页浮层 VANILLA

装载与信号层，按需动态 import。

overlay-impl.ts

搜索、资源采集、任务采集、好奇心采集、选题采集。

selection.ts

捕获网页选区，自动预填标题 / 来源 / 选中文本。

Service Worker · 跨上下文协调 MV3

commands

系统命令分发；默认建议键有限，其余在扩展快捷键页绑定。

zy-ping / zy-where

浮层注入决策与单例新标签页定位询问链。

zy-open-route

现役技术边界：没有 `CurationCenter.vue` 现役路线，没有 `src/mobile`，没有 PC Inbox，没有 Airtable 运行时。浏览器降级入口直接进入应用并打开同一块面板。

数据架构图

DATA ARCHITECTURE · APP DATA

主数据是单个 AppData JSON；关系型能力用独立记录表承接，避免卡片本体互相写 id。附件住 IndexedDB，事件、日统计、热度、AI 配置与 UI 偏好分键保存；云同步使用共同基线的三方合并。

AppData 主根

方向与归属

`compass`：愿景 / 使命 / directions / projects / metrics；任务与选题通过 `projectId`、`metricId` 归属。

四类调度卡

`resources[]` · `tasks[]` · `topics[]` · `curiosities[]`。
四卡池 = 这四类卡的全部现役集合。

台内论证卡

`argCards[]`：只属于策展台，不进四卡池；可与节点正文、资源镜像共存。

选题专属

`topicStatuses[]` 状态定义
`topicResourceLinks[]` 选题 → 资源关系，带 `snapshot`。

策展与组织

`workspaces[]` 策展台
`categories[]` 台内节点
`curationProjections[]` 节点资源镜像
`tagTree[]` 标签树。

今日与统计

`dailyFocus[日期→≤3 槽]`、`focusMeta`、`stats`、`activityLogs`、字段配置与状态定义。

关系表 · 卡片本体不互写对方 id

任务 ← 资源

`SupportLink[]`（含 `subId`、AI / 手动来源与资源快照）

好奇心 ← 资源

`CurioSupportLink[]`；删任一端不级联删除另一端。

选题 ← 资源

`TopicResourceLink[]`；同选题同资源判重，快照独立于源卡后续变化。

策展节点 ← 资源

`CurationProjection[]`；同一资源可镜像到同台不同节点。

资源常用夹

`resourceFolders[]` + `resourceFolderMirrors[]`。

明文引用例外

策展节点 `Category.linkedTopicIds` 直接引用选题卡 id；只记引用、不改选题本体。

读：缓存直读 · 写：300ms 防抖 → normalize / merge → storage.set
本机副通道

UI / 事件 / 统计 / AI / 附件

`K.UI` 偏好、`K.EVENT_LOG` 操作流水、`K.DAILY_STATS` 时间序列、`K.STATS` 热度、`K.AI_CONFIG` 本机 AI 配置、`IDB_NAMES.ASSETS` 附件 Blob。

Supabase 云同步

共同基线三方合并

`K.CLOUD_SYNC_BASE` 保存最近成功同步快照。只同步业务数据；同字段冲突逐项确认，不静默整端覆盖。

归一化

`normalizeAppData()`

本机载入、导入、云恢复统一补齐旧快照缺字段，避免调度台 `.map()` 白屏；迁移戳与旧键清理另走设置与启动迁移。

数据红线

镜像白名单四条

任务 → 资源、策展节点 → 资源、资源常用夹 → 资源、选题 → 资源。每次建立独立快照，删除源不影响镜像。

软删与回收站

删除写 `deletedAt`；可恢复；没有 30 天自动清除。永久删除才清附件与关系。

选题不计任务完成率

选题卡是成果层，状态可自定义且保留唯一完成态；任务卡三态才进入任务完成率。

今日三件事同源

任务 / 选题共用 3 槽；与今日日历双向联动；移出三件事同时清空该卡今日计划日期。

云端边界

UI 偏好、抽屉宽度、筛选排序与 AI 凭据不上云；普通卡片附件不上云，策展节点附件登录后进入私有 Storage。

功能模块架构图

FEATURE MODULE ARCHITECTURE

按工作面分组，不按历史版本分组。每个模块只列现役主入口与真实能力，退役项在第六节集中登记去向。

调度台 · 今日与四卡池

今日三件事

恒 3 槽；任务 / 选题卡型过滤；关键词检索；未勾选推进到进行中，勾选置完成，取消完成优先恢复此前状态。

任务卡池

卡片 / 列表 / 日历；状态与项目筛选；清单可折叠；卡片详情聚焦标题、资源镜像与计划日期。

选题卡池

左侧清单可折叠，右侧月 / 周日历与状态看板；拖拽日历写计划日期，拖拽看板改状态；成果链接首屏显眼、双击直达。

好奇心卡池

状态筛选、来源与支撑资源；单击右侧详情，不跳二级页。

资源卡池

资源唯一真身；网格 / 列表、常用夹、标签、搜索、批量管理；详情右侧滑出，单击不改跳整页。

今日日历

任务与选题同源；月 / 周视图；满 3 格拒绝第 4 项；拖动即改计划执行日期。

方向台 · 目标与行动

六层结构

愿景 / 使命 / 战略目标支持双击就地改文本；使命更新同步品牌区。

项目塔 / 全景

指标整组排序；项目内展开与折叠；只呈现当前项目与上一层的关联脉络。

任务与成果

成功指标下并列任务与选题卡；选题卡带「成果」色与标记，不混入完成率。

方向树策展模式

树状 / 金字塔共享过滤与折叠集合；单项目聚焦后居中、左右端对齐，背景信息降权。

新建任务抽屉

标题输入区放大为主视觉；AI 填表、优先级退役；项目 / 指标 / 计划日期保持克制。

策展台 · 论证与成果

中心论点 / 节点

中心论点与分支结构化；页头与工具条合并为双列控制台，左右对齐。

关联卡片

正文主 CTA；筛选全部 / 资源卡 / 选题卡；资源镜像只读，选题卡保留成果身份。

论证卡

标题 + 正文 + 关联资源；节点内的观点 / 论据 / 反驳，不进入四卡池。

附件与分享

附件次级化；图片预览 / 下载，HTML / PDF 下载并打开；分享 HTML 不重复附件清单。

画布历史

保留当前会话最近 10 步；云同步恢复不清空画布操作历史。

画像洞察

范围控制 + AI 洞察

今天 / 本周 / 本月 / 本年与下方模块同组；指标栏覆盖资源 / 任务 / 选题 / 好奇心，均支持下钻。AI 洞察基于所选模块数据生成汇总分析。

设置与治理

字段 / 状态 / 数据

选题状态可改名改色并保留唯一完成态；附件管理支持无引用附件手动清理；四主题与两档密度；云同步、快捷键、回收站与手册统一入口。

设计系统与交互契约

DESIGN SYSTEM · OPPO-INSPIRED

视觉语言以「圆润、克制、有呼吸感」为基线；主题是语义令牌，不是局部换色。主行动色统一跟随知源 Logo 蓝，OPPO 绿作为独立主题存在。

四套主题

光速黑（默认，暗红强调）
极简白
纸墨白
OPPO 绿

形状与层级

大圆角卡片、低对比分层、柔和阴影；主卡片与次级面板通过 surface / border / shadow 区分，不靠粗重边框。

信息焦点

调度台焦点是今日三件事；方向台焦点是愿景与当前项目链；策展台焦点是中心论点与画布。每个工作面只保留一处 display 级标题。

操作顺序

高频动作前置：关联卡片高于附件；今日行动高于统计；标题高于元数据；资源查找按钮紧邻资源镜像字段。

响应与密度

1440 主容器居中；1024 / 800 无横向溢出；密度仅两档：紧凑 / 舒适。策展画布不受全局密度影响。

动效纪律

只用有意义的进入 / 展开 / 定位反馈；常驻呼吸动画退役；顶栏同步入口不挂呼吸灯。

四个卡池不是四套视觉系统：任务、选题、好奇心、资源共享卡片基底与抽屉语言；仅用卡型徽记、语义色和字段组表达差异。选题卡用「成果」强调色，论证卡只在策展台出现。
