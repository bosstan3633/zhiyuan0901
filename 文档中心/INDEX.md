## 📋 如何跑门禁（最短路径）

```bash
cd v2

# 1. 类型检查
npx vue-tsc --noEmit

# 2. 静态回归（109 个分片，2,536 条断言 · V4.7.6 实测全绿）
node scripts/regression.cjs
#   ★纪律：断言只增不减；新增分片必须同时进 regression.cjs 的 SHARDS 并 git add
#     （否则新克隆 require 直接 MODULE_NOT_FOUND，整条回归在加载期就死）
#   ★数字会随每批增长，引用前一律实跑；权威读数见 评审交接包/01_项目透视卡.md

# 3. E2E（需 Chromium）
node scripts/e2e.cjs

# 4. 死类扫描
node scripts/dead-css-scan.cjs

# 5. 入口矩阵
node scripts/entry-matrix.cjs

# 6. 构建 + 打包
npm run build && node scripts/pack.cjs
```
