| 镜头 | 母本区间 | 成片区间 | 画面 | 旁白（实测时长） |
|---|---|---|---|---|

| 5 信任托底 + 品牌收口 | 00:48–01:00 | 46.0–60.0 | 导出面板 → 数据落地 → 尾帧氛围 → 品牌尾帧 | v5 **12.70s** @46.50（46.50–59.20） |

### 关于镜头4/5 边界的一处必要调整（诚实说明）

母本给定的镜头4/5 边界为 35s / 48s，但**母本自己的旁白字数与时间轴不自洽**：

- 母本标注「旁白全稿约 198 字，语速约 3.3 字/秒」；
- 实测母本旁白原文为 **232 字**（不含标点），60 秒即 **3.87 字/秒**；
- 其中镜头5 的 65 字若压缩到母本给的 12 秒，需 **5.4 字/秒**——这不是母本要求的「平静、清醒」语速。

**处理方式**：保持镜头1/2/3 边界与母本完全一致；镜头4/5 边界由 35/48 调整为 **35/46**，让镜头5 拿到 14 秒。经 TTS 实际生成后 v4 = 9.20s、v5 = 12.70s，均完整落在窗口内且不赶读。
**没有做的事**：没有为塞进 12 秒而删改母本旁白的任何信息点，也没有把语速提到 5.4 字/秒。

## 五、声音设计（实测逐秒电平）

母本「声音设计」节要求：环境杂讯渐强 → 痛点问句处戛然静音 → 10s 起克制极简电子配乐。

| 时刻 | 实测 mean_volume | 对应母本要求 |
|---|---|---|
| 2s | −16.2 dB | 环境杂讯渐强 + 旁白进行中 |
| 7.2s | −30.3 dB | 旁白「走到哪了？」已收，环境杂讯收尾 |
| **8.2s** | **−91.0 dB** | **戛然静音**（母本要求的转折点，真静音） |
| 9.2s | −27.3 dB | 静默尾巴 |
| 10.5s | −12.2 dB | 极简电子配乐淡入 + 镜头2 旁白起 |
| 12–50s | −11 ~ −13 dB | 配乐铺底、旁白主导（配乐音量 0.5×0.16，旁白 +1.5dB 让位） |
| 59s | −27.3 dB | 尾帧配乐淡出 |

- 配乐：`batch_text_to_music` 生成（极简电子氛围，无鼓点、无人声），28.1s 循环铺满 60s；
- 环境杂讯：`ffmpeg anoisesrc` 棕色噪声 0–7.4s 渐强，**不引入外部音效素材**；
- 旁白：TTS 5 段，声线 `Chinese (Mandarin)_Gentleman`（温润男声），分段 `adelay` 精确对位。

## 十、复现方式

```bash
cd 宣传片
node work/make_demo_data.cjs     # 1. 生成演示数据（对齐已验证的审计夹具形状）
node work/shoot_ui.cjs            # 2. 补拍 9 张 1920×1080 真实界面（需先起本地宿主页服务）
python3 work/make_overlays.py     # 3. 渲染字幕 / 品牌尾帧 / 紫色主线
python3 work/build_segments.py    # 4. 16 段标准化（Ken Burns 运镜 + 精确帧数）
python3 work/compose.py           # 5. 拼接 + 叠加 + 混音 → out/
python3 work/redline_check.py     # 6. 红线自查
```

宿主页服务（第 2 步前置，浮层需要真 http 页面，content script 只注入 http/https）：
```bash
cd 宣传片/work && python3 -m http.server 8799 --bind 127.0.0.1
```
