## 一、版面结构（一屏到底，移动端优先）

```
┌──────────────────────────────────────────────┐
│ ★ 第一阶 · 定锚（Why + What）              │

│ ★ 第二阶 · 共鸣（温和 PAS，不平铺焦虑）      │

├──────────────────────────────────────────────┤
│ ★ 第三阶 · 价值与证据（JTBD + 真实界面）     │

│   附真实界面占位与 ①②③ 注释                 │
├──────────────────────────────────────────────┤
│ ★ 第四阶 · 消除防卫 + 行动收口               │
```

**设计原则**：一眼能扫 / 移动端 360~420px 不出横向滚动 / 文字呼吸感胜过信息密度 / 白底为主、OPPO 绿只在关键节点落 / 一张真实界面图胜过十段形容词。

**信任微标（小字号，不抢主视觉）**：
Chromium 扩展 · 100% 本地运行 · 无需注册 · 免费体验中

---

### ★ 第二阶 · 你是否也有这些时刻？

> 不说"你很焦虑"，只描述三种真实的断裂。让读者自己点头。

**断裂 Ⅰ · 方向的断裂**
每天很忙，却说不清手头这件事和自己的赛道，到底是什么关系。

**断裂 Ⅱ · 信息的断裂**
看过、存过很多，真正需要的那一刻，却想不起、找不到、用不上。

**断裂 Ⅲ · 价值的断裂**
持续在解决问题，却没有沉淀成别人愿意为之付费的成果。

> *问题不在你不够努力，在于三段断开了。*

### ★ 第四阶 · 消除防卫 + 行动收口

## 三、设计纪要（给设计 / 前端）

- **画幅**：移动端竖版，内容宽 420px 基准，最终导出 1080 × auto PNG，或 A4 PDF。
- **色板**（同 OPPO 纸墨白体系）：
  - 纸墨白 `#FAF9F5` / 次纸 `#F2F0E9`
  - 墨 `#1A1D23` / 次墨 `#4C5563` / 弱墨 `#8A9099`
  - OPPO 绿 `#00A870` / 深绿 `#00805A` / 浅绿 `#E4F6EF`
  - 迷失标记橙 `#E86A17`（仅三种断裂使用，面积极小）
  - 引导线 `#DDD8CB`
- **字重**：Slogan 700 / 章节标题 700 / 正文 400~500；行高 1.7~1.8；字号梯度 44 / 22 / 17 / 15 / 13。
- **组件**：
  - 三种断裂用竖排三卡，左侧 3px 橙边；
  - JTBD 表用 "①②③④" 圆点 + 左右对照；
  - 底部 CTA 只一个按钮，无次要按钮并排放。
- **禁止**：渐变紫、胶囊堆砌 emoji、彩色横排 tag、"AI 智能""第二大脑""效率倍增"等词。

## 四、渠道落地建议

- **公众号 / 官网长图**：直接用导出的 PNG，按段落裁切。
- **销售对话**：发 PNG 长图（不要发 PDF，手机上 PDF 阅读体验差）。
- **行业版变体**：保留框架，仅替换第二阶三种断裂的具体场景描述与第三阶的界面截图（例如升学规划师版用"政策文件 + 家长咨询现场"作场景）。
