## 〇、一句话结论

> **知源调度台（Ownway）= 你在浏览器里的个人调度中台。**
> 它接管你的新标签页，把链接、文件、Obsidian 笔记、AI 聊天金句、一闪而过的念头统一收纳为三类卡片，
> **让你见过的每一个信息，都具备在正确时刻被召回、被论证、被展示的能力。**
>
> 它不生产内容、不替你决策、不抢你的笔记与协作——**它是一层横在所有工具之上的调度层。**

**拍片人最该记住的三件事**：
1. **这不是一个"工具展示片"，是一条"人生动线片"**——外部万千 → 内有主线。
2. **产品的灵魂是"看见"**（看见方向、看见好奇、看见成果），不是"存了多少"。屏幕上有多少张卡，不等于产品有多少价值。
3. **全片最忌讳的是把知源拍成一个仪表盘或仓库**。它是安静、可信、克制、键盘优先的专业指挥台。

## 二、产品定位四问

### 2.1 我是谁

| 维度 | 定稿 |
|---|---|
| **品类** | **你在浏览器里的个人调度中台** |
| **通俗解释** | 围绕自己的方向，组织探索、调用与成果的工作空间 |
| **名字释义** | **知源** = 知道自己为何出发，也知道所用信息从何而来；**调度** = 围绕自己的问题，让合适的信息、工具与材料参与行动 |
| **不是什么** | 不是书签管理器、不是笔记软件、不是待办清单、不是新标签页美化工具、不是"第二大脑" |
| **竞品判词** | **通用工具比知源"更能装"，知源比通用工具"更能调"** |

### 2.2 对谁说

**不按职业定义，按工作方式识别**——四条特征：
① 主要在浏览器中接触信息与开展工作；② 需独立决定研究什么、投入什么、如何交付；③ 同时使用多个信息来源和工具；④ 希望把探索与行动连接，并形成自己的成果表达。

优先验证人群：**独立顾问 / 研究型创作者 / 独立研究者 / 多项目知识工作者**。

> **不是为谁设计**：想找"存一堆链接就不看"工具的人；已有完整 Notion/Obsidian 工作流且满意的人；强依赖多人实时协作、自动云同步或自动化执行的人。

### 2.3 解决什么问题

> 不是"信息太多"——而是：**外部可能性持续增加，个人却难以把方向、探索和行动组织在一起。**

表现为**四种断裂**：看到新工具想试却不清楚与当前问题有什么关系；产生好奇却没有后续承接；任务做了不少却看不清与长期方向的关系；形成了材料与产出却没组织成能表达判断的成果。

### 2.4 明确不做什么（七不原则）

不做云同步 / 不做 AI 替用户决策 / 不做"第二大脑" / 不做社交协作 / 不做使用追踪与画像 / 不做 KPI 压迫式管理 / 不做复杂长文编辑与事实裁决。

**唯一出网行为**：用户在「设置 → Airtable 同步」自行配置 Personal Access Token 并**手动触发**的单向推送（推到用户自己的 Base，**绝不回写本地**）。除此之外产品不发起任何网络请求。

## 三、内涵与精神层

### 3.1 品牌内涵（2026-09-07 确立，至今未变）

> **以个人方向为中心，以好奇驱动探索，以调用推进问题解决，以策展呈现成果。**
> （搜索、收录与卡片是**实现方式**，不再承担主定位。）

### 3.2 心智画面

> **外部万千，内有主线**——一条属于用户的行动路径：沿途留下好奇，接入所需工具与材料，并形成阶段成果。

**主视觉不是"资源仓库"，也不是"复杂驾驶舱"。** 这是全片最重要的一条审美约束。

### 3.3 三卡 · 六层 · 五动词

**三卡**（一切起点）：

| 卡型 | 是什么 | 归宿 |
|---|---|---|
| **资源卡** | 有出处的事实资产（网页/文件/Obsidian/附件） | 资源卡池 |
| **任务卡** | 可执行事项，需被跟进、被闭环 | 任务卡池 |
| **好奇心卡** | 一闪而过的念头 / 问题 | 好奇心卡池（全局池） |

**六层**（对外称"目标与行动"）：愿景 → 使命 → 战略目标 → 项目 → 成功指标 → 任务。任务必须挂在某个项目的某个成功指标下；未挂即"未归档任务"。

**五动词闭环**：`入台 → 归位 → 调出 → 复用 →（校准）`

> **闭环跑一年，两个用户的资源网络完全不同——工具相同，长出来的是各自的。这是护城河。**

### 3.4 两条生命线

1. **性能、响应速度、稳定性是第一生命线**——慢等于没有。
2. **UI、交互、外观是第二生命线**——**"看见"是产品灵魂**：看见任务、看见项目、看见方向树、看见策展台，所有的看见都要符合阅读的审美。

### 3.5 六条可验证的硬承诺

| 承诺 | 事实 |
|---|---|
| 快速采集 | `Ctrl+Shift+J` 任意网页 **5 秒入台** |
| 好奇心速记 | `Ctrl+Shift+I` **3 秒接住**念头，选中文本自动带来源 |
| 全局搜索 | `Ctrl+K` 任意网页调出，拼音/首字母命中，回车/双击直达 |
| 数据主权 | 100% 本机，无账号、无云端、无追踪，导出 = 一份 JSON |
| 删除可逆 | 删除一律软删，回收站可恢复 |
| 流畅性 | 视图切换全部 **< 40ms**（实测，两帧以内） |

### 3.6 精神底色：本地优先不是功能，是立场

订阅制 + 云服务 = 用户是**租客**；知源坚持让用户做 **owner（所有者）**——数据归自己、判断归自己、节奏归自己。英文名 **Ownway = Own + Way = 走自己的路**。

主色 `#6D5CE8` · 深色基底 `#171B2E` · 浅色背景 `#F7F8FC` · 正文 `#252A3B` · 好奇点色 `#B96A20`（仅用于好奇相关元素）。
> 品牌紫与产品界面强调色同属紫系，**正式定稿前须对齐并检验对比度**。

### 5.4 动效语言（实测 `tokens.css`）

- 时长：`--dur-fast 120ms` / `--dur 150ms` / `--dur-slow 250ms`
- 缓动仅 3 条：`--ease-out-soft cubic-bezier(.2,.8,.2,1)`、`--ease-emphasis cubic-bezier(.16,1,.3,1)`、`--ease-spring cubic-bezier(.34,1.56,.64,1)`
- **产品内：路由零动画**、卡片态切换 ≤150ms、**呼吸类常驻动画禁止**
- **对外物料动效**：路径与节点动画 600~900ms，`cubic-bezier(.16,1,.3,1)`；**不得用动效暗示产品不具备的自动能力**

### 7.1 禁用词

> **掌控一切** / **永不迷失** / **自动识别可信来源** / **所有工具一键调用** / **链接万物** / **第二大脑** / 收藏夹工具 / 笔记软件 / 新标签页美化 / 国产 Notion / 第二个 Obsidian

### 7.2 慎用词

| 词 | 为什么慎用 |
|---|---|
| "AI 驱动" / "智能推荐" | 知源不替用户决策 |
| "三秒"等效率数字 | 仅限已演示动作可用；未验证处写"几秒" |
| "入台" | 首次出现必须解释为"收录到知源" |
| "方向链" | 对外优先说"目标与行动" |

### 7.3 视觉禁用隐喻

大脑 · 文件柜 · 书架 · 放大镜 · 飞机驾驶舱 / 复杂仪表盘 · 神经网络 · 发光粒子流 · "信息汇入搜索框"。
**严禁大红大绿的 KPI 焦虑感仪表盘**；方向状态四指标只能做安静的背景。
**禁止把母题画成"文件柜/书架/文件夹"或"信息汇入搜索框"隐喻。**

### 7.4 表达层级

> **立场 → 体验 → 动作 → 证据**
> （"自有我方向"是立场；"看见方向"是体验；"将今日任务关联到项目"是动作；真实界面和操作演示是证据。）

### 7.5 叙事铁律

> **外部情境 → 自己的问题 → 选择投入 → 调用行动 → 形成成果。**
> 不从"收藏了很多东西"开场，不以"又存了很多卡片"结尾。故事的转折是用户作出了选择，结尾是问题有所推进或形成了表达。
