# 02-4 · 产品演示脚本集

> 对象：销售/创始人/录屏 ｜ 前置：装好演示环境（演示工作台+预置数据，见 [03-5 模板库](../03_用户与交付/03-5_模板库.md)）。铁律：**只演示已实现功能**，禁止现场即兴许愿。叙事结构：外部情境 → 自己的问题 → 选择投入 → 调用行动 → 形成成果（见 [01-4 §2](../01_品牌与定位/01-4_品牌故事与创始人故事.md)）。

## 1. 三分钟极速版（社交场合/初触达）
0:00 情境一句："带着一件正在推进的事进入知源——比如你正在准备的一份方案。"
0:20 Ctrl+Shift+J 现场收录一个相关网页（数秒，自动带标题/链接/选中文本）。
0:40 Ctrl+K 搜索已收录条目 → 调出 → 双击直达。
1:20 把这张卡挂到项目与指标（展示卡片详情抽屉：调用=让材料参与任务）。
2:00 切到调度台：今日三件事 + 方向状态四指标（看见方向）。
2:40 数据安全一句：现场点设置→导出，展示 JSON 文件。收口："看见方向，留下好奇，调用所需，策展成果。"

## 2. 十分钟销售版
三分钟版基础上：+工作台分类树与看板（1 分钟）+好奇心采集与回看转卡（1 分钟）+今日三件事与目标行动关联（2 分钟）+策展中心镜像混排（1 分钟）+异议预答（数据安全/学习成本，1 分钟）。节奏与异议话术见 [02-8](./02-8_销售FAQ与异议处理.md)。

## 3. 三十分钟深度版
十分钟版基础上：+安装实操（带对方装）+书签 HTML 导入 +附件挂卡与预览 +回收站/导出/迁移演练 +按对方职业走 [02-3 场景方案](./02-3_场景化解决方案集.md) 对应节 +送 [03-2 七天上手计划](../03_用户与交付/03-2_七天上手计划.md)。

## 4. 直播演示版
结构同十分钟版，但每 2 分钟埋一个"观众可跟做"的动作（先装好再看）；弹幕高频问题（同步？价格？）统一口径见 02-8；结尾送七天上手计划。

## 5. 无人讲解录屏版（60~90 秒）
纯操作录屏+字幕：收录(5s)→搜索调出(3s 倒计时字幕)→挂项目(10s)→三件事(10s)→策展(10s)→导出 JSON(10s)。字幕只用核心动词，结尾出主 Slogan（万千可调用，自有我方向）。

## 6. 贯穿演示项目（对外宣讲用）
"完成一次专题分享"：先解释为何做这场分享 → 确定今天的任务 → 阅读中记录一个问题（好奇）→ 打开相关工具与信息源（调用）→ 围绕核心判断组织策展材料（成果）。所有操作使用实际版本可完成的路径；需外部工具完成的环节，明确展示工具边界。完整 12 页框架见 [02-2](./02-2_销售演示文稿大纲.md)。
