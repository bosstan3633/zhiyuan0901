# 02-4 · 产品演示脚本集

> 对象：销售/创始人/录屏 ｜ 前置：装好演示环境（演示工作台+预置数据，见 [03-5 模板库](../03_用户与交付/03-5_模板库.md)）。铁律：**只演示已实现功能**，禁止现场即兴许愿。

## 1. 三分钟极速版（社交场合/初触达）
0:00 痛点一句："您有没有过——明明见过，就是找不出来？"
0:20 Ctrl+Shift+J 现场入台一个网页（5 秒）。
0:40 Ctrl+K 输入拼音首字母 → 三秒调出 → 双击直达。
1:20 把这张卡挂到项目与指标（展示卡片详情抽屉）。
2:00 切到调度台：今日三件事 + 方向状态四指标。
2:40 数据安全一句：现场点设置→导出，展示 JSON 文件。收口："调度，不是收藏。"

## 2. 十分钟销售版
三分钟版基础上：+工作台分类树与看板（1 分钟）+好奇心采集与转卡（1 分钟）+今日三件事与方向链（2 分钟）+策展中心镜像混排（1 分钟）+异议预答（数据安全/学习成本，1 分钟）。节奏与异议话术见 [02-8](./02-8_销售FAQ与异议处理.md)。

## 3. 三十分钟深度版
十分钟版基础上：+安装实操（带对方装）+书签 HTML 导入 +附件挂卡与预览 +回收站/导出/迁移演练 +按对方职业走 [02-3 场景方案](./02-3_场景化解决方案集.md) 对应节 +送 [03-2 七天上手计划](../03_用户与交付/03-2_七天上手计划.md)。

## 4. 直播演示版
结构同十分钟版，但每 2 分钟埋一个"观众可跟做"的动作（先装好再看）；弹幕高频问题（同步？价格？）统一口径见 02-8；结尾送七天上手计划。

## 5. 无人讲解录屏版（60~90 秒）
纯操作录屏+字幕：入台(5s)→调出(3s 倒计时字幕)→归位挂项目(10s)→三件事(10s)→导出 JSON(10s)。字幕只用核心动词，结尾出主 Slogan。
