# 知源调度台 1 分钟宣传片 · 分镜脚本与 Agent 提示词母本

> 版本：V1.0 ｜ 2026-10-27 ｜ 事实基线：V3.9.21（2026-10-26 实跑）
> 事实源：《00 产品事实与表达母版》《01-1 品牌定位手册》《01-2 品牌语言手册》。任何镜头与本母本冲突时，以事实源为准。
> 用法：第一至三章供人审阅定稿；第四章「Agent 提示词母本」可整段复制投喂给视频生成 Agent。

## 第一章 · 战略锚定层（唯一叙事主线）

| 锚点 | 定稿内容 |
|---|---|
| 对谁说 | 以浏览器为主要工作入口的独立顾问、研究型创作者、独立研究者、多项目知识工作者 |
| 抓哪个痛 | 不是"信息太多"，而是"外部可能性持续增加，个人却难以把方向、探索和行动组织在一起"——关键时刻材料调不出、忙了一天却看不清与长期方向的关系 |
| 我是谁 | 你在浏览器里的个人调度中台。不是书签、不是笔记软件、不是新标签页美化 |
| 唯一主线 | 外部万千 → 内有主线：从"被打断与散落"到"围绕自己的方向组织探索、调用与成果" |
| 叙事铁律 | 外部情境 → 自己的问题 → 选择投入 → 调用行动 → 形成成果。不从"收藏很多"开场，不以"存了很多卡"结尾 |
| 情绪曲线 | 嘈杂（0-10s）→ 收束（10-20s）→ 笃定（20-35s）→ 升华（35-48s）→ 安心（48-60s） |
| 全片只做一件事 | 演示"带着一件正在推进的事"，从痛点现场走到成果表达 |

**砍掉的次主线**（本片一律不出现）：六层方向树细节、多系统页逐个导览、画像洞察页、四种主题切换、回收站、看板/列表视图切换、批量管理、书签导入。这些留给图文手册与深度演示视频。

## 第二章 · 价值转译层（立场 → 体验 → 动作 → 证据）

| 提炼维度 | 立场/体验（概念层） | 核心动词（动作层） | 画面证据（视觉指令，全部有实装依据） |
|---|---|---|---|
| 破局动线 | 不打断心流，随时接住外部信息与念头 | 收录入台 / 留下好奇 / 调出 | 任意网页 `Ctrl+Shift+J` 浮层数秒收录（自动预填标题/URL/选中文本）；`Ctrl+Shift+I` 念头速记（选中文本自动填入）；`Ctrl+K` 全局搜索浮层，拼音/首字母命中，双击直达 |
| 核心价值 1 | 看见方向：今天的行动有来处 | 校准 / 归位 | 新标签页打开调度台首屏：「今日三件事」高亮主卡，整行点击打开右侧任务详情抽屉，任务挂到主攻项目与成功指标；首屏上方方向状态四指标（战略目标数/推进项目数 · WCE 好奇探索 · WRR 资源复用 · 未归档任务）静默陈列，不打 KPI 焦虑牌 |
| 核心价值 2 | 调用所需：不必事事从零开始 | 调用 / 复用 | 任务详情抽屉内直接挂载/调出关联资源卡与本地附件；镜头给 `🔥 复用计数` 一个特写；必要时快速扫过调度台底部「资源卡池」tab |
| 核心价值 3 | 策展成果：做过的事形成自己的表达 | 策展 / 镜像 | 策展台：顶部 `🏛 中心论点` 横幅 + 金字塔居中树（主题—判断—论点—证据），卡片跨节点拖拽，镜像引用源数据零影响 |
| 信任底盘 | 数据主权：做数据的 Owner 而非租客 | 导出 | 设置页一键导出单根 JSON（全量、含界面偏好）；字幕定格"100% 本地保存 · 无需账号 · 可导出迁移" |

## 第三章 · 60 秒五段式分镜表

> 旁白全稿约 198 字，符合 180–220 字预算；8 个核心画面切换。

### 镜头 1｜00:00 – 00:10｜外部情境与痛点
- **画面**：快速闪切——爆满的浏览器标签页、散落在各处的 AI 报告与聊天记录、聊天框里尴尬打出的"材料稍后找给您"。画面偏冷灰、轻微噪点，暗示失序。
- **旁白**："世界不断上新，工具越攒越多。但你要推进的那件事——走到哪了？"
- **声音**：环境杂讯渐强，在"走到哪了"处戛然静音。
- **红线自查**：不出现"失控""落后""追赶"等贬损用户的措辞，痛点只描述情境，不评价人。

### 镜头 2｜00:10 – 00:20｜产品出场与秒级动线
- **画面**：杂乱画面瞬间收束成一条连续的深空薰衣草紫主线（视觉母题首次出现）。三段实拍级 UI 演示：网页上 `Ctrl+Shift+J` 收录浮层、`Ctrl+Shift+I` 留下好奇、`Ctrl+K` 搜索浮层双击直达，每个动作给快捷键键帽特写。
- **旁白**："知源调度台——你在浏览器里的个人调度中台。收录到知源、留下好奇、随时调出，都只要几秒。"
- **字幕条**：品类解释句"你在浏览器里的个人调度中台"。
- **红线自查**："入台"首次出现已解释为"收录到知源"；效率数字写"几秒"，不写死"3 秒"。

### 镜头 3｜00:20 – 00:35｜选择投入与调用行动（调度台核心体验）
- **画面**：新标签页进入调度台。镜头聚焦首屏唯一主角「今日三件事」高亮主卡；整行点开任务详情抽屉，看到任务关联着主攻项目与成功指标；抽屉内一键挂载/调出历史资源卡，`🔥 复用计数` 特写。方向状态四指标在上方静默可见但不强调。
- **旁白**："每天打开新标签页，先看见今天最重要的三件事——它们挂在哪个项目、指向哪个目标，一目了然。需要的资料和工具，直接调用到任务里，不必事事从零开始。"
- **红线自查**：四指标只做背景不做主角，严禁渲染成 KPI 仪表盘。

### 镜头 4｜00:35 – 00:48｜形成成果（策展台价值升华）
- **画面**：切入策展台。顶部 `🏛 中心论点` 横幅亮起，下方金字塔论证树展开：主题 → 判断 → 论点 → 证据，零散素材卡片逐张镜像接入各节点，最后给完成的专题页整体定格。
- **旁白**："做过的事，别只留在记录里。在策展台，围绕主题取舍、分层，让判断有论据、让观点有支撑——策展成你自己的表达。"
- **红线自查**：措辞为"论证型策展可以用主题—判断—论点—证据"，不承诺所有成果同一形式。

### 镜头 5｜00:48 – 01:00｜信任托底 + 品牌收口 + CTA
- **画面**：设置页一键导出 JSON 文件落盘特写 → 画面收束回紫色主线，主线尽头定格品牌尾帧：Logo + 主 Slogan + 品类句 + CTA。
- **旁白**："你的数据 100% 存在本地，无需账号，随时导出。看见方向，留下好奇，调用所需，策展成果。知源调度台：万千可调用，自有我方向。带着一件正在推进的事，进入知源。"
- **尾帧字幕**：知源 Ownway ｜ 万千可调用，自有我方向 ｜ 免费使用 · 本地安装
- **红线自查**：不说"自动备份""云同步"；Airtable 单向推送本片不提（避免 60 秒内展开信任例外条款，图文材料另行交代）。

## 第四章 · Agent 提示词母本（整段复制投喂）

```text
你将为浏览器扩展产品「知源调度台」（英文名 Ownway）生成一支 60 秒产品宣传片。以下是必须严格遵守的全局规范，任何与规范冲突的自由发挥都视为失败。

【一句话定位】
知源调度台，是你在浏览器里的个人调度中台。面向以浏览器为主要工作入口的独立顾问、研究型创作者、独立研究者。不是书签管理器、不是笔记软件、不是新标签页美化工具。

【叙事结构（五段，不可调换顺序）】
外部情境 → 自己的问题 → 选择投入 → 调用行动 → 形成成果。
严禁从"收藏了很多东西"开场，严禁以"存了很多卡片"结尾。故事的转折是用户作出了选择，结尾是问题有所推进并形成了表达。

【时间轴与旁白（总长约 198 字，±10% 内可微调语感，不可增删信息点）】
00:00-00:10 痛点：爆满的标签页、散落的资料、"材料稍后找给您"的尴尬。旁白："世界不断上新，工具越攒越多。但你要推进的那件事——走到哪了？"
00:10-00:20 破局：画面收束为一条紫色主线。实拍级 UI：Ctrl+Shift+J 收录浮层（自动预填标题/URL/选中文本）、Ctrl+Shift+I 念头速记、Ctrl+K 全局搜索拼音命中双击直达。旁白："知源调度台——你在浏览器里的个人调度中台。收录到知源、留下好奇、随时调出，都只要几秒。"
00:20-00:35 调度台：新标签页首屏，「今日三件事」高亮主卡是唯一主角；整行打开右侧任务详情抽屉，任务挂在主攻项目与成功指标上；抽屉内挂载/调出资源卡，给"🔥 复用计数"特写。上方方向状态四指标（战略目标数/推进项目数、WCE 好奇探索、WRR 资源复用、未归档任务）仅作静默背景。旁白："每天打开新标签页，先看见今天最重要的三件事——它们挂在哪个项目、指向哪个目标，一目了然。需要的资料和工具，直接调用到任务里，不必事事从零开始。"
00:35-00:48 策展台：顶部"🏛 中心论点"横幅 + 金字塔论证树（主题→判断→论点→证据），素材卡片逐张镜像接入节点。旁白："做过的事，别只留在记录里。在策展台，围绕主题取舍、分层，让判断有论据、让观点有支撑——策展成你自己的表达。"
00:48-01:00 信任与收口：设置页一键导出 JSON 特写，字幕"100% 本地保存 · 无需账号 · 可导出迁移"；定格尾帧：Logo + "万千可调用，自有我方向" + CTA"带着一件正在推进的事，进入知源"。旁白："你的数据 100% 存在本地，无需账号，随时导出。看见方向，留下好奇，调用所需，策展成果。知源调度台：万千可调用，自有我方向。带着一件正在推进的事，进入知源。"

【视觉母题（每段都要贯穿）】
核心隐喻是"外部万千，内有主线"：一条连续的深空薰衣草紫主线贯穿全片，沿途节点接入信息与工具，最终收束为成果。
严禁使用以下隐喻：大脑、第二大脑、文件柜、书架、放大镜、飞机驾驶舱/复杂仪表盘、神经网络、发光粒子流。

【色彩与 UI 规范】
- 主色：品牌紫 #6D5CE8；画布：深空薰衣草近黑底色。
- 点缀色：好奇点琥珀 #B96A20（仅用于"好奇"相关元素）。
- 风格：Linear 式克制发丝线分节，一页一主角，大量留白。
- 严禁大红大绿的 KPI 焦虑感仪表盘；方向状态四指标只能做安静的背景。
- 所有 UI 画面必须是实拍级高保真界面录屏风格，不要生成卡通化或概念化的假界面。

【文案红线（违反任何一条即返工）】
1. 禁用词："掌控一切""永不迷失""自动识别可信来源""所有工具一键调用""链接万物""第二大脑"。
2. 不打焦虑：不得把用户描述成落后、失控、必须不停追赶的人；只描述情境，不评价人。
3. "入台"首次出现必须解释为"收录到知源"。
4. 效率数字仅限已演示动作，写"几秒"，不写死"3 秒"。
5. 数据安全只能表述为"100% 本地保存、无需账号、可导出迁移"；严禁出现"自动备份""云同步""云端"，本片不出现 Airtable。
6. 不出现六层方向树细节、多系统页导览、画像洞察页、主题切换、回收站、批量管理等功能堆砌画面。
7. 不使用"AI 驱动""智能推荐"等措辞。
8. 品牌名规范：中文"知源调度台"（简称"知源"），英文 Ownway，不混用中英，不出现旧标识 ZCC。

【声音设计】
00:00-00:10 环境杂讯渐强，痛点问句处戛然静音；00:10 起进入克制、笃定的极简电子配乐；全片无激昂鼓点、无史诗感。旁白为平静、清醒、有探索欲的中文人声，语速约 3.3 字/秒。

【交付物】
60 秒成片（16:9，1920×1080），含字幕轨；另输出 9:16 竖版裁切方案说明。
```
