# 02-8 · 销售 FAQ 与异议处理

> 对象：销售/渠道/客服 ｜ 原则：先共情、再给事实、最后回产品；所有事实与 [00 母版](../00_产品事实与表达母版.md)一致，不确定就记录回访，不现场编。

| 异议 | 应对话术（可口语化，事实不改） |
|---|---|
| 为什么不用书签？ | 书签是仓库，知源是调度台：拼音三秒调出、复用计数、能挂到项目与方向。而且书签可以一键导入知源，不是搬家是升级。 |
| 为什么不用 Notion/Obsidian？ | 继续用，我们不替代写作。知源解决的是"调用那一刻"：非笔记类资源（网页/文件/AI 产出）的三秒召回。Obsidian 还能从知源直达。 |
| 支持同步吗？ | V4 起提供**可选邀请制云同步**：多设备用得上可在「设置 → 数据管理 → 云同步」登录邀请账号、主动**手动上传/恢复**快照（本机是真源，云端是快照，不静默覆盖）。但它**不是自动云端备份**，也不会把你所有数据静默放上别人服务器；不想用完全可以不开，本机本地优先 + 导出迁移照常成立。 |
| 数据丢了怎么办？ | 三层保护：写入失败有告警重试；删除一律进回收站可恢复；导入前自动备份。长期备份建议每周导出一次 JSON。 |
| 本地存储安全吗？ | 数据默认就在你自己的浏览器配置文件里，本地优先；电脑本身的安全等级就是你数据的等级，和你的本地文档一样。V4 起可选邀请制云同步，但**默认不开启**——你自己主动登录、手动上传快照才会上云，普通卡片附件与 AI 凭据不上云；不做使用追踪。 |
| 学习成本高吗？ | 三个快捷键起步：Ctrl+Shift+J 采集、Ctrl+K 调出、新标签页看三件事。第一天就能用起来，第七天形成闭环（有七天计划）。 |
| 为什么买断制？ | 本地产品让用户做所有者：一次买断、数据自有、不订阅绑架。（当前免费，细节以正式发布为准。） |
| "不就是新标签页美化吗？" | 美是副产品。您可以现场只看功能：三秒调出+方向关联，把界面忘掉它依然成立。 |
| "等你们做同步我再买" | 我们把"导出"做到极致：您的数据永远能整包带走——这比把数据先交出去再谈同步，主动权在您手里。 |
