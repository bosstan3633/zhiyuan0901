## 使用纪律

1. 文案修改只在本集内改；涉及到事实口径的改动，先改 [00 母版](../00_产品事实与表达母版.md) 与 [01-6](../01_品牌与定位/01-6_核心叙事与卖点.md)，再回本集同步。
2. 各渠道不直接抄完整母版，本集每份只截取需要的卖点与句子。
3. 发布前过 [01-6 §7](../01_品牌与定位/01-6_核心叙事与卖点.md) 禁用与慎用清单。
4. 屏幕录屏必须取当前版本真实界面；不画产品里没有的界面。
