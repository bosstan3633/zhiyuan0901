# 02-3 · 场景化解决方案集（六角色版 + 示范故事）

> 对象：各垂直人群 ｜ 用途：让每类人一眼看到"我的事如何被组织"。场景事实须与产品能力一致（勿虚构不存在的功能）。对外首次使用"入台"时解释为"收录到知源"；语言红线见 [01-2 §4](../01_品牌与定位/01-2_品牌语言手册.md)。

## 0. 示范故事（虚构演示场景，非真实案例）

以下三篇为**场景化创作**，用于演示产品工作方式；正式案例应替换为获得授权的真实用户过程（流程见 [02-6 客户案例模板](./02-6_客户案例模板.md)）。每个故事以用户的问题开场，以判断、行动或成果收尾；产品只在关键转折中出现，不写成功能清单。叙事结构：外部情境 → 自己的问题 → 选择投入 → 调用行动 → 形成成果。

### 故事一：顾问的服务方案
**标题：工具很多，今天推进什么由自己决定。**

一位独立顾问准备形成新的服务方案。最近出现了很多新工具，但他当前要解决的问题是：如何将一次咨询组织成可重复交付的诊断流程。

他在知源中看见项目目标与今天的行动。浏览资料时，一个新问题引起兴趣，他先留下好奇，不立刻改变当前安排。需要推进研究时，再打开相关工具入口，调用已组织的案例与方法材料。

阶段结束，他围绕诊断流程，将判断、步骤、案例和样例组织成主题策展，检查自己的方案是否有足够支撑。

**品牌落点：**
> 外部的丰富，不必变成任务的分散；它可以成为当前项目的助力。

**应验证的事实：**用户是否真的以项目开始工作，资源关联是否有助于推进任务，策展是否形成了更清晰的方案。

### 故事二：从好奇到专题表达
**标题：一个值得追问的问题，可以慢慢形成自己的判断。**

一位创作者在阅读中产生疑问。他将它留下，继续完成手头工作。

后来回看好奇时，他选择开展专题研究。研究过程中，相关信息源、工具入口和实验材料逐渐围绕这个问题组织起来。

最终，他不再只是展示"读过什么"，而是围绕核心判断，把论点、证据和反例放入策展台，形成专题内容的结构。

**品牌落点：**
> 留下好奇，不是增加待办，而是保留一次自主选择探索的机会。

**应验证的事实：**好奇是否被重新看见，是否自愿转化为探索，材料是否真正参与最终表达。

### 故事三：多项目中的个人路径
**标题：不只看见忙碌，也看见自己正在走的路。**

一位独立工作者同时推进多个项目。他每天都在处理事情，却常常难以解释这些行动与长期方向的关系。

在知源中，他查看项目与目标，确定当日重点；将暂时不推进的问题留在好奇区，而不是全部变成紧急任务。

阶段回顾时，他围绕一个主题，将已完成的交付与相关材料组织起来。看到的不只是任务勾选记录，还有自己形成的工作成果。

**品牌落点：**
> 方向不是每一天都必须证明正确，而是值得被持续看见和重新判断。

**应验证的事实：**用户是否获得行动关系的清晰度，而不是承受更多目标与指标压力。

## 1. 升学规划师版
**痛点**：政策/院校/案例散落各处，咨询现场"稍后找给您"。
**用法**：按省份/批次建策展台与分类 → 政策原文、院校页、案例全部入台打标签 → 现场家长提问 Ctrl+K 三秒调出当场投屏 → 高频口径卡置顶复用 → 家长关心的方案挂进"这一家的项目"，今日三件事 = 跟进动作。
**一句话**：让每一次"稍后找给您"，都有下文。

## 2. 咨询顾问版
**痛点**：多客户并行，证据、访谈纪要、参考框架混作一团。
**用法**：一个客户一个项目挂战略目标 → 证据卡挂成功指标 → 周会前用项目调度看进度 → 交付物模板存为置顶卡复用 → 方向状态四指标看自己是否在"客户交付"主线上跑偏。

## 3. 行业研究员版
**痛点**：信源多、问题多、线索易断。
**用法**：好奇心采集随手记问题（Ctrl+Shift+I）→ 求证时把来源页入台互挂 → 好奇转任务/资源（计入 WCE）→ 研究结论卡按行业策展台归位 → 写作时 Ctrl+K 按拼音调出三个月前的线索。

## 4. 政策研究版
**痛点**：政策原文、解读、地方执行差异需精确溯源。
**用法**：原文链接+发布日期字段入台 → 自定义字段记"文号/生效日/适用范围" → 按"央/地/主题"分类树组织 → 现场答问双击直达原文 → 导出 CSV 做政策台账。

## 5. 内容生产者版
**痛点**：选题、素材、成品分散；灵感稍纵即逝。
**用法**：灵感进好奇心 → 立题转任务挂"内容项目" → 素材卡按选题归位 → 写作时三秒调出引用 → 成品链接回收入台形成"作品卡"复用。

## 6. 数据分析师版
**痛点**：数据集、查询、口径定义反复重找。
**用法**：数据集链接/本地文件入台 → 口径定义卡置顶 → 分析结论挂项目指标 → 复用计数暴露"真高频资产" → 本地文件双击直达（file:// 通道）。
