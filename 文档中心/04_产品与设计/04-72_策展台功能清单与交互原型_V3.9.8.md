## 一、策展台要解决的核心问题

策展台不是另一个资源列表，也不是任务看板。它是「被展示」的终点：

1. **把材料变成判断**：用中心论点回答“这份策展到底主张什么”。
2. **把判断变成结构**：用节点树回答“为什么这个判断成立”。
3. **把结构变成证据**：每个节点下挂资源卡，回答“依据是什么、原文在哪里”。
4. **把证据变成可分享的成果**：导出为自包含 HTML，回答“别人能否不装扩展也读懂并点开原文”。

一句话验收：**一个没装知源的人，打开分享 HTML 后，能看懂结论、顺着论证往下读，并点开节点下的原始资源。**

## 二、信息架构（编辑态）

```
策展台
├── 台身份：图标 / 台名 / 台描述 / 节点数 / 资源数 / 最近更新
├── 论点卡：标题 / 内容 / 创建时间 / 更新时间 / 关联结构 / AI / 分享
├── 指标条：论据卡片 / 佐证附件
├── 工具条：关联资源 / 分享 / 全台检索 / 筛选 / 设置
└── 策展画布
    ├── 布局：金字塔（向下）/ 树状（向右）
    ├── 节点：标题 / 说明 / 资源 chip / 子节点
    ├── 编辑：点击文字就地编辑
    ├── 键盘：Tab 创建子级 / Enter 创建同级
    └── 拖拽：拖动节点到另一节点下改父级
```

**关键取舍**：画布即编辑器，不再维护左侧「论证结构目录」与画布两棵树；删除「论证深度」「来源覆盖」两项难以稳定统计的指标。金字塔与树状共享同一份父子数据，切换布局不改变结构。

## 四、关键交互流程

### 流程 1：从中心论点开始编辑结构

1. 进入策展台，点击顶部论点卡查看或编辑标题、内容与时间。
2. 在画布中选择金字塔或树状布局。
3. 选中中心论点，按 `Tab` 创建二级分支；继续按 `Tab` 创建三级。
4. 选中任意分支，按 `Enter` 创建同级；点击文字直接编辑。
5. 在节点下点「资源」关联资源卡；无资源时显示“缺证据”。
6. 拖动节点到另一分支上，调整父子归属。
7. 点击「分享」，先预览再导出自包含 HTML。
8. 接收方无需安装扩展，即可阅读结构并点开原文。

### 流程 2：发现证据缺口

1. 成果图节点显示“缺证据”或“来源单一”。
2. 点击提示，打开「节点找证据」。
3. AI 在资源池中返回候选，并标注来源类型与匹配理由。
4. 用户勾选后采纳；节点计数与指标即时更新。

### 流程 3：修改中心论点

1. 点击中心论点横幅标题，打开资源卡详情。
2. 或点击「AI 提炼」查看候选论点与结构建议。
3. 用户点击「采用」后才替换；保留撤销入口。
4. 成果图根节点与分享预览同步更新。

## 五、分享 HTML 的阅读规范

### 5.1 内容顺序

1. 分享标题与导语。
2. 中心论点（唯一最高层级）。
3. 策展指标：节点数 / 资源数 / 附件数 / 一级分支数。
4. 目录。
5. 每个 L2 / L3 节点：节点判断 → 说明 → 资源卡列表。
6. 资源卡：来源徽标 → 标题 → 摘要 → 打开原文。
7. 附件清单（可选）。
8. 生成信息与版本页脚。

### 5.2 视觉规则

- 分享页与产品内主题分离，默认「纸白阅读版」，另提供「墨黑演示版」。
- 正文行宽控制在 68–76 个字符；中文段落最大宽度约 760px。
- 标题、节点标题、资源标题三级字阶必须可辨。
- 链接不能只靠颜色区分，必须有下划线或“打开原文”文字。
- 移动端单列；目录折叠；资源卡整卡可点。

### 5.3 安全边界

- 不输出 Airtable PAT、API Key、账号信息。
- 不输出本地绝对路径；本地文件只显示文件名与“本地附件”标记。
- 不执行外部脚本；不加载远程字体；不依赖知源扩展。
- 分享是文件，不是公开链接；产品不托管、不统计访问。

## 六、原型覆盖范围

高保真原型已覆盖：

- 四主题切换。
- 论点卡整卡点击 → 右侧详情 → 编辑保存。
- 金字塔 / 树状布局切换，两者共享同一份结构数据。
- 金字塔自上而下；树状从左上角的中心论点向右展开，首次切换自动定位根节点。
- 点击节点标题或说明直接编辑，失焦保存。
- 根节点 `Tab` 创建二级分支，二级 `Tab` 创建三级分支。
- 任意节点 `Enter` 创建同级分支，并立即聚焦新节点。
- 选中分支拖到另一分支，调整父级与层级。
- 拖动整棵子树时按最深层级校验；超四级时落点变红并显示原因。
- 节点内关联资源卡、资源详情与外链。
- 无资源节点显示“缺证据”并可一键关联。
- 全台检索与节点命中高亮。
- 指标下钻、AI 提炼、分享设置与自包含 HTML 预览。
- 功能标注、功能清单与窄屏布局。

原型不覆盖真实数据读写、真实 AI 请求与真实文件系统权限；这些属于开发阶段实现。原型内的「功能清单」抽屉收录 44 个代表性条目，完整功能范围以本文件第三节为准。

原型内置 14 张资源卡、12 个论证节点，其中 2 个叶子节点特意不放资源，用于评审“证据缺口”提示。页头指标会随关联资源操作实时变化，便于核对镜像计数与分享摘要是否同源。

### 10.1 浏览器实测

- 四主题切换正常；金字塔 / 树状布局可切换，切换后结构不变。
- 顶部论点卡点击可滑出详情，含标题、内容、创建时间、最近更新、关联结构与资源。
- 在中心论点按 `Tab` 创建 L2；选中 L2 按 `Enter` 创建同级；再按 `Tab` 创建 L3，三次均自动聚焦新节点标题。
- 新节点输入期间，状态栏 2.2 秒后只恢复文案，不重建画布，不抢走输入焦点。
- 节点标题与说明可就地编辑，失焦保存。
- 节点关联资源后，资源 chip 与页头、指标同步更新。
- 拖拽：将三级节点“瓶颈迁移”拖到二级节点“支撑证据”，DOM 归属改为其子分支，层级保持 L3，无控制台错误。
- 拖拽边界按整棵子树校验：若移动后最深节点会到 L5，则阻止落点并显示具体原因。
- 非法拖拽时目标节点显示红色落点与原因提示，松手不改变结构。
- 树状布局首次切换后自动校正画布滚动，中心论点根节点保持在左上起点，一级分支从同一水平线向右展开。
- 无资源节点显示“缺证据”，可直接打开资源池关联。
- 分享预览正常生成自包含 HTML，资源链接可点击。
- 760px 视口下无页面级横向溢出，画布内部保留局部横向滚动。
- 功能清单抽屉可展开查看验收说明。
- 键盘：`Cmd/Ctrl+K` 聚焦检索，`Esc` 逐层关闭弹层。
- 键盘拖拽兜底：聚焦节点拖动把手后，用 `↑ / ↓` 选目标，按 `M` 移动；非法目标仍走同一四级校验。
