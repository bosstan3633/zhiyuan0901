## 三、现状勘验

### 3.1 哑卡是怎么产生的

```ts
// :2440 现状
files.forEach(f => d.value.resources.unshift(
  makeHubResource(f.name.replace(/\.[^.]+$/, ''), 'file', f.name, catId)))
//                                                        ↑ 只存文件名，没有本体、没有附件
```

`toOpenableUrl('file', '报告.pdf')` → 仅文件名 → 返回空 → 双击「该卡未设置链接」。用户**无法找到也无法修复**（04-18 §261 原文）。

### 3.2 R14 的图片缺口

```ts
// :1107 现状
const meta = (r.assets || []).find(a => a.id === assetId)
if (!meta || (meta.kind !== 'html' && meta.kind !== 'pdf')) {
  showToast('⚠ 卡片指向的文档附件不存在或已失效'); return   // ← 图片卡走到这里
}
openHtmlAsset(meta)
```
