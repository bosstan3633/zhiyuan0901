## 2. 任务（五项，R173-1 ~ R173-5）

### R173-1 运行错误留痕真断链 ★真缺陷

- **症状**：真机右上角常驻「⚠ 运行错误 0」——读起来像"这里有报错"，且渲染崩溃一条都不进日志。
- **根因**（四条并存）：
  1. `App.vue` 的 `onErrorCaptured` 只 `return false` 并置 `renderError`。Vue 捕获后**不会**再触发 `window.error` ⇒ R48-A1 装的监听接不住渲染期崩溃，`zy_error_log` 恒空。
  2. 徽章无条件渲染 ⇒ 计数 0 也显示。
  3. 计数只在设置页 setup 读一次 ⇒ 进仪表盘不刷新。
  4. ★探针复测追加：即便补了第 3 条，**同文档内的 hash 切换不触发 `watch(activePage)`** ⇒ 本会话新崩的错误仍要等下一次换页才进徽章（探针实测：写入 1 条后徽章仍为空）。
- **落点**：`runtimeError.ts` 补 `source: 'render'` 与 `export function recordRuntimeError()` + `export function subscribeErrorLog()`（订阅 `chrome.storage.local.onChanged`，落盘变化即回填条数）；`App.vue` 边界里显式落盘；`DashboardOverview.vue` 改 `v-if="errorCount > 0"`；`GlobalSettings.vue` 的 `p === 'dashboard'` 分支加 `refreshErrorCount()`，并 `subscribeErrorLog(...)` + `onUnmounted` 退订。
- **判据**：`window.error` / `unhandledrejection` / 渲染管线三路都进 `zy_error_log`；徽章 0 不现、>0 现且**实时**（探针 A1~A4）。
- **★A4 的构造坑（记下来）**：原打算「塞一张缺字段的资源卡」逼出渲染崩溃——打不出来：`repository.ts` / `migration.ts` 对每个数组字段都有 `Array.isArray` 兜底归一化，脏数据会被静默修好。改用**打包后懒加载 chunk 缺失**这条真故障路径（拆包 / 杀软删文件 / 更新中断都会遇到）：临时改名 `GlobalPopups` 产物 chunk → 动态 import 失败 → Vue 异步组件错误处理 → `onErrorCaptured` → 落盘 `source=render`，同时全屏兜底屏接管（`re-msg` + 重试按钮）。

### R173-2 AI 复盘弹框补「选角色 + 一次性提示词」

- **动机**：全站其他 AI 入口都有「选专家 + 一次性指令」，只有复盘报告没有——同一产品里两套交互。
- **落点**：`narrateReview(rep, cfg, opts)` 新增 `NarrateOpts { personaId?, directive? }`（`chainPersonaText(pid)` 进系统消息；`【用户本轮指令】` 进用户消息）；`ReviewReportModal.vue` 加 `.dz-rpt-ctl` 行（角色 select 复用 `allPersonas()` + 指令 input + ↻ 重新生成）。
- **红线不变**：AI 只续写「洞察/建议」，数字白名单越界整段弃用；选角色与指令**都改不了结论与数字**。
- **判据**：切换角色后请求体里 `【执笔视角】` 段随之变化，`【用户本轮指令】` 与输入一致（探针 B1~B3，抓真实请求体而非读源码）。

### R173-3 零动作判词失真（0 动作却写"有在推进"）

- **症状**：全期无动作时报告仍走常规分支，写出「本期 0 个活跃日…整体在使命射程内、有在推进」这类自相矛盾的句子。
- **根因**：`buildReviewReport` 没有零态分流，偏斜/停滞/产出判断在 `acts === 0` 时全都不成立。
- **落点**：`acts === 0` 先分流，唯一主张 `CLAIM.zero = '本期没有任何动作记录'`，结论与论据 `rel` 同源闭环；建议给「先收一张卡进来」。
- **判据**：空库下报告不得出现「有在推进 / 使命射程内 / 注意力分配问题」（探针 C1~C2）。

### R173-4 年度热力图紧凑为一行 12 月 ★真机反馈

- **症状**：12 个月块上下堆叠，热力图段过高。
- **落点**：`.dz-months` 改 `grid-template-columns: repeat(12, minmax(0, 1fr))`；月块头只留「N 月」（分值与星期行隐藏）；格间距 3px→2px；悬停放大 1.6 倍。
- **判据**：12 个月块**同一行**（`top` 全等）+ 1440 / 1280 / 1100 三档页面横向溢出 ≤1px（探针 D；theme-audit 判据自带一条）。
- **★溢出复测（1100 档 +15px）**：撑出去的不是格子而是 `.dz-wk` 星期行——7 个 9px 汉字 + 6 个 2px 缝 = 需 75px，而 1100 档月块只有 66px（每块各溢出 14px；`aspect-ratio:1` 的格子本身能缩，汉字不能）。
- **落点（补）**：`@media (max-width: 1279px) { .dz-wk { display: none } }`。阈值由实测取得：扫描 1000→1440，**1280 档（月块 75.5px）是能装下的最小档**，1240 档仍溢出 3px ⇒ 断点取 1280。该档以下格子只剩 8px、字母本已不可读，日期信息完整保留在每格 tooltip 与「点格子看那一天」里。
- **判据（补）**：三档视口下 `星期行现/隐` 必须等于 `宽 ≥1280`（探针 D 断言，防"把行删了也算过"）。

### R173-5 概览带只留指标、说明悬停才现 ★真机反馈

- **症状**：人话总结整行常驻，占了半张卡。
- **落点**：人话总结收进 `.dz-ov-tip`（`ⓘ 说明` 悬停/聚焦才现，`opacity+visibility`，不折叠不占位）；指标 pill 的长括注挪进 `title`。
- **★ 两条版式坑（本轮实测，别再踩）**：
  1. 人话块从流里拿掉后，`.dz-ov-meta` 的 max-content 宽会**抢走整行**，把 5 张存量 chip 挤成 100px 竖列 ⇒ `.dz-ov-meta { flex: 1 1 100% }` 让它独占第二行。
  2. 浮层若锚在**药丸**上，窄屏（1100）药丸落到行首会把 460px 浮层顶出**左边界 388px** ⇒ 锚 `.dz-ov-meta`（`position: relative`），`right: 0` 即行右缘。另：`.dz-sec` 有 `overflow: hidden` 圆角裁切，悬停期间必须放开（`.dz-sec.dz-tip-open { overflow: visible }`），否则浮层下半截被切掉。
- **判据**：默认藏、悬停现、且**不被任何 overflow 祖先裁切**、不出视口、5 张 chip 同排（theme-audit 概览带场景 + 探针 G1~G3 / 三档视口）。
