## 一、两个场景一句话

| 场景 | 输入 | 生成 |
|---|---|---|
| **A · 方向树模板导入** | 标准化 Markdown（粘贴或选文件） | 战略目标下的 **项目 → 成功指标 → 任务**（含任务详情） |
| **B · 策展台金字塔模板导入** | 标准化 Markdown | **中心论点 → 二/三/四级分类（金字塔节点）+ 每节点一张同名台内卡**（正文为详情） |

共同理念：**论证过程在产品外完成，导入即结构呈现**——把"手工逐级建"变成"一次粘贴生成"。

## 二、场景 A · 方向树：项目/指标/任务生成器

### 2.1 解析规则（映射表）

| Markdown 元素 | 解析为 | 说明 |
|---|---|---|
| `# 标题` | **项目名** | 可多个 H1 → 多个项目 |
| `## 标题` | **成功指标名** | 归属最近的 H1 |
| `### 标题` | **任务名** | 归属最近的 H2 |
| H3 后的正文段落 | **任务详情**（task.description，纯文本保留换行） | 多段以空行合并 |
| H4 及以下 | 降级为正文处理 | 模型只有三层 |
| 列表 / 粗体等 | 保留原符号为纯文本 | 任务详情是纯文本域，不做富渲染 |

### 2.2 容错与冲突规则（默认值，可评审调整）

| 情形 | 默认处理 |
|---|---|
| H3 直属 H1（跳过 H2） | 自动创建指标「通用执行」承接 |
| 同名项目 / 指标 / 任务（导入目标内） | **跳过不重复创建**（幂等，防重复导入炸库）；弹窗复选框「跳过同名项」默认开启 |
| 无任何 H1 | 提示「未识别到项目（一级标题）」，不写入 |
| 导入目标 | 弹窗标题锁定所选战略目标；一次只导入一个目标之下 |

### 2.3 入口与交互

- **入口**：完整方向树页，每个战略目标节点 hover 操作区新增「📋 导入模板」。
- **交互**：模态弹窗（820px）——左栏粘贴 Markdown（支持选 .md 文件），右栏**实时解析预览树**（项目→指标→任务，任务详情可展开查看）+ 底部统计 `N 项目 · M 指标 · K 任务 · 跳过同名 X`；「确认导入」→ 写入 → toast + 树刷新定位到该目标。
- **不做撤销**：预览即确认（弹窗里看得见全部将要创建的内容），一期不做导入回滚。

### 2.4 写入链路

`addProjectToDir`（既有共享函数）建项目 → 指标 push 进 project.metrics → 任务双挂（projectId + metricId）→ 单次 `store.persist()`。

## 三、场景 B · 策展台：金字塔模板导入

### 3.1 解析规则（映射表）

| Markdown 元素 | 解析为 | 说明 |
|---|---|---|
| `# 标题` | **中心论点** | 仅当本台**未设论点**时生效；已设论点则忽略该行并提示（安全默认） |
| `## 标题` | **L2 分类**（金字塔二级节点） | 归属论点 |
| `### 标题` | **L3 分类** | 归属最近的 H2 |
| `#### 标题` | **L4 分类** | 归属最近的 H3（模型 4 级上限内） |
| 标题下的正文 | **该节点的卡片详情** | 见 3.2 建模 |
| 跳级（如 H3 前无 H2） | 提升到最近合法父级 | 容错 |

### 3.2 建模决策（★ 需重点评审）

金字塔节点 = 策展台分类。需求原文「每一个节点都是创建的卡片」⇒ 设计：**每个分类节点创建一张与分类同名的台内卡**（正文写入卡详情），挂在自身分类直属——节点展开即可读内容；台内卡真身留在本台。

### 3.3 容错与冲突

| 情形 | 默认处理 |
|---|---|
| 同父同名分类 | **复用**（不重复建；同名卡已存在则跳过） |
| 已设中心论点 + md 含 H1 | 忽略 H1，弹窗顶部黄条提示「本台已有中心论点，导入将从二级层级挂入」 |
| 分类总数超上限 | 沿用 sanitizeCategoryTree 上限校验，超限整体取消 |
| 已设论点 + 无 H1 | 正常：H2 起挂入现有论点 |

### 3.4 入口与交互

- **入口**：策展台 ⚙ 菜单「📋 导入金字塔模板」（或金字塔视图空态引导）。
- **交互**：同构弹窗——左栏 Markdown，右栏**金字塔缩略预览**（L1 论点 → L2 横排 → L3/L4 逐层缩进，节点卡详情 hover 可见）+ 统计 `N 节点 · M 卡 · 复用 X`；「确认导入」→ 建分类与卡 → 金字塔视图刷新居中呈现。

## 五、安全与边界

纯文本解析（无 HTML 注入面）；单次导入量建议上限 200 节点（超出提示分批）；解析失败（空/无有效标题）不写入任何数据。
