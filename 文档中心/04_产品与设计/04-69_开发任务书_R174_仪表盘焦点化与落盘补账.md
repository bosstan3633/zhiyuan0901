## 3. 任务（七项，R174-1 ~ R174-7）

### R174-1 regression.cjs 分片评估 ★前置硬依赖

- **现状**：5,499 行 / 门禁 5,500（04-65 ④ 增长门禁），R172 两轮撞线靠压缩新增才压回；本轮七任务预计 +10~15 条断言 ⇒ 不分片写不进。R172 §七原话「该排不该再延」。
- **方向**（开发机勘验后定，先立约束）：
  1. 首选按域拆 `scripts/regression/`（若干域文件 + runner 编排），`node scripts/regression.cjs` 单命令入口**不变**；

  3. **分片是搬运不是重写**——1522 条断言零丢失，搬完原样回绿。
- **判据**：分片后 1522 / 0 原样回绿；≥3 个域注入假红探针验证能报红（R165-A 教训：门禁自身改动防静默空转）；新行数门禁落 06-2。

### R174-2 ZIP §G 减重

### R174-3 zy_daily_stats 落盘 ★热力图不褪色的数据地基

- **病根**：见 §2 勘验实据。`dailyStats.ts` 文件头本来的设计即「只增不淘汰的聚合快照」，落盘是补上缺失的最后一环，**结构零迁移**。
- **方案**：
  - **写**：事件追加 / 推进字段变更时**增量**更新当日 DayRec + 防抖落盘；并入既有持久化链路，不新造定时器——R173-T T3-a 热度键写法是先例（小载荷、页隐藏/卸载补写跳防抖）。
  - **读**：启动读快照与事件重算**合并**——事件日志覆盖区间以重算为准（防刷分系数 ×0.5、24h 内软删 ×0.3 只在重放时成立），快照只补日志已淘汰的老日子。
  - **一致性**：落盘物满足「同库同事件 ⇒ 重放 = 快照」幂等；`base` 反推校准（`useDashboardStats.ts`，按真实在库数反推）保留不动。
- **判据**：① 双算对照探针（快照 vs 现算）逐年逐日 `w` / `actsOf` 零差异；② 模拟日志淘汰（事件截到最近 N 条）后热力图老日子不褪、`fullSince` 不漂；③ 重启读回一致；④ 写载荷记账（每日增量应为数百 B 量级小载荷，**不得整库写**——R173-T T3-a 的 27.9× 减载教训反向适用）。
- **边界照旧（不是本轮缺陷）**：`link` 无事件源（`DAILY_LINK_TRACKED = false`）· `system` 摘要事件不入日聚合 · 子任务完成不计分（R166 定案 3）。

### R174-4 概览带压缩为单行紧凑条 ★拍板 A

- **现状**：`DashboardOverview.vue` 五张 `dz-chip` 大卡 + `.dz-ov-meta` 参照系 pill 行，两行大块占据首屏上半，把热力图压到第二屏。
- **落点**：`DashboardOverview.vue` + `dashboard.css`。库容五卡压一行矮 chip（数字为主、标签缩小），参照系 pill 一行紧随；**信息一项不删**（说明文字 R173-5 已收进悬停，保持该机制）。
- **判据**：概览带段总高度 ≤ 现状 50%（探针量化前后对照）；五 chip 一行排开；1440 / 1280 / 1100 三档视口横向溢出 ≤1px；theme-audit 概览带场景判据随迁。
- **★R173-5 两条版式坑仍然有效**：`.dz-ov-meta { flex: 1 1 100% }` 防抢行；`.dz-sec.dz-tip-open { overflow: visible }` 防浮层裁切；浮层锚 `.dz-ov-meta`——压缩布局后**必须复测**悬停浮层仍不出界、不被裁。

### R174-5 热力图焦点化：摘要四卡单行 + 六档色阶加深 ★拍板 B

- **摘要四卡**（`Heatmap.vue` `.dz-sum` 四张卡）压成单行指标条：数字为主，说明收进 tooltip。**导出三件套不受影响**——`exportPng` 的 `kpis` 传的就是 `summary`（Heatmap.vue:138），压条后数据源不动，导出件仍带全量说明。
- **色阶加深**（病根见 §2 勘验实据）：四主题六档全条重校，**低两档拉距优先**。约束：
  1. 六档语义名与档位阈值 `levelOf` **不动**（跨年可比红线，04-68 §6 沿袭）；
  2. 顶档 `--heat-5` 四主题互不相同（R172-T3 既有约定）；
  3. `--heat-ink` 压各档底 ≥4.5（theme-contrast 硬判据——底色变了对文字对比必须复测）；
  4. `exportView.ts` PNG 导出读 CSS 变量自动跟随，人工复核导出图观感。
- **焦点化**：概览带（R174-4）与摘要四卡让位后，格子区自然上移放大；格子尺寸是否再加一档由余量实测定，不硬拍。
- **判据**：探针取相邻档位色差量化判据（l0 对 l1 在亮主题底色上必须可辨，具体阈值开发机勘验后定并落断言）；theme-contrast 全绿；theme-audit 68 图重跑全绿；四主题人工走查截图留痕。

### R174-6 saveReportCard 撤销承诺补账 ★04-68 §5 挂的真缺陷

- **判据**：文案与行为一致（探针）。
