## 二、方向 ② · 模板与角色方案包

### 2.1 用户故事

> 我是一名独立咨询顾问，刚装了知源调度台。打开新标签页，看到一个"选择你的角色方案"引导页，我选了「咨询顾问」，点击"预览方案"——看到了将要生成的分类树（客户 / 方案 / 交付 / 案例）、方向树骨架（愿景 / 使命 / 1 个战略目标 / 1 个项目 / 2 个指标 / 4 个任务）、8 张种子卡片。点击"一键套用"——3 秒后调度台填满了内容，我在模板基础上改就行。

### 2.2 六套角色方案内容（03-5 模板库已有内容底盘）

| 角色 | 分类树骨架 | 方向树骨架 | 种子卡片 |
|---|---|---|---|
| 独立研究者 | 课题 / 文献 / 数据 / 成果 | 研究→论文→发布 | 4 张（文献笔记 / 数据源 / 研究框架 / 成果链接） |
| 咨询顾问 | 客户 / 方案 / 交付 / 案例 | 交付→报告→签约 | 4 张（客户档案 / 方案框架 / 交付模板 / 案例库） |
| 内容创作者 | 选题 / 素材 / 草稿 / 已发布 | 内容→系列→粉丝 | 4 张（选题池 / 素材库 / 爆款分析 / 发布渠道） |
| 政策分析师 | 政策 / 数据 / 报告 / 追踪 | 分析→报告→建议 | 4 张（政策原文 / 数据源 / 分析框架 / 报告模板） |
| 升学规划师 | 院校 / 政策 / 学生 / 方案 | 规划→方案→录取 | 4 张（院校库 / 政策汇编 / 学生档案 / 方案模板） |
| 通用知识工作者 | 收集 / 整理 / 创作 / 输出 | 成长→输出→影响 | 4 张（灵感池 / 工具箱 / 阅读列表 / 输出渠道） |

### 2.3 交互流程

```
调度台（空状态 / 设置页入口）
  ↓
「选择你的角色方案」引导页
  ├── 6 张角色卡片（图标 + 名称 + 一句话描述）
  ├── 点击任意一张 → 展开详细预览
  │   ├── 左：分类树骨架（可勾选/取消每个分类）
  │   ├── 中：方向树骨架（愿景/使命/目标/项目/指标/任务）
  │   └── 右：种子卡片列表（可勾选/取消）
  ├── 「一键套用」→ 进度条 → 完成 toast
  └── 「稍后再说」→ 关闭（不再自动弹出，设置页可再次进入）
```

### 2.4 套用行为

| 维度 | 规则 |
|---|---|
| 分类 | 新建（不合并到已有分类——首次套用时通常为空） |
| 种子卡片 | 新建（挂在对应分类下；内容为示例文案，用户自行替换） |
| 方向树 | 愿景/使命 → **覆盖写入**（首次套用时为空）；战略目标/项目/指标/任务 → 新建 |
| 已有数据 | **不触碰**——套用只新增、不修改、不删除已有内容 |
| 可重复套用 | 允许（第二次套用同名分类/卡片/项目会被同名跳过——幂等） |

### 2.5 入口

| 入口 | 时机 | 说明 |
|---|---|---|
| **调度台空状态** | 首次打开（无任何卡片/分类/方向） | 全屏引导页——6 张角色卡片 +「稍后再说」 |
| **设置 → 角色方案包** | 任何时候 | 同款弹窗——补套其他角色方案 |

## 三、方向 ③ · 调度画像周报

### 3.1 用户故事

> 我用了知源两个月，点击调度台的「📊 周报」——看到了本周全景：入台 12 张 · 调用 28 次 · 完成 3 个任务 · 好奇心转化 2 条。最活跃的方向是「AI 知识管理」（本周 4 个任务完成）。最常调用的资源是「Notion 模板库」（本周调用 8 次）。好奇心转化率 40%（5 条好奇心里 2 条转成了任务）。底部有一句洞察："你的『AI 知识管理』方向本周活跃度提升 40%——保持这个节奏。"我看完对自己的使用模式有了感知。

### 3.2 周报内容结构（四段式）

| 段 | 内容 | 数据源 | 可视化 |
|---|---|---|---|
| **① 调度总览** | 入台 N 张 · 调用 M 次 · 完成任务 K 个 · 未归档 X 条 | `zy_event_log`（kind=新增/删除/恢复/打开）+ `d.tasks` | 4 个大数字 + 环比箭头 |
| **② 方向活跃度** | 各战略目标的本周任务完成数 + 排序 | `d.tasks` + `d.compass.directions` | 水平条形图（CSS 纯实现） |
| **③ 资源调用 TOP 5** | 本周被打开次数最多的 5 张资源卡 | `stats.lastVisits` + `resources.callCount` | 列表 + 🔥 次数 + 迷你条形图 |
| **④ 好奇心转化** | 好奇心总量 / 待探索 / 探索中 / 已求证 / 转化为任务数 | `d.curiosities` + `d.tasks`（convertedFromCuriosityId） | 漏斗 + 转化率百分比 |
| **⑤ 一句话洞察** | 基于数据的自动生成文案（规则引擎，非 AI） | 上述数据推导 | 突出显示（accent 底色） |

### 3.3 洞察规则引擎（纯前端规则，非 AI）

| 条件 | 洞察文案 |
|---|---|
| 某方向本周任务完成 ≥ 3 且环比 ↑ | 「你的『{方向名}』方向本周活跃度提升 {X}%——保持这个节奏。」 |
| 全周 0 次调用 | 「本周没有调用记录——试试 Ctrl+K 搜索一张卡片，三秒召回。」 |
| 好奇心待探索 ≥ 10 | 「你有 {N} 条好奇心待探索——选一条转成任务，让好奇心落地。」 |
| 未归档任务 ≥ 5 | 「{N} 个任务未归档——到北极星下钻视图一键归档。」 |
| 默认 | 「本周入台 {N} 张 · 调用 {M} 次——继续保持调度节奏。」

### 3.4 周期与入口

| 维度 | 规则 |
|---|---|
| 周期 | 默认本周（周一至今天）；可切换上周 |
| 入口 | 调度台页头（方向状态右侧）新增「📊 周报」按钮 |
| 呈现 | 全屏浮层（覆盖调度台，Esc 关闭） |
| 数据源 | `zy_event_log` + `d.tasks` + `d.curiosities` + `stats.lastVisits`——纯读取，零写入 |

### 3.5 明确不做（本期）

不做：导出/分享、月报/年报、AI 生成洞察文案、推送通知、多用户对比。

## 六、需拍板的决策点

1. **角色方案内容**：六套方案的分类树/种子卡/方向树骨架——内容由 AI 生成初稿后由你审核定稿，还是你手写？
2. **调度台空状态引导**：首次打开是全屏引导页（不可跳过）还是可关闭的引导浮层？
3. **周报洞察**：纯规则引擎（本期）还是预留 AI 接口（后续接 Ollama 等）？
