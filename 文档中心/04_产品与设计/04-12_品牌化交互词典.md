# 04-12 · 品牌化交互词典

> 用途：界面动作命名与反馈设计的统一词典；**界面动词与品牌动词一一对应，不再发明同义词。**

| 词典词 | 界面动作 | 触达点 | 反馈设计 |
|---|---|---|---|
| 入台 | 采集为卡 | Ctrl+Shift+J / 浮层 / 应用内 | 保存回执 Toast「✓ 已入台」 |
| 归位 | 拖入资源台分类/挂项目指标 | 资源台/策展台/左树 | 落点高亮 + 「✓ 已移入/已归属」 |
| 调出 | 搜索并打开 | Ctrl+K / 双击卡 | 结果行 + 直达新标签 |
| 复用 | 再次调出 | 任何打开路径 | 🔥 复用计数 +1（可见） |
| 校准 | 查看方向状态/方向树 | 调度台首屏 / 方向台 | 四指标下钻抽屉 |
| 求证 | 好奇心状态推进 | 好奇心卡 | 状态点变色（待探索→已求证） |
| 移出 | 软删除/摘除关联 | 各视图 🗑 / ⨯ | 「进回收站，可撤销」 |
| 保存至本机 | 导出 | 设置→导出 | 「✓ 已下载，数据在你手里」 |

**禁用同义词**：入台≠收藏/添加书签；调出≠搜索结果；归位≠整理。文档与界面统一用左列词。
