### 13. 性能第一 / 视觉第二 —— ⚠️ 半吊子

**已做到**
- 性能：拼音字典按需加载、搜索防抖 60ms、增量渲染、附件只进 IndexedDB、主 JSON 无 base64。
- 视觉：四主题 + WCAG 对比度门禁 + 100 图实拍 + 响应式 12 档。
- 稳定性：静态回归 2,023 条、E2E 44 条、死样式 / 孤儿 / 循环依赖零容忍。

**缺口**
- **没有面向用户的性能预算**：当前只有工程指标（构建体积、门禁），没有"搜索 P95 ≤ X ms、浮层唤起 ≤ X ms、切页 ≤ X ms"这类可验收的产品级 SLO。
- **没有视觉验收清单**：四主题对比度与实拍是工程门禁，但"阅读审美"缺少可逐条勾选的设计验收表（字号层级 / 行宽 / 留白 / 焦点唯一性 / 动效克制）。

**判断**：门禁强于大多数个人项目，但离"第一 / 第二生命线"的产品级承诺还差一层可对外解释的标准。
