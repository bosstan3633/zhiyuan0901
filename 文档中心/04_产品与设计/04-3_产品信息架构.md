# 04-3 · 产品信息架构

> 对象：产品/设计/前端 ｜ 与实现一致性由回归断言守门（仓库 `scripts/regression.cjs`）。

## 顶层结构（路由）
```
/                     调度台（CompassHome，默认首页，刷新固定回此）
/compass              方向台（主航线 → 项目总览 → 任务调度）
/compass/projects     项目详情（左栏双列目录 + 展板）
/compass/tree         完整方向树（六层链全展开）
/curation             资源台（CurationCenter，资源卡唯一存储与镜像源头；路径保留兼容）
/workspace/:id        策展台（CurationBoard，title「策展台」）
/settings             设置中心（数据/字段/标签/Airtable 同步/快捷键/主题）
/recycle              回收站
/manual               使用手册
```

## 三层心智
1. **调度台**=今天从哪里出发（行动视角）；
2. **方向台/项目详情/方向树**=方向与项目的家（战略视角）；
3. **资源台 / 用户自建策展台 ×N**=资产的家（资源台为资源卡唯一存储与镜像源头，策展台通过镜像引用它）。

## 对象归属与跨页关系
- 卡片（资源/任务/好奇）全局唯一，归属于资源台（资源/任务）或不归属（好奇为全局池）；
- 任务挂 项目→指标（未挂=未归档）；卡间零挂载（R165：资源/好奇由台面与状态组织，互不持有对方 id）；
- 策展台可"镜像"资源台源卡（引用式呈现，源数据零影响）；
- 定位跨页：`?hl=<cardId>` 高亮、`?p=<projectId>` 直达项目、`?zone=task` 定位任务模块。

## 全局横切
三浮层（搜索/采集/好奇）= 网页端 Shadow DOM + 应用内组件双实现，行为一致；全局快捷键三件套在任何页面可用。
