# 04-3 · 产品信息架构

> 对象：产品/设计/前端 ｜ 与实现一致性由回归断言守门（仓库 `scripts/regression.cjs`）。

## 顶层结构（路由）
```
/                     调度台（默认首页，刷新固定回此）
/compass              方向台（主航线 → 项目总览 → 任务调度）
/compass/projects     项目详情（左栏双列目录 + 展板）
/compass/tree         完整方向树（六层链全展开）
/curation             策展中心（统一树 + 混排网格）
/workspace/:id        工作台 ×N（用户自定义）
/settings             设置中心（数据/字段/标签/快捷键/主题）
/recycle              回收站
/manual               使用手册
```

## 三层心智
1. **调度台**=今天从哪里出发（行动视角）；
2. **方向台/项目详情/方向树**=方向与项目的家（战略视角）；
3. **工作台 ×N / 策展中心**=资源的家（资产视角）。

## 对象归属与跨页关系
- 卡片（资源/任务/好奇）全局唯一，归属于工作台（资源/任务）或不归属（好奇为全局池）；
- 任务挂 项目→指标（未挂=未归档）；任务单向挂载资源/好奇心；
- 策展中心可"镜像"任意工作台的卡（引用，源零影响）；
- 定位跨页：`?hl=<cardId>` 高亮、`?p=<projectId>` 直达项目、`?zone=task` 定位任务模块。

## 全局横切
三浮层（搜索/采集/好奇）= 网页端 Shadow DOM + 应用内组件双实现，行为一致；全局快捷键三件套在任何页面可用。
