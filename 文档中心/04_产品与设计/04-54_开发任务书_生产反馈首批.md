## 需求梳理与开发任务清单

### F1 ·【P0 缺陷】顶栏左上角乱码字符
- **现象**：顶栏最左渲染出字面文本 `@mouseleave="wsOverflowOpen = false"`（截图 1/2/3 均见）。
- **根因（已定位，属 R105-E2 引入）**：E2 给顶栏 nav 注入鼠标离开监听时，属性被插入到 `<nav …>` 开标签**之后**（成为文本子节点）而非标签内——浏览器把整段当文本渲染。
- **修复**：移除文本节点，把 `@mouseleave` 正确放入 `<nav>` 开标签内。
- **防再犯**：E2 断言（R105-4）补一条「nav 开标签内联 mouseleave 且无文本节点残留」的否定检查。

### F2 ·【体验】顶栏与页面正文左对齐
- **现象**：宽窗口下顶栏页签贴窗口左缘，而调度台/方向台正文居中（1440px 容器）——两套左缘。
- **根因**：顶栏全宽（padding 0 20px），正文各页容器宽不一（调度台/方向台 1440 居中 · 资源台/策展台全宽 20px · 设置 1200 · 手册 1120）。
- **修复**：顶栏内容包一层 `.topbar-inner`，按当前路由匹配正文容器宽（`/workspace|/curation` 满宽 20px · `/` `/compass` 1440 居中 24px · `/settings` 1200 · `/manual` 1120 · 其余默认）——**每个页面里顶栏左缘 = 该页正文左缘**。

### F3 ·【缺陷→需求升级】卡片列数 6/7 不生效
- **现象**：任务卡管理列数选 6/7 无响应，最多 5 列（截图 2）。
- **根因（已定位）**：R72-G6 公式 `repeat(auto-fill, minmax(max(240px, (100%-(N-1)*gap)/N), 1fr))` 在恰好 N 列时因浏览器取整差一位（如 5.998 → 5）——**auto-fill + 精确分数宽在 6/7 列时永远差一**，属公式级缺陷，四处网格同病。
- **需求升级（用户拍板）**：「卡片大小根据排列要求自适应，支持一行最多排 7 个卡片」——**废弃"放不下自动降列"**：选中 N 就精确渲染 N 列，卡片宽度自适应收缩（`repeat(var(--grid-cols), minmax(0,1fr))`）。
- **落点**：四处网格（好奇心 cz-grid · 任务 tm-grid-inner · 资源台/策展台 card-grid）+ cardCols.ts 文档口径 + R72-4/5/6/8 断言重指。

### F4 ·【交互补全】策展台镜像卡三键
- **现状**：单击只弹 toast 阻断，双击开链接可用。
- **需求（用户拍板）**：**单击 = 打开详情（只读，不可编辑）+「定位回资源台编辑」入口；双击 = 打开链接（保持）；Ctrl+Enter = 直接定位回卡片原处**。
- **实现**：内联抽屉加只读模式（`drawerReadonly` + 表单只读态样式 + footer 按钮替换 + Ctrl+Enter 语义切换）；镜像卡单击进只读详情；定位 = `/curation?hl=<源卡id>`（镜像 id 即源卡 id）。

### F5 ·【性能】生产环境卡顿（采集浮层 / 全局搜索 / 页面切换）
- **现象**：非产品页采集资源、全局搜索、产品页切换均不流畅。
- **方法**：**先测量后修**——用 Playwright + Chromium 加载本扩展实测（新标签页打开 / 路由切换 / 搜索浮层），再对确定性热点修复。已知候选：首搜拼音字典懒加载、搜索全量重建、挂载/激活期计算、topbar 毛玻璃重绘。
- **产出**：测量数据 + 修复清单 + 修复；测不出的登记观察。
