# 04-15 · 用户动线与视觉焦点分析

> 对象：产品/UX/UI ｜ 依据：04-3 信息架构、04-5 核心用户旅程、04-7 产品原则、04-10 产品体验原则、04-12 交互词典、产品功能手册 V2.40.0、设计规范_Linear。
> 性质：**设计侧判断，非事实变更**；涉及事实处一律以 `00_产品事实与表达母版.md` 为准。
> **界面依据**：V2.40.0 实际界面（光速黑主题截图）——调度台为**上下堆叠通栏**结构（页头 → 方向状态细条 → 今日三件事通栏卡 → 项目调度通栏卡 → 好奇心培育），**非左右分栏**（`CompassHome.vue:972` `.split{flex-direction:column}`）。

---

## 一、先立两条底层法则

所有动线与焦点的判断，最终都收敛到这两条：

**法则一：调度优先。** 任何页面，"调出"入口（`Ctrl+K`）永远一步可达；**首屏优先行动（三件事）而非资产（库）**。（04-10 #1）

**法则二：外部万千，内有主线。** 产品不是让人"拥有更多信息"，而是让人**保持自己的工作中心**。页面焦点的分配，必须服务于"今天的主线"，而不是"资产的规模"。

由这两条推出的**焦点排序铁律**：

```
行动（今天做什么）  >  资产（我有什么）  >  结构（我的方向长什么样）
```

**页面主角只允许一个。** 一页里若两样东西同等抢眼，等于没有焦点。

---

## 二、用户动线：三层时间尺度

知源最关键、也最容易被忽视的一点是：**它的主战场动线不在产品页面里。** 用户在别人的网页上、在咨询现场、在被质询的一刻使用它。因此动线必须按"时间尺度"而非"页面"来理解。

### 2.1 秒级动线（任意网页，不打断心流）

| 动作 | 触发 | 承诺 |
|---|---|---|
| 入台 | `Ctrl+Shift+J` | 5 秒，自动预填标题/URL/选中文本 |
| 接住念头 | `Ctrl+Shift+I` | 3 秒，选中文本自动带来源 |
| 调出 | `Ctrl+K` | 3 秒，拼音/首字母直达原文/原文件 |

**这是产品的第一动线，也是唯一一条"发生在产品之外"的动线。** 它的体验标准不是"界面好看"，而是**"不打断当前页面"**——浮层用完即走。

### 2.2 分钟级动线（打开新标签页）

```
打开新标签页（默认落「调度台」）
  → 一眼扫方向状态四指标（镜子）
  → 定下今日三件事（≤3 槽）
  → 选中事件 → 右下「项目调度」联动，确认"今天的事挂在哪个项目上"
```

这条动线的终点是**"今天从哪里出发"被回答**，而不是"我收集了多少"。

### 2.3 天/周级动线（整理与校准）

```
资源台归位（拖入分类 / 挂项目指标）
  → 策展台策展（围绕主题取舍、分层、表达）
  → 方向台 / 调度台校准（四指标 + 未归档治理）
```

**天级**：把当天入台的卡归位（文档目标：晚上 3 分钟闭环）。
**周级**：周末 30 分钟策展 + 每周一次校准，决定下周采集方向。

### 2.4 主链路（页面间导航图）

```
        ┌─ 调度台（默认首页，刷新固定回此）
顶栏 ───┼─ 方向台 ──┬─ 项目详情（/compass/projects）
        │           └─ 完整方向树（/compass/tree）
        ├─ 资源台（/curation）── 镜像 ──▶ 策展台 ×N（/workspace/:id）
        └─ 策展台 ×N（一等公民，常驻顶栏）
旁路：设置（/settings）· 回收站（/recycle）· 手册（/manual）
横切：三浮层（搜索/采集/好奇）在任意页面可用
```

**三条关系线必须保持"一步可达"**：① 任意页 → `Ctrl+K`；② 任务 → 所属项目/指标（方向关系可追溯，04-10 #4）；③ 策展台镜像卡 → 资源台真身。

## 三、动线的四个断点风险（迭代优先盯这四处）

| # | 断点 | 表现 | 已有对策 |
|---|---|---|---|
| 1 | **采集后不归位** | 未归档任务持续堆积（体检报告真机截图见 0/11、0/13） | 任务卡库「⚠ 未归档」筛选 + 调度台未归档格下钻就地归档 |
| 2 | **好奇不转化** | WCE 停摆——念头只被记录，没变成行动 | 好奇心四态流转 + 转任务/转资源（计入 WCE 转化口径） |
| 3 | **调出失败** | 网页端 `Ctrl+K` 需现场加载字典，首屏未就绪时体验降级 | 字典分级/懒加载 + 纯文本匹配兜底（R70 已分包） |
| 4 | **双真身混淆** | 策展台误以为在编辑"自己的卡"，实际写的是资源台真身 | 镜像卡虚线边框 + 📡 标识 + 写操作自动回落真身 |

> **迭代判断**：任何新功能若加剧这四个断点，优先级应下调；若能缩短"采集→归位""好奇→转化"的最后一厘米，优先级应上调。

## 四、每一页的视觉焦点

> 记法：**F 点** = 第一视觉落点；**次焦** = 第二落点；**退后** = 应主动弱化的元素。

| 页面 | 页面回答的问题 | **F 点（主角）** | 次焦 | 应退后 |
|---|---|---|---|---|
| **顶栏**（全局框架） | 我在哪 / 能去哪 | **当前页签高亮态**（调度台页签固定第一位） | 策展台页签 ×N | 主题/搜索/设置图标（工具位，弱化；备份红点仅提醒不打扰） |
| **调度台**（默认首页） | 今天，从哪里出发？ | **今日三件事**（通栏卡片 + 强调色光晕边框，首屏第一块） | 方向状态四指标（**紧凑单行细条**，镜子非仪表盘） | 操作记录四计数（挂在方向状态条右端，轻量）；存储/同步 chip 在页头；不做红色轰炸 |
| **方向台** | 我的方向与项目长什么样？ | **主航线**（愿景/使命 + 战略目标模块） | 项目总览卡片墙 | 任务调度（全量任务属"工作台"性质，置于下方） |
| **项目详情** | 这个项目做到哪了？ | **右侧展板**（按成功指标分组的任务板＝执行现场） | Hero 四指标卡（可下钻） | 左栏双列目录（导航位，不抢执行焦点） |
| **完整方向树** | 我的方向链完整吗？ | **六层链的纵深关系**，用停滞 ⚠ / 主攻 🎯 引导视线 | 顶部全树规模计数 | 避免全树平均用力（会失焦） |
| **资源台** | 我有什么？ | **卡片网格**（默认卡片视图） | 左侧分类树（默认根「全部分类」＝进门先看全貌） | 台头工具条（视图/排序/批量/导入）；镜像 chip 是提示不是主角 |
| **策展台 ×N** | 这个主题我怎么表达？ | **中心论点（🏛 主题卡）**——金字塔 L1 根，"先有判断，再谈证据" | 金字塔/分组分类树的层级结构 | 5 指标条（紧凑单行，可下钻但不上台面） |
| **设置中心** | 我要调整什么？ | **左侧导航分组**（无强焦点，工具页） | 当前面板标题 | 一切——工具页不需要视觉戏剧 |
| **回收站** | 我删了什么？ | **卡片 + 「恢复」**（恢复是主行动） | 分区切换（资源/任务/好奇） | 「永久删除」（次行动，必须二次确认） |
| **搜索浮层** | 我要找什么？ | **输入框**（自动聚焦）+ 首条结果 | 结果行的类型徽标 + 🔥 热度 | Tab 类型切换（有输入后才显著） |
| **采集浮层** | 我要留住什么？ | **标题/URL/选中文本**（已自动预填，几乎免输入） | 「保存」动作 | 策展台/分类下拉（归位是加分项，不是必填） |
| **好奇浮层** | 我在想什么？ | **问题输入框**（选中文本已自动填入） | 「保存」动作 | 来源信息（自动附带，不要求用户操作） |

## 五、跨页焦点纪律（五条，可当评审清单）

1. **一页一主角。** 若某页两个元素同等抢眼，先删/弱化其中一个。
2. **主色稀缺。** 主题强调色（`--accent`，**随 4 套主题变化**：深空薰衣草=薰衣草蓝 / 光速黑=珊瑚红 / 极简白·纸墨白=蓝）只给三处：主 CTA、焦点环、当前选中态；绝不做区块背景或卡片填充（Linear 规范）。**状态色（好奇心四态）是语义色，不受此限。**
3. **数字必须可下钻。** 任何数字的完整链路是「数字 → 清单 → 单卡」，不能是死数字（调度台四指标、项目四指标卡均已达标）。
4. **行动 > 资产 > 结构。** 首屏永远优先回答"今天做什么"，资产与结构向下沉。
5. **状态可见但不焦虑。** 用事实数字（如未归档 N/M），不用红色轰炸；无徽标强迫症（04-10 #5）。

---

## 六、给下一轮迭代的三条建议

1. **收敛"未归档"的最后一厘米**：任务卡库已有「⚠ 未归档」筛选，但三件事空槽态、好奇浮层保存后都缺少"顺手归位"的轻引导——这是动线断点 #1 的直接修补点。
2. **给「完整方向树」一个焦点装置**：全树平均呈现会失焦。建议让「停滞 ⚠」与「🎯 主攻」成为默认视觉锚点，其余节点降一档对比度。
3. **顶栏做一次"减负审计"**：策展台页签 ×N 会随自建台数量增长，需确认「≪ 收起」在台数增多时仍是默认预期，避免顶栏与内容抢焦点。
