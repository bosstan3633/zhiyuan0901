01 / 痛点

每天都很忙，忙完不知道自己在忙什么

信息爆炸、工具爆炸、AI 焦虑、工作失速——学得越多越焦虑，收藏得越多越用不上，工具越装越多、日程越满，产出反而越少。

这不是三个毛病，是三个迷失。

迷失 Ⅰ方向的迷失科技爆炸的潮流里，不知道自己在做的事和赛道有什么关系，容易被每个新热点牵着走。
迷失 Ⅱ信息的迷失见过的东西太多，真正需要时想不起来、找不回、用不了——知识没有变成解决问题的能力。
迷失 Ⅲ价值的迷失长期只解决自己的问题，投入没有沉淀成可被他人使用、可变现的成果。
问题不在你不够努力，在于三段断开了：方向断了、信息断了、价值断了。
02 / 是什么

你在浏览器里的个人调度中台

你在浏览器里工作、看信息、处理问题。知源接管你的新标签页，把「收、找、用、做、复盘」合成一个地方：看见方向、留下好奇、调用所需、策展成果。

  • 形态 — Chromium 浏览器扩展（MV3），接管新标签页
  • 边界 — 不替你写作、不替你协作、不替你决策
  • 信任 — 100% 本地运行，无账号、无云端、无追踪
它不生产智能，它组织智能。真正重要的是你去过哪里、想往哪去——不是工具本身。
03 / 主线

两条主线，一个闭环

向外：从解决自己的问题，到解决别人的问题

把你每天浏览的信息组织成可调用的资产，在需要的时候调回来、用证据论证它；最终围绕一个主题把「判断 + 依据」组织成可交付的成果——别人打开就能看到你怎么看、为什么。

我看过→我调得出→我有依据→我能证明给你看→价值落地

向内：知道自己做的事与赛道的关系

把个人赛道写成一棵六层方向树——愿景 → 使命 → 战略目标 → 项目 → 成功指标 → 任务。主攻项目不超过两个；每天三件事必须挂在方向上；每周用数据照镜子，看行动还在不在赛道上。

赛道清楚了，科技怎么爆炸都不慌——新工具新热点只有一个问题：它对我的赛道有没有用？

两条主线是一个闭环

向外变现的前提是向内清楚；向内清楚的能量来自向外的反馈。知源把这两条主线按五个动词串成闭环：入台 → 归位 → 调出 → 复用 → 校准。

05 / 落地

12 个模块，各只做一件事

不理解「好用」，只看「怎么落地」。点开每一条，看它到底解决什么。

01三卡捕获 — 把一切见过的东西一按收进来
⌘Shift+J 收网页 / 文件 / Obsidian；⌘Shift+I 速记一闪而过的念头（选中自动带来源）。卡片只有三种：资源卡（有出处的事实资产）、任务卡（要被跟进闭环）、好奇心卡（全局池，不归任何项目）。快捷键 5 秒收完。捕获不是目的，后续的使用才是产品精髓。
02卡片池 — 三卡有自己的家
三类卡 = 三张数据表，统一沉淀在卡片池，操作面在「调度台」底部的三池页签。池里没有「杂乱收藏」，只有待调用的资产。删除一律软删，回收站可恢复。
03全局调用 ⌘K — 需要时三秒调回来
任意网页按 ⌘K（或 Ctrl+K）立刻调出。关键词、拼音首字母命中；单击回车直达原文；AI 自然语义检索（可选）。单击 / 双击两种交互可配置。
04AI 赋能 — 24 个入口，整理但不替你判断
资源卡自动打标与批量归类、任务子任务拆解建议、成功指标拆解、单项目深度诊断、今日三件事候选排序复核、画像洞察续写。AI 是「判断力之外的整理力」，判断权永远在你；AI 建议不入库，采纳才成现实。
05任务与好奇的跟进闭环
好奇心可培育成熟（状态、热度、成熟度），成熟后转化为任务卡或资源卡；AI 可为任务 / 好奇匹配池内的支撑资源卡；任务可挂到方向树的项目与成功指标下，「未归档任务」有归位引导。
06方向树 — 把赛道写出来
六层结构：愿景 → 使命 → 战略目标 → 项目 → 成功指标 → 任务。作用一：在方向台看见自己的状态、位置与停滞点；作用二：每个项目下的所有任务一眼可见，主攻项目 ≤ 2。
07今日三件事 — 每一天都有来处
每天早上选三件任务，恒三槽。事件必须挂方向归属；弹药（支撑资源卡）就绪才允许主推；拉开详情抽屉，一键直达。每天早上 3 分钟。
08策展台 — 把判断组织成能交付的表达
围绕一个主题搭论证树：金字塔（树状向下）/ 树状（全部向右）两种结构，节点挂资源卡，顶部标论据卡总数与佐证附件数。一键分享为自包含 HTML——别人打开就能看到你的论点和证据；对方的 HTML 还能回导成新的策展台。
09画像洞察 — 每周给自己照一次镜子
年任热力图（53 周、6 档）、收 / 调 / 转化统计、当日报表（四格统计 + 热力带 + 时间线 + 导出 PNG/HTML）、生命周期（活跃 / 冷却 / 归档 + 高价值沉睡唤醒）。「看见了什么」比「做了什么」重要。
10导入导出与同步 — 全面、不绑定
Markdown 书签批量导入 / 数据包 JSON / CSV / PNG；Airtable 单向同步（用户自备 Token、手动触发、绝不回写）。
11系统与设置
快捷键中心、四主题 + 三档密度、更新日志（187 个版本全量）、运行手册、手动备份、错误日志导出。
12性能与视觉 — 两条不拿来吹的生命线
⌘K 首屏 P95 < 100ms、冷启动 < 500ms；120 图四主题视觉对比度每版门禁零失败。快与美是基本要求，不当作卖点。
06 / 场景与上路

一个真实场景：独立顾问的第 N 次交付

早上读几份行业报告，两张按 ⌘⇧J 收进资源池（自动带出处）；在报告里标记一张卡到战略目标「企业服务」的项目，一条题案的事转为好奇心卡留到晚上。下午客户追问，按 ⌘K、键入两字、回车直达原报告那一段。客户问「你凭什么这么说」，把相关行业数据和出处挂到论据上。晚上把诊断整理成一棵金字塔论证树，导出 HTML 发给客户——客户点开，每条依据都能直达原始出处。

结果：方案不是靠「我说得多」，而是靠判断 + 依据一起呈现。

新手 7 天，长出一套组织智能的方法

  1. 第 1 天：打开新标签，写下愿景一行、使命一句。不用完美，只是开端
  2. 第 2 天：写 1 个战略目标，挂 1 个项目，项目下设 1 个指标
  3. 第 3 天：今天三件事挂上归属，试用 ⌘⇧J 收三份资料
  4. 第 4 天：遇到问题按 ⌘K 调出，点开原始出处
  5. 第 5 天：围绕一件小事搭 1 个策展台，挂 3 份证据，分享给一个可信的同事
  6. 第 6 天：看画像洞察，问自己「这周真的在推进吗」
  7. 第 7 天：补一遍本周的成果分享（HTML），发给一个需要的人，或写进周报

它也明确不适合谁

想找「存一堆链接就不看」的工具的人；已有完整 Notion / Obsidian 工作流且满意的人（知源互补，不替代）；强依赖多人实时协作与自动云同步的人；想让 AI 替自己做决定的人。

知源不能替你走，但能让你知道当下在哪、往哪去、走到了哪。

好的工具不是让工作更快，而是让工作更有来处、有方向、有结果。
