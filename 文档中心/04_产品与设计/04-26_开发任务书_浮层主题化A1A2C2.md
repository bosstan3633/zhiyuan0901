## 二、现状勘验

**样式注入机制**：`injectStyles()`（`:72-204`）把一整段 CSS 字符串注入宿主页面 `<style id="__zy_styles__">`。浮层是 **content script 注入到宿主文档** 的独立 DOM，**拿不到新标签页的 `tokens.css`**（不同文档）⇒ 主题色必须由 JS 传入。

**硬编码色清单**（`:76-202` 共 126 行，全部硬编码）：

| 现值 | 语义 | 变量 |
|---|---|---|
| `#FDFDFC` | 面板底 / 输入底 / kbd 底 / ghost 按钮底 | `--zy-bg` |
| `#F7F5F0` | 次级底（foot / seg-control / cur-src） | `--zy-bg-2` |
| `#EFEDE7` | 三级底（hover / 中性徽标） | `--zy-bg-3` |
| `#E8E5DE` | 边框 | `--zy-border` |
| `#D4D0C8` | 强边框 / 滚动条 | `--zy-border-strong` |
| `#1A1D23` | 主文字 / toast 底 | `--zy-text` |
| `#5C6370` | 次文字 | `--zy-text-2` |
| `#9AA0A6` | 三级文字 | `--zy-text-3` |
| `#BFC3C9` | 四级文字 | `--zy-text-4` |
| `#0E7A4E` | **品牌绿（强调）** | `--zy-accent` |
| `#E7F3EC` | 强调淡底 | `--zy-accent-light` |
| `rgba(14,122,78,.14)` 等 | 强调透明底 | `color-mix(... var(--zy-accent) ...)` |
| `::before` 绿色渐变条（`:91`） | 装饰 | **删除** |

**四主题强调色**（`shared/styles/tokens.css` 实测）：

| 主题 | `--accent` | 底色明暗 | 主按钮文字 |
|---|---|---|---|
| `linear`（默认） | `#5E6AD2` | 暗 | `#FFFFFF` |
| `apple` | `#0071E3` | 亮 | `#FFFFFF` |
| `raycast` | `#FF6363` | 暗 | `#17181C`（珊瑚红配白字对比度仅 2.9:1，改用深字 4.8:1） |
| `notion` | `#2383E2` | 亮 | `#FFFFFF` |

主题选择持久化在 `zy_ui_v2.theme`（`newtab/main.ts:41` 写 `data-theme` 属性）。

**语义色不属品牌色**：徽标用的浅淡底（`#FBEAEA` / `#FBF1DE` / `#E4F2E8` 等）是"浅底深字"，暗色模式下仍然可读 ⇒ **保留不动**，只把品牌色变量化。
