## 一、产品定位

**前提**：用户长时间基于浏览器进行信息的获取、论证与处理。知源是**浏览器插件**，不做站内闭环世界——它长在用户真实的信息流上。

**一句话定义**：知识工作者在信息处理过程中的**个人认知调度中枢**。

**双价值主张**（产品的精髓：捕获不是目的，使用才是）：

| 主张 | 内容 | 终点 |
|---|---|---|
| **解决问题**（从解决自己的问题到解决他人的问题） | 卡片被调用、被论证、被展示 | 专业能力**变现** |
| **明确值得解决的问题**（为什么做） | 方向树澄清个人赛道，今日三件事保证行动在轨 | 看见赛道、达成目标、**成就自己** |

## 四、数据模型与数据关系

### 4.1 三张卡表（池化层核心）
```
资源卡 ResourceCard   任务卡 TaskCard   好奇心卡 CuriosityCard
  title/desc/link       title/status      question
  linkType(url/file/    priority          status(todo/doing)
  obsidian)             projectId ──────▶ 挂项目（方向树）
  tags[]                metricId ──────▶ 挂成功指标（方向树）
  callCount/lastCalled  completedAt       convertedAt/conver
  workspaceId(池归属)    tags[]            tedTo(转化离场)
  assets[](附件)        mountedResourceIds 已随卡间零挂载红线退役
  importedAt(双口径)     description
```
**红线**：卡间零挂载——任务卡↔资源卡的支撑关系**不写在卡上**，独立表承载（下条）。

### 4.2 关联与结构表
| 表/集合 | 关系 | 语义 |
|---|---|---|
| **SupportLink** | taskId × resourceId（多对多） | 任务/好奇的**证据支撑**（显式关联，非标签相似） |
| **compass.directions[]** | 战略目标 → projects[] → metrics[] | 六层链的下三层容器；metric.taskIds 双向并集口径 |
| **compass.vision/mission** | 愿景/使命原文 + 关联卡片 | 第 1/2 层（linkedResourceIds/linkedCuriosityIds） |
| **Category（策展树）** | workspace 内父子树（parentId，≤4 级） | 金字塔/树状共享同一棵树 |
| **CurationProjection** | 策展台 ↔ 池卡（投射，不复制） | 台内镜像不改池卡本体 |
| **ArgumentCard** | 策展台原生论点卡 | L1 唯一入口 |

### 4.3 行为与统计数据
| 数据 | 语义 |
|---|---|
| **事件日志 CardEvent[]** | create/call/status/delete… 全动作流水（检索历史、画像、Airtable 的真源；空日志回退卡片时间派生） |
| **按日统计快照** | 每日聚合（45s 独立时间闸写盘）；热力图/战报/驾驶舱吃这一份 |
| **dailyFocus** | 今日三件事三槽（sourceType=task 挂任务） |
| **UIPrefs / UIPrefs.tagTree** | 主题/密度/已完成显隐/标签树/冷却阈值等偏好（可导出同步） |

### 4.4 生命周期字段
`lifecycleArchived / coolingDays / snoozeAt / callCount / lastCalledAt` → 活跃/冷却/归档三态（lifecycleState 单一真源）。

## 九、术语表

| 术语 | 定义 |
|---|---|
| 三卡 | 资源卡 / 任务卡 / 好奇心卡——一切信息的载体形态 |
| 卡片池 | 三卡的统一存放处（资源卡池 `zy-curation` 为隐藏池 id） |
| 支撑（SupportLink） | 任务↔资源的显式证据关联，独立表，不写在卡上 |
| 方向树 | 愿景→使命→战略目标→项目→成功指标→任务 的六层链 |
| 主攻 | 标记为战略重心的项目（≤2），三台面同源 |
| 今日三件事 | 每日三槽核心标的，槽可挂任务卡 |
| 弹药 | 三件事所挂任务的支撑资源卡（只算存活卡） |
| 策展台 | 围绕主题的论证树（金字塔/树状）+ 节点挂卡 + 分享 |
| 论点卡 | 策展台原生卡（ArgumentCard），L1 唯一入口 |
| 镜像 | 池卡在策展台的投射引用（不复制本体） |
| 调用 | 资源卡被打开（call 事件，WRR 权重统计的输入） |
| 冷却/归档 | 生命周期三态：30 天不用冷却、90 天归档（逐卡可调） |
| 一处不两说 | 同一笔账只在一处报（计数/读数去重纪律） |
