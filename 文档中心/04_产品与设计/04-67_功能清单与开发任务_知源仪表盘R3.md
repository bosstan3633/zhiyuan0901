## 7. 数据模型与口径

### 7.1 `zy_event_log` 变更

| 项 | 现状 | 变更 |
|---|---|---|
| `EventAction` | `'create' \| 'delete' \| 'restore' \| 'purge' \| 'status'`（**无 `call`**） | **新增 `'call'`** |
| 容量 | `EVENT_LOG_CAP = 5000` | 不变 |
| `SnapshotEntry` diff | 只比 `createdAt` / `deletedAt` / `status` | 不变（`call` 是纯增量事件，不入 diff） |

> ⚠ **历史数据现实**：现有「写入记录」里的"调出"是 `lastCalledAt >= 今日零点` **现算**的，不是日志事件。所以**今天看得到、历史看不到**。T1 之后才有历史。

### 7.2 加权分值表（`W`）

| 行为 | 权重 | 行为 | 权重 |
|---|---|---|---|
| 采集 · 资源卡 | 1.0 | 状态 · 好奇→探索中 | 1.5 |
| 采集 · 好奇卡 | 1.2 | 状态 · 好奇→已求证 | 2.5 |
| 采集 · 任务卡 | 1.5 | 状态 · 好奇→已搁置 | 0.5 |
| 调出 · 任一卡 | 1.0 | 状态 · 任务→进行中 | 1.5 |
| 子任务完成 | 0.8 | 状态 · 任务→已完成 | 3.0 |
| 攻坚推进（focus） | 2.5 | 卡↔资源关联（link） | 1.0 |

**加权总分** = 上表逐项加权求和。**有效动作件数**（R3 主数字）= `采集(资源+好奇+任务) + 调出 + 状态变更(好奇+任务) + 推进` 的**条数总和**（不加权）。

### 7.3 档位映射（★ R3 核心）

| 档 | 语义名 | 分数区间 | 释义 |
|---|---|---|---|
| 0 | **静默** | `0 分` | 这天没动 |
| 1 | **轻触** | `1–8 分` | 收了几张、翻了几下 |
| 2 | **常规** | `9–18 分` | 正常干活的一天 |
| 3 | **高负荷** | `19–32 分` | 比平时干得多 |
| 4 | **冲刺** | `33–52 分` | 明显超出常态 |
| 5 | **满格** | `≥53 分` | 一年里最猛的那几天 |

> **实现约束**：`levelOf(w) = !w ? 0 : w<=8 ? 1 : w<=18 ? 2 : w<=32 ? 3 : w<=52 ? 4 : 5`
> **展示约束**：UI 只显示语义名；分数区间仅出现在 tooltip 与分数口径表。**不得**出现 `L1`~`L5` 裸代号。

### 7.4 `zy_daily_stats`（新增，按日聚合）

| 字段 | 含义 |
|---|---|
| `k` | 日期键 `YYYY-MM-DD` |
| `c.{res,curio,task}` | 当日采集数（分卡类） |
| `del.{res,curio,task}` | 当日删除数 |
| `s.{curio,task}` | 当日状态变更数 |
| `u` | 当日调出数（`call`） |
| `d` | 当日推进数 |
| `link` | 当日卡↔资源关联数 |
| **`x.{add,del}`** ★ | **当日存量净变化**（R3 新增，用于时间绑定） |
| `w` | 当日加权分 |

- **只增不淘汰**（与 `EVENT_LOG_CAP` 的淘汰机制不同 —— 日志会滚动淘汰，聚合键不会）
- 查询"截至某天的库容"走**前缀和**，不重扫全库
- 参考先例：`shared/utils/hotStats.ts`（`zy_stats_v1` 小载荷通道）

### 7.5 存量基线（时间绑定的起点）

`BASE = { res: 560, task: 198, curio: 78, link: 36 }` —— 首次启用时按真实库容写入 `zy_daily_stats` 的 `fullSince` 首日。

### 7.6 8 条复盘规则（`runRules`）

| ID | 名称 | 触发条件 | 提示 |
|---|---|---|---|
| R1 | 囤积倾向 | `采集 ≥ 15k && 转化率 < 15%` | 本期采集 N 张，转化为推进仅 M 项 |
| R2 | 资源未被调用 | `新增资源 ≥ 8k && 调出 = 0` | 采了没打开过 |
| R3 | 主攻停滞 | `完成 = 0 && 进行中 > 0` | 在等，不在走 |
| R4 | 并行过载 | `进行中 ≥ 12k && 完成 = 0` | 同时推太多 |
| R5 | 好奇堆积 | `好奇状态变更 ≥ 20k && 求证 = 0` | 好奇没孵化 |
| R6 | 突击式使用 | `峰值单日 > 本期总分 × 40%` | 集中爆发型 |
| R7 | 游离工作 | `采集任务 ≥ 3k && 关联率 < 10%` | 在忙，但没挂到资源上 |
| R8 | 只读不推进 | `调出 ≥ 20k && 状态变更 = 0` | 看了很多，没动一步 |

> `k = max(0.25, 天数 / 30)` —— 短窗口的阈值缩放因子。

### 7.7 可读性映射（L1~L4）

| 层 | 规则 |
|---|---|
| **L1** 主数字人话量 | 主数字用"件数 / 天数 / 张数"，加权分降为副行小字 |
| **L2** 档位语义化 | 用 §7.3 的语义名，废弃裸代号 |
| **L3** 每数字配参照系 | 环比（等长窗口）+ P 分位 + 年度排名 |
| **L4** 口径可查 | 分数口径表 12 行，随时可展开核对 |
