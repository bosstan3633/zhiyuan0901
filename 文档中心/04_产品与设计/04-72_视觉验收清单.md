## 逐项检查

- [x] **字阶**：标题、正文、辅助信息、数字读数使用既有字号令牌；没有为局部观感新增孤立字号；长标题不挤压主操作。
- [x] **行宽**：正文、说明、表单帮助文本保持在舒适阅读宽度；没有整屏超长行；窄容器内文字可换行且不溢出。
- [x] **留白**：区块间距有明确层级；页面边缘、卡片内边距、分组间距一致；没有为“显得丰富”堆叠无意义空隙。
- [x] **焦点唯一**：每个视野只有一个主行动；主按钮、次按钮、危险按钮层级清楚；同一动作只保留一个入口，重复入口已说明理由。
- [x] **动效**：只保留帮助理解状态变化的动效；入场、抽屉、切换时长与既有令牌一致；减少动态偏好下无强制位移动画。
- [x] **四主题**：`linear / raycast / apple / notion` 四套主题均检查文字、边框、底色、强调色、禁用态、选中态和浮层遮罩。
- [x] **浅色主题**：`apple / notion` 下正文、辅助文字、细线、卡片阴影可辨；没有把深色主题的白色或半透明白直接复用。
- [x] **深色主题**：`linear / raycast` 下浮层、抽屉、弹出菜单不与背景融为一体；发丝线与聚焦环清晰。
- [x] **窄屏 800px**：方向台、调度台、策展台、设置页与分享抽屉无横向溢出；关键按钮仍可达；标题与工具条不互相遮挡。
- [x] **28px 热区**：所有可点击图标、关闭键、齿轮、更多菜单、抽屉操作按钮的命中区不小于 28×28px；视觉小图标可用透明内边距扩大热区。
- [~] **键盘可用**：本轮项目全景已使用原生按钮、焦点环与 Esc 边界；**全站通用 Tab 顺序与读屏语义尚未通过**，`a11y-tab-audit` 仍报告 250 处可点击不可聚焦元素、54 处 `outline:none`，列入 V3.9.13 R-01。
- [x] **对比度**：运行 `node scripts/theme-contrast.cjs` 并记录真实结果；正文、辅助文字、边框和状态色不得只凭目测通过。
- [~] **原生语义**：项目全景项目切换器、摘要动作、泳道详情与任务标题使用原生按钮 / 键盘语义；**全站可点击 div / span 的语义债尚未清零**，按 `a11y-tab-audit` 报告逐项登记在 V3.9.13 R-01。
- [x] **真实空态**：无数据、筛选无结果、加载失败分别有明确说明与下一步动作；不显示伪数据或无意义占位。
- [x] **截断与溢出**：长标题、长标签、长 URL、长数字在卡片、抽屉、表格和分享页中均有明确策略；不得遮挡相邻操作。
- [x] **性能体感**：运行 `node scripts/perf-slo.cjs` 并记录真实 P50/P95；浮层、⌘K、搜索键入、页面切换、分享抽屉、长图生成六类均看报告，不以单次点击感受替代。

## 分享页专项

- [x] **桌面阅读**：1440px 下标题、目录、正文、资源卡与附件层级清楚；长文可连续阅读，论证树可横向滚动且不截断节点。
- [x] **移动阅读**：390px 宽下无横向页面溢出；标题不超屏；资源链接、节点和下载入口可点击；目录折叠或隐藏策略明确。
- [x] **打印**：打印预览中去掉固定下载按钮和交互阴影；正文、引用、资源标题不被跨页切断；页脚保留生成信息。
- [x] **资源链接**：公开 `http(s)` 资源可点击；无公开网址和本地附件按既定边界降级为标题与说明，不伪装成可打开链接。
- [x] **长图结果**：分享页内可下载高清长图；下载后检查 L1–L4 层级、节点说明、资源卡和连线完整，无白屏、裁切或错误层级标签。

- 「部分通过」必须写明已覆盖范围与未覆盖范围；不得用专项通过替代全站通过。
- 任一项目未执行：状态写「未验证」，并在交付说明里列为残余风险。
- 截图、采样报告和人工检查结论必须来自本批次代码，不得沿用旧批次读数。
