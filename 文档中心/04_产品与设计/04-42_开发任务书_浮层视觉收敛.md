## 一、需求原文

**A5 · 类型 Tab 与搜索框内 chip 重复表达同一状态**（`04-16:86-90`）
> **现状**：`:105-110` 常驻一行类型 Tab；`:101-104` 搜索框内又有同义 chip。两套控件表达同一个 `searchType`。
> **方案**：二选一。推荐**保留 chip**，Tab 行改为"有输入时才出现的轻量提示行"。

**A6 · 结果图标 6 种颜色，违反"主色稀缺"**（`04-16:92-97`）
> **现状**：图标底色 6 种（资源蓝 / 任务完成绿 / 进行黄 / 待办灰 / 好奇黄 / 策展台紫），徽标 8 种配色。
> **方案**：**类型用图标/形状区分**，颜色只保留"当前选中态"一个强调色；状态徽标收敛为「中性 / 强调 / 警示」三档。
> **注意**：**不要动主应用里好奇心卡的状态色**（那是语义色，合理且必要）。

## 二、只读勘验结论

### 2.1 A5：两套控件现状

| 控件 | 位置 | 出现条件 | 表达 |
|---|---|---|---|
| `.zy-type-tabs` | 搜索框下方常驻一行，6 个带计数的块 | **永远** | 当前 `searchType`（active 态）**且可点击切换** |
| `.zy-search-chip` | 搜索框内部，输入框左侧 | `searchType !== 'all'` | 当前 `searchType` + `×` 复位 |

**★ 关键发现：按提案字面实现会砍掉一个真实用法。**

提案是"Tab 行**只在有输入时**出现"。但浮层空态（`renderResults` 的 `!lastQuery && searchType === 'all'` 分支）只有
**四个"打开 X 页面"的快捷操作 + 近期最常用**——**没有任何类型浏览入口**。
⇒ 无输入时隐藏 Tab 行，**"打开浮层直接点『任务卡』浏览全部任务"这条路径就断了**。

**本轮采用反向去重**（能力零损失，见 §三 T4）：
- **Tab 行常驻，但轻量化**（这才是提案说的"轻量提示行"）；
- **chip 只在有输入时出现**——无输入时 Tab 行的 active 态**已经**说清了当前类型，chip 是**第二份**，
  冗余恰恰发生在这里。

> ⚠ **这是对提案的一处偏离，需产品负责人裁决**。回退方法：把 `updateChip()` 的显隐条件改回
> `searchType !== 'all'`，并把 `.zy-type-tabs` 的显隐改为由 `lastQuery` 控制。

### 2.2 A6：图标 6 色是**硬编码**且**无暗色覆盖**

```css
.zy-ri-icon.res{background:#E9F1FA;}         /* 资源蓝 */
.zy-ri-icon.task-done{background:#E4F2E8;}   /* 完成绿 */
.zy-ri-icon.task-doing{background:#FBF1DE;}  /* 进行黄 */
.zy-ri-icon.task-todo{background:#EFEFEA;}   /* 待办灰 */
.zy-ri-icon.curio{background:#F9F3E4;}       /* 好奇黄 */
.zy-ri-icon.ws{background:#E9EAF6;}          /* 策展台紫 */
```

六条**全在 `prefers-color-scheme: dark` 覆盖块之外** ⇒ 宿主是暗色时，这些**浅色块会直接突出来**。
这是 A6 顺带挖出的**真缺陷**，不只是"颜色多"。

`iconClass` 的取值来源：`res` / `task-${status}` / `curio` / `ws` / `proj`。
`iconText` 已经是形状区分：`📄 / ✓ / ◐ / ○ / 💡 / 📁 / 🗂 / ↵ / 📦`
⇒ **底色统一为中性，信息零损失**（形状仍在）。

### 2.3 A6：徽标 8 色 + 三处内联硬编码色

现役徽标：`ws` `cat` `ws-badge` `curio-status` `prio-high` `prio-mid` `status-todo` `status-doing` `status-done`。
其中 5 条是硬编码（`#FBEAEA/#C03B3B` 等），**无暗色覆盖**。

顺带发现 **3 处内联硬编码**：

| 行 | 内容 | 缺陷 |
|---|---|---|
| 866 / 913 | `<span style="color:#BFC3C9">` 计数 | `#BFC3C9` 浅灰在**明色白底几乎看不见**（暗色下反而正常）⇒ **明色缺陷** |
| 1339 | `.zy-saved-icon style="background:#FBF1DE;color:#8A5A00"`（重复卡确认） | 浅琥珀底在**暗色下突出来** |
| 222 | `.zy-saved-icon` 默认 `#E4F2E8 / #2E7D42`（保存成功） | 浅绿底在**暗色下突出来** |

## 三、改动清单

### T1 · A6 图标底色收敛（6 → 1 中性）

删掉 6 条 `.zy-ri-icon.*{background:…}`，改为一条：

```css
/* R93（A6）：类型/状态一律靠 iconText 的形状区分（📄 ✓ ◐ ○ 💡 📁 🗂 📦），底色统一中性。
   改前六种硬编码浅底色**且无暗色覆盖** ⇒ 宿主暗色时这些浅块会突出来（真缺陷，不止是"颜色多"）。
   加 1px 边框：中性底在明暗两套下都需要一条边界才立得住。 */
.zy-ri-icon{…;background:var(--zy-bg-3);border:1px solid var(--zy-border);}
```

`iconClass` / `iconText` **一个字都不改** —— 形状区分仍在，零信息损失。

### T2 · A6 状态徽标收敛为三档

新增两个浮层变量（明/暗各一套，取自 `tokens.css` 的 apple/linear 两套）：

| 变量 | 明（apple） | 暗（linear） |
|---|---|---|
| `--zy-warn` | `#A66A00` | `#D9A03C` |
| `--zy-ok` | `#1E7A34` | `#6FCE8B` |

三档映射：

| 档 | 成员 | 样式 |
|---|---|---|
| **中性**（默认） | `ws` `cat` `ws-badge` `curio-status` `prio-mid` `status-todo` | `background:var(--zy-bg-3); color:var(--zy-text-2)` |
| **强调** | `status-doing` | `background:color-mix(in srgb, var(--zy-accent) 14%, transparent); color:var(--zy-accent)` |
| **警示** | `prio-high` | `background:color-mix(in srgb, var(--zy-warn) 16%, transparent); color:var(--zy-warn)` |

- `status-done` → **中性 + `opacity:.6`**（已完成是终结态，去饱和对齐 `.archived` / `.cf-item.done` 既有口径）。
- `prio-mid`（🟡 中）归**中性** —— "中"不需要警示色；它自带的 🟡 emoji 已承载了信息。
- 强调色出口仍是 R77 C2 定的三处 + 本轮"进行中"徽标一处，**不新增强调色的铺色**。

### T3 · A6 顺带修三处硬编码色

| 行 | 改为 |
|---|---|
| 866 / 913 | `color:#BFC3C9` → `color:var(--zy-text-4)`（两处，明色缺陷） |
| 1339 | 重复卡确认图标内联色 → 走**警示档**令牌（抽 `.zy-saved-icon.warn`） |
| 222 | `.zy-saved-icon` 默认绿 → 走 `--zy-ok` 令牌（**保留语义色**，A6 原文只禁止动主应用的好奇心卡语义色） |

### T4 · A5 Tab 行轻量化 + chip 只在有输入时出现

**CSS 轻量化**（"轻量提示行"）：

```css
/* R93（A5）：Tab 行轻量化——去掉每个 tab 的背景块与 hover 底色，
   改为纯文字 + 计数一行；当前项用**强调色文字 + 底部下划线**标出
   （强调色出口与 R77 C2 一致：主按钮 / 焦点环 / 当前选中行）。 */
.zy-type-tabs{display:flex;gap:14px;padding:10px 22px 6px;}
.zy-type-tab{padding:0 0 4px;font-size:12px;color:var(--zy-text-3);cursor:pointer;
  border-bottom:2px solid transparent;display:flex;align-items:center;gap:4px;}
.zy-type-tab:hover{color:var(--zy-text-2);}
.zy-type-tab.active{color:var(--zy-accent);border-bottom-color:var(--zy-accent);font-weight:600;}
```

**chip 显隐时机**（`updateChip()`）：

```ts
// R93（A5）：chip **只在有输入时**出现。
// 无输入时 Tab 行的 active 态已经说清了当前类型，chip 是第二份——冗余恰在此处。
// 有输入时输入框内容长、注意力在输入框，chip 紧邻输入框最能说明「当前只看 X」。
chip.style.display = (searchType === 'all' || !lastQuery) ? 'none' : 'inline-flex'
```

**能力清单（零损失）**：

| 场景 | 类型显示 | 类型切换 | 复位 |
|---|---|---|---|
| 无输入 + 全部 | Tab 行 active=全部 | ✅ 点 Tab 行 | — |
| 无输入 + 已选类型（Tab 键指令设的） | Tab 行 active | ✅ 点 Tab 行 | ✅ 点「🔍 搜全部」 |
| 有输入 | chip（贴输入框）+ Tab 行 active | ✅ 点 Tab 行 | ✅ chip 的 × |
