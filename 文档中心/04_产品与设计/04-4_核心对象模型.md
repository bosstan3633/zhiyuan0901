# 04-4 · 核心对象模型

> 对象：产品/设计/研发 ｜ 字段级定义见 [05-3 数据字典](../05_研发与数据/05-3_领域模型与数据字典.md)；红线见 [05-2](../05_研发与数据/05-2_本地数据架构.md)。

## 对象清单
| 对象 | 是什么 | 关键属性 |
|---|---|---|
| **资源卡** | 有出处的事实资产（网页/文件/Obsidian/附件） | 标题、链接、工作台+分类、标签、复用计数、置顶/星标 |
| **好奇心卡** | 一闪而过的念头 | 问题、状态（待探索/探索中/已求证/已搁置）、来源链接 |
| **行动卡（任务）** | 可执行事项 | 标题、状态、优先级、项目+指标双挂、挂载资源/好奇（单向） |
| **项目** | 承接战略的攻坚单位 | 名称、进度、成功指标[]、主攻（isFocused）、投射（pinnedToLighthouse） |
| **成果标志（成功指标）** | 可衡量的完成口径 | 标题、taskIds、完成率 |
| **方向（战略目标）** | 阶段方向 | 名称、期限、项目[] |
| **愿景/使命** | 终极方向/行动准则 | 内容、关联资源/好奇（linked*） |
| **工作台/分类** | 资源的域与层级 | 名称、图标、分类树（≤2 级） |

## 对象间关系（单向引用红线）
- 任务 → 挂载 资源[]/好奇心[]（**只有任务持有挂载**；资源/好奇 Schema 禁止出现 taskId）；
- 愿景/使命 → 关联 资源[]/好奇[]（linked*）；
- 策展投射 → 引用源卡（源删即隐/回落，源数据零影响）；
- 删除一律软删（deletedAt），回收站可逆。

## 状态机速记
任务：todo → doing → done（唯一出口 setTaskStatusOf，completedAt 卫生在内）。
好奇：todo → doing → done / shelf；可 convertCard → 任务/资源（写 fromCuriosityId）。
