# 04-9 · 产品指标体系

> 对象：产品/运营 ｜ 两层：**产品内指标**（本地可算，保护隐私不上传）与**经营指标**（需用户授权渠道，见 08-2）。本文定义数据口径，不等同于页面必须展示指标条。

## 产品内调度健康指标（用户自己可见）
| 指标 | 定义 | 现役呈现 |
|---|---|---|
| 方向健康度 | 未停滞战略目标数 ÷ 战略目标总数；某目标下最近一次任务更新超过 14 天记为停滞 | 方向台页头 |
| 主攻 / 停滞 | 主攻=可见项目中 `isFocused` 的数量（≤2）；停滞=近 14 天无推进且已有任务的可见项目数 | 方向台页头 |
| 六层计数 | 愿景 / 使命 / 战略目标 / 项目 / 成功指标 / 任务 | 战略骨架条（唯一账本） |
| WCE 好奇探索 | 好奇卡「创建 + 状态变更 + 删除」的事件数 | 数据层口径；无页面级指标条 |
| WRR 资源复用 | 日=今日打开卡数；周=本周次数；累计=累计次数（资源卡被打开次数） | 卡片热度与画像洞察；无页面级指标条 |
| 未归档任务 | 未挂项目/指标或引用失效的任务（N）/ 全部未删除任务（M） | 任务卡池筛选与断链治理入口 |
| 云端同步（V4 起） | 最近上传/恢复时间与云端/本机差异状态（手动快照，非自动备份） | 设置→数据管理→云同步 |

## 闭环转化指标（本地事件日志可派生，用户授权后方可外报）
| 指标 | 定义 | 目标感 |
|---|---|---|
| 首次入台率 | 安装后 24h 内完成 ≥1 次采集 | 越早越好 |
| 首次调出率 | 安装后 72h 内完成 ≥1 次 Ctrl+K 调出 | 核心激活 |
| 三秒调出成功率 | 调出操作 ≤3s 占比 | ≥80% |
| 资源归位率 | 有归属（分类/标签/项目）的卡占比 | ≥70% |
| 今日三件事关联项目率 | 三件事中挂项目槽位占比 | ≥60% |
| 项目关联方向率 | 有方向（战略目标）的项目占比 | 100%（结构保证） |
| 七日价值达成率 | 7 日内完成"入台→调出→复用"闭环用户占比 | 核心留存先导 |
