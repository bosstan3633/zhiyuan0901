## 一、只读勘验结论（动工前）

### 1.1 R6：搜索口径现状

`filteredResources`（`:1224-1227`）当前判据：

```ts
r.title.toLowerCase().includes(q)
|| (r.description||'').toLowerCase().includes(q)
|| (Array.isArray(r.tags) ? r.tags : []).join(',').toLowerCase().includes(q)
```

| R6 规格 | 现状 | 结论 |
|---|---|---|
| 搜索扩展至 `tags` | 已含（`join(',')`） | ✅ 已有 |
| 搜索扩展至 `customFields` | **无** | ❌ **缺**——自定义字段能在卡片上显示（`fieldValue` 的 `custom_` 分支），却搜不到 |
| 支持 `#标签` 直筛 | **无** | ❌ **缺** |

> ⚠ `04-20` 写的落点是「hub 分支 `searchHit`」——**全仓已无 `searchHit`**（CurationCenter 时代的旧名，随 R16 收敛消失）。实际落点就是 `filteredResources` 的搜索段。

### 1.3 W4：镜像卡当前有四个"点了只会弹提示"的按钮

三视图动作条（`:288-296` / `:359-368` / `:388-394`）当前是**一套七动作无条件渲染**，镜像卡靠各动作的**函数内**拦截：

| 动作 | 对镜像卡的行为 |
|---|---|
| `↗ 打开` | ✅ 正常（双击/单击都能开链接） |
| `📌 置顶` | ❌ `showToast('📡 镜像卡为引用——置顶请在资源台操作')` |
| `⭐ 星标` | ❌ 同上 |
| `📂 移动分类` | ❌ 同上 |
| `📡 镜像` | `v-if="isHub && !isMirrorView(r)"` 已隐藏 |
| `📋 挂载` | `v-if="!isMirrorView(r)"` 已隐藏 |
| `🗑 删除` | ⚠ 实际执行 `removeMirror(r)`——**按钮写着"删除"，干的是"移出镜像"** |

⇒ **镜像卡上七个按钮，四个点了只有一句提示，一个名不副实**。W4 要的就是：镜像卡只给三个**真能用**的。

好消息：`🎯 定位源` 与 `✕ 移出镜像` **能力都已存在** —— `locateMirrorSource(r)`（`:1278`，下钻抽屉在用）与 `removeMirror(r)`（`hub.ts`，🗑 分支已在调）。**本轮只是把它们接到该去的地方。**

### 1.4 改动方式的选择：加 `v-if` 而非重构分支

W4 可以用 `v-if/v-else` 两套模板实现，但：
- `R79-2/3/5`（六动作顺序）与 `R82-1/2`（📋 位置与 `v-if="!isMirrorView(r)"`）都是**基于字符串顺序**的断言；
- 拆两套模板会让"原生卡七动作"这条链断开，需重指 4 条断言。

⇒ 采用**最小改法**：保留一条动作条，给四个写动作加 `v-if="!isMirrorView(r)"`，再追加两个镜像专属动作 `v-if="isMirrorView(r)"`。**效果等价，零重指。**

## 二、改动清单

### T1 · R6：搜索扩到 `customFields` + `#标签` 直筛

抽两个函数（**一处使用，故留在组件内**，符合"≥2 处才抽共享"）：

```ts
/** 解析查询串：`#a #b 关键词` → { tags:['a','b'], kw:'关键词' } */
function parseQuery(raw: string): { tags: string[]; kw: string }
/** 匹配：#标签**全部命中（交集）**才算；关键词走 标题/描述/标签/自定义字段值 */
function matchCard(r: ResourceCard, p: { tags: string[]; kw: string }): boolean
```

- 普通词匹配范围：**新增 `Object.values(r.customFields || {})`**（`String(v)` 后比对，null/undefined 跳过）
- `#标签` 语义：多个 `#a #b` **取交集**（都要命中）——"直筛"是收窄，不是扩大
- 标签比对统一 `toLowerCase`；`#` 单独一个字符不算标签（回落为普通词）
- 搜索框 `title` 补一行用法说明：`#标签 可直筛（多个取交集）`

### T2 · W5：筛选补 `starred`

四处同步（同一份白名单/谓词/标签/下拉，避免漏一处）：

| # | 位置 |
|---|---|
| 1 | `FILTER_KEYS` 白名单加 `'starred'` |
| 2 | `FILTER_PREDICATES` 加 `starred: (r) => !!r.starred` |
| 3 | `FILTER_LABELS` 加 `starred: '⭐ 星标'`（生效值徽标自动沿用） |
| 4 | 「筛选」气泡下拉「按状态」组加 `<option value="starred">⭐ 星标</option>` |

### T3 · W4：镜像卡只读三件套

三视图（卡片 `.rc-action` / 列表 `.rr-action` / 看板 `.kc-action`）各：

| 动作 | 条件 | 行为 |
|---|---|---|
| `↗ 打开` | 无条件 | 保持既有 |
| `📌` `⭐` `📂` `🗑` | **加 `v-if="!isMirrorView(r)"`** | 原生卡保持，镜像卡隐藏 |
| `🎯 定位源` | `v-if="isMirrorView(r)"` | `locateMirrorSource(r)` |
| `✕ 移出镜像` | `v-if="isMirrorView(r)"` | `removeMirror(r)`，`class="... delete"`（红色） |

- 🗑 对镜像卡隐藏后，`removeMirror` 改由 ✕ 承担——**语义终于对上了**（"移出镜像"不再是"删除"）

### 不做（边界声明）

- **不做** W10（搜索范围统一为 `title + link + description + tags`）—— P2 条目，且本轮不动 `link`
- **不做** A9（全局搜索的 `@项目名` / `#标签` 前缀过滤）—— P2 浮层条目，与台内搜索是两套实现
