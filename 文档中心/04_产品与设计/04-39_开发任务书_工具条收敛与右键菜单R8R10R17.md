> - **R8 问题**：页头一行塞了 7 个元素（面包屑 + 3 视图 Tab + 搜索 + 批量 + 导入 + **常驻虚线提示胶囊** + 新建卡片）；主 CTA「＋ 新建卡片」被挤到最右。

> - **R17 问题**：`ResourceEditForm.vue:48` `wsOptions = computed(() => store.workspaces)`，而 `store.workspaces` **排除 hub**（`stores/app.ts:18` `w.id !== CURATION_WS_ID`）。于是在资源台打开一张真身卡的详情，「策展台」下拉**没有匹配当前值的选项 → 显示空白**；用户一旦改选并保存，卡片 `workspaceId` 被改写，**静默离开资源台**，而 `curationProjections` 里的镜像仍指向它。

### 1.3 R17：下拉无匹配项 ⇒ 空白 + 静默迁台

`ResourceEditForm.vue:49-50`：

```ts
const wsOptions = computed(() => store.workspaces)
```

`stores/app.ts:18`：

```ts
data.value?.workspaces.filter((w) => !w.archived && w.id !== CURATION_WS_ID).sort(...)
```

⇒ 资源台真身卡（`workspaceId === CURATION_WS_ID`）打开详情时，`v-model` 的值在选项列表里**不存在**，原生 `<select>` 表现为**显示空白**（浏览器把无匹配的 `value` 渲染为首项或空白，各引擎不一）。用户随手改选 ⇒ `onWsChange()` 清空分类 ⇒ 保存后真身搬去策展台，`curationProjections` 中指向它的镜像继续挂着 —— **源数据被静默搬走，镜像还在原地**。

**方案（照 04-18 原文）**：`model.workspaceId === CURATION_WS_ID` 时，在下拉**首位注入「🗂 资源台（真身）」**并默认选中。

> 不改 `store.workspaces` —— 那是全局口径（"策展台列表"在别处出现时不应混入资源台，如 `GlobalSettings` 的搬家目标台、`overlay` 的计数）。**只在这个下拉里注入，属于表单层的局部补救。**

### T1 · R8-① 常驻教学文案改「?」气泡

文案常量（沿用 04-18 原文，一字不改）：

```ts
/** R8：常驻提示条改「?」气泡——原文案「卡片在此存储为真身 · 📡 单卡/📤 分类可镜像到各策展台 · 源数据零影响」 */
```

### T3 · R8-③ 资源台 fallback 副标题降为 tooltip

`.wsh-desc` 拆成两态：

```html
<!-- 用户自定义台描述：信息量真实，保留内联（W1 要求台身份可见） -->
<span v-if="wsHeadDescOwn" class="wsh-desc" :title="wsHeadDescOwn">· {{ wsHeadDescOwn }}</span>
<!-- 资源台 fallback 定位语：降为 ⓘ tooltip（R8：它是定位语，不是每屏必读） -->
<span v-else-if="wsHeadDescFallback" class="wsh-locator" :title="wsHeadDescFallback">ⓘ</span>
```

```ts
const wsHeadDescOwn = computed(() => (workspace.value?.desc || '').trim())
/** R8：仅资源台（且未填描述）回落的定位语，降为 ⓘ tooltip，不再内联占位 */
const wsHeadDescFallback = computed(() => (wsHeadDescOwn.value ? '' : (isHub.value ? '资源卡唯一存储 · 镜像源头' : '')))
```

### T5 · R17 抽屉下拉注入「资源台（真身）」

`ResourceEditForm.vue`：

```ts
import { CURATION_WS_ID, type ResourceCard, … } from '@/shared/models'

/**
 * R17：策展台选项——store.workspaces 显式排除资源台（stores/app.ts:18），
 * 于是在资源台打开真身卡时 v-model 的值在选项里不存在 ⇒ 下拉显示空白；
 * 用户随手改选并保存会把真身**静默迁去策展台**（镜像投射仍指向它）。
 * 故在 model.workspaceId === CURATION_WS_ID 时首位注入「资源台（真身）」。
 */
const wsOptions = computed(() => {
  const list = store.workspaces
  if (props.model.workspaceId !== CURATION_WS_ID) return list
  return [{ id: CURATION_WS_ID, name: '资源台（真身）' } as (typeof list)[number], ...list]
})
```

> 类型：`store.workspaces` 是 `Workspace[]`；注入项只需 `id` / `name` 被模板消费，用 `as` 收敛到同型，避免为一行 UI 造半个对象。
