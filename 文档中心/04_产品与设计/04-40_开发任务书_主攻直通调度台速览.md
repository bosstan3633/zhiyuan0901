## 一、坏账是什么

两处白纸黑字的承诺：

| 出处 | 原文 |
|---|---|
| `v2/src/shared/models/index.ts:65` | `** 是否主攻项目（最多2个，同步至任务中心顶部）` |
| `v2/src/newtab/manual-data.ts:229` | `🎯 主攻（最多 2 个）**直通调度台速览**；14 天无推进自动亮 ⚠ 停滞。` |

**性质**：这不是"还没排期的需求"，是**已经写进产品说明书、但代码里没有**的能力。用户读手册会去找一个不存在的东西。自 R85 提出后一直未拍板。

## 二、只读勘验结论

### 2.1 两处承诺指向同一处

- `focusedProjects`（`stores/compass.ts:92`）是现成的 computed：`allProjects().filter(p => p.isFocused && p.status !== 'archived')`。
- 它的**唯一消费方**是 `LighthousePanel.vue:153` 的主攻聚焦条（R85 加的，在**方向台** `/compass`）。
- **调度台 `/`（`CompassHome.vue`）零消费。**
- 「任务中心」是 **R49 已退役的旧页**（`/tasks` 路由已删，回归有 `check('旧任务中心路由已退役', …)` 把守）；`goToTask` 现在 `router.push('/')` 并提示"已跳转任务中心"——**"任务中心"这个叫法在用户侧已经等价于调度台首页**。

⇒ 「同步至任务中心顶部」与「直通调度台速览」是**同一件事**，落点就是 `CompassHome.vue` 顶部。

### 2.2 手册还承诺了"停滞"，方向台聚焦条也没做

`isProjectStalled`（14 天无推进）在 store 里早就导出，被用于：
- R83 主航线项目胶囊（`projMeta.stall`）
- R86 项目总览状态筛选

**方向台的主攻聚焦条没有用** —— 它只显示 🎯 + 名字 + 进度。故手册那句「14 天无推进自动亮 ⚠ 停滞」在主攻这个语境下**同样是空头支票**。本轮在调度台速览条上兑现（方向台那条是否补，见 §五 遗留）。

### 2.3 首页现有结构（决定插入位置）

```
page-head      面包屑「调度台 · 今天，从哪里出发」+ 存储/同步 chip
MetricBar      方向状态四格（战略目标 / WCE / WRR / 未归档）+ 右端操作记录四格
split          左：今日三件事 ｜ 右：项目调度（跟随三件事联动）
底部专区       好奇心培育
```

> 首页面包屑原文是「**今天，从哪里出发**」——主攻正是这个问题的答案。放在 `MetricBar` 之下、`split` 之上，正是"速览"的位置。

## 三、改动清单

### T1 · 调度台主攻速览条

`CompassHome.vue` 新增一行 `.ch-focus-strip`（**≤40px**，沿用 R84/R85 的行高约束），置于 `MetricBar` 之后、`#dispatch-split` 之前：

```html
<!-- R91：主攻速览条——手册「🎯 主攻（最多 2 个）直通调度台速览」的落点。
     首页面包屑写着「今天，从哪里出发」，主攻就是这个问题的答案；
     改前 focusedProjects 的唯一消费方在方向台，调度台零消费 ⇒ 承诺落空。 -->
<div class="ch-focus-strip" :class="{ empty: !focusedProjects.length }">
  <template v-if="focusedProjects.length">
    <span class="cf-label">🎯 主攻</span>
    <span v-for="p in focusedProjects" :key="p.id" class="cf-item"
      :class="{ done: focusMeta.get(p.id)?.finished }"
      :title="p.name + ' · 点击进入项目详情'" @click="openFocusProject(p)">
      <span class="cf-name">{{ p.name }}</span>
      <span class="cf-pct">{{ focusMeta.get(p.id)?.pct || 0 }}%</span>
      <!-- R91：手册承诺的「14 天无推进自动亮 ⚠ 停滞」在此兑现（isProjectStalled 既有口径） -->
      <span v-if="focusMeta.get(p.id)?.stall" class="cf-stall" title="近 14 天无推进">⚠ 停滞</span>
      <span v-if="focusMeta.get(p.id)?.open!" class="cf-open">待办 {{ focusMeta.get(p.id)?.open }}</span>
    </span>
    <span class="cf-go" @click="router.push('/compass')">去方向台 ›</span>
  </template>
  <span v-else class="cf-hint" @click="router.push('/compass')">
    🎯 尚无主攻项目 —— 去方向台指定（最多 2 个）
  </span>
</div>
```

**script**（性能红线 R83：`projectProgress` / `isProjectStalled` / `projectTasksOf` 内部都遍历 `d.tasks`，
**不得在模板里逐项调用** ⇒ 预计算成索引；主攻 ≤2 个，成本可忽略）：

```ts
const { d, allProjects, projectProgress, projectTasksOf } = useCompass()
const { focusedProjects, isProjectStalled, isProjectDone } = useCompass()   // 合并进既有解构

/** R91：主攻速览的预计算索引（R83 性能红线——不在模板里逐项调遍历型函数） */
const focusMeta = computed(() => {
  const m = new Map<string, { pct: number; stall: boolean; finished: boolean; open: number }>()
  for (const p of focusedProjects.value) {
    const open = projectTasksOf(p).filter(t => !t.deletedAt && t.status !== 'done').length
    m.set(p.id, { pct: projectProgress(p).pct, stall: isProjectStalled(p), finished: isProjectDone(p), open })
  }
  return m
})
function openFocusProject(p: Project) {
  router.push({ path: '/compass/projects', query: { p: p.id } })
}
```

**样式**：与方向台 `.mr-focus-bar` 同款（≤40px 一行、tokens 变量、无硬编码色），但加 `.cf-stall` 用 `var(--warning)`（R87 已确认该令牌存在）。

> **与方向台聚焦条的分工**（不是重复）：
> 方向台那条在**目标卡上下文里**，是"管"的视角（hover 能就地切换主攻）；
> 调度台这条在**"今天从哪出发"的语境里**，所以多了**停滞警示**与**待办数**——直接回答"今天该推哪个"。
