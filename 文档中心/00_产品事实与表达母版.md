## 1. 产品名称
- 中文名：**知源调度台**
- 英文名：Zhiyuan Control Center（缩写 ZCC，一般不单独使用）
- 口头称呼：知源、调度台

## 2. 品类
**个人资源调度台**（自造新品类）。不是书签管理器，不是笔记软件，不是待办清单，不是新标签页美化工具。

## 3. 核心心智词
**调度**。心智画面：**信息洪流中的控制中心**——用户是指挥官，AI 与工具是被调度的部队。

## 4. 主 Slogan
> **以好奇过滤信息，以调度致用于己。**

场景化 Slogan 池（按场景取用，不得改动核心动词）：
- 收工前问一句：今天调出了什么？（习惯养成）
- 你不缺第 18 个工具，你缺的是调度它们的那个东西。（品类教育）
- 三秒，把你见过的信息召回来。（能力承诺）
- 让每一次"稍后找给您"，都有下文。（升学规划/咨询场景）

## 5. 一句话定位
**信息洪流中的控制中心——AI 时代知识工作者的个人资源调度台。** 它横在所有工具之上做调度层：不生产内容，经营你的**认知周转率**。

## 6. 目标用户
- **首要画像**：AI 重度使用的「独立深度研究者 / 咨询顾问」——5 个以上日常 AI 工具、主要在浏览器工作、横跨十几个网页、产出高度碎片化、独立执业、对数据主权敏感。
- **同延人群**：升学规划师、行业/政策研究员、分析师、深度内容生产者、终身学习者。
- **不是为谁设计**：想找"存一堆链接就不看"工具的人；已有完整 Notion/Obsidian 工作流且满意的人；换电脑无所谓反正有云同步的人。

## 7. 核心问题（时代的病根）
**资源失血症 + 工具碎片化**：①做过的事找不到；②正在用的工具太多、节奏全断；③资产锁在别人云端。AI 让"生成"变得极廉价，瓶颈变成"能不能把散落的产出在正确时刻调度回来"。

## 8. 三大价值
1. **收得进**——网页、本地文件、Obsidian 笔记、AI 金句、零星念头，五秒入台；
2. **调得出**——拼音首字母三秒召回，全局搜索穿透所有页面，双击直达；
3. **信得过**——100% 本地存储，零账号零云端零追踪，导出即带走，删除可恢复。
（支撑性价值：看得见——三系统页全景；带得走——完整导出迁移。）

## 9. 核心功能事实（对外可讲的功能清单）
- **三大系统页 + 自定义工作台 ×N**：调度台（今天从哪里出发：方向状态四指标 + 今日三件事 + 项目调度 + 好奇心培育）、方向台（主航线 + 项目总览 + 任务调度）、策展中心（灵活策展空间：分类树 + 混排网格 + 镜像），以及用户自定义的 N 个资源工作台。
- **六层思维链**：愿景 → 使命 → 战略目标 → 项目 → 成功指标 → 任务；任务可挂指标，未挂即"未归档任务"可级联归档。
- **全局搜索（Ctrl+K）**：任意网页浮层 + 新标签页内均可调出；标题/标签/分类/项目名命中；拼音与首字母匹配；置顶>星标>标题命中>热度>最近调出排序；双击直达。
- **快速采集（Ctrl+Shift+J）**：任意网页 5 秒入台，自动预填标题/URL/选中文本。
- **好奇心采集（Ctrl+Shift+I）**：念头速记，选中文本自动填入；可转为任务卡或资源卡。
- **今日三件事**：≤3 槽锁定当日最重要行动，与项目/指标关联，可复制昨日、导出 CSV。
- **方向状态四指标**：DHI 方向契合度 / WCE 好奇探索（含转化）/ WRR 资源复用 / 未归档任务；日/周/累计三档，四格均可下钻。
- **策展中心**：镜像分类与原生分类同树混排、卡片自由拖拽、拖动即物化、源数据零影响。
- **回收站**：删除一律软删，可单条恢复或永久删除（含附件清理）。
- **导入导出**：JSON 全量导出/按工作台导出、CSV（UTF-8 BOM）、Markdown；书签 HTML 导入；导入前自动备份；并集合并。
- **附件**：图片/HTML/PDF 挂卡，IndexedDB 本地存储，单文件 ≤20MB。
- **主题与密度**：四套主题（深空薰衣草默认）、三档密度。

## 10. 数据与安全事实
- 数据 100% 存储本机：主数据 `chrome.storage.local` 单根 JSON（已申请 unlimitedStorage，无 10MB 上限）；附件存 IndexedDB。
- **无账号、无云端、无用户标识、无使用追踪、代码内无任何 http 上传**。
- 删除一律软删（回收站可恢复）；导入前自动备份到本地文件；多窗口并发写入有合并保护。
- 导出 = 一份 JSON/CSV/Markdown 文件，可拷贝到任何设备；迁移 = 导出 → 导入并集。
- 卸载扩展 = 数据随浏览器配置文件存在（导出是唯一推荐的长期备份方式）。

## 11. 产品边界（我们不做什么）
不做云同步；不做 AI 替用户决策；不做"第二大脑"/复杂笔记；不做协作与社交；不做使用追踪与画像；不做 KPI 压迫式管理。

## 12. 价格与版本
- 当前状态：**免费使用**（本地分发，开发者模式加载 dist 目录）。
- 商业化方向：**买断制**（一次付费、永久使用、本地授权），价格带与服务细则**规划中，一切以官方发布为准**——对外不得承诺具体价格与时间。

## 13. 标准术语（核心动词 + 名词）
| 术语 | 定义 |
|---|---|
| **入台** | 把网页/文件/笔记/念头收进调度台，成为一张卡 |
| **归位** | 给卡片归属：工作台、分类、标签、项目、指标 |
| **调出** | 需要时把卡片找回来并打开（三秒标准） |
| **复用** | 同一资源被再次调出使用（WRR 计数） |
| **校准** | 用方向状态与方向树检视行动与方向的关系 |
| 工作台 | 用户自定义的资源域（含分类树/看板/列表） |
| 调度台 | 默认首页：今天从哪里出发 |
| 方向台 | 主航线 + 项目总览 + 任务调度 |
| 策展中心 | 跨工作台的灵活策展空间（含镜像） |
| 三件事 | 今日 ≤3 件最重要行动 |
| 主攻 | 被标记为当前重心、置前并高亮的项目 |
| 镜像 | 策展中心对源卡的引用式呈现，源数据零影响 |
| 未归档任务 | 未挂项目/指标或引用失效的任务 |

## 14. 禁止与慎用表述
- ❌ 不要说：收藏夹工具、笔记软件、新标签页美化、国产 Notion、第二个 Obsidian。
- ❌ 不要承诺：云同步即将上线、具体价格/上市时间、团队协作功能。
- ⚠ 慎用："AI 驱动"（知源不替用户决策，AI 是被调度的部队）；"智能推荐"（我们做算法无关的确定性调度）。
- ✅ 表达层级：品类词（个人资源调度台）→ 心智词（调度）→ 能力（三秒调出）→ 证据（本地/买断/导出）。
