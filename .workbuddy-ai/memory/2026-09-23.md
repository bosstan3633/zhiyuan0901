## 九、交接包交付前的数字复核（★ 本卡自己踩了「引用型数字失真」的坑）

**教训**：交接包初稿里的数字，有 5 处是**凭记忆/引用写的**，逐项实测后**全部对不上**。
这正好复现了项目纪律里那条「引用型数字必然失真」——**连"讲这条纪律的那份文档"自己都犯了**。

| # | 初稿写的 | 实测真值 | 性质 |
|---|---|---|---|
| 1 | 本包 1,131 行 / 约 2 万 token / 压缩比 19:1 | **810 行 / 63,788 B / ≈14,829 token / ≈26:1** | 凭感觉估的，没算 |
| 2 | 代码规模表分项和 37,548 ≠ 合计 37,775 | 分项含**漏掉的 2 个根级文件**（`manifest.ts` 84 + `vite-env.d.ts` 8 = 92）；`newtab` 23,486 / `shared` 11,403 | **表内自相矛盾**（差 227 行） |
| 3 | `regression.cjs` 681KB / 约 1.4 万行 | **681,562 B（≈666KB）/ 4,617 行** | 把字节数当 KB；行数夸大 3 倍 |
| 4 | `v-html` 8 处 | **6 处**（ManualPage:55 · GlobalSettings:314/880 · GlobalPopups:145/156 · Icon:46） | 引用旧账 |
| 5 | 静默 `catch {}` 14 处 | `catch` 共 **147** 个：**0 个真空体**，**54 个仅含注释**（有意静默回落，均标理由） | 引用旧账，且口径不清 |

**实跑复核过的（可作可信基线）**：
- `node scripts/regression.cjs` ⇒ **1415 通过 / 0 失败，EXIT=0**
- `npx vue-tsc --noEmit` ⇒ **EXIT=0，0 行输出**
- `gen-code-index.cjs` 同口径重算 ⇒ **143 文件 / 37,775 行**，且索引内部**完全闭合**

**方法论收获（已写进透视卡开头，作为给外部模型的"材料可信度说明"）**：
