# 知源调度台（Ownway）

> **知源 · 信息洪流中的控制中心——以好奇过滤信息，以调度致用于己，成就独一无二的自己。**
>
> AI 让"产出"变得前所未有的廉价，于是个人认知的真正瓶颈不再是"能不能创造"，而是**"能不能把散落各处的产出，在正确的时刻重新调度回来"**。知源不生产内容——它经营你的**认知周转率**。

> **当前版本 V3.6.8**——新增贯穿方向台 / 资源台 / 策展台 / 任务台的 AI 认知协作者层与 20 个场景，密钥只在本机、启动零 AI 负担、建议须勾选采纳才落库。详见 [发版说明](./docs/RELEASE_NOTES_V3.0.0.md)。

## 它是什么

知源调度台是一套**浏览器扩展**（Chrome / Edge / Brave 等 MV3），**接管你的新标签页**，把你每天使用的链接、本地文件、Obsidian 笔记、AI 聊天金句、零星念头——统一收纳为可被你自己指挥的卡片，**三秒内召唤回来**。

它不是书签插件，不是 PKM 笔记软件，也不是新标签页美化工具。

它是 **信息洪流中的控制中心——AI 时代知识工作者的个人资源调度台**——把"工具碎片化"和"信息失血症"这两个时代的病根，集中在一个属于你的工作台里治好。它不是"第 N 个工具"，而是横在所有工具之上的一层**调度层**：一个总指挥。

---

## 它给谁用

**首选：AI 重度使用的"独立深度研究者 / 咨询顾问"**

具体特征画像：

- 有 5 个以上日常 AI 工具（ChatGPT / Claude / Perplexity / Notion AI / 国内各家大模型）
- 主要在浏览器里干活，使用场景横跨**十几个网页**（不是 3-5 个）
- 产出高度碎片化（研究 / 报告 / 答疑 / 客户交付）
- **独立工作者**（不依赖团队协作流程，所以不需要"企业级 SaaS"那种复杂系统）
- 对**数据主权**敏感（不愿把核心资产锁在某个云服务的数据库里）

创作者、终身学习者、深度播客主等同类型用户，同样适用——只是优先级稍后。

> **不是为谁设计**：不是为"存一堆链接就不看"的人设计的；不是为"已经有 Notion/Obsidian 全套工作流且满意"的人设计的；不是为"换电脑无所谓反正有云同步"的人设计的。

## 它解决什么问题

### 时代的病根：资源失血症

AI 让"生成答案"的速度比"找到自己产出"的速度快一千倍。
**症状三连**：

1. **做过的事找不到**——三个月前做过的某份分析，搜不到、记不清、没办法再调出上下文；
2. **正在用的 AI 工具太多**——每次写报告要在 N 个 Chat 窗口 / 文件夹 / 标签页之间跳来跳去；
3. **资产不属于自己**——核心稿件存在某个云的某个数据库里，换工具或涨价时只能被迫迁移。

**知源调度台把三件事一次性治好**：

| 时代病根 | 你日常的痛 | 知源怎么治 |
|---|---|---|
| **工具碎片化** | 几秒切一次 Tab，节奏全断 | 全部链接/文件/笔记/Obsidian 一卡通吃，新标签页即指挥台 |
| **资源失血症** | 做过、找不回、重做 | 全本地单根 JSON，三秒拼音首字母召回，毫秒回上下文 |
| **数据被绑架** | 换工具等于从零开始 | 零账号、零云端、零订阅；导出=复制粘贴 |

### 为什么要"本地优先"

订阅制 + 云服务 + 算法推荐这套组合，今天的服务免费、明天的数据定价、更后天的服务停服——这是**数据主权的反向路径**。

知源坚持走反向的路径：

- 你的资源只存在你自己电脑里（`chrome.storage.local`，已申请 `unlimitedStorage` 权限，无 10MB 容量上限）
- 没有任何账号、没有 token、没有用户标识
- 单击导出 = 一份 JSON 文件，可以拷贝到任何地方、任何设备

迁移成本 = 0。换工具从来不需要导出你的智慧。

## 它如何解决：六个核心动作

| # | 动作 | 触发方式 | 时间 |
|---|---|---|---|
| 1 | **快速采集** | `Ctrl+Shift+J` 任意网页 | 5 秒 |
| 2 | **三秒搜索** | `Ctrl+K` 全场景（任意网页浮层 / newtab 内） | 3 秒 |
| 3 | **追想法念头** | 好奇心采集 `Ctrl+Shift+I` | 10 秒 |
| 4 | **一键直跳** | 双击搜索结果 | 0 思考 |
| 5 | **方向管理** | 知源引擎（愿景 / 使命 / 方向 / 项目 / 指标 / 任务） | 锚定主攻方向 |
| 6 | **完整导出** | 设置 → 导出全部数据 | 一份 JSON |

**全局快捷键系统**通过 `chrome://extensions/shortcuts` 自定义键位，共 6 个命令项（4 个自带默认键位 + 2 个由你按需分配，包括"打开设置"键）。

## 它坚持不做什么

| 不做 | 原因 |
|---|---|
| ❌ **不做云同步** | 同步 = 把你的数据上别人的服务器。这是功能，不是缺陷。 |
| ❌ **不做 AI 替你决策** | AI 是你的部队，知源是你的指挥台；你不该被任何一个 AI 工具替代判断。 |
| ❌ **不做"第二大脑"** | 不抢 Notion/Obsidian 的市场，它们仍然是最好的写作工具——知源只调度你需要的"素材"那一层。 |
| ❌ **不做社交/协作** | 单一用户的认知工具，不引入他人数据、他人算法、他人权限。 |
| ❌ **不做跟踪分析** | 没有用户画像、没有使用画像、没有广告位。 |

## 与同类产品的本质区别

知源不是"又一个收藏夹"。它与两类工具同场竞技——**直接竞品**（同样经营个人知识/资源）与**间接竞品**（AI 时代浏览器自带的默认选项）——但它的货架位置不同。

### 直接竞品：同赛道，不同货架

| 竞品 | 它是什么 | 知源的不同 |
|---|---|---|
| **Notion** | 一体化工作空间（笔记/数据库/协作） | 知源不做笔记与数据库，只做调度台。Notion 用户最常见的困境是"库越建越重、找回越来越慢"——知源把"三秒进出"做到极致，把深度写作交还给它 |
| **Obsidian** | 本地双链笔记 | 互补而非竞争：知源收录并直达 `obsidian://` 链接，深度写作仍留在 Obsidian |
| **Flomo** | 碎片化记录 | 好奇心与 Flomo 同源，但好奇心只是六层链的一环——知源把它接进方向、项目与北极星，不止是"存起来" |
| **Raindrop.io / Eagle** | 书签管理 / 素材管理 | 它们收藏"链接"本身；知源调度"资源 + 任务 + 好奇心 + 方向"四类对象，且数据 100% 本机 |
| **Raycast / LaunchBar** | 启动器（命令/检索） | 同频"三秒召回"，但它们是系统级命令面板；知源是个人认知资源的总调度——有方向、有策展、有北极星 |
| **Momentum / Tabist** | 新标签页美化 | 它们卖"好看"，知源卖"调度"——好看只是副产品 |

### 间接竞品：AI 时代的默认选项

| 默认选项 | 为什么不够 | 知源的解法 |
|---|---|---|
| **浏览器书签** | 只存不找；层级深了等于没有 | 拼音首字母三秒召回；标签/分类双树；双击直达 |
| **AI 对话框收藏** | 内容锁在对话里，与你的资源库隔离 | `Ctrl+K` 全场景穿透，AI 产出与人工收集同库调度 |
| **"稍后读"应用** | 读完就没有下游了 | 好奇 → 求证 → 项目 → 指标 → 任务，五步各有去处 |

> 类目的力量：**书架的位置决定商品的价格。** 选错货架的茅台，只能按散酒论斤卖。通用工具比知源"更能装"，知源比通用工具"更能调"——它不抢你的写作、不抢你的协作、不抢你的云，只做一件事：**让你见过的每一个信息，都具备在正确时刻被召回的能力。**

## 🤖 给 AI 智能体 / 接手开发者的须知

本仓库的设计目标之一：**换一个环境，由任意智能体接手后，仅凭本仓库即可继续迭代**。

### 接手顺序

1. 读本文件（尤其下方「硬性规则」）；
2. 读 [`v2/README.md`](./v2/README.md) 获取工程全貌（架构/数据模型/快捷键/主题/FAQ）；
3. 读 [`docs/技术架构与数据模型.md`](./docs/技术架构与数据模型.md) 与 [`docs/开发指南与回归验证.md`](./docs/开发指南与回归验证.md)；
4. 读 [`docs/项目盘点报告_2026-08-31.md`](./docs/项目盘点报告_2026-08-31.md) 了解现存技术债；
5. 最新一轮交付明细见 `docs/交付说明_*.md`。

### 硬性规则（违反即返工）

| # | 规则 | 说明 |
|---|------|------|
| 1 | **版本号唯一来源 = `v2/src/manifest.ts`** | 改版本必须同步 `package.json`、设置页关于、手册页、`regression.cjs` 版本锚、`v2/README.md` 版本行共 6 处 |
| 2 | **单向挂载红线** | 仅 TaskCard 持有 `mountedResourceIds/mountedCuriosityIds`；Resource/Curiosity/TagNode Schema 禁止出现 taskId |
| 3 | **删除一律软删** | 任何删除只写 `deletedAt`（回收站 `/recycle` 可恢复）；`stats.lastVisits` 只经 `recordResourceOpen` 更新 |
| 4 | **排序 computed 禁止 `.sort()`** | 支持拖拽排序的列表，渲染 computed 不得原地 sort |
| 5 | **样式只用 `tokens.css` 令牌** | 禁止硬编码色值；新增 UI 须在六主题下逐一走查 |
| 6 | **定位不走 tabs.query 的 hash** | chrome.tabs.query 返回不含 hash，页面内定位走 zy-where 询问链路 |
| 7 | **新增功能同步追加回归** | 每轮新功能必须在 `v2/scripts/regression.cjs` 追加断言项 |
| 8 | **构建前清空 dist** | vite 配置 `emptyOutDir:false`，不清理会累积多轮构建残留 |
| 9 | **迭代按轮次记录** | 每完成一轮在 `docs/` 落一份交付说明，并更新 regression.cjs 轮次注释 |

## 🛠️ 快速开始

```bash
git clone git@github.com:bosstan3633/zhiyuan0901.git
cd zhiyuan0901/v2
npm install              # 还原依赖（node_modules 不入库）
npm run build            # vue-tsc 0 错误 + vite build
node scripts/regression.cjs   # 回归断言全绿
```

加载到浏览器：`chrome://extensions/` → 开发者模式 → 加载已解压 → 选 `v2/dist/`。
