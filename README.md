# 知源工作台（Zhiyuan Workbench）

> **从好奇出发，向源头求证。**
> AI 时代，为知识工作者守护并增强认知能力的个人操作系统。

---

## 🌊 我们正站在什么样的时代

我们正处在人类历史上从未有过的**信息洪流 + 认知外包**双重浪潮之中。

每一天，你都被动接收成千上万条信息：浏览器收藏夹堆积的链接、公众号的推送、PDF 的角落、Notion 里长草的页面、Excel 里的清单、聊天群里一闪而过的金句。它们原本是你思考的**养料**，却在失控中变成了**负担**。

与此同时，AI 越来越能"替你想"、"替你写"、"替你决策"。当所有答案都由大模型三秒给出，你的思考、你的判断、你独立建构知识的能力，正在被静默外包。

**这不是工具的胜利，这是认知主体性的危机。**

一个知识工作者最珍贵的，不是他手里有多少信息，而是他**仍然保有独立追问、独立串联、独立判断的能力**。当工具让这件事变得困难，工具就是问题本身。

---

## 🧭 知源工作台是什么

**知源工作台不是一个笔记软件，不是一个收藏夹，不是一个待办清单**——它是你的**个人认知操作系统**。

它把浏览器新标签页变成一个**本地化、可调度、可溯源**的控制塔：

- 🏠 **首页 = 你的思考起点** · 快速输入、快速触达今天要关注的事
- 🧭 **罗盘 = 你的认知地图** · 项目、好奇、收藏、标签，所有资源按你的逻辑组织
- 📌 **任务 = 你的执行流** · 看板、分组、密度自适应，从想法到落地
- 🔍 **搜索 = 你的认知检索** · 拼音、模糊、命中度排序，毫秒级回到你想要的上下文
- ♻️ **回收站 = 你的安全感** · 所有删除可恢复，敢于整理、敢于断舍离
- 🌗 **主题与密度 = 你的舒适区** · 6 套主题、3 档密度，工具反过来适应你

**100% 本地**（`chrome.storage.local` 单根 JSON）、**零账号**、**零云端**、**零订阅**——你的认知资产，只属于你。

## 🛡️ 它如何守护并增强你的认知

| 时代困境 | 知源工作台的回应 |
|---|---|
| 收藏夹 = 数字垃圾场 | **强制结构化** · 资源、好奇、项目、任务四象限，归属清晰 |
| 想到的事转瞬即忘 | **快速入口** · 新标签页直输，新想法 ≤ 5 秒落地 |
| 信息散落各处，无法串联 | **双向链接 + 标签** · 同一事实在多项目复用时自动归并 |
| 工具太多，每个都要登录 | **一个本地 JSON** · 迁移即复制粘贴，永久可控 |
| AI 替你思考，导致认知退化 | **强化"提问—求证—归档"链** · 任何添加都要求追到源头 |
| 用着用着，数据被云端拿走 | **零云端 + 软删 + 回收站** · 你的主权不可被剥夺 |

**核心理念：工具应该让用户更自由地思考，而不是让用户更像机器的奴隶。**

### 硬性规则（违反即返工）

| # | 规则 | 说明 |
|---|------|------|
| 1 | **版本号唯一来源 = `v2/src/manifest.ts`** | 改版本必须同步 `package.json`、设置页关于、手册页、`regression.cjs` 版本断言共 5 处 |
| 2 | **单向挂载红线** | 仅 TaskCard 持有 `mountedResourceIds/mountedCuriosityIds`；Resource/Curiosity/TagNode Schema 禁止出现 taskId |
| 3 | **删除一律软删** | 任何删除只写 `deletedAt`（回收站 `/recycle` 可恢复）；`stats.lastVisits` 只经 `recordResourceOpen` 更新 |
| 4 | **排序 computed 禁止 `.sort()`** | 支持拖拽排序的列表，渲染 computed 不得原地 sort |
| 5 | **样式只用 `tokens.css` 令牌** | 禁止硬编码色值；新增 UI 须在六主题下逐一走查 |
| 6 | **定位不走 tabs.query 的 hash** | chrome.tabs.query 返回不含 hash，页面内定位走 zy-where 询问链路 |
| 7 | **新增功能同步追加回归** | 每轮新功能必须在 `v2/scripts/regression.cjs` 追加断言项 |
| 8 | **构建前清空 dist** | vite 配置 `emptyOutDir:false`，不清理会累积多轮构建残留 |
| 9 | **迭代按轮次记录** | 每完成一轮在 `docs/` 落一份交付说明，并更新 regression.cjs 轮次注释 |

## 🛠️ 快速开始

```bash
git clone git@github.com:bosstan3633/zhiyuan0901.git
cd zhiyuan0901/v2
npm install              # 还原依赖（node_modules 不入库）
npm run build            # vue-tsc 0 错误 + vite build
node scripts/regression.cjs   # 218/218 全绿
```

加载到浏览器：`chrome://extensions/` → 开发者模式 → 加载已解压 → 选 `v2/dist/`。

> 完整构建/开发说明见 [`v2/README.md`](./v2/README.md) 第四节。
