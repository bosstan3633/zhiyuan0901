# 知源调度台（Ownway）

> **知源 · 信息洪流中的控制中心——以好奇过滤信息，以调度致用于己，成就独一无二的自己。**
>
> AI 让"产出"变得前所未有的廉价，于是个人认知的真正瓶颈不再是"能不能创造"，而是**"能不能把散落各处的产出，在正确的时刻重新调度回来"**。知源不生产内容——它经营你的**认知周转率**。

> **当前版本 V4.7.6**——「卡片节奏与每日三件事」：任务 / 选题 / 好奇心卡池新增卡片流时间线，单击开完整详情、双击直达卡片链接；任务列表与看板支持按项目分组。画像以年度卡片热力为首屏，新增三件事视图与卡片分析；历史日历以虚线卡保留过往三件事，可看详情、可取消该日落图，当下卡保持实线；调度台展示最多三个主攻项目。

## 它是什么

知源调度台（Ownway）是一套**浏览器扩展**（Chrome / Edge / Brave 等 MV3），**接管你的新标签页**，是知识工作者在信息获取、信息论证、信息处理过程中的**个人认知调度中枢**。它把你每天使用的链接、本地文件、Obsidian 笔记、AI 聊天金句、零星念头——统一收纳为可被你自己指挥的四类卡片（资源 / 任务 / 选题 / 好奇心），**三秒内召唤回来**。

它不是书签插件，不是 PKM 笔记软件，也不是新标签页美化工具。

它是 **信息洪流中的控制中心——AI 时代知识工作者的个人认知调度中枢**——把"工具碎片化"和"信息失血症"这两个时代的病根，集中在一个属于你的工作台里治好。它不是"第 N 个工具"，而是横在所有工具之上的一层**调度层**：一个总指挥。

**它的两条生命线**：性能、响应速度、稳定性是第一生命线——全局检索与快捷操作必须快，慢等于没有；UI、交互、外观是第二生命线——"看见"是产品灵魂，看见任务、看见项目、看见方向树、看见策展台，所有的看见都要符合阅读的审美。

**它的核心抽象是四卡**：资源卡（有出处的事实资产）、任务卡（可执行事项）、**选题卡（面向外界的成果）**、好奇心卡（一闪而过的念头）。四卡通过浏览器快捷键在信息处理现场直接捕获进各自卡池（无中间收件箱），再进入两条使用闭环：

- **解决问题**：被调用 → 被论证 → 被展示。收口于策展台：围绕重复问题给出方案，节点「关联卡片」可挂资源卡与选题卡，分享出去实现商业价值。
- **明确赛道**：任务卡 / 选题卡 → 方向树 → 今日三件事。两者都挂到项目的成功指标下（选题在树里带「成果」标记且不计入任务完成率），今日三件事恒 3 槽由任务与选题共用、与今日日历严格同源，让行动持续在轨道上。

**现役功能事实以 [`文档中心/00_产品事实与表达母版.md`](./文档中心/00_产品事实与表达母版.md) §9 为准，已退役能力见其 §9.1**；[`04-70_产品需求基准文档_V3.9系.md`](./文档中心/04_产品与设计/04-70_产品需求基准文档_V3.9系.md) 是 V3.9 阶段的定盘基线，其三卡口径已被 V4.5.0 四卡池覆盖，只作历史参照。

## 它给谁用

**首选：AI 重度使用的"独立深度研究者 / 咨询顾问"**

具体特征画像：

- 有 5 个以上日常 AI 工具（ChatGPT / Claude / Perplexity / Notion AI / 国内各家大模型）
- 主要在浏览器里干活，使用场景横跨**十几个网页**（不是 3-5 个）
- 产出高度碎片化（研究 / 报告 / 答疑 / 客户交付）
- **独立工作者**（不依赖团队协作流程，所以不需要"企业级 SaaS"那种复杂系统）
- 对**数据主权**敏感（不愿把核心资产锁在某个云服务的数据库里）

创作者、终身学习者、深度播客主等同类型用户，同样适用——只是优先级稍后。

> **不是为谁设计**：不是为"存一堆链接就不看"的人设计的；不是为"已经有 Notion/Obsidian 全套工作流且满意"的人设计的；不是为"换电脑无所谓反正有云同步"的人设计的。

## 它解决什么问题

### 时代的病根：资源失血症

AI 让"生成答案"的速度比"找到自己产出"的速度快一千倍。
**症状三连**：

1. **做过的事找不到**——三个月前做过的某份分析，搜不到、记不清、没办法再调出上下文；
2. **正在用的 AI 工具太多**——每次写报告要在 N 个 Chat 窗口 / 文件夹 / 标签页之间跳来跳去；
3. **资产不属于自己**——核心稿件存在某个云的某个数据库里，换工具或涨价时只能被迫迁移。

**知源调度台把三件事一次性治好**：

| 时代病根 | 你日常的痛 | 知源怎么治 |
|---|---|---|
| **工具碎片化** | 几秒切一次 Tab，节奏全断 | 全部链接/文件/笔记/Obsidian 一卡通吃，新标签页即指挥台 |
| **资源失血症** | 做过、找不回、重做 | 全本地单根 JSON，三秒拼音首字母召回，毫秒回上下文 |
| **数据被绑架** | 换工具等于从零开始 | 默认本地优先、可选邀请制云同步、无使用追踪；导出=一份 JSON |

### 为什么要"本地优先"

订阅制 + 云服务 + 算法推荐这套组合，今天的服务免费、明天的数据定价、更后天的服务停服——这是**数据主权的反向路径**。

知源坚持走反向的路径：

- 默认只存在你自己的电脑里（`chrome.storage.local`，已申请 `unlimitedStorage` 权限，无 10MB 容量上限）
- 只有你主动登录邀请制 Supabase 后才生成账号标识；普通卡片附件与 AI 凭据不上云
- 单击导出 = 一份 JSON 文件，可以拷贝到任何地方、任何设备

迁移成本 = 0。换工具从来不需要导出你的智慧。

## 它如何解决：六个核心动作

| # | 动作 | 触发方式 | 时间 |
|---|---|---|---|
| 1 | **快速采集** | `Ctrl+Shift+J` 任意网页 | 5 秒 |
| 2 | **三秒搜索** | `Ctrl+K` 全场景（任意网页浮层 / newtab 内） | 3 秒 |
| 3 | **追想法念头** | 好奇心采集 `Ctrl+Shift+I` | 10 秒 |
| 4 | **一键直跳** | 双击搜索结果 | 0 思考 |
| 5 | **方向管理** | 方向台六层（愿景 / 使命 / 战略目标 / 项目 / 成功指标 / 任务）+ 今日三件事 | 锚定主攻方向 |
| 6 | **完整导出** | 设置 → 导出全部数据 | 一份 JSON |

**全局快捷键系统**通过 `chrome://extensions/shortcuts` 自定义键位，共 **15 个命令项**（4 个自带默认键位 + **11 个由你按需分配**，包括四个卡池直达、任务与选题采集、立即同步云端、今日战报、画像时间轴与方向树策展模式）。真源是 `v2/src/manifest.ts` 的 `commands`。

## 它坚持不做什么

| 不做 | 原因 |
|---|---|
| ❌ **主数据不做默认开启或后台无保护上传** | 卡片、方向与策展结构默认保存在本机。登录邀请制 Supabase 后可手动同步，也可主动开启约每小时一次的安全同步；同步以共同基线做三方合并，不同记录与字段自动取并集，同字段或删除 / 修改冲突必须人工逐项确认，绝不静默整端覆盖。普通卡片附件与 AI 凭据不上云；策展节点附件在登录后默认保存至你的私有 Supabase Storage，可随时在设置页关闭。 |
| ❌ **不做 AI 替你决策** | AI 是你的部队，知源是你的指挥台；你不该被任何一个 AI 工具替代判断。 |
| ❌ **不做"第二大脑"** | 不抢 Notion/Obsidian 的市场，它们仍然是最好的写作工具——知源只调度你需要的"素材"那一层。 |
| ❌ **不做社交/协作** | 单一用户的认知工具，不引入他人数据、他人算法、他人权限。 |
| ❌ **不做跟踪分析** | 没有用户画像、没有使用画像、没有广告位。 |

## 与同类产品的本质区别

知源不是"又一个收藏夹"。它与两类工具同场竞技——**直接竞品**（同样经营个人知识/资源）与**间接竞品**（AI 时代浏览器自带的默认选项）——但它的货架位置不同。

### 直接竞品：同赛道，不同货架

| 竞品 | 它是什么 | 知源的不同 |
|---|---|---|
| **Notion** | 一体化工作空间（笔记/数据库/协作） | 知源不做笔记与数据库，只做调度台。Notion 用户最常见的困境是"库越建越重、找回越来越慢"——知源把"三秒进出"做到极致，把深度写作交还给它 |
| **Obsidian** | 本地双链笔记 | 互补而非竞争：知源收录并直达 `obsidian://` 链接，深度写作仍留在 Obsidian |
| **Flomo** | 碎片化记录 | 好奇心与 Flomo 同源，但好奇心只是六层链的一环——知源把它接进方向、项目与北极星，不止是"存起来" |
| **Raindrop.io / Eagle** | 书签管理 / 素材管理 | 它们收藏"链接"本身；知源调度"资源 + 任务 + 选题 + 好奇心 + 方向"五类对象，数据默认本地保存，也可以手动同步到云端 |
| **Raycast / LaunchBar** | 启动器（命令/检索） | 同频"三秒召回"，但它们是系统级命令面板；知源是个人认知资源的总调度——有方向、有策展、有北极星 |
| **Momentum / Tabist** | 新标签页美化 | 它们卖"好看"，知源卖"调度"——好看只是副产品 |

### 间接竞品：AI 时代的默认选项

| 默认选项 | 为什么不够 | 知源的解法 |
|---|---|---|
| **浏览器书签** | 只存不找；层级深了等于没有 | 拼音首字母三秒召回；标签/分类双树；双击直达 |
| **AI 对话框收藏** | 内容锁在对话里，与你的资源库隔离 | `Ctrl+K` 全场景穿透，AI 产出与人工收集同库调度 |
| **"稍后读"应用** | 读完就没有下游了 | 好奇 → 求证 → 项目 → 指标 → 任务，五步各有去处 |

> 类目的力量：**书架的位置决定商品的价格。** 选错货架的茅台，只能按散酒论斤卖。通用工具比知源"更能装"，知源比通用工具"更能调"——它不抢你的写作、不抢你的协作、不抢你的云，只做一件事：**让你见过的每一个信息，都具备在正确时刻被召回的能力。**

### 硬性规则（违反即返工）

| # | 规则 | 说明 |
|---|------|------|
| 1 | **版本号唯一来源 = `v2/src/manifest.ts`** | 改版本必须同步 **7 处**：`manifest.ts`、`package.json`、`package-lock.json`（2 行）、设置页关于（动态读 manifest，无需手改）、手册页 `ManualPage.vue`、`regression` 版本锚、`v2/README.md` 版本行、根 README 当前版本行。**此清单以 `v2/README.md` 第 17 行为准**（该行自 R96 起已纳入回归断言把守） |
| 2 | **卡间零挂载红线** | 卡片本体互不持有对方 id（R162 退任务↔资源、R165 退任务↔好奇与好奇↔资源、R166 退溯源引用 fromCuriosityId）；明文豁免四条独立记录表：`SupportLink`（任务→资源）、`CurationProjection`（策展节点→资源）、资源常用夹成员镜像、`topicResourceLinks`（选题→资源，带快照）；策展节点 `linkedTopicIds` 只记选题引用不改其本体，已在模型注释备案；六层归属（projectId/metricId）不受限 |
| 3 | **删除一律软删** | 任何删除只写 `deletedAt`（设置页内嵌回收站可恢复，旧 `/recycle` 重定向到 `/settings?page=recycle`；无期限、无自动清除）；`stats.lastVisits` 只经 `recordResourceOpen` 更新 |
| 4 | **排序 computed 禁止 `.sort()`** | 支持拖拽排序的列表，渲染 computed 不得原地 sort |
| 5 | **样式只用 `tokens.css` 令牌** | 禁止硬编码色值；新增 UI 须在**四套正式主题**（光速黑 / 极简白 / 纸墨白 / 知源蓝）下逐一走查 |
| 6 | **定位不走 tabs.query 的 hash** | chrome.tabs.query 返回不含 hash，页面内定位走 zy-where 询问链路 |
| 7 | **新增功能同步追加回归** | 每轮新功能必须在 `v2/scripts/regression.cjs` 追加断言项 |
| 8 | **构建前清空 dist** | vite 配置 `emptyOutDir:false`，不清理会累积多轮构建残留 |
| 9 | **迭代按轮次记录** | 每完成一轮在 `docs/` 落一份交付说明，并更新 regression.cjs 轮次注释 |
